## Deliberate non-copy decisions

- 2025 Wellness Month task names, colours-as-meaning, cue timestamps, source sentences and model content are not reused.
- 2025’s current divergent `index.html` is not treated as canonical.
- 2019 keeps the existing accessible bilingual reconstruction and 19 original scans; Super Curation is an additional semantic layer, not a replacement facsimile.
- Remote authentic audio remains one immutable source endpoint; the page does not duplicate or synthesize the recording.
- 2019 has 107 sentence-level recording cues and six native note destinations, whereas the 2025 reference has a different cue/field manifest; the transaction grammar is transferred, never the 2025 content.
- Task letters A/B/C are presented alongside the target paper’s official Task 8/9/10 labels, so the motion grammar transfers without renaming the examination tasks.
