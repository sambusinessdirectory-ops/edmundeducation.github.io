### 0.1 考評局題目界線（按用戶提供的試題截圖）

**題目：** *Photo-taking visitors not welcomed by everyone*。現代人經常拍攝食物與風景並上傳社交平台，但一些地方開始反對遊客拍照所引起的影響。

| 閱讀材料中的案例 | 材料所述事實 | 可討論的核心爭議 |

| 美國 Vermont 小鎮 | 官員投票決定在秋天樹葉轉色時封閉道路；材料提到大量遊客為拍照而在住宅附近泊車、損壞財物、與居民爭執，並引起交通、環境及生活質素問題。 | 景色吸引力 vs. 居民通行、私人物業及社區承載力。 |
| 日本富士山附近小鎮 | 材料指出 2024 年 5 月有小鎮建牆遮擋富士山景觀，原因包括大量遊客拍照後亂拋垃圾、泊車不當和不遵守規則。 | 熱門取景點 vs. 遊客行為管理；遮擋景觀是否過度。 |
| 德國 Berlin 餐廳 N&S | 餐廳負責人要求訪客不拍照、不拍片，以顧及其他食客私隱及讓客人專注於食物的味道和體驗。 | 場地自訂守則 vs. 顧客拍照分享；記錄 vs. 體驗當下。 |

**Part A 三個指定討論方向（不是只能提出三條論點）：**

1. Why people might not like others taking photos in public places.
2. Places in Hong Kong that are popular for taking photos.
3. Whether Hong Kong needs to have rules for photo-taking in public places.

**Part B：** 考官可按 Part A 提出 8 題個人回應問題；本講義逐題收錄可選擇的不同立場、理由、每點詞彙和可改寫的英文示範回應。

### 0.2 核心衝突與資料邊界

- **核心衝突：** 記錄生活、藝術表達、旅遊及地方經濟的利益，如何與居民安寧、當事人私隱、交通安全、環境保育及場地正常使用取得平衡？
- **三個要分清的動作：** `take a photo`（拍攝）、`target/follow a person`（針對某人跟拍）、`publish/share an image`（發布／傳播）。三者的影響不同，不能一概而論。
- **公共地方不等於完全沒有私隱；但公眾場合有人偶然入鏡，也不等於攝影者自動違法。** 實際法律責任、拍攝權限及場地規則須視乎用途、行為和具體情況；請勿把下列**政策建議**誤當香港已實施的現行規定。
- **事實標記：** 三個海外例子來自題目；香港地點的特色屬官方／公開旅遊資料與一般地理背景；所有關於「若實行某政策，可能……」的分析是**合理推論／課堂辯論主張**，並非已發生的統計結果。自創情境一律以「若／假設」表達。
- **閱讀方法：** 每個條目先學「主張 → 原因／機制 → 可能結果」，然後用下方的 5 項 Glossary 練習英語表達。Part A 小組討論應挑選幾個*互不重複*的最強觀點深入互動，不需要把整個論點庫逐項背出。

## 一、Part A｜問題一：為何有人不喜歡別人在公共場所拍照？

**討論提醒：**前面是反對滋擾性攝影的原因；最後特設最強「反向視角」，避免把所有攝影者都描述成麻煩製造者。

### 角度：個人私隱、同意與數碼風險

#### A1-01｜未經同意成為照片主角

路人雖身處公共地方，也未必願意被陌生人近距離拍攝或放上網。當鏡頭刻意對準某人的臉或私人活動，當事人可能失去選擇如何呈現自己的空間；這與無意間出現在遠景中不同。

| English（自然單字／詞組） | 繁體中文（本題語境） |
|---|---|
| photograph strangers | 拍攝陌生人 |
| seek consent | 徵求同意 |
| identifiable face | 可辨認的臉孔 |
| unwanted attention | 不受歡迎的關注 |
| personal boundaries | 個人界線 |

#### A1-02｜兒童難以理解網上曝光的長遠後果

小朋友可能不知道照片一旦公開便會被截圖、轉載或辨認；家長也未必在場給予同意。拍攝陌生兒童特寫並公開分享，比普通街景更需要審慎，以減少他們將來面對的私隱風險。

| English（自然單字／詞組） | 繁體中文（本題語境） |
|---|---|
| children's privacy | 兒童私隱 |
| informed consent | 知情同意 |
| online exposure | 網上曝光 |
| digital footprint | 數碼足跡 |
| protect minors | 保護未成年人 |

#### A1-03｜住宅窗口可能暴露私人生活

即使拍攝者站在街上，高角度鏡頭或長焦鏡頭仍可能拍到住戶室內、陽台和日常作息。居民難以在自己家中避開鏡頭，持續拍攝會削弱本應在家享有的安寧。

| English（自然單字／詞組） | 繁體中文（本題語境） |
|---|---|
| residential windows | 住宅窗戶 |
| private living spaces | 私人生活空間 |
| telephoto lens | 長焦鏡頭 |
| household routines | 家庭日常作息 |
| intrusion into privacy | 侵犯私隱 |

#### A1-04｜影像連同位置資訊可能暴露行蹤

照片除了人像，還可能包含拍攝時間、地點標籤和背景線索。若在社交平台即時發布，陌生人可能推斷某人的位置或慣常路線，因此分享方式有時比按快門本身更敏感。

| English（自然單字／詞組） | 繁體中文（本題語境） |
|---|---|
| location tags | 地點標籤 |
| reveal someone's whereabouts | 暴露某人的行蹤 |
| geolocation data | 地理位置資料 |
| real-time posting | 即時發布 |
| personal security | 人身安全 |

#### A1-05｜照片可能被斷章取義

一張相片只捕捉瞬間，未必反映事件前因後果。例如路人可能因不知情被拍成看似爭吵或失禮，之後受到網民批評；拍攝者的標題和剪裁方式足以改變觀眾理解。

| English（自然單字／詞組） | 繁體中文（本題語境） |
|---|---|
| misleading captions | 誤導性圖片說明 |
| lack of context | 缺乏背景脈絡 |
| distorted impression | 失真的印象 |
| reputational harm | 聲譽損害 |
| selective framing | 選擇性取景 |

#### A1-06｜惡意轉載可能導致網絡欺凌

一名學生或路人的尷尬表情若被拍下並製成迷因，可能迅速在群組流傳。即使攝影者原先只想開玩笑，持續轉發也可能令當事人承受羞辱和社交壓力。

| English（自然單字／詞組） | 繁體中文（本題語境） |
|---|---|
| online harassment | 網上騷擾 |
| cyberbullying | 網絡欺凌 |
| viral circulation | 病毒式傳播 |
| embarrassing images | 令人尷尬的照片 |
| emotional distress | 精神困擾 |

#### A1-07｜人像可能遭人工智能濫用

清晰的面部照片有機會被他人用於冒認身分、製作深度偽造影像或虛假帳戶。不能說每張照片都會造成這些傷害，但當可辨認影像大量公開時，濫用材料便更容易取得。

| English（自然單字／詞組） | 繁體中文（本題語境） |
|---|---|
| facial images | 面部影像 |
| identity impersonation | 冒認身分 |
| AI-generated deepfakes | 人工智能深度偽造影像 |
| image misuse | 影像濫用 |
| online impersonation | 網上冒充他人 |

#### A1-08｜拍攝與公開發布是兩個不同決定

拍攝私人紀念照片與向大量網民發佈他人肖像，造成的曝光程度不同。一個人容許朋友拍照，不等於同意相片用於廣告、公開直播或永久保存，因此分享前應再次考慮用途。

| English（自然單字／詞組） | 繁體中文（本題語境） |
|---|---|
| private keepsake | 私人紀念照 |
| publish online | 在網上公開 |
| secondary use | 二次使用 |
| audience reach | 接觸的觀眾範圍 |
| consent to publication | 同意公開發布 |

#### A1-09｜文化或宗教場合需要保持莊重

在寺廟、悼念活動或傳統儀式中，參與者可能重視寧靜及尊重多於照片。若遊客不斷要求他人擺姿勢或使用閃光燈，活動可能被當成表演，令參與者感到不受尊重。

| English（自然單字／詞組） | 繁體中文（本題語境） |
|---|---|
| religious ceremonies | 宗教儀式 |
| cultural sensitivity | 文化敏感度 |
| solemn atmosphere | 莊重氣氛 |
| intrusive photography | 造成干擾的拍攝 |
| show respect | 表示尊重 |

#### A1-10｜患者或悲傷人士可能處於脆弱狀態

醫院、意外現場或喪禮附近的人，可能正在經歷焦慮或悲痛。即使事件發生於某些對外開放的區域，隨意拍攝特寫亦可能令當事人感到被消費，與一般旅遊照片的倫理不同。

| English（自然單字／詞組） | 繁體中文（本題語境） |
|---|---|
| vulnerable individuals | 處境脆弱人士 |
| emotional vulnerability | 情緒脆弱 |
| distressing circumstances | 令人難受的處境 |
| insensitive behaviour | 欠缺體諒的行為 |
| respect dignity | 尊重尊嚴 |

### 角度：居民生活質素、公共空間與人身安全

#### A1-11｜打卡人潮阻塞出入口

當數十人同時站在住宅大門前拍照，住戶可能需要繞路，送貨員及輪椅使用者也可能難以通行。問題不一定在於照片本身，而在於群體佔用了原本供日常出入的空間。

| English（自然單字／詞組） | 繁體中文（本題語境） |
|---|---|
| block entrances | 堵塞出入口 |
| pedestrian access | 行人通道 |
| daily inconvenience | 日常不便 |
| wheelchair users | 輪椅使用者 |
| crowd congestion | 人群擠塞 |

#### A1-12｜為拍好照片站在馬路上

部分人可能為了取得完整背景而走出行人路、在彎位停下，甚至要求車輛等待。這會使駕駛者和行人需要臨時避讓，增加碰撞或交通混亂的可能性。

| English（自然單字／詞組） | 繁體中文（本題語境） |
|---|---|
| step into traffic | 走進車流 |
| road safety | 道路安全 |
| obstruct vehicles | 阻礙車輛 |
| dangerous positioning | 危險站位 |
| traffic disruption | 交通受阻 |

#### A1-13｜佔用行人路增加跌倒風險

三腳架、補光燈和背包若散放在狹窄行人路，其他市民可能絆倒或被迫走到車道。拍攝器材佔地不大時未必有問題，但在人多、地窄的地方便需要作出限制。

| public safety | 公共安全 |

#### A1-14｜高危自拍可能引發救援風險

有人為取得驚險照片而靠近懸崖、越過圍欄或登上不穩固位置。若發生意外，不只拍攝者受傷，救援人員也可能要在惡劣地形中承擔額外風險。

#### A1-15｜閃光燈與補光設備令人不適

在安靜的餐廳、演出場地或夜間居住區，突然閃光可能分散他人注意力。對部分對強光敏感的人來說，頻繁補光更會造成不適，所以即使沒有觸犯正式禁令亦應克制。

#### A1-16｜直播和長時間拍攝製造噪音

直播主可能多次重拍開場白、播放音樂或大聲指揮同伴。當拍攝時間延長至深夜，噪音會直接影響附近家庭休息，居民自然可能對此類訪客反感。

#### A1-17｜為了拍照把其他人趕出畫面

## 三、Part A｜問題三：香港應否為公共場所拍照訂立規則？

**工作定義：**「需要規則」不必等於「所有地方禁止拍照」。比較支持限制、反對廣泛禁令及有條件管理三種有力立場；以下均為**建議或辯論觀點**，不是對香港現行法例的保證。

### 角度：支持訂立規則：保障私隱、秩序與公共利益

#### A3-S01｜保護被刻意拍攝者的個人尊嚴

攝影者若反覆對準一名陌生人、無視其要求停止，可能令對方感到被侵犯。規則可以優先針對持續跟拍及滋擾，而不是把所有街景中偶然入鏡的人都視為受害者。

### Question 7. Can taking photos spoil an experience?

## 七、使用與教學建議（DSE Speaking 而非背書式 News Discussion）

1. **Part A 先互動，不要獨白。** 選一個清楚立場，用一個因果機制講清楚「誰受到甚麼影響」，之後邀請另一人補充或回應。可選 A1 的居民私隱、A2 的住宅景點、A3 的行為規則作自然的跨題連結。
2. **每個新論點須真正不同。** 「保護住戶」「保障居民安寧」若只是重說人流擠迫，應合併；但「住宅窗口暴露行蹤」「車道拍照增加碰撞風險」「商業團隊佔用資源」機制不同，可分開發展。
3. **Part A 第 2 題並非景點背誦賽。** 選 2–3 個性質不同的香港地點，解釋為何受歡迎、誰會受影響，以及如何合乎禮貌地拍攝，比一口氣背十個地名更有討論價值。
4. **Part A 第 3 題要回答反駁。** 若支持禁拍，應解釋為何警告、告示或局部限制不足；若反對禁拍，應同時承認居民、兒童、病人與交通安全有合理需要；若提出折衷，要交代實際操作。
5. **Part B 採「直接回答 → 理由 → 例子／限制 → 簡短收結」**。講述自己的旅行、拍照習慣和朋友時，必須保持真實；不必同意上方的示範答覆。
6. **留意過度概括。** 不要說所有遊客都亂拋垃圾、所有長者不愛拍照、香港所有公共地方都禁止／完全容許拍攝，或拍照必然造成網絡欺凌。此類說法既欠準確，也不利於有深度的互動。
