# So / So That / So As To｜結果、目的及相關用法

**學習主線：這件事「造成甚麼」，還是做事的人「想達到甚麼」？**  
香港繁體中文解釋；英式英語為主。圖片核心為 so、so that、so as to；本文件亦整理容易混淆的 so ... that、such ... that、too/enough，以及閱讀中其他 so 用法。

`S01–S30` 為查閱編號。先學第一至四部分，再讀第五部分的邊界與延伸。例句和練習均為本次新編。

## 一、先看意思：結果不等於目的

### S01｜三種寫法的決策總表

| 想說甚麼 | 常用寫法 | 後面接甚麼 | 例句 |
|---|---|---|---|
| 所以有這個結果／決定 | so | 主語 + 動詞 | The shop was closed, so we went home. |
| 為了讓某事可能／希望某結果 | so that | 主語 + 動詞；常有 can/could/will/would | I wrote it down so that I would remember. |
| 為了做某事 | so as to | 動詞本來的寫法；通常與前面同一做事者 | I left early so as to avoid the traffic. |

中文依次是：店關門，所以回家；寫下來以便記住；早走為了避開交通。這張表是常見核心，不代表 so 只有結果、so that 永遠只表示目的。後面會教其他意思。

### S02｜目的可以沒有達到

> I left early so as to catch the bus, but I still missed it.  
> 我提早離開以趕上巴士，但最後仍錯過了。

目的說「想做到」，不保證成功。結果則報告實際發生或由情況推論出的結果：

> I left early, so I caught the bus.  
> 我提早離開，所以趕上了巴士。

不能把第一句自動改成第二句，因為那會憑空增加成功的事實。

### S03｜四步選擇

1. 是**原因 → 結果**，還是**行動 → 目的**？
2. 後面要有完整主語嗎？誰做第二個動作？
3. 第二件事是可能、希望、能力，還是已實現的事實？
4. 最後才選 so / so that / so as to，並檢查否定和動詞。

## 二、so：所以有這個結果或決定

### S04｜so 連接結果，順序通常是原因先、結果後

> The lift was broken, so we used the stairs.  
> 升降機壞了，所以我們走樓梯。

一般連句形式是 `原因小句, so + 結果小句`。不能把結果小句搬到前面仍以同樣的 so 接原因：`So we used the stairs, the lift was broken` 不是這個正常句型。

### S05｜so 後是完整小句；前後主語可以不同

> It was getting dark, so the guide turned on a torch.  
> 天色漸暗，所以導遊開了電筒。

不用強迫 it 和 the guide 相同。要保留主語與有時間的動詞；不要寫 `so to turn on a torch` 表這個已發生的結果。

### S06｜逗號、because 與 therefore

- 兩個完整小句用 so 連接，書面常在 so 前放逗號；短句有時可省。
- `Because the lift was broken, we used the stairs` 已有 because，普通標準作文不再加另一個 so 形成 `Because ..., so ...`。
- `The lift was broken; therefore, we used the stairs` 可用分號或另起一句；therefore 不是在兩個完整句之間只放逗號便足夠的連接詞。
- 句首 `So we used the stairs` 可承接上一句，尤其敘事或口語。不能把「同一句結果在後」誤教成「So 永不能在句首」。

### S07｜so 的結果不只用過去式

> The road is closed, so we cannot drive through.  
> 道路封閉，所以我們不能駛過。

> The road will be closed tomorrow, so we will leave earlier.  
> 明天會封路，所以我們會早點出發。

so 不決定動詞時態；時間、情況和說話意思才決定。

## 三、so that：有主語的目的小句

### S08｜so that + 主語 + 動詞

> I moved the chair so that my grandmother could sit down.  
> 我移開椅子，讓祖母可以坐下。

前後做事者可不同：我移椅子、祖母坐下。不要寫 `so that to sit`，也不要把主語漏掉。若前後同一人也可以用 so that：`I wrote it down so that I would remember`。

緊接主句的目的小句通常不加逗號。目的小句放句首時通常以逗號分開；較正式的前置目的也常用 in order that。標點要幫助讀者，不應靠一個逗號便斷言句子只有一個意思。

### S09｜can / could 常說「讓某人能夠」

> Speak clearly so that everyone can hear you.  
> 說清楚一點，讓大家聽得到。

> She spoke clearly so that everyone could hear her.  
> 她說得清楚，讓大家聽得到。

現在／將來的目的常見 can；過去目的常見 could。could 在這裏描述目的中的能力，不單靠這個字就保證大家真的都聽到。

### S10｜will / would 常說預期的目的結果

> I will send a reminder so that you will not forget.  
> 我會寄提醒，讓你不會忘記。

> I sent a reminder so that he would not forget.  
> 我寄了提醒，讓他不會忘記。

這裏 would 配合當時的目的；不是想像已知沒有發生的第三類條件句。不要見 would 就譯成「本來會」。

### S11｜so that 後不一定要有情態動詞

> I will put the key here so that you find it easily.  
> 我會把鎖匙放在這裏，讓你容易找到。

也可說 `so that you can find it easily`。普通現在式、will、can 都可能成立，視乎要突出結果還是能力。**不能把 unless 後普通未來不用 will 的規則搬來 so that。**

正式目的也可見 may/might：`The grant was increased so that more students might benefit`（資助增加，讓更多學生能受惠）。may/might 在這裏不是報告已實現的結果，也沒有固定成功百分比。

### S12｜時間配合不是盲目的退一步

過去敘述常用 could/would，但若目的在現在仍相關，也可能保留現在意思：

> I saved a copy yesterday so that we can use it today.  
> 我昨天儲存了一份，好讓我們今天使用。

today 明示目的在現在；不能單靠主句 yesterday 便判 can 錯。

### S13｜否定目的：so that ... not

> I whispered so that I would not wake the baby.  
> 我低聲說話，以免吵醒嬰兒。

`so that the baby would not wake up` 也自然，但主語和動詞改了：第一句我不吵醒，第二句嬰兒不醒。改寫時要保留因果和誰做動作，而不是只替換連接詞。

### S14｜that 可以省略，省略後 so 仍可能表示目的

> I labelled the boxes so you could find everything.  
> 我標示了箱子，好讓你找到所有物品。

這裏是 `so (that)`，不是一定在報告找到的結果。看到 so 要看說話者是不是在交代意圖，以及後面的 can/could/will/would 等資料；不能教成「沒有 that 就只有所以」。正式、易含糊的句子可保留 that。

### S15｜so that 也可以表示結果

> The ferry stopped running, so that the island was cut off for two days.  
> 渡輪停駛，結果島嶼對外交通中斷了兩天。

這不是有人刻意讓島嶼隔絕。逗號與事實語境有助識別，但**逗號不是目的／結果的唯一判斷鍵**。in order that 通常只表目的，不能在這句中任意替代表示結果的 so that。

## 四、so as to：通常共用做事者的目的

### S16｜so as to + 動詞本來的寫法

> I checked the address so as to avoid a mistake.  
> 我核對地址，為了避免出錯。

不用 `so as to avoiding`、`so as avoid` 或 `so as that`。so as to 一般比簡單 to 更正式，也可強調目的；不是每句都必須寫得較長。

### S17｜誰要做後面的動作？

> I opened the window so as to cool the room.  
> 我開窗，為了讓房間涼快一點。

是我開窗，也由我的行動使房間降溫。若目的需要另一個人當明確主語，通常改用 so that：

> I opened the door so that the children could come in.  
> 我開門，讓孩子進來。

`I opened the door so as to come in` 通常表示我自己要進去，不能用來保留「孩子進來」的原意。避免 `so as for the children to ...`；清楚用 so that，或 `in order for the children to ...`。

### S18｜so as not to：把「不要」放在目的裏

> We left quietly so as not to disturb the neighbours.  
> 我們安靜地離開，以免打擾鄰居。

常用形式是 `so as not to + verb`。`We did not leave ...` 是否定離開這件事；`We left ... so as not to disturb ...` 是否定想避免的打擾，兩者不同。`not to` 可在其他句型成立，基本目的改寫用 so as not to 最清楚。

### S19｜to / in order to / so as to

| 寫法 | 常見風格 | 例句 |
|---|---|---|
| to | 最簡潔、日常 | I went upstairs to get my bag. |
| in order to | 較明確、較正式 | I went upstairs in order to get my bag. |
| so as to | 較正式，常放主句後 | I went upstairs so as to get my bag. |

三句都表示我上樓拿袋。句首目的常用 `To ...` 或 `In order to ...`：`In order to catch the train, we left early`。句首 so as to 較不常見，不應為了生硬對稱而強迫使用。

### S20｜被動、進行及較長動詞鏈

> She wore a badge so as to be recognised by the staff.  
> 她戴上名牌，讓職員認得她。

形式是 `so as to be + V3`，不是 `so as to recognised`。`so as to be working on the right version` 等較長寫法也可能成立，但通常可改得簡潔。目的本來指向行動想達到的事；不要因主句是過去便把後面 to 改成過去式。

### S21｜前後看似不同主語：先辨別是主動者還是受影響者

> The shelves were lowered so as to make the books easier to reach.  
> 書架調低了，讓書本較容易拿到。

書架不是有意圖的人；改動書架的行動有一個目的。被動句和事物設計可以自然用 so as to。若讀者不清楚誰要做後面的動作，就改成完整 so that 小句，不把「必須同一主語」背成沒有語境例外的口訣。

## 五、與相似形式的界線

### S22｜so that 與 so ... that：相鄰兩字不一定同一種結構

> I spoke slowly **so that** everyone could follow.  
> 我慢慢說，為了讓大家跟得上。（目的）

> I spoke **so slowly that** everyone became impatient.  
> 我說得太慢，大家都不耐煩了。（程度導致結果）

`so + 形容詞／副詞 + that 小句` 表示「如此……以致……」。so 與 that 之間有程度描述；不要把整組當作目的連接詞。

### S23｜so + adjective / adverb；such + noun phrase

| 描述甚麼 | 形式 | 例句 |
|---|---|---|
| 形容詞 | so + adjective + that | The bag was so heavy that I needed help. |
| 動作方式 | so + adverb + that | She spoke so softly that I could hardly hear her. |
| 一個名詞 | such a/an + adjective + singular noun + that | It was such a heavy bag that I needed help. |
| 複數／不可數名詞 | such + adjective + noun + that | They gave such useful advice that we changed our plan. |

基本寫法不說 `so a heavy bag`。正式文體可見 `so heavy a bag`，但不是初學改寫的首選。

### S24｜so many / much / few / little

> There were so many people that we could not enter.  
> 人太多，我們無法進入。

> There was so little time that we skipped lunch.  
> 時間太少，我們沒有吃午餐。

數量用 so many/few + 複數名詞、so much/little + 不可數名詞。little 若指「體積小」而非「數量少」，可見 `such little children`（這麼小的孩子）；要先看 little 的意思。

### S25｜so ... that 與 too ... to / enough to 的改寫

> The box was so heavy that I could not lift it.  
> The box was too heavy for me to lift.  
> 箱子太重，我搬不起。

> She was tall enough to reach the shelf.  
> 她夠高，可以碰到架子。

改寫時檢查：正面／負面結果、誰做動作、代名詞是否重複。`too heavy for me to lift it` 在這個標準改寫中多了 it。`so ... that` 若明說已成功做某事，改成 enough to 有時只保留能力，會丟失實現的事實；不要只按詞序套換。

### S26｜for + 名詞／-ing 與目的 to

> This tool is for cutting wire. 這工具用來剪電線。（功能）  
> I bought this tool to cut wire. 我買這工具是為了剪電線。（買的目的）

不能把所有目的動詞前的 to 換成 for：`I went out for buy bread` 錯。for + 名詞可說目的，如 `for lunch`；for + -ing 常說用途，但語境也能有更廣的目的關係，不能一律判 for doing 錯。

### S27｜in order that、because、in case 的對照

| 表達 | 關係 | 例句及意思 |
|---|---|---|
| in order that | 正式目的；完整小句 | We sent a map in order that visitors could find us. 寄地圖讓訪客找到。 |
| because | 做事的原因 | We left because it was late. 因為太晚而離開。 |
| in case | 預先防備可能情況 | Take a coat in case it gets cold. 帶外套以防變冷。 |
| so that | 目的或某些結果 | Take a coat so that you will stay warm. 帶外套以保持溫暖。 |

in case 的防備不等於結果已發生；so that 的目的也不等於已達成。

### S28｜so ... as to：形式相近，但未必是意圖

> The instructions were so unclear as to be useless.  
> 指示含糊得根本沒有用。

這是正式的 **so + 程度描述 + as to + verb**，表示程度與結果，並非有人「為了無用」。

> Would you be so kind as to close the door?  
> 可以麻煩你關門嗎？

這是客氣請求。也可見 so as to 描述安排造成的結果，未必有一個人蓄意策劃；學校的基本目的句先學 S16，但進階閱讀要看有沒有程度詞及實際意思。

### S29｜閱讀中其他 so，不屬這三個連接詞的替換題

| 用法 | 例句 | 意思／形式 |
|---|---|---|
| 同樣如此 | “I can swim.” “So can I.” | 我也可以；so + 助動詞／modal + 主語。 |
| 確認原來如此 | “You left it here.” “So I did.” | 我真的放了；主語在動詞前，非「我也」。 |
| 代替一件已說的事 | I think so.／I hope not. | 我想是／希望不是；並非所有動詞都能接 so。 |
| 代替動作 | Please close the door if you have not done so. | done so 代替關門。 |
| 程度 | It is so cold! | 很冷；不一定接 that。 |
| 到目前為止 | so far | 與時間有關，非目的。 |
| 大約 | twenty minutes or so | 大約二十分鐘。 |
| 條件 | so long as | 只要；相當於 as long as 的某些用法。 |
| 話語開場 | So, what happened next? | 那麼，之後怎樣？ |

這一部分幫助辨認，不能把每個 so 都翻成「所以」。

### S30｜改寫時的保留清單

把 `so that` 改成 `so as to` 前，逐項檢查：

1. **目的沒有變成已實現的結果**。
2. **做事的人沒有被換掉**；不同主語時保留 so that 通常最清楚。
3. **否定位置正確**：so as not to，而非不小心否定主句。
4. **動詞形式正確**：so that + 主語 + 動詞；so as to + 動詞本來的寫法。
5. **能力或許可的意思沒有無故丟失**：could 有時不只是一個可刪的字。
6. **文體自然**：簡單 to 已合適時，不必強加冗長表達。

## 六、常見錯誤與修正

| 容易出錯的寫法 | 改正／說明 |
|---|---|
| I left early so as to caught the bus. | so as to catch；不因 left 是過去便把 catch 改過去。 |
| I left early so that to catch the bus. | so that I could catch / so as to catch。 |
| I left early so as I could catch ... | so that I could catch ... |
| I left quietly so as to not disturb ... | so as not to disturb 是較常教的形式；to not 這類分開不定詞的寫法並非所有語境都不合文法。 |
| I opened the door so as the children to enter. | so that the children could enter。 |
| Because it rained, so we stayed home. | Because it rained, we stayed home.／It rained, so we stayed home. |
| so that 永遠只說目的 | 也可說結果，見 S15。 |
| so 永遠只說結果 | 可省略目的 so that 的 that，見 S14。 |
| so that 後必須 can/could | 普通現在式及 will/would 等也可。 |
| so as to 一定代表結果已成功 | 目的可以失敗，見 S02。 |
| so a useful book | such a useful book；正式文體另有 so useful a book。 |
| so much students | so many students。 |

## 七、練習與答案

### A. 先做

**S-Q01** Fill **so / so as to**: The train was cancelled, _____ we took a bus.  
【火車取消了，所以我們乘巴士。】

**S-Q02** Fill **so that / so as to**: I moved aside _____ the children could see the stage.  
【我移開，讓孩子看得到舞台。】

**S-Q03** Fill **so that / so as to**: I set an alarm _____ wake up early.  
【我設鬧鐘，為了早起。】

**S-Q04** Rewrite using **so as not to**: We spoke softly so that we would not disturb the patient.  
【我們輕聲說話，以免打擾病人。】

**S-Q05** Is the meaning preserved? I saved a seat so that my friend could sit down. → I saved a seat so as to sit down.  
【原句是為朋友留座；改寫後還一樣嗎？】

**S-Q06** I left early so as to catch the train, but I missed it. 有沒有語意矛盾？  
【我早走為趕火車，但仍錯過了。】

**S-Q07** What does **so** mean? I wrote the address clearly so everyone could read it.  
【我把地址寫清楚，好讓大家看得懂。】

**S-Q08** What does **so that** mean? The only road collapsed, so that the village was cut off.  
【唯一道路倒塌，結果村莊對外隔絕。】

**S-Q09** Fill **so / such**: It was _____ a difficult question that nobody answered.  
【題目太難，沒有人作答。】

**S-Q10** Correct: I put the sign up so that visitors to find the entrance.  
【我豎立告示，好讓訪客找到入口。】

**S-Q11** Compare: I spoke slowly so that everyone could follow.／I spoke so slowly that everyone became bored.  
【慢慢說讓人跟得上／說得太慢以致大家覺得悶。】

**S-Q12** Can **can** be correct? I saved the file yesterday so that we can use it today.  
【昨天儲存，讓今天使用。】

| 02 | I moved aside so that the children could see the stage. 後面有 children + could see，不同做事者。 | S08 |
| 03 | I set an alarm so as to wake up early. 後面直接接 wake；一般寫作也可用 to / in order to。 | S16 |
| 04 | We spoke softly so as not to disturb the patient. | S18 |
| 05 | 不保留。改寫後變成我自己坐下，不是朋友坐。 | S17 |
| 06 | 沒有。目的不保證達成。 | S02 |
| 07 | 目的；可還原 so that。 | S14 |
| 08 | 結果，不是村民刻意要與外界隔絕。 | S15 |
| 09 | It was such a difficult question that nobody answered. | S23 |

### C. 七步示範：S-Q02

1. **先看句子在說甚麼：** 說話者讓開位置，希望孩子看得到舞台。
2. **把事情的關係排清楚：** 我移開；孩子看舞台，是兩個不同主語。
3. **找出最重要的提示：** 空格後有 `the children could see` 這個完整小句。
4. **決定要用哪種寫法：** 用 so that 引出目的。
5. **把答案一步一步寫出來：** so that + the children + could + see。
6. **比較最容易混淆的另一個寫法：** so as to 後直接接動詞，不能接這個完整小句；若改成 so as to see，通常會變成我自己看。
7. **放回完整句子，再做最後檢查：** I moved aside so that the children could see the stage. 【我移開，讓孩子看得到舞台。】最後問：看舞台的人仍是孩子嗎？

### D. 七步示範：S-Q04

1. **先看句子在說甚麼：** 我們壓低聲音，希望不要打擾病人。
2. **把事情的關係排清楚：** 輕聲說話和避免打擾的主語都是 we。
3. **找出最重要的提示：** `we would not disturb` 是否定的目的，並非否定說話這件事。
4. **決定要用哪種寫法：** 共用做事者，且要求以 so as not to 改寫。
5. **把答案一步一步寫出來：** 刪去重複的 we would，保留目的的 not，寫 so as not to disturb。
6. **比較最容易混淆的另一個寫法：** `We did not speak` 變成沒有說話；`so as to disturbed` 動詞形式錯。
7. **放回完整句子，再做最後檢查：** We spoke softly so as not to disturb the patient. 【我們輕聲說話，以免打擾病人。】最後問：主句動作與想避免的事是否都保留？
