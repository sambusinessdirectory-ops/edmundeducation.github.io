# Built-in ImageGen fitting prompts

Image 1 in each pair was the character's canonical standing atlas, made visible for the built-in editor. Image 2 was the corresponding user design screenshot. Each output path is the unmodified fit file in this directory. The built-in tool used `num_last_images_to_include: 2`, except Eddy bomber, which used three recent images and explicitly excluded Noir's atlas.

## Eddy brown leather bomber

Use case: identity-preserve. Asset type: 1024-square 4-by-4 standing wardrobe fitting atlas. Among the three most recent images, the orange-brown cartoon horse 4x4 sheet is the EDIT TARGET for Eddy, the dark horse sheet is another character and must be ignored, and the single brown leather jacket is the DESIGN REFERENCE. Change ONLY Eddy's torso and upper arms in EACH of the 16 existing cells to make him wear the distressed brown leather bomber: wide pointed collar, brass center zipper, two flap pockets, warm brown ribbed cuffs and waistband. Preserve EXACTLY the 4x4 layout, per-cell position, facing direction, original head, ears, mane, muzzle, eyes, tail, hands/hooves, feet, legs, pose, size and light gray background of the Eddy target. Jacket collar below muzzle, cuffs before hooves, waistband at hips, side belly covered, original tail visible. Output the whole 4x4 sheet; no crop, grid, labels, checkerboard or extra clothing.
