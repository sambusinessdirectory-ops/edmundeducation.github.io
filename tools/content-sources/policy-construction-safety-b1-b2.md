# 當地盤面對趕工壓力時，工程管理層應如何在維持工程進度與保障工人安全之間取得平衡？

**Construction site safety vs project deadlines｜香港政策設計多角度論點庫（B1–B2 英文詞彙版）**

> **核心答案：**不要把「盡快完成」與「停工保命」設定成只能二選一。工程管理層應以合理工期、預先控制高危工序、現場停工與復工機制、對分判商公平的合約付款，以及有明確責任的監督，減少因趕工而增加的風險。
> **身份界線：**建議包括企業可自行採取的做法，以及需要修訂合約／規則的政策倡議；**不是所有建議均為香港現行法定要求**。除另註外，標題上的標籤只是教學分類。

## 一、題目與資料界線

此題以香港地盤在趕工時的**安全、成本、交付時間、工人權利及公共利益**為分析對象。上載的 News 2 範例曾以 2026 年 10 月 15 日東涌拆卸天秤墮下事故作背景；原文件指出事故原因當時仍有待調查；本稿未核實其後調查進度，**不能直接推斷「趕工」是原因**。本教材各項做法主要是一般政策設計，不代表涉事工程曾有任何特定缺失。

### 1.1 實際監管與合約責任（不要混淆）

| 角色 | 真正能做甚麼 | 不應誤當成 |
|---|---|---|
| 地盤總承建商／工程管理層 | 排工序、配人手、提供安全系統、監督工種、在危險時停止工序 | 政府執法者 |
| 工人／工會／安全代表 | 報告危險、參與風險評估、提出停止不安全工作及改善安排 | 可以代替僱主履行全部安全責任 |
| 業主／發展商／公共工程項目客戶 | 訂立合理交付期、撥款、合約支付安全工作及監督承建商 | 對所有工地直接發法定停工通知 |
| 勞工處（LD）職業安全及健康部 | 依職安健法例巡查、調查、發改善／暫時停工通知、採取執法行動 | 公私營工程的日常排工序主管 |
| 發展局（DEVB） | 制訂公共工程合約、招標和安全政策方向，監察工務承建商表現 | 私人地盤的普遍直接執法機關 |
| 建築署／土木工程拓展署／路政署／渠務署／水務署等工務部門 | 以各自公共工程項目管理者身分設計、監督工期及合約安全要求 | 負責全港所有地盤安全法定執法 |
| 屋宇署（BD） | 執行《建築物條例》下私人建築工程圖則、施工及地盤監督要求 | 取代勞工處處理所有職安健檢控 |
| 房屋委員會／房屋署（HA/HD） | 對其房屋工程運用安全付款、巡查、合約評分和承建商管理 | 監管所有私人地盤 |
| 建造業議會（CIC）／香港建造學院（HKIC） | 推動技術指引、行業合作、職業及安全培訓 | 可對違法地盤直接發法定罰款 |
| 職業安全健康局（OSHC） | 教育、推廣、培訓和安全文化工具 | 職安健法定執法處 |
| 香港天文台（HKO） | 發天氣預報及警告，供承建商啟動應變計劃 | 判定每個地盤可否復工 |
| 消防處（FSD） | 按自身職能處理火警、救援和相關消防安全事項 | 常規吊運／高空工作巡查的主責部門 |
| 保險公司／設備供應商／工程顧問 | 以承保條件、設備設計、專業檢查及合約服務推動安全 | 取代法定責任或工人經驗 |

**已核實的香港制度例子（截至 2026-10-29）：**勞工處職安健檢查、改善及暫時停工通知；發展局公共工程安全評標與安全表現考核、公共工程 4S 智慧工地安全系統、分判商安全付款安排；屋宇署對部分私人建築工程的移動機械／天秤警示系統條件；房屋署按安全表現支付款項。2026 年 7 月公共工程有關工用梯的限制須按適用合約指示理解，**不可當作所有私人地盤一律受禁**。詳見文末 [S1]–[S11]。

### 1.2 政策標籤的意思

`[工期管理]` 調整工作次序和時間；`[安全規則]` 訂明最低操作條件；`[財務誘因]` 以付款／獎勵改變選擇；`[處罰]` 對已證實違規者追責；`[培訓]` 提升能力；`[公開資料]` 讓人比較和監督；`[科技]` 以設備輔助發現危險；`[工人保障]` 讓工人敢於求助；`[部門協作]` 釐清分工；`[救援]` 降低事故後傷害；`[試點]` 先試後推；`[申訴]` 處理錯判。每項可有多個標籤。

### A｜工期與資源規劃：把安全時間放進工程進度

#### 001. 把安全檢查列入主進度表 [工期管理][安全規則]

**負責與操作：**項目總監、總承建商；把棚架驗收、設備檢查和高危工序核准列為不能跳過的進度節點。 **理由／界線：**事前安排可減少突然停工的混亂；須防止只在表格上完成。

### B｜業主、發展商與合約：讓安全不再被削價競爭

**負責與操作：**勞工處（按法定工作）、僱主、媒體、家屬；保留現場證據、核實工序及各方職責，再提出安全修正；不要以「有人趕工」直接推斷因果。 **理由／界線：**及時採取臨時安全措施不必等調查全部結束。

## 三、不同人真正擁有的「安全決策權」

| 身份 | 在趕工壓力下應作的實際決策 |
|---|---|
| 發展商／業主 | 接受有證據支持的安全工期調整，而不是只看開售或交樓日期。 |
| 項目總監 | 用可核實的進度節點取代每日「全部趕快」的指示。 |
| 總承建商地盤經理 | 因應危險暫停受影響工序，同時重新調配其他不受影響的工作。 |
| 安全主任／安全督導員 | 提出風險改善與復工條件，保留獨立報告途徑。 |
| 前線管工／領班 | 查設備、看工人疲勞與工種衝突，不以進度獎金壓過安全檢查。 |
| 工人／學徒 | 知道何時報告危險、如何避免參與不安全操作，以及向誰求助。 |
| 總承建商採購／財務部 | 支付安全設備、合理分判費用及訓練工時。 |
| 分判商老闆／領班 | 不要用趕工壓力迫使短缺人手超時或跨工種冒險。 |
| 設計師／工程師 | 改動圖則或臨時支撐時，審查施工過程風險及監督方案。 |
| 設備製造商／租賃商 | 提供符合現場用途的設備、維修紀錄及使用訓練。 |
| 保險公司 | 把有證據的預防措施納入評估，而非只獎勵低報意外數字。 |
| 工會／工人安全代表 | 集中收集不敢具名的風險及工資疑問，協助協商修正措施。 |
| 工務部門／屋宇署／勞工處 | 按各自法定或合約職責履職，不能把所有監督工作互相推卸。 |
| 地盤附近居民／商戶 | 反映圍板、路口、吊運區及公眾通行的不安全安排。 |
| 家屬 | 支持工人報告傷患及疲勞，而非把加班視為唯一收入保障。 |
| 緊急救援人員 | 與地盤協調清楚出入口、救援路線及危險物位置。 |

## 四、四個實用政策組合：不同預算怎樣選？

**組合 1｜本週便可做（低成本）**：總承建商安排每日短會、危險清單、跨工種分區、書面停工／復工條件及每週趕工風險重排；工人參與回報；監督顧問查證整改。

**組合 2｜下份合約便可改（中成本）**：業主設明確安全時間與安全付款項目；招標考慮過往安全、真實人手安排與施工方法；直接把部分安全付款給合資格分判商，並建立合約化延長工期的核證程序。

**組合 3｜高危工程加強版（較高成本）**：在天秤、吊運、高空、深坑及密閉空間使用有資質人士的工程審核、危險區隔離、適合的警示科技、救援演練及獨立覆檢；不要只要求工人「小心」。

**組合 4｜政府及全行業改進（制度層面）**：勞工處按風險執法；發展局與工務部門用公共工程合約展示可行標準；屋宇署執行私人建築工程適用的監督要求；房屋署運用安全付款及巡查；CIC／HKIC／OSHC 推廣訓練與匿名分享險失教訓。

## 五、成效評估：不要只看「有沒有意外」

| 指標（KPI） | 建議的觀察方法 | 防止被造假的設計 |
|---|---|---|
| 高危工序合規率 | 抽樣查已完成的安全檢查及工作許可 | 突擊實地核對，避免只看表格 |
| 險失事故通報率 | 比較通報數、糾正速度與再發情況 | 鼓勵報告而非單純懲罰數量多者 |
| 停工後問題關閉速度 | 記錄危險、修正、覆核及復工時間 | 不以「停得少」直接當作安全 |
| 工人疲勞與合理休息 | 抽查工時及匿名回饋 | 兼顧分判／散工，勿只記總承建商員工 |
| 安全付款流向 | 查安全款是否到達實際做工的分判商 | 要求收據及第三方抽樣核對 |
| 設施與警示系統可用率 | 查設備運作、誤報與處置紀錄 | 避免「已安裝」冒充「有效使用」 |
| 安全與進度聯合表現 | 觀察高危返工、工程延誤與事故 | 分開外部變數，不以單宗事故概括全部 |

## 八、引導討論的最強核心衝突

1. **安全時間 vs 交付承諾：**延長工期由誰批准？誰承擔成本？哪些風險不能用錢交換？
2. **政府規管 vs 企業管理：**勞工處可執法，但不能代替每日的管工安排；業主怎樣把安全要求寫進合約？
3. **停工保障 vs 誤用：**怎樣讓真正危險立即停止，同時以清楚記錄和獨立覆核防止爭議？
4. **科技監測 vs 工人私隱：**哪些資料與高危工作直接有關？誰可以查閱及保存多久？
5. **大型工程 vs 小型地盤：**同一要求是否對設備、人手、租金和現金流不同的承建商公平？
6. **事故數字 vs 隱瞞誘因：**如何獎勵及早報告問題，而不是獎勵沒有申報問題？
