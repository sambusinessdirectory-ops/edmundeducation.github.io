# DSE Practical Writing visual assets

## Ownership and permitted use

All production assets listed here were generated specifically for EdmundEducation
with OpenAI's built-in ImageGen tool. They are not crops, edits or traces of the
supplied third-party game screenshots. The commercial screenshots remain outside
the public site and were used only to communicate camera angle, depth, directional
lighting and the physical-paper metaphor.

- `learning-route-v1.webp` — original academic learning-route desk.
- `writing-desk-v1.webp` — original practical-writing workspace.
- `briefing-folio-v1.webp` — original academic briefing folio.
- `selection-map-v2.webp` — original regional learning map on a walnut study table,
  generated 2026-11-05; public output derived from `imagegen-sources/selection-map-v2.png`.
- `location-marker-v2.webp` — original oxblood enamel-and-brass location marker,
  generated 2026-11-05; public output derived from `imagegen-sources/location-marker-v2.png`.
- `writing-file-v2.webp` — original three-part archival writing file on a walnut desk,
  generated 2026-11-05; public output derived from `imagegen-sources/writing-file-v2.png`.
- `mode-folders-v2.webp` — original paired learning/practice folders beneath a study lamp,
  generated 2026-11-05; public output derived from `imagegen-sources/mode-folders-v2.png`.
- `briefing-dossier-v2.webp` — original layered lesson and mission dossier with index tabs,
  generated 2026-11-05; public output derived from `imagegen-sources/briefing-dossier-v2.png`.

For the 2026-11-05 replacement assets, the source screenshots were supplied to
ImageGen only as composition references with explicit instructions to copy none
of their artwork, objects, map geometry, printed forms, branding, controls or
distinctive details. No reference screenshot is stored in the repository or
served by the website.

## Release audit

- No third-party names, logos or trademarks.
- No readable embedded text, menu labels, social icons or version numbers.
- No characters, weapons, military objects or occult symbols.
- No decorative controls that could be mistaken for working website controls.
- No recognisable reproduction of a supplied reference scene.
- All real labels and interactions remain HTML, keyboard-accessible and testable.

## Generation prompts

The 2026-11-05 map prompt required an original 16:9, elevated three-quarter walnut
desk with a dominant cream-and-sage regional map, rivers, roads, contours, open
interactive regions and a warm brass study lamp. The marker prompt required an
isolated oxblood enamel-and-brass plus-shaped locator on transparency. The writing
prompt required a large three-part blank archival file with cotton-paper fibre,
fine rules, central writing lines, layered sheets and warm-to-charcoal lamp falloff.
The mode prompt required two equally weighted blank folders with sage and oxblood
tabs. The briefing prompt required one long, layered blank dossier with a header
rule, inset paper panels and visible side tabs for long bilingual lessons.
Every prompt explicitly excluded logos, brands, commercial interface elements,
readable text, weapons, military equipment, characters and recognisable copied art.
