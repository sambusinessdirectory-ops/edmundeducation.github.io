# Professional English course photo and persistent controls

- Test3GR retains its existing student role and receives only course-photo editing through a server-validated, course-scoped permission. Existing admins may also edit via the RPC. Course members can view the photo; unassigned accounts cannot read or write it.
- A single photo sits beside the My courses Refresh button. JPEG/PNG/WebP uploads are resized to at most 1000 px and re-encoded as JPEG in the browser, removing source metadata. The server caps the encoded payload at 500,000 characters and verifies the JPEG envelope. Revision checks prevent stale replacement. The visible page polls for a new revision every 15 seconds and when focused; unchanged reads omit the image bytes.
- `professional_media.course_photos` is private, has RLS enabled and no direct client table grants. Its INFO “RLS Enabled No Policy” advisor finding is intentional deny-by-default. Access uses the existing Professional English opaque session token and course membership, not the unrelated homework accounts or Supabase Auth identities. Public RPC is SECURITY INVOKER; the private helper has a fixed empty search path and validates the session on every call.
- Dialogue highlights wrap complete coloured ranges (including spaces) while retaining individual word bookmarks. Phrase buttons no longer inherit the square audio-button width.
- In-exercise difficulty/hint switching preserves separate mode drafts even when offline. Internal mode changes do not prompt to abandon an exercise; actual departure still retains the existing leave protection. Completed answers continue to use the original per-draft activity identities.
- The audio toolbar contains the percentage progress and mode switcher. Reading controls stay visible; page navigation measures their actual height so Safari does not cover the selected page. The PDF link follows the selected page.

Validation: course-photo database permission/format/conflict tests; existing reader, library, feedback, community, activity, sync, save-conflict and polysemy-resume checks; Chromium and WebKit feature flows at 320, 390, 768 and 1280 px using intercepted synthetic accounts. No production student activity or course photo was created by testing.
