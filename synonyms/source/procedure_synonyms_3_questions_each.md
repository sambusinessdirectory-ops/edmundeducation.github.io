# SYNONYMS · 同義詞學習系統

# Procedure

**`procedure` 可以指完整流程、完成事情的方法、一套步驟、正式規程、例行做法、工作流程、步驟次序或機構標準作業程序。不同替代表達的重點並不相同。**

核心替代表達：

`process / method / set of steps / protocol / routine / workflow / sequence / standard operating procedure`

> **核心原則**：先判斷 procedure 指的是 **overall process, way of doing something, explicit steps, formal protocol, repeated routine, work flow, ordered sequence, or documented SOP**。

---

# 01 同義詞指南

## 01 Process

**過程；程序**

當 `procedure` 指由多個階段組成、從開始到完成的一整套流程時，`process` 很自然。它比 `procedure` 更強調整體進展，而不一定強調每一步必須按固定方式執行。

**EXAMPLE · 例句**

> The application process usually takes two weeks.

申請流程通常需時兩星期。

**SEMANTIC CUE · 語義提示**

> **a series of stages through which something develops or is completed**

**REGISTER · 語域**

所有語域

---

## 02 Method

**方法；做法**

當 `procedure` 的重點是『用甚麼方式完成某項工作』時，`method` 很合適。它強調方式，而不是一連串固定步驟。

**EXAMPLE · 例句**

> The laboratory uses a reliable method for measuring acidity.

實驗室採用可靠的方法量度酸度。

**SEMANTIC CUE · 語義提示**

> **a particular way of doing something**

**REGISTER · 語域**

一般、學術、專業

---

## 03 Set of steps

**一套步驟；一連串步驟**

非常透明的描述性改寫，當 `procedure` 明確由多個依次執行的步驟構成時很適合。它沒有 `protocol` 或 `standard operating procedure` 那麼正式。

**EXAMPLE · 例句**

> The guide explains the set of steps needed to reset the device.

指南說明重設裝置所需的一套步驟。

**SEMANTIC CUE · 語義提示**

> **a sequence of individual actions performed in order**

**REGISTER · 語域**

一般、教學、技術

---

## 04 Protocol

**規程；正式程序；操作規範**

當 `procedure` 是醫療、研究、安全、外交或其他專業領域中必須遵守的正式規範時，`protocol` 很精準。它比一般 `procedure` 更有制度和規範意味。

**EXAMPLE · 例句**

> Researchers must follow the approved safety protocol.

研究人員必須遵守已批准的安全規程。

**SEMANTIC CUE · 語義提示**

> **a formal set of rules governing how an activity must be carried out**

**REGISTER · 語域**

醫療、研究、安全、正式

---

## 05 Routine

**例行程序；慣常做法**

當 `procedure` 指經常重複、已形成習慣的日常程序時，`routine` 很自然。它不一定有正式規定，只表示慣常反覆做。

**EXAMPLE · 例句**

> The technician follows the same maintenance routine every Friday.

技術員每星期五都按照相同的例行保養程序工作。

**SEMANTIC CUE · 語義提示**

> **a regularly repeated way of doing something**

**REGISTER · 語域**

一般、工作、日常

---

## 06 Workflow

**工作流程**

當 `procedure` 涉及工作、文件、任務或數據如何在不同人員／系統／階段之間流轉時，`workflow` 很精準。它特別常見於辦公、軟件和業務流程。

**EXAMPLE · 例句**

> The new software simplifies the invoice approval workflow.

新軟件簡化了發票審批工作流程。

**SEMANTIC CUE · 語義提示**

> **the flow of tasks, information, or approvals through a work system**

**REGISTER · 語域**

商業、辦公、科技

---

## 07 Sequence

**次序；一連串步驟**

當 `procedure` 的重點是步驟必須按特定先後次序進行時，`sequence` 很合適。它描述 order，而不一定包含完整規則。

**EXAMPLE · 例句**

> The machine must be shut down in the correct sequence.

機器必須按正確次序關閉。

**SEMANTIC CUE · 語義提示**

> **an ordered succession of actions or stages**

**REGISTER · 語域**

技術、一般、正式

---

## 08 Standard operating procedure

**標準作業程序；標準操作程序**

非常正式和具體，指機構為確保一致性、安全或合規而制定的書面標準程序，常縮寫為 `SOP`。它比一般 `procedure` 更制度化。

**EXAMPLE · 例句**

> Staff must follow the standard operating procedure when handling hazardous materials.

員工處理危險物料時必須遵守標準作業程序。

**SEMANTIC CUE · 語義提示**

> **a formally documented procedure that standardises how a task is performed**

**REGISTER · 語域**

企業、醫療、實驗室、正式

# 02 False synonyms

## Procedure / Process
`process` 強調整體進展和階段；`procedure` 更常帶「應如何做」的操作意味。

**ENGLISH COMPARISON**  
The application process may take two weeks.  
The application procedure explains what documents to submit and in what order.

## Procedure / Method
`method` 是完成事情的方式，不一定包含多個固定步驟。

**ENGLISH COMPARISON**  
A method tells you how something is done.  
A procedure often tells you which actions to perform and in what order.

## Procedure / Set of steps
`set of steps` 是最透明的描述性改寫，但正式程度較低。

**ENGLISH COMPARISON**  
The manual gives a set of steps for resetting the device.  
A laboratory may document the same actions as a formal procedure.

## Procedure / Protocol
`protocol` 更正式，常涉及安全、醫療、研究或官方規範。

**ENGLISH COMPARISON**  
A simple office procedure may explain how to file expenses.  
A safety protocol specifies rules that must be followed.

## Procedure / Routine
`routine` 強調反覆、慣常，不一定是正式規定。

**ENGLISH COMPARISON**  
A morning routine is repeated every day.  
An emergency procedure may be used only rarely.

## Procedure / Workflow
`workflow` 特別強調工作如何在人、系統和階段之間流轉。

**ENGLISH COMPARISON**  
A procedure explains how to approve an invoice.  
A workflow shows how the invoice moves from requester to manager to finance.

## Procedure / Sequence
`sequence` 只突出先後次序，不一定包括所有規則和理由。

**ENGLISH COMPARISON**  
A shutdown sequence gives the correct order of actions.  
A shutdown procedure may also include safety checks and responsibilities.

## Procedure / Standard operating procedure
`standard operating procedure` 是更正式、更制度化的固定術語，通常有書面文件和一致執行要求。

**ENGLISH COMPARISON**  
A team may have an informal procedure for routine tasks.  
A laboratory follows a documented standard operating procedure for hazardous work.

## 練習 01.1

**Target phrase: Process · 過程；程序**

### READ THE CONTEXT · 閱讀語境

**中文翻譯**

| A | process |
| B | method |
| C | workflow |
| D | set of steps |
| E | processing |
| F | single action |

### CORRECT ANSWER · 正確答案

**A. process · 過程；程序**

> The hiring process begins with an online application and ends with a final interview.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. process ✓**

**E. processing**  
`processing`：處理；動名詞／名詞，不是本題所需的 `process` 名詞。 本句線索是「begins with ... and ends with ...，強調完整流程」；除了語義差異外，詞性、單複數、構詞或標準拼法也不符合這個空位。

# 04 Target-word / phrase contrast map

| `procedure` 真正重點 | 較精準替代表達 |
|---|---|
| 由開始到完成的整體流程 | **process** |
| 完成工作的方式 | **method** |
| 一連串明確操作 | **set of steps** |
| 正式必須遵守的專業規程 | **protocol** |
| 經常重複的慣常程序 | **routine** |
| 任務／文件／審批的工作流轉 | **workflow** |
| 動作的先後次序 | **sequence** |
| 書面標準化機構程序 | **standard operating procedure** |

# 05 高價值近義詞辨析

- **Process vs Procedure** — process 看整體進展；procedure 看如何執行。
- **Method vs Procedure** — method 是方式；procedure 通常有步驟。
- **Set of steps vs Sequence** — set of steps 是多個動作；sequence 特別強調順序。
- **Protocol vs Procedure** — protocol 更正式、更具規範性。
- **Routine vs Procedure** — routine 重點是反覆慣常；procedure 不一定經常使用。
- **Workflow vs Process** — workflow 特別看工作如何流轉；process 可以更廣。
- **Sequence vs Protocol** — sequence 是 order；protocol 是 rules。
- **Procedure vs SOP** — SOP 是 procedure 的高度標準化、書面化版本。

# 08 Grammar & structure traps

## Process
> the application process  
> a process involving several stages

## Method
常見搭配：

> a method **for** doing something  
> a method **of** doing something

## Set of steps
> a set of steps **for** resetting the device

不要把 `set` 遺漏：

> a steps ✗  
> a set of steps ✓

## Protocol
> follow a protocol  
> safety protocol  
> research protocol

## Workflow
現代標準拼法通常是一個字：

> workflow ✓  
> work flow △

## Sequence
> in the correct sequence  
> a sequence of actions

## Standard operating procedure
常縮寫為：

> SOP

單數：

> an SOP

複數：

> SOPs

# 09 核心決策問題

1. 想說完整流程？ → **process**
2. 想說採用哪種做法？ → **method**
3. 想清楚寫成一套逐步操作？ → **set of steps**
4. 專業領域正式規範？ → **protocol**
5. 每天／每週反覆的慣例？ → **routine**
6. 任務在部門／系統之間如何流轉？ → **workflow**
7. 重點只是先後次序？ → **sequence**
8. 機構書面標準化程序？ → **standard operating procedure**

# 10 Final note for system use

核心替代表達：

`process / method / set of steps / protocol / routine / workflow / sequence / standard operating procedure`

尤其要記住：

> **process** = 整體流程  
> **method** = 方法  
> **set of steps** = 一套步驟  
> **protocol** = 正式規程  
> **routine** = 例行慣例  
> **workflow** = 工作流轉  
> **sequence** = 先後次序  
> **SOP** = 標準化書面程序
