# SYNONYMS · 同義詞學習系統

# Duty

**「職責／責任／義務／任務」，究竟是在說一般責任、必須履行的義務、被指派的工作、制度職能，還是重要使命？**

核心替代表達：

`responsibility / obligation / task / role / assignment / function / charge / commitment / requirement / chore / mission`

> **核心原則**
>
> 真正要判斷的是：
>
> **Is the duty a responsibility you are accountable for, an obligation you must fulfil, a specific task, an assigned job, an institutional function, a long-term commitment, or a mission?**

---

# 01 同義詞指南

## 01 Responsibility

**責任；職責**

最接近的廣義近義詞之一，強調某人應負責處理、照顧或確保完成的事情。

---

## 02 Obligation

**義務；責任**

當 `duty` 強調法律、道德、合約或社會規範要求某人必須做某事時，`obligation` 很精準。

---

## 03 Task

**任務；工作**

當 `duty` 指一項具體要完成的工作，而不是較抽象的責任時，`task` 很自然。

---

## 04 Role

**角色；職能**

當 `duty` 指某人在團隊、機構或制度中應扮演的角色及其職責範圍時，`role` 很合適。

---

## 05 Assignment

**指派工作；任務**

當 `duty` 是由上司、老師、機構等正式分配的一項工作時，`assignment` 很精準。

---

## 06 Function

**職能；功能**

當 `duty` 指某職位、部門或制度應執行的正式職能時，`function` 很自然。

---

## 07 Charge

**責任；照管；受託事項**

較正式，表示被交託照管某人、某事或某範疇的責任，常見 `in someone's charge` / `take charge of`。

---

## 08 Commitment

**承諾；責任承擔**

當 `duty` 帶有已作出承諾、需要持續投入時間或精力的意味時，`commitment` 很自然。

---

## 09 Requirement

**要求；必須履行的事項**

當 `duty` 被制度、規則、職位或程序明確列為必須完成的要求時，`requirement` 很精準。

---

## 10 Chore

**例行雜務；家務**

當 `duty` 指日常、重複而實際的小工作，尤其家務或例行雜務時，`chore` 很自然。

---

## 11 Mission

**使命；任務**

當 `duty` 指一項重要、具明確目的、需要完成的任務或使命時，`mission` 很自然，語氣通常比 task 更重大。

---

# 02 False synonyms

## Duty / Responsibility
兩者高度接近；`responsibility` 最廣，強調對事情或結果負責。

## Duty / Obligation
`obligation` 更強調 legal / moral / contractual requirement。

**ENGLISH COMPARISON**  
A responsibility is something you are expected to take care of. An obligation is something you are required to do.

## Duty / Task
`task` 是具體可完成的工作；`duty` 可以是長期、抽象的職責。

## Duty / Role
`role` 是在團隊／制度中的定位與作用；不是每一項 role 都是一個單獨 duty。

## Duty / Assignment
`assignment` 帶有「被某人／機構指派」的意味。

## Duty / Function
`function` 特別適合部門、職位、制度的正式作用。

## Duty / Commitment
`commitment` 強調持續投入／承諾，不等於所有 duty。

## Duty / Chore
`chore` 偏日常重複雜務；正式職責或法律義務不能一律叫 chore。

# 03 練習與解釋

> 每個目標詞三題，共 **33 題**。  
> 每題六個選項；答案位置分散於 **A–F**。  
> 每個錯誤選項均按 **詞義 → 一般用途 → 為甚麼在這一句不合** 個別解釋。

## 練習 01.1

**Target word: Responsibility · 責任；職責**

### READ THE CONTEXT · 閱讀語境

> It is the manager's duty to ensure the team follows safety rules.

**中文翻譯**

確保團隊遵守安全規則是經理的責任。

| | 選項 |
|---|---|
| A | Obligation |
| B | Role |
| C | Responsibility |
| D | Task |
| E | Privilege |
| F | Choice |

### CORRECT ANSWER · 正確答案

**C. Responsibility · 責任；職責**

> It is the manager's responsibility to ensure the team follows safety rules.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. Obligation**  
`obligation`：obligation = 義務；強調法律、道德、合約或社會要求必須履行。 它需要某種 must / legal / moral / contractual 壓力；「對結果負責」若只是一般工作安排或角色，會太強。

**B. Role**  
`role`：role = 角色／職能；某人在團隊或制度中的定位與作用。 它描述人在團隊／制度中的定位；「對結果負責」若是具體被指派工作、法律義務或照管責任，並不相同。

**C. Responsibility ✓**  
`Responsibility` = 責任；職責。本句關鍵線索是 **對結果負責**；這正好對應 `Responsibility` 的責任來源、工作範圍或義務程度，因此最精準。

**D. Task**  
`task`：task = 任務／工作；一項具體可完成的工作。 「對結果負責」若是長期責任、制度職能或義務，而不是單一可完成工作，task 會太窄。

**E. Privilege**  
`Privilege`：privilege = 特權／榮幸；不是責任。 本句「對結果負責」談的是必須履行／負責的事項，而這個詞偏權利、選擇或許可，方向不同。

**F. Choice**  
`Choice`：choice = 選擇；表示可自行決定，不是必須履行。 本句「對結果負責」談的是必須履行／負責的事項，而這個詞偏權利、選擇或許可，方向不同。

# 05 高價值近義詞辨析

- **Duty vs Responsibility** — responsibility 最廣，偏 accountability。
- **Duty vs Obligation** — obligation 更突出 must / legal / moral force。
- **Duty vs Task** — task 是具體工作；duty 可較長期、抽象。
- **Duty vs Role** — role 是定位；duty 是應履行的責任。
- **Task vs Assignment** — assignment 特別有「被指派」意味。
- **Role vs Function** — role 常用於人；function 常用於職位／部門／制度。
- **Responsibility vs Charge** — charge 特別強調受託照管或掌管。
- **Obligation vs Requirement** — obligation 是人所承擔的義務；requirement 是規則本身提出的要求。
- **Duty vs Commitment** — commitment 加入持續投入／承諾意味。
- **Task vs Chore** — chore 通常日常、重複，而且往往不太吸引人。
- **Task vs Mission** — mission 通常更重要、更有明確目的。

# 08 Grammar & structure traps

- `a duty to do something`
- `a responsibility for something`
- `an obligation to do something`
- `a task to complete`
- `a role in a team`
- `an assignment from a supervisor`
- `the function of a department`
- `in someone's charge`
- `a commitment to do something`
- `a requirement for entry`
- `household chores`
- `a mission to protect / rescue / restore`

注意：

> **on duty** = 當值  
> **off duty** = 非當值

以及：

> **duty** ≠ **right**

A duty is something you are expected or required to do; a right is something you are entitled to have or do.

# 09 核心決策問題

1. 是一般責任／對結果負責？ → **responsibility**
2. 是法律／道德／合約必須履行？ → **obligation**
3. 是一項具體工作？ → **task**
4. 是團隊／制度中的角色？ → **role**
5. 是被上司／機構指派？ → **assignment**
6. 是部門／職位的正式作用？ → **function**
7. 是受託照管某人／某事？ → **charge**
8. 是長期承諾／持續投入？ → **commitment**
9. 是規則列明的必須要求？ → **requirement**
10. 是日常重複小工作？ → **chore**
11. 是重要、有明確目的的任務？ → **mission**

# 10 Final note for system use

核心替代表達：

`responsibility / obligation / task / role / assignment / function / charge / commitment / requirement / chore / mission`

最重要的 near-miss：

`right / privilege / choice / permission / job / reward / benefit`

真正的選詞依據是：

> **Is “duty” a responsibility, an obligation, a concrete task, an assigned piece of work, an institutional function, a commitment, or an important mission?**
