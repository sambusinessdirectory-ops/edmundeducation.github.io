# FACTOR — Complete Synonym Lesson

## 01 同義詞指南

### Factor 的 8 種更精準說法

> Note: “factor” can mean **a consideration in a decision, an element within a whole, an influence on behavior, a determinant of an outcome, a structural component, a research variable, a driver of change, or one contributing cause among several**.
> 「factor」可以表示 **決策中的考慮因素、整體中的要素、影響行為的因素、決定結果的因素、結構中的組成部分、研究變數、推動變化的力量，或多個成因中的其中一項**。以下按這些語境區分。

### 01 Consideration
**考慮因素；需要考慮的事項**

當 factor 指作決定、計劃或評估時需要納入考慮的一項事情，可用 consideration。重點是『決策時要考慮甚麼』。

**EXAMPLE · 例句**  
Cost is an important consideration when choosing a university.  
選擇大學時，費用是一個重要考慮因素。

---

### 02 Element
**要素；元素；構成因素**

當 factor 指某個整體中不可忽視的一項要素或特徵時，可用 element。它比 component 更抽象，可指信任、風格、風險等非物理成分。

**EXAMPLE · 例句**  
Trust is a key element of a successful partnership.  
信任是成功合作關係的一個關鍵要素。

---

### 03 Influence
**影響因素；影響力**

當 factor 強調某人、某事或環境對結果、行為或決定產生影響時，可用 influence。

**EXAMPLE · 例句**  
Family background can be a strong influence on career choices.  
家庭背景可以對職業選擇產生很大影響。

---

### 04 Determinant
**決定因素；決定性因素**

較正式，指對結果具有強烈決定作用的因素。常見於經濟、醫療、社會科學和正式分析。

**EXAMPLE · 例句**  
Access to education is a major determinant of long-term opportunity.  
接受教育的機會是長遠發展機會的重要決定因素。

---

### 05 Component
**組成部分；構成成分**

當 factor 指一個系統、計劃、產品或整體中的具體組成部分時，可用 component。它比 element 更偏結構性。

**EXAMPLE · 例句**  
Training is one component of the wider safety program.  
培訓是整體安全計劃的一個組成部分。

---

### 06 Variable
**變數；可變因素**

常見於研究、實驗、統計和模型，指可能改變、可被測量，並可能影響結果的一項因素。

**EXAMPLE · 例句**  
Temperature was the only variable changed during the experiment.  
溫度是實驗中唯一被改變的變數。

---

### 07 Driver
**推動因素；主要驅動力**

常用於商業、經濟、政策和趨勢分析，指推動增長、變化、需求或行為的主要力量。

**EXAMPLE · 例句**  
Consumer demand is a major driver of economic growth.  
消費需求是經濟增長的一個主要推動力。

---

### 08 Contributing Cause
**促成原因；成因之一**

當 factor 指造成某個結果的其中一項原因、但不是唯一原因時，可用 contributing cause。適合事故、問題、疾病或失敗分析。

**EXAMPLE · 例句**  
Fatigue was identified as a contributing cause of the accident.  
疲勞被認定為事故的一項促成原因。

---

## 02 False synonyms

### 看起來相關，意思卻不同

### 01 Fact
**事實不等於一般的 factor**

**fact = 事實**

fact 是已知或可證實的資訊；factor 是會影響、構成或需要考慮的一項因素。

**ENGLISH COMPARISON**  
A fact is information; a factor contributes to a situation or result.

---

### 02 Reason
**理由；原因不等於一般的 factor**

**reason = 理由；原因**

reason 有時和 factor 重疊，但 reason 通常直接回答 why；factor 可以只是影響結果的其中一項條件。

**ENGLISH COMPARISON**  
A reason explains why; a factor may be only one influence among several.

---

### 03 Result
**結果不等於一般的 factor**

**result = 結果**

result 是因素作用之後產生的結果，方向和 factor 不同。

**ENGLISH COMPARISON**  
Factors affect a result; the result is the outcome.

---

### 04 Effect
**影響；結果不等於一般的 factor**

**effect = 影響；結果**

effect 通常是某原因或因素所造成的後果，不是造成結果的 factor 本身。

**ENGLISH COMPARISON**  
A factor can cause an effect.

---

### 05 Feature
**特徵不等於一般的 factor**

**feature = 特徵**

feature 是某人或某物具有的特點。某個 feature 可能成為考慮因素，但 feature 本身不等於 factor。

**ENGLISH COMPARISON**  
A feature describes something; a factor influences or contributes to an outcome.

---

### 06 Criterion
**標準；準則不等於一般的 factor**

**criterion = 標準；準則**

criterion 是用來判斷、評估或選擇的標準。它可以成為 consideration，但不是所有 factors 都是正式評分準則。

**ENGLISH COMPARISON**  
A criterion is a standard for judgment; a factor is any relevant influence or consideration.

---

### 07 Factorial
**階乘的；因子的不等於一般的 factor**

**factorial = 階乘的；因子的**

factorial 是數學或統計相關形容詞／名詞，例如 5!，不是 factor 的一般同義詞。

**ENGLISH COMPARISON**  
A factor affects a result; factorial is a mathematical term.

---

### 08 Actor
**演員；行動者不等於一般的 factor**

**actor = 演員；行動者**

actor 拼寫和 factor 相近，但意思完全不同。它可指演員或在某系統中採取行動的參與者。

**ENGLISH COMPARISON**  
An actor performs or acts; a factor influences an outcome.

---

# 01 Consideration · 考慮因素；需要考慮的事項

## 練習 01.1

**Target word: Consideration · 考慮因素；需要考慮的事項**

### READ THE CONTEXT · 閱讀語境

Price is an important factor when families decide which apartment to rent.

### 中文翻譯

家庭決定租哪個單位時，價格是一個重要考慮因素。

A. consideration
B. component
C. influence
D. variable
E. determinant
F. driver

### CORRECT ANSWER · 正確答案

**consideration · 考慮因素；需要考慮的事項**

Price is an important consideration when families decide which apartment to rent.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. consideration ✓**  
consideration = 考慮因素。when families decide which apartment to rent 明確表示 price 是作決定時需要考慮的一項事情。

**B. component**  
component = 組成部分。價格不是公寓本身的一個物理或結構組件。

**C. influence**  
influence = 影響因素。價格確實會影響決定，但本句特別強調『決定時要考慮甚麼』，consideration 更精準。

**D. variable**  
variable = 變數。較常用於研究、數據或可變條件，不適合一般租屋決策。

**E. determinant**  
determinant = 決定因素。語氣較強，暗示它直接決定結果；本句只說是重要考量之一。

**F. driver**  
driver = 推動因素。通常表示推動趨勢或變化，不是作選擇時的一項考慮。

# 05 Component · 組成部分；構成成分

## 練習 05.1

**Target word: Component · 組成部分；構成成分**

### READ THE CONTEXT · 閱讀語境

Staff training is one factor of the company's wider safety program.

### 中文翻譯

員工培訓是公司整體安全計劃的一個組成部分。

A. component
B. influence
C. consideration
D. determinant
E. variable
F. driver

### CORRECT ANSWER · 正確答案

**component · 組成部分；構成成分**

Staff training is one component of the company's wider safety program.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. component ✓**  
component = 組成部分。one ... of the wider safety program 明確表示 training 是整個計劃中的一部分。

**B. influence**  
influence = 影響。不是說 training 如何影響 program，而是 program 由哪些部分構成。

**C. consideration**  
consideration = 考慮因素。沒有決策語境。

**D. determinant**  
determinant = 決定因素。沒有說 training 決定安全結果。

**E. variable**  
variable = 變數。不是研究模型。

**F. driver**  
driver = 推動因素。不是在說促使安全改善的原因。

# 06 Variable · 變數；可變因素

**Target word: Variable · 變數；可變因素**

### READ THE CONTEXT · 閱讀語境

In the experiment, temperature was the only factor deliberately changed by the researchers.

在實驗中，溫度是研究人員唯一刻意改變的變數。

A. variable
B. determinant
C. component
D. consideration
E. driver
F. element

### CORRECT ANSWER · 正確答案

**variable · 變數；可變因素**

In the experiment, temperature was the only variable deliberately changed by the researchers.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. variable ✓**  
variable = 變數。experiment + deliberately changed 是最典型的 experimental variable 語境。

**B. determinant**  
determinant = 決定因素。可能影響結果，但不代表它就是被操控的實驗變數。

**C. component**  
component = 組成部分。溫度不是實驗設備的一部分。

**D. consideration**  
consideration = 考慮因素。不是決策。

**E. driver**  
driver = 推動因素。不是趨勢或變化的推動力。

**F. element**  
element = 要素。太廣，沒有實驗測量含義。

統計模型把年齡、收入和教育程度列作不同變數。

A. determinants
B. variables
C. components
D. considerations
E. drivers
F. elements

### CORRECT ANSWER · 正確答案

**variables · 變數；可變因素**

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. determinants**  
determinants = 決定因素。模型可能最後顯示某些是 determinants，但單純被納入模型時先稱 variables 更準確。

**B. variables ✓**  
variables = 變數。statistical model + age, income, education 是最典型的研究變數列表。

**C. components**  
components = 組成部分。它們不是模型的軟件或結構部件。

**D. considerations**  
considerations = 考慮因素。不是人作決策時的考量。

**E. drivers**  
drivers = 推動因素。未經分析不能假定它們都推動結果。

**F. elements**  
elements = 要素。過於籠統，失去統計語境的精確性。

# 08 Contributing Cause · 促成原因；成因之一

## 練習 08.1

**Target word: Contributing Cause · 促成原因；成因之一**

### READ THE CONTEXT · 閱讀語境

Investigators found that poor visibility was one factor that helped cause the collision.

### 中文翻譯

調查人員發現，能見度低是促成碰撞的一項原因。

A. contributing cause
B. consideration
C. component
D. variable
E. element
F. driver

### CORRECT ANSWER · 正確答案

**contributing cause · 促成原因；成因之一**

Investigators found that poor visibility was a contributing cause of the collision.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. contributing cause ✓**  
contributing cause = 促成原因。one factor that helped cause the collision 明確表示它是多個成因之一。

**B. consideration**  
consideration = 考慮因素。事故不是因為有人作選擇時考慮能見度。

**C. component**  
component = 組成部分。能見度不是 collision 的構件。

**D. variable**  
variable = 變數。除非在研究模型中，否則不如 cause 準確。

**E. element**  
element = 要素。太模糊，沒有因果含義。

**F. driver**  
driver = 推動因素。多用於趨勢和增長，不常描述交通事故成因。
