# SYNONYMS · 同義詞學習系統

# Exist

**「存在」，究竟是在說某物在某地方存在、真實存在、某現象出現、仍然存在，還是生物繼續存活？**

核心替代表達：

`be present / be real / occur / be found / remain / survive / live / subsist / have existence / exist in reality`

> **核心原則**
>
> `exist` 很廣。`be present` 偏位置／存在狀態；`be real` 偏真實性；`occur` 偏現象出現；`remain` 偏持續；`survive/live` 偏生命或存續。

---

# 01 同義詞指南

## 01 Be present

**存在；在場；出現**

表示某物實際存在於某地方、系統或情況中。

---

## 02 Be real

**是真實的；確實存在**

強調某物並非虛構、想像或幻覺。

---

## 03 Occur

**發生；出現**

常用於現象、問題、差異或事件出現。

---

## 04 Be found

**可見於；存在於**

強調某物可在某地、某群體或某資料中找到。

---

## 05 Remain

**仍然存在；繼續存在**

強調某物之前已存在，而且現在仍存在。

---

## 06 Survive

**存續；倖存**

強調經過時間、危險或破壞後仍然存在。

---

## 07 Live

**生存；活着**

最自然地用於人或生物活着、生活。

---

## 08 Subsist

**維持生存**

較正式，強調靠有限資源維持生存。

---

## 09 Have existence

**具有存在性**

非常正式、抽象，常見於哲學或邏輯討論。

---

## 10 Exist in reality

**現實中存在**

強調現實存在，常和想像、虛構或理論對比。

---

# 02 False synonyms

## Exist / Be present
`be present` 特別適合某物存在於某地方／系統／樣本中。

## Exist / Be real
`be real` 要有真實 vs 虛構／想像的對比。

## Exist / Occur
`occur` 常用於現象、錯誤、問題、差異或事件出現。

## Exist / Remain
`remain` 加入「之前已存在，現在仍然存在」的時間含義。

## Exist / Survive
`survive` 通常暗示經過危險、破壞或時間後仍存在。

## Exist / Live
`live` 主要用於人和其他生物。

## Exist / Appear
`appear` 只表示出現／看起來，不代表持續存在。

## Exist / Exist in reality
`exist in reality` 更明確和想像／理論作對比。

# 03 練習與解釋

> 每個目標詞三題，共 **30 題**。  
> 每題六個選項；正確答案位置平均分散在 **A–F**。  
> 每個錯誤選項均按 **詞義 → 一般用途 → 為甚麼在這一句不合** 個別解釋。

## 練習 01.1

**Target word/phrase: Be present · 存在；在場；出現**

### READ THE CONTEXT · 閱讀語境

> Small traces of the chemical exist in the water.

**中文翻譯**

水中存在微量這種化學物。

| | 選項 |
|---|---|
| A | Be found |
| B | Occur |
| C | Be present |
| D | Remain |
| E | Be absent |
| F | Disappear |

### CORRECT ANSWER · 正確答案

**C. Be present · 存在；在場；出現**

> Small traces of the chemical are present in the water.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. Be found**  
`Be found`：強調某物可在某地、某群體或某資料中找到。 本句關鍵是「存在於某介質中」；這個詞所強調的存在方式、時間延續、真實性或生命狀態與本句不同，因此不是最精準答案。

**C. Be present ✓**  
`Be present` = 存在；在場；出現。本句關鍵線索是 **存在於某介質中**；這正好對應 `Be present` 的存在方式、時間延續、真實性或生命狀態，因此最精準。

**Target word/phrase: Exist in reality · 現實中存在**

### READ THE CONTEXT · 閱讀語境

> The creature appears in stories but does not exist.

**中文翻譯**

這種生物出現在故事中，但現實中並不存在。

| | 選項 |
|---|---|
| A | Be real |
| B | Have existence |
| C | Be present |
| D | Imagine |
| E | Exist in reality |
| F | Appear |

### CORRECT ANSWER · 正確答案

**E. Exist in reality · 現實中存在**

> The creature appears in stories but does not exist in reality.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. Be real**  
`Be real`：強調某物並非虛構、想像或幻覺。 本句關鍵是「和故事虛構對比」；這個詞所強調的存在方式、時間延續、真實性或生命狀態與本句不同，因此不是最精準答案。

**B. Have existence**  
`Have existence`：非常正式、抽象，常見於哲學或邏輯討論。 本句關鍵是「和故事虛構對比」；這個詞所強調的存在方式、時間延續、真實性或生命狀態與本句不同，因此不是最精準答案。

**C. Be present**  
`Be present`：表示某物實際存在於某地方、系統或情況中。 本句關鍵是「和故事虛構對比」；這個詞所強調的存在方式、時間延續、真實性或生命狀態與本句不同，因此不是最精準答案。

**D. Imagine**  
`imagine`：想像，不是實際存在。 本句「和故事虛構對比」需要實際存在，而 imagine 只表示在腦中想像。

**E. Exist in reality ✓**  
`Exist in reality` = 現實中存在。本句關鍵線索是 **和故事虛構對比**；這正好對應 `Exist in reality` 的存在方式、時間延續、真實性或生命狀態，因此最精準。

**F. Appear**  
`appear`：出現／看起來；不一定等於持續存在。 本句「和故事虛構對比」要求存在狀態；appear 只表示出現或看起來如此。

# 04 Target-phrase contrast map

| `exist` 真正重點 | 較精準替代表達 |
|---|---|
| 某物在某處／系統中存在 | **be present** |
| 並非虛構、確實真實 | **be real** |
| 某現象／問題出現 | **occur** |
| 某物可在某地找到 | **be found** |
| 經時間後仍存在 | **remain** |
| 經危險／時間後存續 | **survive** |
| 人／生物活着、棲息 | **live** |
| 靠有限資源維持生存 | **subsist** |
| 抽象／哲學上的存在性 | **have existence** |
| 和想像／理論對比的現實存在 | **exist in reality** |

# 05 高價值近義詞辨析

- **Exist vs Be present** — be present 偏位置／狀態。
- **Exist vs Be real** — be real 偏真實性。
- **Exist vs Occur** — occur 偏現象／問題出現。
- **Exist vs Be found** — be found 偏分布／可找到。
- **Exist vs Remain** — remain 明確加入「仍然」。
- **Exist vs Survive** — survive 暗示經過威脅／時間後存續。
- **Exist vs Live** — live 最適合有生命的主語。
- **Live vs Subsist** — subsist 更強調最低限度維持生活。
- **Be real vs Exist in reality** — 後者更明確和虛構／理論作對比。

# 06 Common expressions · 常用表達

- **exist in nature** — 存在於自然界

# 08 Grammar & structure traps

- `exist in a place`
- `exist among a population`
- `be present in a sample`
- `occur in older systems`
- `be found in nature`
- `remain after the change`
- `survive for centuries`
- `live in forests`
- `subsist on very little`

注意：

> `The problem exists.` ✓  
> `The problem is existing.` ✗（一般情況）

# 09 核心決策問題

1. 在某地方／樣本中存在？ → **be present**
2. 強調是真的、不是想像？ → **be real**
3. 現象／問題在某情況下出現？ → **occur**
4. 某物可在某地找到？ → **be found**
5. 強調仍然存在？ → **remain**
6. 經過時間／危險後仍存續？ → **survive**
7. 主語是人／生物，表示活着？ → **live**
8. 靠有限資源維持生活？ → **subsist**
9. 哲學／抽象存在性？ → **have existence**
10. 和虛構／理論作對比？ → **exist in reality**

# 10 Final note for system use

核心替代表達：

`be present / be real / occur / be found / remain / survive / live / subsist / have existence / exist in reality`

最重要的 near-miss：

`appear / develop / imagine / disappear / die`

真正的選詞依據是：

> **Does “exist” mean be present, be real, occur, be found, remain, survive, live, or have existence in an abstract sense?**
