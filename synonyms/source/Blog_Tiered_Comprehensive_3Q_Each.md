# BLOG · 分層同義詞學習系統

## Blog

**「網誌／網上日誌」，這個詞本身已非常精準，因此不應為了數量而硬塞大量『同義詞』。**

本單元集中處理 **blog = a regularly updated website or section of a website containing posts, articles, reflections, commentary, or diary-style entries**。你提供的 **online journal; web log; personal website** 很好地指出三個方向：**直接名稱（online journal / weblog）**、**日誌式內容（online diary / web journal）**、以及**較廣的網站／出版形式（personal website / online publication）**。

這次刻意保留 **12 個**真正有教學價值的詞／表達，而不是硬湊 14 個。其中 **personal website / online publication / web publication** 會清楚標示為較廣義的語境替代，而非假裝與 blog 完全同義。

每項均包含 **核心語義、語域、用法提示、常見搭配、搭配對象、與 blog 的直接辨析、使用限制、例句及翻譯**；每個目標詞／表達設 **3 道題**，每題六個選項均有完整、逐題的情境化解釋。

## Tier 1 — Close synonyms / transparent equivalents · 核心近義詞與直接改寫

### 01 Online journal

**Tier**：1  
**中文**：網上日誌；網上期刊式網誌  
**語域**：neutral / common  
**核心語義**：a regularly updated online publication containing dated entries or articles  
**用法提示**：和 blog 最自然的解釋性替代之一，尤其當網誌以個人反思、經驗記錄或定期文章為主。  
**常見搭配**：personal online journal; travel online journal; keep an online journal; write an online journal; regular online journal.  
**常見搭配對象**：personal reflections, travel, study, hobbies, professional updates.  
**與 blog 的辨析**：Blog 是最常用的現代名稱；online journal 更描述性，也較容易令人聯想到日誌式內容。  
**使用限制**：不要把 academic online journal（網上學術期刊）和 blog 混為一談；語境必須清楚。

**EXAMPLE · 例句**  
She keeps an online journal about studying abroad.  
她寫了一個關於海外留學生活的網上日誌。

### 02 Weblog

**Tier**：1  
**中文**：網誌；網絡日誌  
**語域**：neutral / dated but standard  
**核心語義**：the original full form from which the word blog developed  
**用法提示**：語義上和 blog 極接近，是歷史上較完整的名稱。  
**常見搭配**：personal weblog; maintain a weblog; weblog entry; weblog archive; company weblog.  
**常見搭配對象**：personal site, commentary, diary-style posts, organisation updates.  
**與 blog 的辨析**：WeBlog/weblog 與 blog 幾乎同義，但現代日常英語通常直接說 blog。  
**使用限制**：現在比 blog 少見，可能帶早期互聯網語感。

**EXAMPLE · 例句**  
The researcher maintained a weblog documenting the project.  
研究員維護一個網誌，記錄該項目。

### 03 Web log

**Tier**：1  
**中文**：網絡日誌；網誌  
**語域**：neutral / explanatory  
**核心語義**：a log or journal published on the web  
**用法提示**：是 weblog 的分寫形式，可用作透明解釋，但現代實際用法較少。  
**常見搭配**：personal web log; keep a web log; web log entry; project web log; daily web log.  
**常見搭配對象**：project record, personal diary, commentary, updates.  
**與 blog 的辨析**：意思和 weblog/blog 接近，但 web log 作兩字形式現在較少見。  
**使用限制**：不要和 technical web/server log（網站伺服器記錄）混淆。

**EXAMPLE · 例句**  
They created a web log to record progress on the expedition.  
他們建立網絡日誌，記錄探險進度。

### 04 Web journal

**Tier**：1  
**中文**：網上日誌；網絡期刊式網誌  
**語域**：neutral / descriptive  
**核心語義**：a journal-style publication hosted on the web  
**用法提示**：當 blog 以持續記錄、評論或較完整文章為主時可自然改寫。  
**常見搭配**：personal web journal; travel web journal; maintain a web journal; web journal entries; regular web journal.  
**常見搭配對象**：travel, personal reflection, study, professional commentary.  
**與 blog 的辨析**：Web journal 是描述性名稱；blog 更自然、更普及。  
**使用限制**：和 online journal 一樣，要避免讓人誤解成正式學術期刊。

**EXAMPLE · 例句**  
His web journal follows life in several remote communities.  
他的網上日誌記錄多個偏遠社區的生活。

### 05 Online diary

**Tier**：1  
**中文**：網上日記  
**語域**：neutral / common  
**核心語義**：a personal online record of experiences, thoughts, or daily life  
**用法提示**：當 blog 明確是私人生活、旅遊、心情或日常經歷記錄時很接近。  
**常見搭配**：personal online diary; travel diary; keep an online diary; daily online diary; photo diary.  
**常見搭配對象**：daily life, travel, feelings, personal experience.  
**與 blog 的辨析**：Online diary 比 blog 更私人、更日記化；很多 blog 並不是 diary。  
**使用限制**：新聞、企業、技術或專業分析型 blog 通常不叫 online diary。

**EXAMPLE · 例句**  
The blog began as an online diary of her first year at university.  
這個網誌最初是她大學一年級生活的網上日記。

## Tier 2 — Broadly usable contextual equivalents · 廣泛可用的語境近義表達

### 06 Personal blog

**Tier**：2  
**中文**：個人網誌  
**語域**：neutral / very common  
**核心語義**：a blog mainly written by an individual about their own interests, experiences, or views  
**用法提示**：當 blog 的作者和內容以個人為核心時，personal blog 是最精準的具體化說法。  
**常見搭配**：write a personal blog; run a personal blog; personal blog post; popular personal blog; start a personal blog.  
**常見搭配對象**：lifestyle, travel, study, opinion, hobbies.  
**與 blog 的辨析**：Personal blog 是 blog 的一種，不是所有 blog 都是 personal blog。  
**使用限制**：公司、新聞機構、團體網誌不應改成 personal blog。

**EXAMPLE · 例句**  
She started a personal blog about books and everyday life.  
她開設個人網誌，分享書籍和日常生活。

### 07 Blog site

**Tier**：2  
**中文**：網誌網站  
**語域**：neutral / common  
**核心語義**：a website whose main purpose is to host a blog or collection of blog posts  
**用法提示**：當句子強調 blog 作為網站而非單篇內容時很實用。  
**常見搭配**：personal blog site; company blog site; visit a blog site; launch a blog site; blog site archive.  
**常見搭配對象**：website, archive, posts, author page.  
**與 blog 的辨析**：Blog 可指整個網站，也可指內容／網誌本身；blog site 明確指網站。  
**使用限制**：如果句子說的是一篇 blog post，不可改成 blog site。

**EXAMPLE · 例句**  
The organisation launched a blog site for weekly updates.  
該機構推出網誌網站，每週發布更新。

### 08 Journal-style website

**Tier**：2  
**中文**：日誌式網站；期刊式網站  
**語域**：neutral / descriptive  
**核心語義**：a website organised around dated journal-like entries  
**用法提示**：當不想直接用 blog，而又要描述其按日期發布文章的網站形式時很有用。  
**常見搭配**：personal journal-style website; a journal-style site; regular dated entries; journal-style posts; maintain a journal-style website.  
**常見搭配對象**：personal writing, travel, commentary, project updates.  
**與 blog 的辨析**：這是描述 blog 形式的短語，而不是固定詞典同義詞。  
**使用限制**：若網站沒有日誌／文章更新結構，就不適合。

**EXAMPLE · 例句**  
The project uses a journal-style website to publish weekly reflections.  
該項目使用日誌式網站發布每週反思。

### 09 Personal website

**Tier**：2  
**中文**：個人網站  
**語域**：neutral / very common  
**核心語義**：a website created or maintained by an individual, which may contain a blog  
**用法提示**：當 blog 幾乎構成某人的整個個人網站時，可作較寬的語境替代。  
**常見搭配**：personal website; run a personal website; personal website with a blog; author's website; maintain a website.  
**常見搭配對象**：profile, portfolio, blog, biography, personal content.  
**與 blog 的辨析**：Personal website 比 blog 範圍更廣：它可包含履歷、作品集、聯絡資料而完全沒有 blog。  
**使用限制**：因此它只能算廣義語境近義詞，不能普遍替換 blog。

**EXAMPLE · 例句**  
Her personal website contains essays, travel notes and regular updates.  
她的個人網站載有文章、旅遊札記和定期更新。

## Tier 3 — Publishing-style variants · 發布形式與較廣義變體

### 10 Online publication

**Tier**：3  
**中文**：網上刊物；網上出版物  
**語域**：neutral / formal  
**核心語義**：material or a publication released online for readers  
**用法提示**：當 blog 較正式、編輯化，或持續發布文章給公眾閱讀時可作較廣義替代。  
**常見搭配**：independent online publication; regular online publication; digital publication; publish online; online publication platform.  
**常見搭配對象**：articles, commentary, reviews, professional content.  
**與 blog 的辨析**：Online publication 是上位詞；blog 只是其中一種形式。  
**使用限制**：個人隨筆式小型 blog 若稱 online publication，可能顯得過正式。

**EXAMPLE · 例句**  
The blog grew into an independent online publication with several writers.  
這個網誌發展成由多名作者撰稿的獨立網上刊物。

### 11 Web publication

**Tier**：3  
**中文**：網站刊物；網絡出版物  
**語域**：neutral / descriptive  
**核心語義**：a publication distributed primarily through the web  
**用法提示**：和 online publication 接近，在描述較成熟、文章導向的 blog 時可用。  
**常見搭配**：independent web publication; web publication archive; publish a web publication; professional web publication; regular web publication.  
**常見搭配對象**：articles, commentary, reviews, specialist writing.  
**與 blog 的辨析**：Web publication 強調網上發布媒介，而 blog 更具按篇更新、時間排序的典型形式。  
**使用限制**：不是所有 web publication 都是 blog。

**EXAMPLE · 例句**  
What began as a blog is now a specialist web publication.  
最初只是一個網誌，現在已成為專業網絡刊物。

### 12 Digital journal

**Tier**：3  
**中文**：數碼日誌；電子期刊式刊物  
**語域**：neutral / formal  
**核心語義**：a journal-like publication produced in digital form  
**用法提示**：當 blog 有較正式、定期、長篇文章或反思記錄風格時可近似。  
**常見搭配**：personal digital journal; digital journal entries; maintain a digital journal; research digital journal; independent digital journal.  
**常見搭配對象**：reflection, research notes, personal writing, long-form entries.  
**與 blog 的辨析**：Digital journal 比 blog 更正式，也可能令人聯想到電子學術期刊。  
**使用限制**：在學術語境尤其容易歧義，必須看上下文。

**EXAMPLE · 例句**  
The site functions as a digital journal for the design team.  
該網站作為設計團隊的數碼日誌。

## 04 False synonyms / scope traps · 容易誤選的詞與範圍陷阱

### 01 Blog post

**網誌文章不等於整個 blog**  
blog post 是網誌中的單篇文章；blog 是整個網誌／網站或持續發布的內容集合。

**ENGLISH COMPARISON**  
A blog contains blog posts; one post is not the whole blog.

### 02 Website

**網站過於寬泛**  
website 可以是商店、銀行、學校、搜尋器或任何網站；blog 只是其中一種網站／內容形式。

**ENGLISH COMPARISON**  
Every blog may be hosted on a website, but most websites are not blogs.

### 03 Personal website

**個人網站不一定是 blog**  
personal website 可包含履歷、作品集、聯絡資料或相簿；只有以定期文章為主時才和 blog 接近。

**ENGLISH COMPARISON**  
A personal website may contain a blog without itself being primarily a blog.

### 04 Forum

**論壇不等於網誌**  
forum 以多名使用者討論串和回覆為核心；blog 通常由一名或少數作者發布主要文章。

**ENGLISH COMPARISON**  
A forum is discussion-led; a blog is usually post-led.

### 05 Social-media account

**社交媒體帳戶不等於 blog**  
社交媒體可以發布短文和更新，但其平台結構、追蹤機制和內容形式不同。

**ENGLISH COMPARISON**  
A social-media account may share posts, but it is not normally called a blog.

### 06 News site

**新聞網站不等於 blog**  
news site 主要發布新聞報道；blog 可以評論、記錄或分享專門內容。

**ENGLISH COMPARISON**  
A news site may host blogs, but the whole news site is not necessarily a blog.

### 07 Journal

**journal 有多個意思**  
journal 可以是私人日記，也可以是正式學術期刊；只有特定語境才接近 blog。

**ENGLISH COMPARISON**  
An academic journal is a scholarly publication, not simply a blog.

### 08 Web page

**網頁不等於網誌**  
web page 是網站中的單一頁面；blog 通常由多篇文章和頁面組成。

**ENGLISH COMPARISON**  
A web page is one page; a blog is typically an ongoing collection of posts.

## 05 練習與解釋 · Practice

### 練習 01.1

**Tier 1 · Target word / phrase**: Online journal · 網上日誌；網上期刊式網誌

**READ THE CONTEXT · 閱讀語境**

She writes a blog about her experiences studying overseas.

**中文翻譯**  
她寫網誌記錄海外留學經歷。

- A. online journal
- B. forum
- C. news site
- D. web page
- E. social-media account
- F. academic journal

**CORRECT ANSWER · 正確答案**

**online journal** · 網上日誌；網上期刊式網誌

**Correct rewrite · 正確改寫**  
She writes an online journal about her experiences studying overseas.

**SIX-OPTION FEEDBACK · 六個選項的詳細解釋**

- **A. online journal ✓ — 內容是持續記錄個人留學經歷，日誌式 blog 最適合改寫成 online journal。**
- **B. forum — forum 以多人討論串為核心，不是單一作者持續發文。**
- **C. news site — 留學個人經歷不是以新聞報道為主要形式。**
- **D. web page — 單一網頁不能表達持續更新的整個網誌。**
- **E. social-media account — 社交帳戶可能分享經歷，但平台形式和 blog 不同。**
- **F. academic journal — 學術期刊經同行評審或正式出版，與個人留學網誌不同。**

## 06 Semantic map · 語義總覽

| Blog 的語境 | 最接近的詞／表達 | Diagnostic question |
|---|---|---|
| 日誌式一般網誌 | **online journal** | 是否以持續文章／反思記錄為主？ |
| blog 的歷史完整名稱 | **weblog** | 是否只需非常接近的舊式名稱？ |
| 透明解釋『web 上的 log』 | **web log** | 是否是記錄進度／經歷的網上 log？ |
| 網上期刊式日誌 | **web journal** | 是否有 dated entries / reflections？ |
| 私人日常記錄 | **online diary** | 是否主要記錄個人生活和感受？ |
| 個人作者型網誌 | **personal blog** | 是否明確由個人經營？ |
| 強調整個網站 | **blog site** | 是否談 archive/search/site structure，而非單篇文章？ |
| 描述性日誌網站 | **journal-style website** | 是否要描述網站形式而避免直接重複 blog？ |
| 較廣個人網站 | **personal website** | 是否還有 CV/portfolio/contact 等非 blog 內容？ |
| 成熟多人網上刊物 | **online publication** | 是否已有 editors / multiple writers / regular articles？ |
| 網絡出版物 | **web publication** | 是否強調專業網上發布形式？ |
| 正式／長篇數碼日誌 | **digital journal** | 是否是 dated notes / reflective entries 的較正式形式？ |

## 07 Direct contrasts · 核心辨析

- **blog vs online journal**: online journal 更描述性，也更容易帶日誌／反思色彩；blog 更常用、更廣。
- **blog vs weblog**: 兩者語義幾乎相同，但 weblog 現代使用率較低。
- **blog vs online diary**: online diary 更私人、更日常；很多專業 blog 不是 diary。
- **blog vs personal blog**: personal blog 是 blog 的子類，排除公司／機構／多人編輯型網誌。
- **blog vs blog site**: blog 可指內容／整體；blog site 明確指網站本身。
- **blog vs personal website**: personal website 範圍更廣，可完全沒有網誌。
- **blog vs online publication**: online publication 是上位詞，較正式，也可有多名作者和編輯。
- **blog vs forum**: blog 以 posts 為核心；forum 以 discussion threads/replies 為核心。
- **blog vs blog post**: blog 是整體；blog post 是單篇文章。
- **blog vs web page**: web page 是單一頁面；blog 通常是持續更新的多篇內容集合。

## 08 Grammar, number & terminology traps · 文法、單複數與術語陷阱

- **blog** 是可數名詞：a blog / several blogs。
- **blog post** = 一篇網誌文章；不要把 post 和整個 blog 混為一談。
- **weblog / web log** 都可見，但現代最普通的名稱仍是 **blog**。
- 你提供的複數 **online journals / web logs** 只是 **online journal / web log** 的複數形式，不需要當成新的同義詞項目重複教授。
- **online journal / digital journal** 在學術環境可能被理解成電子學術期刊；若語境可能混淆，直接用 **blog** 最清楚。
- **personal website ≠ personal blog**：個人網站可以只有 portfolio/CV/contact pages，完全沒有定期 posts。
- **blogger** 是寫／經營 blog 的人，不是 blog 本身。
- **blogging** 是寫網誌的活動；**blog** 是名詞，也可作動詞：She blogs about travel。
- **website / site** 是上位詞；不能因某內容在網上就把任何 website 都叫 blog。
- **journal** 單獨使用時要小心：它可能是日記，也可能是學術期刊，語境決定意思。
