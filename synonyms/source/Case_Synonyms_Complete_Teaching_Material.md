# CASE — Complete Synonym Teaching Material

## 01 同義詞指南

**case** = 情況；個案；例子；事例；事件

在你這一組語境中，**case** 不是指「箱子」或「法律案件」，而是指某一個具體情況、事例或情形。

英文會按語境選用不同說法，例如：

- 某一個具體事例 → **instance**
- 用來說明規則或觀點的例子 → **example**
- 某個實際情況 → **situation**
- 影響事情發展的具體條件 → **circumstance**
- 假設或可能出現的情況 → **scenario**
- 某件實際發生的事 → **occurrence**
- 某個特定事件或一段插曲 → **episode**
- 某件需要處理的事情 → **matter**
- 某個特殊情況／場合 → **occasion**
- 某種條件或狀態 → **condition**
- 某項具體個案 → **individual case / particular case**

---

### 01 Instance
事例；個別情況

和 **case** 非常接近，特別表示某一個具體發生的例子。

**EXAMPLE · 例句**  
In one **instance**, the system failed to save the user's data.

在一個事例中，系統未能儲存使用者資料。

---

### 02 Example
例子；實例

當 **case** 用來說明一個規則、觀點、現象或問題時，**example** 很自然。

**EXAMPLE · 例句**  
This is a good **example** of how poor communication can cause delays.

這是一個很好的例子，說明溝通不良如何造成延誤。

---

### 03 Situation
情況；情形

表示某一刻或某段時間內的整體情況，尤其強調人或事件所處的狀態。

**EXAMPLE · 例句**  
In this **situation**, the safest option is to stop the machine.

在這種情況下，最安全的做法是停止機器。

---

### 04 Circumstance
情況；處境；具體條件

較正式，強調影響事情的具體背景或條件，常用複數 **circumstances**。

**EXAMPLE · 例句**  
Under these **circumstances**, the meeting should be postponed.

在這些情況下，會議應該延期。

---

### 05 Scenario
情境；可能情況

常用於假設、規劃、風險分析或討論可能發生的情況。

**EXAMPLE · 例句**  
In the worst-case **scenario**, the system could stop working completely.

在最壞情況下，系統可能完全停止運作。

---

### 06 Occurrence
發生的事情；事件；個別事例

較正式，強調某件事「實際發生過」，尤其適合事故、故障、問題或異常事件。

**EXAMPLE · 例句**  
Each **occurrence** of the fault must be reported.

每次故障發生都必須報告。

---

### 07 Episode
事件；一段插曲

表示一段有明確開始和結束的事件或經歷，尤其是較特殊、令人注意或不尋常的情況。

**EXAMPLE · 例句**  
The hospital reviewed the entire **episode** after the patient recovered.

病人康復後，醫院檢討了整段事件。

---

### 08 Matter
事情；問題；事項

當 **case** 指一件需要處理、討論或決定的事情時，**matter** 很自然。

**EXAMPLE · 例句**  
The manager said the **matter** would be investigated immediately.

經理表示會立即調查這件事。

---

### 09 Occasion
情況；場合；某一次

當 **case** 指某一次特定發生的時候或場合時，**occasion** 可以使用。

**EXAMPLE · 例句**  
On one **occasion**, the alarm sounded even though there was no fire.

有一次，警報在沒有火警的情況下響起。

---

### 10 Condition
情況；狀態；條件

當 **case** 的重點是某種具體狀態或條件，而不是事件本身時可用。

**EXAMPLE · 例句**  
The treatment is only recommended in certain **conditions**.

這種治療只建議在某些情況下使用。

---

### 11 Particular case
特定個案；某一具體情況

直接而精確，當需要強調「這一個具體個案」與一般規則不同時很自然。

**EXAMPLE · 例句**  
In this **particular case**, the usual rule does not apply.

在這個特定個案中，一般規則並不適用。

---

## 02 False synonyms

看起來相關，意思卻不同。以下詞語常和 **case** 出現在相似語境，但不能在所有情況直接互換。

---

### 01 Event
事件不一定等於 case

**event** 通常是一件發生的事情；**case** 更常表示「某一個需要分析或討論的具體情況」。

**ENGLISH COMPARISON**  
An **event** happens. A **case** may be an event viewed as a particular example or situation.

---

### 02 Problem
問題不等於個案

**problem** 表示困難或需要解決的事情；**case** 本身可以是好、壞或中性的情況。

**ENGLISH COMPARISON**  
Every **problem** is a difficult situation, but not every **case** is a problem.

---

### 03 Issue
議題／問題不等於 case

**issue** 常指需要討論的問題、議題或爭議；**case** 可以只是某個具體事例。

**ENGLISH COMPARISON**  
An **issue** is something to discuss or resolve. A **case** is one specific situation or example.

---

### 04 Example / Instance
例子和事例的重點不同

**example** 常用來說明一個概念；**instance** 更強調一個實際發生的個別事例。

**ENGLISH COMPARISON**  
An **example** illustrates a point. An **instance** is one particular occurrence of something.

---

### 05 Circumstance / Situation
背景條件和整體情況不同

**circumstance** 強調具體條件或背景；**situation** 強調整體狀態。

**ENGLISH COMPARISON**  
The **circumstances** explain why something happened. The **situation** describes what is happening overall.

---

### 06 Case study
案例研究不等於 case

**case study** 是對某個個案作詳細研究的文章、方法或研究活動，不是個案本身。

**ENGLISH COMPARISON**  
The company is the **case** being examined. The written analysis is the **case study**.

---

### 07 Case / cases
單數和複數影響意思

**case** 是一個個案；**cases** 是多個個案或情況。

**ENGLISH COMPARISON**  
This **case** is unusual.  
Several similar **cases** were reported.

---

### 08 In case / in this case
固定搭配意思不同

**in case** 常表示「以防萬一」；**in this case** 才表示「在這種情況下」。

**ENGLISH COMPARISON**  
Take an umbrella **in case** it rains.  
**In this case**, the rule does not apply.

---

## 03 練習與解釋

### 練習 01.1

**Target word: Instance · 事例；個別情況**

**READ THE CONTEXT · 閱讀語境**  
In one case, the system failed to save the user's data.

**中文翻譯**  
在一個事例中，系統未能儲存使用者資料。

A. instance  
B. issue  
C. problem  
D. circumstance  
E. scenario  
F. case study

**CORRECT ANSWER · 正確答案**  
**instance · 事例；個別情況**

In one **instance**, the system failed to save the user's data.

**SIX-OPTION FEEDBACK · 六個選項的解釋**

**A. instance ✓**  
instance = 個別事例。**in one instance** 是非常自然的固定搭配，表示某一次具體發生的情況。

**B. issue**  
issue = 問題／議題。可以說 system issue，但 **in one issue** 不能表示一次具體事例。

**C. problem**  
problem = 問題。系統未儲存資料確實是問題，但原句重點是「其中一次案例」。

**D. circumstance**  
circumstance = 背景條件。通常不說 **in one circumstance** 來指一宗實際事件。

**E. scenario**  
scenario = 情境。較常用於假設或可能情況，而這裡是實際發生。

**F. case study**  
case study = 案例研究。是分析文本或研究方法，不是單一事件本身。

**Target word: Instance · 事例；個別情況**

**CORRECT ANSWER · 正確答案**  
**instances · 事例；個別情況**

**SIX-OPTION FEEDBACK · 六個選項的解釋**

**A. instances ✓**  
instances = 多個具體事例。**instances of the same error** 是典型搭配。

**B. circumstances**  
circumstances = 情況背景。不是錯誤發生的次數。

**C. scenarios**  
scenarios = 假設情境。原句是已經發生。

**D. issues only**  
issues = 問題。可以說 several issues，但不如 instances 精確表達同一 error 重複發生多次。

**E. case studies**  
case studies = 案例研究。不是錯誤事件。

**F. conditions**  
conditions = 條件。不是發生次數。

**Target word: Particular case · 特定個案；某一具體情況**

**READ THE CONTEXT · 閱讀語境**  
The committee reviewed the case separately because it involved unusual circumstances.

**中文翻譯**  
委員會因這個特定個案涉及不尋常情況而單獨審視。

A. particular case  
B. general issue  
C. case study  
D. scenario  
E. occasion  
F. condition

**CORRECT ANSWER · 正確答案**  
**particular case · 特定個案；某一具體情況**

The committee reviewed the **particular case** separately because it involved unusual circumstances.

**SIX-OPTION FEEDBACK · 六個選項的解釋**

**A. particular case ✓**  
particular case = 特定個案。**reviewed separately** 和 unusual circumstances 都表明它是需要個別處理的案例。

**B. general issue**  
general issue = 一般問題。和 separately 及 particularity 相反。

**C. case study**  
case study = 案例研究。不是被委員會處理的個案本身。

**D. scenario**  
scenario = 情境。較偏假設。

**E. occasion**  
occasion = 某一次。沒有審查個案的正式感。

**F. condition**  
condition = 條件。不是整個個案。

### 練習 11.3

**Target word: Particular case · 特定個案；某一具體情況**

**READ THE CONTEXT · 閱讀語境**  
Although the policy is usually strict, this case may justify an exception.

**中文翻譯**  
雖然政策通常很嚴格，但這個特定個案可能值得例外處理。

A. particular case  
B. case study  
C. example only  
D. condition only  
E. issue  
F. event

**CORRECT ANSWER · 正確答案**  
**particular case · 特定個案；某一具體情況**

Although the policy is usually strict, this **particular case** may justify an exception.

**SIX-OPTION FEEDBACK · 六個選項的解釋**

**A. particular case ✓**  
particular case = 特定個案。**justify an exception** 表示一般規則下的一個特殊個案。

**B. case study**  
case study = 案例研究。不是政策實際處理對象。

**C. example only**  
example = 例子。重點不是說明規則，而是是否給予例外。

**D. condition only**  
condition = 條件。只涵蓋某項狀態，不能代表整宗個案。

**E. issue**  
issue = 問題。可能存在，但沒有 individual-case 意味。

**F. event**  
event = 事件。太寬泛，也不一定需要政策裁量。
