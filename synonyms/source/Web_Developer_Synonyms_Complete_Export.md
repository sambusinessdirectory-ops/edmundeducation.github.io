# WEB DEVELOPER — Complete Synonym Lesson

## 01 同義詞指南

### Web developer 的 7 種更精準說法

> 本課聚焦 **web developer = 建立、編寫、維護或改善網站與 Web 應用程式的人**。自然可用的近義職稱包括 **website developer**（直接強調網站）、**web programmer / website programmer**（突出寫程式）、**web engineer**（工程、效能與架構語感較強）、**web application developer**（專指互動式 Web 應用）、較口語的 **web coder**，以及較正式的 **web software engineer**。像 **front-end developer, back-end developer, full-stack developer** 雖然高度相關，但屬更窄的專門角色，因此不當作完全同義詞。

### 01 Website Developer
**網站開發人員；網站開發者**

website developer 是 web developer 很直接的改寫，尤其當工作重點明確是建立、維護或改善網站，而不是更廣泛的網頁應用程式或平台時。

**EXAMPLE · 例句**
The company hired a website developer to rebuild its online store.
公司聘請了一名網站開發人員重建網上商店。

---

### 02 Web Programmer
**網頁／網站程式員**

web programmer 強調以程式碼實作網站或網頁功能，特別適合談 coding、程式邏輯、伺服器端功能或互動功能時。它和 web developer 很接近，但 programmer 更突出寫程式。

**EXAMPLE · 例句**
The team needs a web programmer to implement the new payment workflow.
團隊需要一名網頁程式員實作新的付款流程。

---

### 03 Website Programmer
**網站程式員**

website programmer 是可理解而自然的改寫，重點同樣是為網站寫程式。它比 web programmer 稍明確指出工作對象是 website，常見於較直白的職位描述。

**EXAMPLE · 例句**
A website programmer added the custom search feature.
一名網站程式員加入了自訂搜尋功能。

---

### 04 Web Engineer
**網頁工程師；Web 工程師**

web engineer 通常比 web developer 更強調工程方法、可擴展性、效能、可靠性、架構和大型系統。很多公司會把兩者當近義職稱，但 engineer 的工程語感較強。

**EXAMPLE · 例句**
The platform hired a web engineer to improve scalability and reliability.
平台聘請了一名 Web 工程師改善擴展性和可靠性。

---

### 05 Web Application Developer
**網頁應用程式開發人員；Web 應用開發者**

當 web developer 的工作重點不是一般資訊網站，而是具有登入、互動、資料處理、工作流程等功能的 web app，可用 web application developer。這是範圍較窄、但很實用的近義職稱。

**EXAMPLE · 例句**
The company is hiring a web application developer for its online booking platform.
公司正為網上預約平台招聘 Web 應用程式開發人員。

---

### 06 Web Coder
**網頁程式編寫者；寫 Web 程式的人（口語）**

web coder 是較口語、較非正式的說法，強調實際寫 HTML、CSS、JavaScript 或其他 Web 程式碼的人。它可作 web developer 的近義稱呼，但不適合所有正式職稱或資深工程語境。

**EXAMPLE · 例句**
We need a web coder to turn the prototype into a working site.
我們需要一名 Web 程式編寫者把原型變成可運作網站。

---

### 07 Web Software Engineer
**Web 軟件工程師**

web software engineer 是較正式、工程導向的職稱，適合以軟件工程原則開發大型 Web 系統、平台或服務的角色。它和 web engineer 很接近，但更明確強調軟件工程。

**EXAMPLE · 例句**
The company hired a web software engineer to improve the platform's architecture.
公司聘請了一名 Web 軟件工程師改善平台架構。

---

## 02 False synonyms

### 看起來相關，意思卻不同。Web 工作職稱的範圍很容易重疊；有些是設計職、較窄專門方向、更廣軟件職稱，或較高階架構角色，因此不能一概和 web developer 互換。

### 01 Web Designer
**網頁設計師不等於一般的 web developer**

web designer 主要負責網站的視覺、版面、介面與使用者體驗；有些人也會寫前端程式，但這個職稱本身不等於 web developer。

**ENGLISH COMPARISON**
A web designer focuses on design; a web developer focuses on building and coding web functionality.

---

### 02 Front-End Developer
**前端開發人員不等於一般的 web developer**

front-end developer 是 web development 的一個重要子類型，主要處理瀏覽器端介面與互動；並不是所有 web developers 都只做前端。

**ENGLISH COMPARISON**
Front-end development is one specialization within web development.

---

### 03 Back-End Developer
**後端開發人員不等於一般的 web developer**

back-end developer 主要負責伺服器、資料庫、API 和後端邏輯，是 web development 的一個較窄專門方向。

**ENGLISH COMPARISON**
A back-end developer may be a web developer, but the terms are not always interchangeable.

---

### 04 Full-Stack Developer
**全端開發人員不等於一般的 web developer**

full-stack developer 通常同時處理前端與後端，比一般 web developer 更具體地描述技術範圍。

**ENGLISH COMPARISON**
Full-stack is a specific type of web development role.

---

### 05 Software Developer
**軟件開發人員不等於一般的 web developer**

software developer 是更廣的職稱，可以開發桌面、手機、嵌入式或 Web 軟件；web developer 只聚焦 Web。

**ENGLISH COMPARISON**
All web developers are software developers in a broad sense, but not all software developers work on the web.

---

### 06 Network Engineer
**網絡工程師不等於一般的 web developer**

network engineer 負責路由、交換器、防火牆、網絡連線等基礎設施，不是網站應用程式開發。

**ENGLISH COMPARISON**
Network engineering and web development are different technical disciplines.

---

### 07 Webmaster
**網站管理員；網站負責人不等於一般的 web developer**

webmaster 是較舊式、範圍很廣的職稱，可能負責內容、伺服器、維護和管理；不一定專職寫程式。

**ENGLISH COMPARISON**
A webmaster may manage a site without being its primary developer.

---

### 08 Web Architect
**Web 架構師不等於一般的 web developer**

web architect 偏重高階系統架構、技術方向和設計決策，通常比一般 web developer 更資深、更專門。

**ENGLISH COMPARISON**
A web architect defines architecture; a web developer may implement it.

---
