# SYNONYMS · 同義詞學習系統

# Exam

**「考試／測驗」，究竟是在說一般 test、正式 examination、短 quiz、整體 assessment，還是某種特定用途的考試？**

核心替代表達：

`test / examination / assessment / quiz / paper / final / midterm / entrance exam / certification exam / written exam`

> **核心原則**
>
> `exam` 和 `test` 很接近，但 `assessment` 通常更廣；`quiz` 通常更短；`final / midterm / entrance exam` 則各自加入明確時間或用途。
>
> 真正要判斷的是：
>
> **Is it a general test, a formal examination, a short quiz, a broader assessment, a specific exam paper, or an exam defined by timing or purpose?**

---

# 01 同義詞指南

## 01 Test

**測驗；考試**

最直接、最常用的近義詞之一。`test` 通常比 `examination` 稍口語，可指課堂小測、能力測試、入學測試等。

---

## 02 Examination

**考試；正式考核**

較正式，常指學校、大學、專業資格或公開考試。

---

## 03 Assessment

**評估；考核**

當 `exam` 的重點是衡量學習成果、能力或表現，而不一定是一場傳統筆試時，`assessment` 很自然。

---

## 04 Quiz

**小測；短測驗**

通常比 exam 短、範圍較窄、較低風險，常見於課堂或網上學習。

---

## 05 Paper

**試卷；一科考試**

在英式英語及學校／公開考試語境中，`paper` 可指一份試卷或某一科考試。

---

## 06 Final

**期末考試；終期考核**

當 `exam` 指課程結束時的重要考試，`final` 很自然，尤其美式英語。

---

## 07 Midterm

**期中考試**

指學期或課程中段進行的考試，常見於美式教育語境。

---

## 08 Entrance exam

**入學考試**

當 `exam` 的目的明確是決定能否進入學校、課程或機構時，這個表達最精準。

---

## 09 Certification exam

**認證考試；資格考試**

當 `exam` 用來取得專業認證、資格或執業證明時，這個表達很精準。

---

## 10 Written exam

**筆試**

當 `exam` 明確以書面作答為主、和 oral/practical exam 對比時使用。

---

# 02 False synonyms

## Exam / Test
兩者高度接近；`test` 通常稍口語、範圍更廣。

## Exam / Examination
`examination` 是較正式的完整形式，常見於學校、大學和專業資格語境。

## Exam / Assessment
`assessment` 比 exam 更廣，可以包括：
- exam
- project
- presentation
- practical work
- continuous assessment

## Exam / Quiz
`quiz` 通常更短、範圍較窄、風險較低。

**ENGLISH COMPARISON**  
A quiz may take ten minutes and cover one topic. A final exam may last hours and cover the whole course.

## Exam / Paper
`paper` 在英式教育語境可表示一份試卷或某一科考試。

## Exam / Final
`final` 必須是課程／學期結束時的考試。

## Exam / Entrance exam
`entrance exam` 的目的明確是 admission。

## Exam / Certification exam
`certification exam` 的目的明確是取得專業認證或資格。

# 03 練習與解釋

> 每個目標詞／表達三題，共 **30 題**。  
> 每題六個選項；正確答案位置平均分散在 **A–F**。  
> 每個錯誤選項均按 **詞義 → 一般用途 → 為甚麼在這一句不合** 個別解釋。

## 練習 01.1

**Target word/phrase: Test · 測驗；考試**

### READ THE CONTEXT · 閱讀語境

> We have an exam on Friday.

**中文翻譯**

我們星期五有測驗。

| | 選項 |
|---|---|
| A | Examination |
| B | Quiz |
| C | Test |
| D | Assessment |
| E | Homework |
| F | Lesson |

### CORRECT ANSWER · 正確答案

**C. Test · 測驗；考試**

> We have a test on Friday.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. Examination**  
`examination`：examination = 正式考試；常見於學校、大學、專業資格。 它較正式；「一般課堂考試」若明確是短小 quiz、綜合 assessment 或某種特定考試類型，仍不夠精準。

**B. Quiz**  
`quiz`：quiz = 小測；通常短、範圍窄、低風險。 它通常短、低風險；「一般課堂考試」若是正式長時間或高風險考試，程度不合。

**C. Test ✓**  
`Test` = 測驗；考試。本句關鍵線索是 **一般課堂考試**；這正好對應 `Test` 的正式程度、時間位置、考核形式或用途，因此最精準。

**D. Assessment**  
`assessment`：assessment = 評估／考核；可包括考試、項目、匯報、實作等。 它可以包含多種考核形式；「一般課堂考試」若明確是一場傳統筆試／短測，範圍太廣。

**E. Homework**  
`Homework`：homework = 家課；平日作業，不是正式考試。 本句「一般課堂考試」需要的是考核／考試本身，而這個詞表示學習活動、作業、課程或準備。

**F. Lesson**  
`Lesson`：lesson = 課堂；不是考核。 本句「一般課堂考試」需要的是考核／考試本身，而這個詞表示學習活動、作業、課程或準備。

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. Examination**  
`examination`：examination = 正式考試；常見於學校、大學、專業資格。 它較正式；「和口試對比」若明確是短小 quiz、綜合 assessment 或某種特定考試類型，仍不夠精準。

**B. Oral exam**  
`oral exam`：oral exam = 口試；以口頭回答為主。 本句「和口試對比」明確以書面作答，因此形式相反。

**C. Written exam ✓**  
`Written exam` = 筆試。本句關鍵線索是 **和口試對比**；這正好對應 `Written exam` 的正式程度、時間位置、考核形式或用途，因此最精準。

**D. Test**  
`test`：test = 測驗／考試；最廣、較口語，可指多種能力或知識測試。 本句關鍵是「和口試對比」；若語境明確要求正式考試、期中／期末、入學或資格用途，test 會太廣。

**E. Interview**  
`interview`：interview = 面試；以問答交流評估，不是一般 exam。 它以交流問答評估；本句「和口試對比」談的是考試而非面試。

**F. Grade**  
`Grade`：grade = 成績；是考試結果，不是考試本身。 它是考試可能產生的結果／資格文件，不是考試本身。

# 05 高價值近義詞辨析

- **Exam vs Test** — test 稍口語、較廣。
- **Exam vs Examination** — examination 更正式。
- **Exam vs Assessment** — assessment 可以不包含傳統考試。
- **Exam vs Quiz** — quiz 通常短、低風險。
- **Exam vs Paper** — paper 可指試卷本身或一科考試。
- **Final vs Midterm** — 一個在終期，一個在中期。
- **Entrance exam vs Certification exam** — 前者決定 admission；後者取得認證。
- **Written exam vs Oral exam** — 一個書面作答，一個口頭作答。

# 10 Final note for system use

核心替代表達：

`test / examination / assessment / quiz / paper / final / midterm / entrance exam / certification exam / written exam`

最重要的 near-miss：

`homework / project / grade / certificate / interview / revision`

它們分別表示 **家課、項目作業、成績、證書、面試、溫習**；都和考試相關，但不是 `exam` 本身的通用同義詞。

真正的選詞依據是：

> **Is “exam” a general test, a formal examination, a short quiz, a broader assessment, or a specific exam defined by timing, format, or purpose?**
