# BASE · 分層同義詞學習系統

## Base

**「基礎／依據／基地／據點」，必須按語義分支理解。**

這個 headword 比前幾個詞更**多義**。你給的例子 **foundation; site; groundwork** 本身已經跨越至少兩個主要意思：**(A) foundation/basis = 基礎、依據**，以及 **(B) site/operational base = 基地、所在地**。因此本單元不把所有詞假裝成可以互換，而是在三層系統內清楚標示語義分支和限制。

每項包含 **核心語義、語域、用法提示、常見搭配、搭配對象、與 base 的直接辨析、使用限制、例句及翻譯**；每個目標詞／表達設 **3 道題**，每題六個選項均有逐題、逐選項的情境化解釋。

## Tier 1 — Core foundation senses · 核心「基礎」近義詞

### 01 Foundation

**Tier**：1  
**中文**：基礎；根基  
**語域**：neutral / very common  
**核心語義**：the supporting basis on which something physical or abstract is built  
**用法提示**：和 base 的『基礎／根基』義最接近。可用於建築、制度、知識、關係、技能等。  
**常見搭配**：a solid foundation; the foundation of a building; a foundation for learning; build a foundation; provide the foundation.  
**常見搭配對象**：building, knowledge, relationship, system, skill.  
**與 base 的辨析**：Foundation 強調支撐其上其他部分的根基；base 也可指底部、基地或出發點，範圍更廣。  
**使用限制**：若 base 指實際活動地點／總部，foundation 不適用。

**EXAMPLE · 例句**  
Basic literacy provides a foundation for later learning.  
基本讀寫能力為日後學習提供基礎。

### 02 Basis

**Tier**：1  
**中文**：基礎；依據  
**語域**：neutral / very common  
**核心語義**：the underlying reason, principle, or set of facts on which something depends  
**用法提示**：當 base 指某個判斷、制度、關係或論證的依據時非常接近。  
**常見搭配**：the basis for a decision; on the basis of; a scientific basis; the basis of the argument; provide a basis.  
**常見搭配對象**：decision, argument, policy, relationship, calculation.  
**與 base 的辨析**：Basis 更偏抽象『依據／根據』；foundation 更像支撐整體的根基。  
**使用限制**：通常不指實體建築底座或機構所在地。

**EXAMPLE · 例句**  
The survey provides a useful basis for future planning.  
這項調查為未來規劃提供有用依據。

### 03 Groundwork

**Tier**：1  
**中文**：基礎工作；準備工作  
**語域**：neutral / formal  
**核心語義**：preparatory work that creates the conditions for later progress  
**用法提示**：當 base 指『先打好基礎，讓後續工作能展開』時很精準。  
**常見搭配**：lay the groundwork; groundwork for reform; preliminary groundwork; provide the groundwork; essential groundwork.  
**常見搭配對象**：reform, project, negotiation, research, future development.  
**與 base 的辨析**：Groundwork 強調前期準備；base/foundation 可以是持續存在的根基。  
**使用限制**：若沒有『為之後鋪路』的時間關係，groundwork 未必合適。

**EXAMPLE · 例句**  
The pilot study laid the groundwork for a larger research project.  
試點研究為更大型研究項目奠定了基礎。

### 04 Underpinning

**Tier**：1  
**中文**：支撐基礎；根本支柱  
**語域**：formal  
**核心語義**：an underlying support, principle, or idea that holds a system or argument together  
**用法提示**：當 base 指制度、理論、政策或論證背後的深層支撐時很有用。  
**常見搭配**：theoretical underpinning; economic underpinning; the underpinning of the system; provide underpinning; strong underpinnings.  
**常見搭配對象**：theory, policy, system, argument, framework.  
**與 base 的辨析**：Underpinning 比 base 更正式，也更強調『在下面支撐』的結構性作用。  
**使用限制**：一般日常『基地』或簡單起點不適用。

**EXAMPLE · 例句**  
Trust is an important underpinning of effective teamwork.  
信任是有效團隊合作的重要支撐基礎。

### 05 Footing

**Tier**：1  
**中文**：立足基礎；基礎狀態  
**語域**：neutral / formal  
**核心語義**：a secure basis or position on which something can operate or develop  
**用法提示**：常見於 put something on a firm/secure/equal footing，表示令制度、關係或財務狀況建立在穩固基礎上。  
**常見搭配**：on a firm footing; on a sound footing; equal footing; put on a secure footing; financial footing.  
**常見搭配對象**：organisation, finances, relationship, business, arrangement.  
**與 base 的辨析**：Footing 常出現在固定搭配，表示『穩定立足狀態』；base 更廣。  
**使用限制**：不能普遍逐字替換 every base。

**EXAMPLE · 例句**  
The new funding put the organisation on a firmer footing.  
新資金令該機構建立在更穩固的基礎上。

## Tier 2 — Site / operational senses · 「基地／所在地」常用近義詞

### 06 Site

**Tier**：2  
**中文**：地點；所在地；場地  
**語域**：neutral / very common  
**核心語義**：a physical location where an organisation, activity, or facility is situated  
**用法提示**：當 base 指某個團隊、設施或行動的實際所在地時可近似。  
**常見搭配**：operational site; work site; research site; site location; main site.  
**常見搭配對象**：facility, project, research, operations, construction.  
**與 base 的辨析**：Site 只強調『位置』；base 往往還帶有由此出發、管理或支援活動的功能。  
**使用限制**：若重點是總部／指揮中心，site 可能太中性。

**EXAMPLE · 例句**  
The team uses the building as its main research site.  
團隊以這座建築作為主要研究地點。

### 07 Headquarters

**Tier**：2  
**中文**：總部；總部所在地  
**語域**：neutral / organisational  
**核心語義**：the main administrative or command centre of an organisation  
**用法提示**：當 base 指機構的主要管理或指揮所在地時很接近。  
**常見搭配**：company headquarters; regional headquarters; headquarters building; move headquarters; based at headquarters.  
**常見搭配對象**：company, organisation, agency, military command, regional office.  
**與 base 的辨析**：Headquarters 特指主要行政／指揮中心；base 可以是分支基地或操作地點。  
**使用限制**：小型臨時基地或一般工作地點不一定是 headquarters。

**EXAMPLE · 例句**  
The organisation moved its headquarters to a larger building.  
該機構把總部遷到更大的大樓。

### 08 Centre

**Tier**：2  
**中文**：中心；活動中心  
**語域**：neutral / British  
**核心語義**：a place from which a particular activity is organised or carried out  
**用法提示**：當 base 是某類活動、研究、培訓或服務集中進行的地方時很自然。  
**常見搭配**：research centre; training centre; operations centre; service centre; regional centre.  
**常見搭配對象**：research, training, operations, service, coordination.  
**與 base 的辨析**：Centre 強調活動集中；base 更常帶『以此為據點』的功能。  
**使用限制**：如果 base 是單純底座或抽象基礎，centre 不適用。

**EXAMPLE · 例句**  
The city serves as a regional centre for medical research.  
該城市是區內醫學研究中心。

### 09 Base of operations

**Tier**：2  
**中文**：行動基地；營運據點  
**語域**：neutral / idiomatic  
**核心語義**：the main place from which a person or group carries out activities  
**用法提示**：是 base『活動據點』義的最透明改寫之一，適合旅行、研究、救援、商業或項目團隊。  
**常見搭配**：use as a base of operations; main base of operations; temporary base of operations; establish a base of operations; serve as a base of operations.  
**常見搭配對象**：team, expedition, project, fieldwork, operation.  
**與 base 的辨析**：比單獨 base 更明確說明這是『由此開展活動』的據點。  
**使用限制**：不適合 base 的『抽象基礎』義。

**EXAMPLE · 例句**  
The hotel served as the team's base of operations during the survey.  
調查期間，酒店作為團隊的行動基地。

### 10 Operating base

**Tier**：2  
**中文**：營運基地；操作據點  
**語域**：formal / organisational  
**核心語義**：a place from which regular operations are conducted  
**用法提示**：當 base 指公司、交通、救援、物流或專業團隊日常運作據點時很自然。  
**常見搭配**：main operating base; regional operating base; establish an operating base; temporary operating base; overseas operating base.  
**常見搭配對象**：airline, rescue team, logistics, company, field unit.  
**與 base 的辨析**：Operating base 強調持續營運；base 可更廣或更口語。  
**使用限制**：不適用於純粹象徵性總部或抽象 foundation。

**EXAMPLE · 例句**  
The airport became the airline's main operating base.  
該機場成為航空公司的主要營運基地。

### 11 Hub

**Tier**：2  
**中文**：樞紐；中心據點  
**語域**：neutral / common  
**核心語義**：a central place where activity, transport, information, or people are concentrated  
**用法提示**：當 base 指一個活動高度集中、連接其他地方或單位的中心據點時可近似。  
**常見搭配**：transport hub; technology hub; regional hub; business hub; logistics hub.  
**常見搭配對象**：transport, technology, business, logistics, communication.  
**與 base 的辨析**：Hub 更強調連接與集中；base 更強調作為活動出發／支援據點。  
**使用限制**：若只是單一辦公地點，hub 可能過強。

**EXAMPLE · 例句**  
The city has become a regional hub for technology companies.  
該城市已成為區內科技公司的樞紐。

## Tier 3 — Common expressions / stronger conceptual variants · 常用表達與較強概念變體

### 12 Bedrock

**Tier**：3  
**中文**：根基；最根本基礎  
**語域**：figurative / expressive  
**核心語義**：the most fundamental and dependable basis of something  
**用法提示**：當 base 指非常核心、不可動搖的原則或支柱時可用，語氣比 foundation 更強。  
**常見搭配**：the bedrock of society; the bedrock of trust; a bedrock principle; form the bedrock; economic bedrock.  
**常見搭配對象**：trust, democracy, relationship, institution, principle.  
**與 base 的辨析**：Bedrock 是較強烈的比喻，表示『最底層、最可靠的根基』。  
**使用限制**：不適合一般中性 base，也不指實際活動基地。

**EXAMPLE · 例句**  
Mutual trust is the bedrock of a strong partnership.  
互相信任是穩固伙伴關係的根本基礎。

### 13 Starting point

**Tier**：3  
**中文**：起點；出發點  
**語域**：neutral / very common  
**核心語義**：the initial basis from which discussion, planning, learning, or development begins  
**用法提示**：當 base 指後續分析、計劃、討論或學習的出發基礎時很實用。  
**常見搭配**：a useful starting point; starting point for discussion; starting point for analysis; provide a starting point; good starting point.  
**常見搭配對象**：discussion, research, planning, analysis, learning.  
**與 base 的辨析**：Starting point 強調『從這裡開始』；base/foundation 更強調支撐。  
**使用限制**：如果基礎是長期支柱而不是起始材料，starting point 不夠準確。

**EXAMPLE · 例句**  
The existing data provides a useful starting point for the review.  
現有資料為這次檢討提供有用的出發點。

### 14 Home base

**Tier**：3  
**中文**：主要據點；大本營  
**語域**：informal / common  
**核心語義**：the regular or familiar place from which a person or group operates  
**用法提示**：較口語，適合旅行團隊、巡迴工作者、運動隊、項目人員等的主要據點。  
**常見搭配**：return to home base; use as a home base; our home base; temporary home base; make somewhere home base.  
**常見搭配對象**：team, traveller, crew, project, family.  
**與 base 的辨析**：Home base 帶熟悉、固定、回歸據點的感覺；base 更中性。  
**使用限制**：正式行政／學術語境通常用 base of operations / headquarters。

**EXAMPLE · 例句**  
The apartment became our home base while we explored the region.  
我們探索該地區期間，這個單位成為我們的主要據點。

## 04 False synonyms · 容易誤選的詞

### 01 Bottom

**底部不等於所有 base**  
bottom 只表示最低部分；base 可表示底座、基礎、基地或依據。某物的 base 可能是 bottom，但抽象 base 不能一律換成 bottom。

**ENGLISH COMPARISON**  
The bottom is the lowest part; a base may also be a foundation, headquarters, or point of support.

### 02 Floor

**地板不等於 base**  
floor 是房間或空間的地面；base 是支撐物、底部或據點。

**ENGLISH COMPARISON**  
A table stands on the floor, but its base is part of the table.

### 03 Root

**根源不等於 base**  
root 可表示原因、來源或植物根部；有時與 foundation 有比喻重疊，但不能普遍替換 base。

**ENGLISH COMPARISON**  
The root of a problem is its underlying cause; the base may simply be its support or operational centre.

### 04 Origin

**起源不等於 base**  
origin 指某事最初從哪裡開始；base 更常指支撐點或據點。

**ENGLISH COMPARISON**  
An origin explains where something began; a base explains what supports it or where it operates from.

### 05 Branch

**分部不等於基地**  
branch 是機構的分支辦事處；base 可以是任何營運據點，未必是正式組織分部。

**ENGLISH COMPARISON**  
A branch is an organisational unit; a base is a place from which operations are carried out.

### 06 Office

**辦公室不等於 base**  
office 是辦公場所；base 可以是辦公室，但也可以是實驗室、營地、機場或其他據點。

**ENGLISH COMPARISON**  
An office may function as a base, but the terms are not equivalent.

### 07 Source

**來源不等於 base**  
source 是資訊、材料或事物的來源；basis/base 是依據或支撐。

**ENGLISH COMPARISON**  
A source provides information or material; a basis provides grounds or support.

### 08 Platform

**平台不等於 base**  
platform 可指實體平台、科技平台或發言舞台；只有某些比喻語境與 foundation 有重疊。

**ENGLISH COMPARISON**  
A platform may enable activity, but it is not generally a synonym for base.

### 練習 01.1

**Tier 1 · Target word / phrase**: Foundation · 基礎；根基

**READ THE CONTEXT · 閱讀語境**

Basic numeracy forms the base for more advanced mathematics.

**中文翻譯**

- A. foundation
- B. bottom
- C. floor
- D. origin
- E. branch
- F. office

**CORRECT ANSWER · 正確答案**

**foundation** · 基礎；根基

**Correct rewrite · 正確改寫**  
Basic numeracy forms the foundation for more advanced mathematics.

**SIX-OPTION FEEDBACK · 六個選項的詳細解釋**

- **A. foundation ✓ — more advanced mathematics 是建立在 basic numeracy 之上的後續能力，foundation 最自然。**
- **B. bottom — 只表示最低部分，不能表示學習基礎。**
- **C. floor — 是地面／地板，不符抽象能力。**
- **D. origin — 起源不等於支撐其上的學習根基。**
- **E. branch — 分支機構，不符。**
- **F. office — 辦公室，不符。**

## 06 Semantic map · 語義總覽

| Base 的語境 | 最接近的詞／表達 | Diagnostic question |
|---|---|---|
| 一般根基／支撐 | **foundation** | 其他東西是否建立在它之上？ |
| 抽象依據／根據 | **basis** | 是否是 decision/argument/calculation 的依據？ |
| 前期準備 | **groundwork** | 是否為後續工作鋪路？ |
| 制度／理論深層支撐 | **underpinning** | 是否是 framework/system 背後的核心支撐？ |
| 穩定立足狀態 | **footing** | 是否可說 on a firm/sound/secure ...？ |
| 實際所在地 | **site** | 是否只是強調某活動在哪裡進行？ |
| 主要行政／指揮所在地 | **headquarters** | 是否是 organisation 的主要管理中心？ |
| 活動集中地 | **centre** | 是否是 research/training/service 的中心？ |
| 由此開展活動的據點 | **base of operations** | 是否是團隊由此向外工作？ |
| 固定營運據點 | **operating base** | 是否是 airline/company/rescue 等日常運作基地？ |
| 連接／集中樞紐 | **hub** | 是否強調網絡連接和活動集中？ |
| 最根本支柱 | **bedrock** | 是否需要很強的『根本、不可動搖』語氣？ |
| 起始材料／出發點 | **starting point** | 是否只表示後續工作的開始位置？ |
| 口語主要據點 | **home base** | 是否是熟悉、會返回的活動據點？ |

## 07 Direct contrasts · 核心辨析

- **base vs foundation**: foundation 聚焦支撐根基；base 還可指底部、所在地、營運據點。
- **base vs basis**: basis 更抽象，常是 decision/argument/calculation 的依據。
- **base vs groundwork**: groundwork 是先期準備，含『為日後鋪路』意味。
- **base vs underpinning**: underpinning 更正式，強調制度／理論背後的深層支撐。
- **base vs footing**: footing 常在 on a firm/sound/secure footing 等固定搭配中出現。
- **base vs site**: site 只是地點；base 往往還包含由此運作或支援活動的功能。
- **base vs headquarters**: headquarters 是主要行政／指揮中心；base 不一定是最高層級。
- **base vs centre**: centre 強調活動集中；base 強調據點功能。
- **base vs hub**: hub 強調連接與集中；base 強調操作出發點。
- **base vs starting point**: starting point 強調開始；foundation/base 更強調支撐。

## 08 Grammar & collocation traps · 文法與搭配陷阱

- **the base of** 可指底部／基礎：the base of the tower；但抽象『依據』常更自然用 **the basis of**。
- **basis** 的複數是 **bases** /ˈbeɪsiːz/；和 base 的複數 **bases** 拼法相同但讀音、來源不同。
- **lay the groundwork for** 是固定搭配；一般不說 *make the groundwork for*。
- **on a firm/sound/secure footing** 是固定搭配；footing 很少單獨作所有 base 的替代詞。
- **headquarters** 形式上有 -s，但可作單數或複數概念；例如 The company's headquarters is/are ...，實際用法受英美及句意影響。
- **centre** 採英式拼寫；美式為 **center**。
- **base of operations** / **operating base** 都指營運據點，但前者更描述性，後者更機構化。
- **hub** 常見於 transport / logistics / technology / business；不要因任何地點『很重要』就機械改成 hub。
- **base ≠ bottom / floor**：實體最低部分與抽象基礎、營運基地是不同語義。
- **base ≠ origin / source**：起源、來源、支撐依據三者要分開。
