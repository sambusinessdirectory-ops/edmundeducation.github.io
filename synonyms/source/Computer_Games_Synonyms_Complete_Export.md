# COMPUTER GAMES — Complete Synonym Lesson

## 01 同義詞指南

### Computer games 的 9 種更精準說法

> Note: “computer games” can be used broadly for digital/video games, or narrowly for games played specifically on personal computers. The alternatives below distinguish general category terms from platform-, delivery-, research-, and industry-specific expressions.
> 「computer games」有時泛指電子／數碼遊戲，有時特指在個人電腦上玩的遊戲。以下把一般類別詞、平台用語、網絡／瀏覽器形式、研究用語和遊戲產業用語分開處理。

### 01 Video Games
**電子遊戲；電玩**

最常見、最廣泛的近義詞之一，可包括電腦、遊戲主機、手機等平台上的遊戲。範圍通常比 computer games 更廣。

**EXAMPLE · 例句**  
Many young people enjoy playing video games after school.  
很多年輕人放學後喜歡玩電子遊戲。

---

### 02 Digital Games
**數碼遊戲；數字遊戲**

較正式、教育或研究語境常用，泛指以數碼裝置運行的遊戲，範圍可包括電腦、手機、平板和主機。

**EXAMPLE · 例句**  
The course explores the educational use of digital games.  
這門課探討數碼遊戲在教育上的應用。

---

### 03 Electronic Games
**電子遊戲**

較正式、較廣泛的說法，表示依靠電子裝置運作的遊戲。可包含電腦、主機、手提機和其他電子平台。

**EXAMPLE · 例句**  
Electronic games became increasingly popular in the late twentieth century.  
電子遊戲在二十世紀後期愈來愈受歡迎。

---

### 04 Pc Games
**電腦遊戲；個人電腦遊戲**

表示專門在 personal computer 上玩的遊戲，通常指 Windows、macOS 或 Linux 電腦，不包括主機遊戲。

**EXAMPLE · 例句**  
PC games often allow players to adjust graphics settings.  
電腦遊戲通常容許玩家調整畫面設定。

---

### 05 Computer-Based Games
**以電腦為基礎的遊戲；電腦式遊戲**

較正式、描述性的說法，常見於教育、研究和技術文章，強調遊戲由電腦系統運行。

**EXAMPLE · 例句**  
The researchers used computer-based games to test problem-solving skills.  
研究人員利用電腦式遊戲測試解難能力。

---

### 06 Online Games
**網上遊戲；線上遊戲**

當 computer games 需要連接互聯網、和其他玩家連線或在伺服器上運行時，可用 online games。

**EXAMPLE · 例句**  
Online games let players compete with people around the world.  
網上遊戲讓玩家和世界各地的人競賽。

---

### 07 Browser Games
**瀏覽器遊戲；網頁遊戲**

表示直接在網頁瀏覽器中運行的遊戲，通常不需要安裝完整桌面程式。

**EXAMPLE · 例句**  
Browser games can be played without installing extra software.  
瀏覽器遊戲通常毋須安裝額外軟件便可玩。

---

### 08 Gaming Titles
**遊戲作品；遊戲產品**

較常見於遊戲產業、評論、媒體和零售語境，title 指一款獨立發行的遊戲作品。

**EXAMPLE · 例句**  
The publisher plans to release three new gaming titles this year.  
發行商計劃今年推出三款新的遊戲作品。

---

### 09 Game Software
**遊戲軟件**

較技術或商業化的說法，強調遊戲是軟件產品，而不是遊戲活動本身。

**EXAMPLE · 例句**  
The company develops game software for personal computers.  
這家公司開發個人電腦遊戲軟件。

---

## 02 False synonyms

### 看起來相關，意思卻不同

### 01 Board Games
**桌上遊戲不等於一般的 computer games**

**board games = 桌上遊戲**

board games 通常以實體棋盤、棋子或卡牌進行，不需要電腦運行。

**ENGLISH COMPARISON**  
Chess on a physical board is a board game; a computer chess program is a digital game.

---

### 02 Console Games
**遊戲主機遊戲不等於一般的 computer games**

**console games = 遊戲主機遊戲**

console games 專門指在 PlayStation、Xbox、Nintendo 等主機上玩的遊戲，不等於 computer games。

**ENGLISH COMPARISON**  
A console game runs on a game console; a PC game runs on a computer.

---

### 03 Mobile Games
**手機遊戲不等於一般的 computer games**

**mobile games = 手機遊戲**

mobile games 主要在手機或平板上運行，平台和 computer games 不同。

**ENGLISH COMPARISON**  
A mobile game runs on a phone or tablet.

---

### 04 Arcade Games
**街機遊戲不等於一般的 computer games**

**arcade games = 街機遊戲**

arcade games 傳統上指專用街機上的遊戲，不等於一般電腦遊戲。

**ENGLISH COMPARISON**  
Arcade games use dedicated arcade machines.

---

### 05 Game Console
**遊戲主機不等於一般的 computer games**

**game console = 遊戲主機**

game console 是硬件裝置，不是遊戲本身。

**ENGLISH COMPARISON**  
A console runs games; it is not a game.

---

### 06 Gaming Hardware
**遊戲硬件不等於一般的 computer games**

**gaming hardware = 遊戲硬件**

gaming hardware 包括顯示卡、控制器、電腦或主機等設備，不是 computer games 本身。

**ENGLISH COMPARISON**  
Gaming hardware runs or controls games.

---

### 07 Game Engine
**遊戲引擎不等於一般的 computer games**

**game engine = 遊戲引擎**

game engine 是製作和運行遊戲的開發技術，例如 Unity 或 Unreal Engine，不是完成的遊戲作品。

**ENGLISH COMPARISON**  
Developers build games with a game engine.

---

### 08 Gambling
**賭博不等於一般的 computer games**

**gambling = 賭博**

gambling 涉及下注金錢或有價物品；computer games 一般並不等於賭博。

**ENGLISH COMPARISON**  
A computer game may contain chance, but that does not automatically make it gambling.

---
