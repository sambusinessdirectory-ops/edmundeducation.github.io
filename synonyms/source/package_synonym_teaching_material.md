# SYNONYMS · 同義詞學習系統

# Package

**本課限定語境：package = a group of products, services, features, benefits, or arrangements offered together as one unit · 「套餐；組合；套裝；方案」**

> **同義詞數量不固定。**
> 本課只保留真正自然、常用，而且能在商業、旅遊、電訊、軟件和訂閱語境中接近 `package` 的表達。
>
> 本課**不處理** `package = parcel / 包裹` 這個意思。
>
> `package` 在本課中的核心是：
>
> **把多個項目、服務、功能或權益組合成一個整體供人購買、選擇或使用。**
>
> 本課保留 **7 個**實用替代表達：
>
> 1. **bundle** → 組合包；捆綁套餐
> 2. **set** → 套裝；一組
> 3. **plan** → 方案；計劃
> 4. **subscription package** → 訂閱套餐
> 5. **package deal** → 套餐優惠；打包交易
> 6. **offering** → 產品／服務方案
> 7. **service bundle** → 服務組合
>
> 特別注意：
>
> - `bundle` 很接近 package，尤其是多個產品／服務捆綁出售。
> - `set` 多用於實體物件或一組配套項目。
> - `plan` 強調收費、權益、使用條款或服務等級，不一定真的把實體產品「包」在一起。
> - `subscription package` 只適合訂閱服務。
> - `package deal` 常見於旅遊、促銷和一次性打包優惠。
> - `offering` 很廣，可以指公司提供的一項產品／服務組合，但不一定明示「綑綁」。
> - `service bundle` 強調多項服務被組合在一起。
>
> 每個 target expression 配 **3 道完整練習題**，共 **21 題**。

# 01 同義詞指南

## 01 Bundle

**組合包；捆綁套餐**

表示多個產品、服務或功能一起出售或提供。

**EXAMPLE · 例句**

The company offers a bundle that includes internet, television, and phone service.

公司提供一個包含上網、電視和電話服務的組合套餐。

**USAGE · 用法提示**

非常常見於：
- telecom
- software
- retail
- streaming
- promotions

常見：
- product bundle
- software bundle
- service bundle
- bundle of features

---

## 02 Set

**套裝；一組**

表示多個彼此相關的物件或項目組成一套。

**EXAMPLE · 例句**

The store sells a set containing six kitchen tools.

商店售賣一套包含六件廚房工具的套裝。

**USAGE · 用法提示**

特別自然於實體產品：

- gift set
- tool set
- stationery set
- cookware set

比 `package` 更偏「一套物件」。

---

## 03 Plan

**方案；計劃；收費方案**

表示某項服務的收費、權益、功能或使用條款組合。

**EXAMPLE · 例句**

The basic plan includes 100 GB of cloud storage.

基本方案包括 100 GB 雲端儲存空間。

**USAGE · 用法提示**

常見於：
- phone plans
- internet plans
- insurance plans
- subscription plans
- pricing plans

比 `package` 更突出方案結構和使用條款。

---

## 04 Subscription Package

**訂閱套餐**

表示訂閱服務中提供的一組功能、內容或權益。

**EXAMPLE · 例句**

The premium subscription package includes ad-free viewing and offline downloads.

高級訂閱套餐包括無廣告觀看和離線下載。

**USAGE · 用法提示**

只適合 subscription-based services，例如：
- streaming
- software
- memberships
- online platforms

如果不是訂閱模式，這個詞就太窄。

---

## 05 Package Deal

**套餐優惠；打包交易**

表示多個產品或服務一起出售，通常比逐項購買更方便或更優惠。

**EXAMPLE · 例句**

We booked a package deal that included flights and accommodation.

我們預訂了一個包含機票和住宿的套餐優惠。

**USAGE · 用法提示**

特別常見於：
- travel
- holidays
- promotions
- combined purchases

通常帶有「一起買／一起訂」的意味。

---

## 06 Offering

**產品／服務方案；所提供的項目**

表示公司或機構提供給客戶的一項產品、服務或組合方案。

**EXAMPLE · 例句**

The new premium offering includes priority support and extra storage.

新的高級方案包括優先支援和額外儲存空間。

**USAGE · 用法提示**

比 `package` 更廣。

它可以是一個單一產品，也可以是一整套服務，因此屬於 contextual near-synonym。

---

## 07 Service Bundle

**服務組合；服務套餐**

表示多項服務被組合成一個方案。

**EXAMPLE · 例句**

Customers can save money by choosing the service bundle.

客戶選擇服務組合可以節省費用。

**USAGE · 用法提示**

特別適合：
- telecom services
- business services
- IT services
- subscriptions

比單獨 `bundle` 更清楚表明組合內容是「服務」。

---

# 02 False Synonyms / 容易誤選的相關詞

## 01 Parcel

**包裹 ≠ 套餐／方案**

`parcel` 是實體寄送包裹。

本課的 `package` 是「組合方案」，意思不同。

---

## 02 Product

**單一產品 ≠ 套餐**

product 可以只是 package 中的一個項目。

---

## 03 Service

**單一服務 ≠ 服務組合**

service 只表示一項服務；
package 可以把多項服務合在一起。

---

## 04 Subscription

**訂閱本身 ≠ 訂閱套餐**

subscription 表示訂閱關係；
subscription package 表示訂閱中所包含的功能／權益組合。

---

## 05 Offer

**優惠／提出 ≠ 所有 package**

offer 可以是：
- discount offer
- special offer
- job offer

不一定是多項內容組合。

---

## 06 Deal

**交易／優惠 ≠ 必然 package**

deal 很廣；
`package deal` 才明確表示打包出售。

---

## 07 Package / Packaging

**詞義不同**

- package = 套餐／包裹／組合
- packaging = 包裝材料／包裝方式

---

## 08 Bundle / Bundled

**詞性差異**

- bundle = 名詞／動詞
- bundled = 形容詞／過去分詞

> a service bundle  
> services bundled together

# 01 Bundle

## 練習 01.1

The company offers a package that combines internet, television, and phone service.

**中文翻譯**

公司提供一個結合上網、電視和電話服務的套餐。

A. bundle  
B. plan  
C. set  
D. offering  
E. subscription  
F. parcel

### CORRECT ANSWER · 正確答案

**A. bundle · 組合套餐**

The company offers a **bundle** that combines internet, television, and phone service.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. bundle ✓**  
三項服務被捆綁成一個方案，是 `bundle` 的典型用法。

**B. plan**  
也可能成立，但更強調收費和使用條款；原句突出多項服務組合。

**C. set**  
通常更適合一套實體物品。

**D. offering**  
太廣，只表示公司提供的產品／服務。

**E. subscription**  
只表示訂閱關係，不直接表達三項服務捆綁。

**F. parcel**  
是郵寄包裹，意思不同。

# 05 高階辨析補充

## Package vs Bundle

兩者非常接近：

- **package**：較廣，可表示方案、套餐、整套安排。
- **bundle**：更強調多個項目「綁在一起」。

---

## Package vs Set

- **package**：可包含產品或服務。
- **set**：更常指一套實體、彼此相關的物品。

> gift set  
> software package

---

## Package vs Plan

- **package**：內容被組合在一起。
- **plan**：強調價格、權益、用量或服務等級。

> mobile plan  
> premium package

---

## Package vs Subscription Package

`subscription package` 是 package 的較窄類型，只適合持續訂閱服務。

---

## Package vs Package Deal

- **package**：中性，指一套內容。
- **package deal**：多帶「一起買／一起訂，而且通常有優惠」的交易意味。

---

## Package vs Offering

- **package**：通常明示有多個組成部分。
- **offering**：更廣，可以是一項單一產品，也可以是整套服務。

---

## Package vs Service Bundle

- **package**：可有產品＋服務。
- **service bundle**：內容主要或全部是服務。

# 08 教學核心

**Package 的自然替代表達，最重要的是先判斷它是在說「多件商品組成一套、服務被捆綁、收費方案、訂閱套餐，還是帶優惠意味的打包交易」。**

- 多項內容捆綁 → **bundle**
- 一套實體物品 → **set**
- 收費／權益方案 → **plan**
- 訂閱套餐 → **subscription package**
- 打包優惠 → **package deal**
- 公司提供的廣義方案 → **offering**
- 多項服務組合 → **service bundle**

最重要的界線是：

> **`package` 是廣義上位詞；`set` 偏實體物件，`plan` 偏收費與權益，`subscription package` 只適合訂閱，而 `package deal` 通常額外帶有交易或優惠意味。**
