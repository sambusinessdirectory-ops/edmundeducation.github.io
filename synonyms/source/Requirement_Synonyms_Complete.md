# Requirement

「要求／條件／先決條件」，究竟是哪一種 requirement？

一般必須符合的 `condition`、先後順序明確的 `prerequisite`、評審用 `criterion`、合約中的 `stipulation`、個人 `qualification`、資格制度中的 `eligibility requirement`，以及技術 `specification`、法律 `obligation` 和正式條文 `provision`——英文會按 `requirement` 是資格、規則、責任、規格還是實際必要性，選用不同但更精確的說法。

# 01 同義詞指南

## Requirement 的 11 種更精準說法

### 01 Condition

條件；要求

當 `requirement` 指某件事必須先符合、某項安排才會成立的條件時很自然；常見於申請、合約、資格和程序語境。

**EXAMPLE · 例句**

Meeting the language condition is necessary before the application can proceed.

申請要繼續處理前，必須符合語言條件。

### 02 Prerequisite

先決條件；必要前提

表示在進行下一步之前必須先具備或完成的條件；比一般 `requirement` 更強調先後次序。

**EXAMPLE · 例句**

Basic statistics is a prerequisite for the advanced research course.

基礎統計是修讀高階研究課程的先決條件。

### 03 Criterion

標準；準則

當 `requirement` 指用來判斷是否合資格、是否通過或是否符合標準的評審條件時適用；複數是 `criteria`。

**EXAMPLE · 例句**

Relevant work experience is one criterion used to assess applicants.

相關工作經驗是評估申請人的其中一項準則。

### 04 Stipulation

明文規定；條款要求

較正式，表示合約、規則或協議中明確列出的要求或限制；常帶有必須遵守的意味。

**EXAMPLE · 例句**

The contract includes a stipulation that all changes must be approved in writing.

合約明文規定，所有改動都必須以書面批准。

### 05 Qualification

資格條件；合資格條件

當 `requirement` 指某人需要具備的學歷、證書、技能或經驗，才能申請工作、課程或專業資格時可用。

**EXAMPLE · 例句**

A recognised degree is an essential qualification for the post.

認可學位是這個職位的一項必要資格。

### 06 Eligibility requirement

資格要求；合資格條件

正式而精確，指決定某人是否符合申請、參加或獲得某項資格的必要條件。

**EXAMPLE · 例句**

Applicants must satisfy every eligibility requirement before submitting the form.

申請人提交表格前必須符合所有資格要求。

### 07 Necessity

必要條件；必需之物

當 `requirement` 強調某事是必需、不可缺少，而不是一條行政規則時可用；比 condition 更著重必要性本身。

**EXAMPLE · 例句**

Reliable internet access has become a practical necessity for many remote workers.

可靠的網絡連線已成為很多遙距工作者的實際必需條件。

### 08 Specification

規格要求；技術要求

當 `requirement` 指產品、工程、設計或採購中明確列出的技術條件、尺寸或性能要求時最精確。

**EXAMPLE · 例句**

The device must meet the safety specifications in the contract.

這個裝置必須符合合約中的安全規格要求。

### 09 Obligation

義務；必須履行的責任

當 `requirement` 指法律、合約、職責或道德上必須做的事情時適用；重點是責任，而不是資格條件。

**EXAMPLE · 例句**

Employers have a legal obligation to provide a safe workplace.

僱主有法律義務提供安全的工作環境。

### 10 Demand

要求；需求

當 `requirement` 指某人或某制度提出的強烈要求，或工作／情況對人提出的要求時可用；語氣比一般 condition 更強。

**EXAMPLE · 例句**

The job places heavy demands on employees' time and concentration.

這份工作對員工的時間和專注力有很高要求。

### 11 Provision

規定；條款

在法律、政策或合約中，當 `requirement` 被寫成一項正式條文時可用；強調文件中的具體規定。

**EXAMPLE · 例句**

The agreement contains a provision requiring annual safety inspections.

協議包含一項規定，要求每年進行安全檢查。

# 02 False synonyms

看起來相關，意思卻不同。`requirement` 表示必須符合、具備或履行的條件；preference、recommendation、option、request 等則分別是偏好、建議、選項和請求，通常沒有同樣的強制性。也要分清 `condition`、`prerequisite`、`criterion` 和 `qualification` 各自不同的功能。

### 01 Preference

偏好不等於要求

`preference` 表示較喜歡某個選項；`requirement` 表示必須符合或完成的條件。

**ENGLISH COMPARISON**

A preference is desirable; a requirement is compulsory.

### 02 Recommendation

建議不等於要求

`recommendation` 是建議做某事；`requirement` 通常具有必須遵守的性質。

**ENGLISH COMPARISON**

A recommendation can be optional; a requirement is not.

### 03 Option

選項不等於必要條件

`option` 是可選擇的做法；`requirement` 是不能隨意省略的條件。

**ENGLISH COMPARISON**

An option gives a choice; a requirement removes that choice.

### 04 Benefit

好處不等於要求

`benefit` 是某事帶來的優點；`requirement` 是要先具備或完成的條件。

**ENGLISH COMPARISON**

A benefit is an advantage, not a condition that must be met.

### 05 Criterion

評審準則只在部分語境等同 requirement

`criterion` 用來評估或判斷；有些 criterion 是 mandatory requirement，有些只是評分因素。

**ENGLISH COMPARISON**

A criterion may influence assessment without being a strict requirement.

### 06 Condition / prerequisite

一般條件與先決條件不同

`condition` 可以是任何必須符合的條件；`prerequisite` 特別指在下一步之前必須先具備的東西。

**ENGLISH COMPARISON**

Every prerequisite is a condition, but not every condition is a prerequisite.

### 07 Requirement / request

要求與請求不同

`request` 是請求別人做某事，對方未必必須答應；`requirement` 表示規則、制度或情況上的必要條件。

**ENGLISH COMPARISON**

A request can be refused; a requirement must usually be met.

### 08 Required / requirement

形容詞與名詞不同

`required` 是形容詞或過去分詞；`requirement` 是名詞。

**ENGLISH COMPARISON**

A passport is required. A passport is a requirement.

## 練習 01.1

**Target word: Condition · 條件；要求**

**READ THE CONTEXT · 閱讀語境**

One requirement of the scholarship is that applicants maintain a full-time course load.

**中文翻譯**

獎學金的一項條件是申請人必須維持全日制修課量。

A. preference
B. recommendation
C. condition
D. option
E. benefit
F. request

**CORRECT ANSWER · 正確答案**

**condition · 條件；要求**

One condition of the scholarship is that applicants maintain a full-time course load.

**SIX-OPTION FEEDBACK · 六個選項的解釋**

**A. preference**
preference = 獎學金規定不是個人偏好。

**B. recommendation**
recommendation = 如果只是建議，就不會成為 scholarship 的必要資格。

**C. condition ✓**
condition = `of the scholarship` + 必須持續符合的規則，是典型 `condition`。

**D. option**
option = 申請人不能把這項要求當成可選項目。

**E. benefit**
benefit = 這不是獎學金帶來的好處。

**F. request**
request = 制度上的規定不是單純請求。
