# DESCRIBE · 分層同義詞學習系統

## Describe

**「描述／描繪／說明／敘述」，要先分清是在呈現外觀或情況、刻畫人物、解釋原因、概述重點，還是詳細交代事件。**

本單元集中處理 **describe = to give an account of what someone or something is like, what happened, or what its main features are**。你提供的 **depict; portray; explain** 都很重要，但不能機械互換：**depict** 偏呈現，**portray** 偏形象刻畫，**explain** 則偏使人理解 how/why。

這次保留 **13 個**自然且高實用度的詞／表達，並把 **藝術描繪、人物刻畫、因果解釋、概述、特徵描述、詳細說明、正式列明、事件敘述、修辭性描寫** 分開。每個目標設 **3 道題**；所有 distractor 均具體說明其真正功能及為何在該句不合適。

## Tier 1 — Core describing / explaining equivalents · 核心描述、描繪與說明近義詞

### 01 Depict

**Tier**：1  
**中文**：描繪；描寫；呈現  
**語域**：neutral / formal  
**核心語義**：to show or represent someone or something in words, pictures, film, or another medium  
**用法提示**：當 describe 是透過文字、圖像、影片或藝術作品把某事呈現出來時很自然。  
**常見搭配**：depict a scene; depict a character; depict life; depict events; vividly depict.  
**常見搭配對象**：scene, character, event, life, condition.  
**與 describe 的辨析**：Depict 強調『呈現出來』，尤其適合視覺或文學作品；describe 更中性。  
**使用限制**：單純解釋原因或運作方式時，explain 更自然。

**EXAMPLE · 例句**  
The painting depicts daily life in the old harbour.  
這幅畫描繪舊港口的日常生活。

### 02 Portray

**Tier**：1  
**中文**：描寫；刻畫；塑造形象  
**語域**：neutral / formal  
**核心語義**：to represent a person, group, situation, or character in a particular way  
**用法提示**：當 describe 涉及人物形象、角色塑造或帶某種觀點的呈現時很實用。  
**常見搭配**：portray a character; portray someone as; portray society; portray events; accurately portray.  
**常見搭配對象**：person, character, group, society, event.  
**與 describe 的辨析**：Portray 常暗示『以某種方式呈現』；describe 不一定帶觀點或形象塑造。  
**使用限制**：一般技術性步驟或數據說明不適用。

**EXAMPLE · 例句**  
The novel portrays the main character as deeply conflicted.  
小說把主角刻畫成內心十分矛盾的人。

### 03 Explain

**Tier**：1  
**中文**：解釋；說明  
**語域**：neutral / very common  
**核心語義**：to make something clear by giving reasons, details, causes, or an account of how it works  
**用法提示**：當 describe 不只是說『是甚麼樣』，而是要讓人明白『為甚麼／怎樣』時最自然。  
**常見搭配**：explain a process; explain why; explain how; explain the reason; clearly explain.  
**常見搭配對象**：process, reason, idea, cause, method.  
**與 describe 的辨析**：Explain 著重使人理解原因或機制；describe 著重提供特徵、外觀或情況。  
**使用限制**：若只需形容外貌或場景，不宜用 explain。

**EXAMPLE · 例句**  
The guide explains how the booking system works.  
指南解釋預約系統如何運作。

### 04 Outline

**Tier**：1  
**中文**：概述；簡述  
**語域**：neutral / formal  
**核心語義**：to describe the main features or points of something without giving every detail  
**用法提示**：當 describe 只需交代主要內容、步驟或重點時很自然。  
**常見搭配**：outline a plan; outline the main points; outline a process; briefly outline; outline the problem.  
**常見搭配對象**：plan, process, argument, proposal, problem.  
**與 describe 的辨析**：Outline 是簡要描述；describe 可以很詳細。  
**使用限制**：若需要豐富細節或生動畫面，不適合。

**EXAMPLE · 例句**  
The report outlines the main causes of the delay.  
報告概述延誤的主要原因。

### 05 Characterise

**Tier**：1  
**中文**：描述特徵；刻畫為  
**語域**：formal / academic  
**核心語義**：to describe the distinctive qualities or features of a person, thing, period, or situation  
**用法提示**：當 describe 重點是指出某事物的典型特徵、性質或整體特性時很精準。  
**常見搭配**：characterise a period; characterise a relationship; characterise behaviour; characterise as; accurately characterise.  
**常見搭配對象**：period, behaviour, relationship, condition, trend.  
**與 describe 的辨析**：Characterise 強調『定義其特徵』；describe 更廣。  
**使用限制**：日常簡單描述物件外觀時可能過於正式。

**EXAMPLE · 例句**  
The report characterises the market as highly competitive.  
報告把市場描述為競爭非常激烈。

## Tier 2 — Structured / formal description variants · 結構化與正式描述變體

### 06 Illustrate

**Tier**：2  
**中文**：說明；以例子展示；圖示  
**語域**：neutral / academic  
**核心語義**：to make an idea, situation, or point clear by giving examples, images, or cases  
**用法提示**：當 describe 是透過例子、圖表或具體個案來說明時很常用。  
**常見搭配**：illustrate a point; illustrate with examples; graph illustrates; clearly illustrate; illustrate the difference.  
**常見搭配對象**：point, difference, trend, concept, process.  
**與 describe 的辨析**：Illustrate 強調用例子／圖像令內容清楚；describe 不需要這種輔助方式。  
**使用限制**：若只是純文字列出特徵，不一定適用。

**EXAMPLE · 例句**  
The chart illustrates how demand changed over time.  
圖表顯示需求如何隨時間改變。

### 07 Present

**Tier**：2  
**中文**：呈現；介紹；陳述  
**語域**：neutral / formal  
**核心語義**：to show, describe, or communicate information, findings, or a situation to an audience  
**用法提示**：當 describe 出現在報告、簡報、研究或正式溝通中，重點是把內容呈現給人時很自然。  
**常見搭配**：present findings; present a case; present information; present an overview; present a picture of.  
**常見搭配對象**：findings, evidence, case, overview, information.  
**與 describe 的辨析**：Present 強調向受眾展示／陳述；describe 更偏內容本身的描寫。  
**使用限制**：文學人物刻畫通常 portray / depict 更自然。

**EXAMPLE · 例句**  
The report presents a clear picture of changing consumer habits.  
報告清楚呈現消費習慣的變化。

### 08 Detail

**Tier**：2  
**中文**：詳述；詳細說明  
**語域**：neutral / formal  
**核心語義**：to describe something fully by giving specific facts, features, or steps  
**用法提示**：當 describe 要求較完整、具體、逐項說明時很實用。  
**常見搭配**：detail the process; detail the findings; detail requirements; detail changes; detail what happened.  
**常見搭配對象**：process, requirement, finding, change, event.  
**與 describe 的辨析**：Detail 強調具體細節；outline 則只給主要重點。  
**使用限制**：簡短摘要不適合用 detail。

**EXAMPLE · 例句**  
The document details the steps required to apply.  
文件詳細說明申請所需步驟。

### 09 Set out

**Tier**：2  
**中文**：列明；清楚說明  
**語域**：neutral / especially British  
**核心語義**：to describe or state information, rules, reasons, or plans clearly and in an organised way  
**用法提示**：英式／香港正式寫作很常見，尤其政策、文件、條款、報告。  
**常見搭配**：set out the reasons; set out the rules; set out a plan; clearly set out; set out the findings.  
**常見搭配對象**：reason, rule, plan, requirement, finding.  
**與 describe 的辨析**：Set out 帶有條理地陳述；describe 更一般。  
**使用限制**：視覺描繪或人物刻畫不適用。

**EXAMPLE · 例句**  
The policy sets out the conditions for receiving support.  
政策列明獲得支援的條件。

### 10 Give an account of

**Tier**：2  
**中文**：敘述；交代……經過  
**語域**：neutral / formal  
**核心語義**：to describe an event, experience, or sequence of events in an organised narrative  
**用法提示**：當 describe 是交代事件經過、親身經歷或事故過程時很自然。  
**常見搭配**：give an account of events; give a detailed account; eyewitness account; account of what happened; first-hand account.  
**常見搭配對象**：event, incident, experience, journey, what happened.  
**與 describe 的辨析**：Give an account of 偏事件敘述；describe 可形容任何事物。  
**使用限制**：抽象概念或靜態物件通常不用這個表達。

**EXAMPLE · 例句**  
The witness gave a detailed account of what happened.  
目擊者詳細敘述了事情經過。

## Tier 3 — Literary / vivid representation variants · 文學與生動呈現變體

### 11 Evokes

**Tier**：3  
**中文**：喚起；營造出；使人感受到  
**語域**：literary / expressive  
**核心語義**：to create a vivid impression, feeling, atmosphere, or mental image rather than directly describing every detail  
**用法提示**：當 describe 是透過文字／藝術令讀者或觀眾感受到某種氣氛、景象或情緒時很有用。  
**常見搭配**：evoke a sense of; evoke an atmosphere; evoke memories; vividly evoke; evoke an image.  
**常見搭配對象**：atmosphere, memory, image, feeling, mood.  
**與 describe 的辨析**：Evoke 是間接喚起印象；describe 是直接說明。  
**使用限制**：技術文件、步驟說明通常不適用。

**EXAMPLE · 例句**  
The poem evokes a strong sense of isolation.  
這首詩營造出強烈的孤獨感。

### 12 Paint a picture of

**Tier**：3  
**中文**：生動描繪；勾畫出……景象  
**語域**：neutral / idiomatic  
**核心語義**：to describe a situation vividly enough that the listener or reader can imagine it clearly  
**用法提示**：當 describe 強調生動、具畫面感地描寫時很自然。  
**常見搭配**：paint a picture of life; paint a vivid picture; paint a bleak picture; paint a picture of events; vividly paint.  
**常見搭配對象**：life, situation, future, event, community.  
**與 describe 的辨析**：這個表達比 describe 更生動、更具修辭性。  
**使用限制**：正式技術說明不宜。

**EXAMPLE · 例句**  
The interviews paint a vivid picture of life in the neighbourhood.  
訪談生動描繪了該社區的生活面貌。

### 13 Render

**Tier**：3  
**中文**：描繪；呈現；表現  
**語域**：formal / artistic  
**核心語義**：to represent or depict something in art, writing, performance, or another expressive form  
**用法提示**：當 describe 出現在藝術、文學、設計或精緻書面語境時可用。  
**常見搭配**：render a scene; render in detail; render a character; artist's rendering; faithfully rendered.  
**常見搭配對象**：scene, figure, landscape, character, image.  
**與 describe 的辨析**：Render 比 depict 更藝術化、較正式。  
**使用限制**：一般口語或行政說明不適合。

**EXAMPLE · 例句**  
The artist rendered the city skyline in remarkable detail.  
藝術家以極細緻方式描繪城市天際線。

## 04 False synonyms / description traps · 容易誤選的詞與描述陷阱

### 01 Name

**命名不等於 describe**  
name 只是指出名稱；describe 要提供特徵、情況或細節。

**ENGLISH COMPARISON**  
Naming identifies; describing gives characteristics or details.

### 02 List

**列出不等於 describe**  
list 只是逐項列出；describe 通常還要說明每項的特徵或情況。

**ENGLISH COMPARISON**  
Listing enumerates; describing explains what something is like.

### 03 Define

**定義不等於 describe**  
define 是精確說明詞義／概念邊界；describe 可以較靈活地提供特徵。

**ENGLISH COMPARISON**  
Defining states meaning or boundaries; describing gives features.

### 04 Explain

**explain 和 describe 有重疊，但焦點不同**  
explain 回答 how/why；describe 主要回答 what something is like / what happened。

**ENGLISH COMPARISON**  
Explanation gives causes or mechanisms; description gives features or an account.

### 05 Summarise

**摘要不等於完整 describe**  
summarise 只保留主要重點；describe 可以很詳細。

**ENGLISH COMPARISON**  
Summarising compresses; describing may include rich detail.

### 06 Evaluate

**評估不等於 describe**  
evaluate 是判斷質素／價值；describe 本身不要求作價值判斷。

**ENGLISH COMPARISON**  
Evaluation judges quality; description can remain neutral.

### 07 Mention

**提及不等於 describe**  
mention 只是簡短提到；describe 需要更多資訊。

**ENGLISH COMPARISON**  
Mentioning refers briefly; describing provides detail.

### 08 Describe / description

**詞性陷阱**  
describe 是動詞；description 是名詞。句子結構不能直接互換。

**ENGLISH COMPARISON**  
Describe is a verb; description is a noun.

### 練習 01.1

**Tier 1 · Target word / phrase**: Depict · 描繪；描寫；呈現

**READ THE CONTEXT · 閱讀語境**

The painting describes daily life in the old harbour.

**中文翻譯**  
這幅畫描繪舊港口的日常生活。

- A. depicts
- B. explains
- C. lists
- D. defines
- E. evaluates
- F. mentions

**CORRECT ANSWER · 正確答案**

**depicts** · 描繪；描寫；呈現

**Correct rewrite · 正確改寫**  
The painting depicts daily life in the old harbour.

**SIX-OPTION FEEDBACK · 六個選項的詳細解釋**

- **A. depicts ✓ — painting 透過視覺呈現 daily life，depict 是最自然的藝術用語。**
- **B. explains — 畫作未必解釋原因或機制。**
- **C. lists — 畫作不是逐項列出生活元素。**
- **D. defines — 不涉及詞義或概念邊界。**
- **E. evaluates — 原句沒有評價生活好壞。**
- **F. mentions — 畫作不是簡短提及。**

## 06 Semantic map · 語義總覽

| Describe 的語境 | 最接近的詞／表達 | Diagnostic question |
|---|---|---|
| 文字／圖像呈現 | **depict** | 是否是 art / film / writing 展示一個場景或情況？ |
| 人物／形象刻畫 | **portray** | 是否有 portray X as Y？ |
| 說明 how / why | **explain** | 是否要講原因、機制或運作？ |
| 只講主要重點 | **outline** | 是否是 briefly / in broad terms？ |
| 指出典型特徵 | **characterise** | 是否是 characterise X as/by Y？ |
| 用例子／圖表說明 | **illustrate** | 是否靠 example / chart 令概念清楚？ |
| 正式呈現資料 | **present** | 是否是 report / paper / findings？ |
| 詳列具體細節 | **detail** | 是否是 every step / in detail？ |
| 政策／文件列明 | **set out** | 是否是 rules / conditions / reasons？ |
| 敘述事件經過 | **give an account of** | 是否是 witness / experience / what happened？ |
| 喚起氣氛／印象 | **evoke** | 是否是 mood / atmosphere / memory？ |
| 生動勾畫景象 | **paint a picture of** | 是否需要 vivid / bleak / rich picture？ |
| 藝術／文學精細呈現 | **render** | 是否是 artist / illustrator / literary description？ |

## 07 Direct contrasts · 核心辨析

- **describe vs depict**: depict 更強調透過文字／圖像呈現畫面或情況。
- **describe vs portray**: portray 常把人／群體／情況呈現成某種形象。
- **describe vs explain**: describe 回答『是怎樣／發生了甚麼』；explain 回答『為甚麼／怎樣運作』。
- **describe vs outline**: outline 只給主要重點。
- **describe vs detail**: detail 則要求充分具體細節。
- **describe vs characterise**: characterise 強調典型特徵或整體性質。
- **describe vs illustrate**: illustrate 透過例子、圖表或個案說明。
- **describe vs set out**: set out 是有條理地正式列明。
- **describe vs summarise**: summarise 壓縮內容；describe 可以很完整。
- **describe vs evaluate**: evaluate 要作價值／質素判斷；describe 可以保持中性。

## 08 Grammar, collocation & description traps · 文法、搭配與描述陷阱

- **describe + object**：describe the scene / problem / process；一般不說 *describe about something*。
- **describe + object + as + complement**：describe the situation as serious。
- **depict + object**：depict a scene / event；也可 **depict someone as + adjective/noun**。
- **portray + object + as + complement**：portray the character as ambitious。
- **explain + how/why/that-clause**：explain how it works / explain why it failed。
- **outline + plan/process/main points**：outline the proposal / outline the steps。
- **characterise + object + as/by**：characterise the market as competitive / a period characterised by change。
- **illustrate + point/difference/trend**；也可 **illustrate with + example**。
- **detail + object** 作動詞：The report details the changes。
- **set out + rules/reasons/requirements** 是英式／香港正式文體很常見。
- **give an account of + event/experience**：give an account of what happened。
- **evoke + feeling/atmosphere/memory**：不是直接『描述』，而是令讀者感受到。
- **describe ≠ define**：define 要準確界定意思；describe 則提供特徵或情況。
- **describe ≠ mention/list**：mention 太簡短；list 只逐項列出。
