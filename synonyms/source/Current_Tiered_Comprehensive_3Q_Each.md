# CURRENT · 分層同義詞學習系統

## Current

**「目前的／現行的／當前的」，本課只處理時間狀態義，不處理名詞 current = 電流／水流／氣流。**

本單元集中處理 **current = existing, happening, valid, used, or relevant at the present time**。你提供的 **present; existing now** 正好是核心：**present** 表示目前，**existing** 表示現有。同時需要分清 **ongoing = 正在進行**、**latest = 最新一個**、**up-to-date = 已更新**、**in force = 正在生效**、**incumbent = 現任職位人士**。

這次保留 **13 個**高實用度詞／表達，並把 **一般目前狀態、當代語境、進行中、版本更新、法律效力、在任職位、啟用狀態** 分開。每個目標設 **3 道題**；所有 distractor 均完整說明其本身意思及為何在該句不合適。

## Tier 1 — Core present-time equivalents · 核心「目前／現時」近義表達

### 01 Present

**Tier**：1  
**中文**：目前的；現時的；當前的  
**語域**：neutral / very common  
**核心語義**：existing, happening, or being considered now  
**用法提示**：和 current 最直接、最廣泛的替代之一，尤其適合 present situation / present system / present level 等。  
**常見搭配**：present situation; present system; present condition; present level; at present.  
**常見搭配對象**：situation, system, condition, level, circumstances.  
**與 current 的辨析**：Present 和 current 高度接近；present 稍偏『現在這一刻／目前狀態』，current 常見於制度、版本、職位、趨勢等。  
**使用限制**：若重點是『最新版本』，latest / up-to-date 可能更精準。

**EXAMPLE · 例句**  
The present system will remain in place until next year.  
現行制度會維持至明年。

### 02 Existing

**Tier**：1  
**中文**：現有的；目前存在的  
**語域**：neutral / formal  
**核心語義**：already in existence at the present time  
**用法提示**：當 current 指現時已存在、而不是新建／擬議的制度、安排、資源或客戶時很自然。  
**常見搭配**：existing system; existing rules; existing customers; existing resources; existing arrangements.  
**常見搭配對象**：system, rule, customer, resource, arrangement.  
**與 current 的辨析**：Existing 強調『已存在』；current 更可表示現時採用／有效。  
**使用限制**：描述正在發生的趨勢或事件時 existing 通常不自然。

**EXAMPLE · 例句**  
The proposal would replace the existing rules.  
這項建議會取代現有規則。

### 03 Present-day

**Tier**：1  
**中文**：現今的；當代的  
**語域**：neutral  
**核心語義**：belonging to or characteristic of the present time  
**用法提示**：當 current 用來和過去時代比較、指『現今社會／現代情況』時很適合。  
**常見搭配**：present-day society; present-day conditions; present-day technology; present-day usage; present-day world.  
**常見搭配對象**：society, technology, world, practice, conditions.  
**與 current 的辨析**：Present-day 有『現今時代』意味；current 通常更中性、時間範圍更短。  
**使用限制**：一份剛更新的文件版本不會通常叫 present-day version。

**EXAMPLE · 例句**  
Present-day technology makes remote work much easier.  
現今科技令遙距工作容易得多。

### 04 Contemporary

**Tier**：1  
**中文**：當代的；現代的；同時期的  
**語域**：neutral / formal  
**核心語義**：belonging to the present period, especially in culture, society, art, or ideas  
**用法提示**：當 current 指當代文化、藝術、思想、社會問題等時很自然。  
**常見搭配**：contemporary society; contemporary art; contemporary issues; contemporary culture; contemporary practice.  
**常見搭配對象**：art, society, culture, literature, issue.  
**與 current 的辨析**：Contemporary 常指較廣的『當代』；current 可以只是最近幾天／幾月正在發生。  
**使用限制**：current balance / current price 之類數值狀態不能改成 contemporary。

**EXAMPLE · 例句**  
The course examines contemporary social issues.  
課程探討當代社會議題。

### 05 Ongoing

**Tier**：1  
**中文**：正在進行的；持續中的  
**語域**：neutral / common  
**核心語義**：continuing to happen or develop at the present time  
**用法提示**：當 current 的重點是某活動、討論、調查、問題仍在進行時很精準。  
**常見搭配**：ongoing investigation; ongoing project; ongoing discussion; ongoing problem; ongoing work.  
**常見搭配對象**：project, investigation, discussion, work, issue.  
**與 current 的辨析**：Ongoing 強調『仍在進行』；current 只表示目前相關／目前存在。  
**使用限制**：current address / current version 等靜態資料不適用。

**EXAMPLE · 例句**  
The report summarises the ongoing investigation.  
報告總結仍在進行中的調查。

## Tier 2 — Updated / prevailing / official-status variants · 更新、盛行與正式狀態變體

### 06 Up-to-date

**Tier**：2  
**中文**：最新的；已更新的；符合現況的  
**語域**：neutral / very common  
**核心語義**：updated so that it contains the newest available information or reflects the present situation  
**用法提示**：當 current 指資料、名單、軟件或文件『已更新到最新狀態』時很自然。  
**常見搭配**：up-to-date information; up-to-date records; up-to-date software; keep up to date; fully up-to-date.  
**常見搭配對象**：information, record, software, database, knowledge.  
**與 current 的辨析**：Up-to-date 加入『已更新』意味；current 不一定是最新，只表示目前使用／有效。  
**使用限制**：current government / current situation 不能機械改成 up-to-date。

**EXAMPLE · 例句**  
Please make sure your contact details are up-to-date.  
請確保你的聯絡資料是最新的。

### 07 Latest

**Tier**：2  
**中文**：最新的；最近的  
**語域**：neutral / very common  
**核心語義**：most recent in a sequence of versions, events, reports, or developments  
**用法提示**：當 current 實際要表達『最新一版／最新消息／最近數據』時可用。  
**常見搭配**：latest version; latest report; latest figures; latest news; latest update.  
**常見搭配對象**：version, report, figure, news, update.  
**與 current 的辨析**：Latest = 最近期的一個；current = 現在使用／有效的一個。兩者常重疊但不完全相同。  
**使用限制**：目前員工／現任職位等不能用 latest。

**EXAMPLE · 例句**  
The latest version includes several security fixes.  
最新版本包含數項安全修正。

### 08 Prevailing

**Tier**：2  
**中文**：現行的；普遍存在的；盛行的  
**語域**：formal  
**核心語義**：existing or most common at the present time in a particular place, field, or situation  
**用法提示**：當 current 指現時盛行的觀點、條件、價格、風向或做法時很有用。  
**常見搭配**：prevailing view; prevailing conditions; prevailing practice; prevailing rate; prevailing attitude.  
**常見搭配對象**：view, condition, practice, rate, attitude.  
**與 current 的辨析**：Prevailing 加入『目前占主導／普遍』意味；current 不一定普遍。  
**使用限制**：單一個人的 current address 不適用。

**EXAMPLE · 例句**  
The policy reflects prevailing attitudes toward data privacy.  
該政策反映現時普遍存在的資料私隱觀念。

### 09 In force

**Tier**：2  
**中文**：現行有效的；正在生效的  
**語域**：formal / legal  
**核心語義**：officially valid and operating at the present time  
**用法提示**：當 current 指法律、規則、合約條款、政策目前仍有效時非常精準。  
**常見搭配**：remain in force; regulations in force; law in force; rules currently in force; come into force.  
**常見搭配對象**：law, rule, regulation, agreement, policy.  
**與 current 的辨析**：In force 強調法律／規則的效力；current 只是較廣的時間描述。  
**使用限制**：一般產品、人物、趨勢不適用。

**EXAMPLE · 例句**  
The current regulations remain in force until December.  
現行規例會有效至十二月。

### 10 Incumbent

**Tier**：2  
**中文**：現任的；在任的  
**語域**：formal  
**核心語義**：currently holding a particular office, position, or official role  
**用法提示**：當 current 修飾 president / mayor / chair / office-holder 等職位人士時很精準。  
**常見搭配**：incumbent president; incumbent mayor; incumbent chair; incumbent government; incumbent office-holder.  
**常見搭配對象**：president, mayor, chair, government, office-holder.  
**與 current 的辨析**：Incumbent 只用於現任職位／權力位置；current 範圍遠廣。  
**使用限制**：current version / current price / current issue 都不能用 incumbent。

**EXAMPLE · 例句**  
The incumbent chair will remain in office until March.  
現任主席會留任至三月。

## Tier 3 — Active-use / sentence-level variants · 啟用、現用與句子層級變體

### 11 Active

**Tier**：3  
**中文**：現用的；有效中的；活躍中的  
**語域**：neutral / technical  
**核心語義**：currently operating, enabled, in use, or participating  
**用法提示**：當 current 指帳戶、訂閱、案例、程序或系統目前仍啟用／運作時可近似。  
**常見搭配**：active account; active subscription; active case; active user; active session.  
**常見搭配對象**：account, subscription, case, user, session.  
**與 current 的辨析**：Active 強調啟用／運作狀態；current 只表示目前。  
**使用限制**：current price / current government 不適用。

**EXAMPLE · 例句**  
Only active subscriptions receive the monthly update.  
只有目前有效的訂閱才會收到每月更新。

### 12 Now in use

**Tier**：3  
**中文**：目前使用中的；現時採用的  
**語域**：neutral / explanatory  
**核心語義**：being used at the present time rather than merely existing or being proposed  
**用法提示**：當 current 指目前正在使用的系統、方法、表格或版本時是透明自然的解釋性改寫。  
**常見搭配**：system now in use; method now in use; version now in use; equipment now in use; form currently used.  
**常見搭配對象**：system, method, version, equipment, form.  
**與 current 的辨析**：Now in use 把 current 的『現正使用』義說清楚。  
**使用限制**：若只是存在但沒有被使用，existing 更準。

**EXAMPLE · 例句**  
The system now in use was introduced three years ago.  
目前使用中的系統是三年前引入的。

### 13 As things stand

**Tier**：3  
**中文**：按目前情況；就現況而言  
**語域**：neutral / idiomatic  
**核心語義**：according to the situation as it exists at the present moment  
**用法提示**：當 current situation / current position 要改寫成整句的『按目前情況』時很實用。  
**常見搭配**：as things stand; as matters stand; current position; present situation; for now.  
**常見搭配對象**：situation, outlook, position, arrangement, decision.  
**與 current 的辨析**：這是句子層級的時間狀態表達，不是形容詞。  
**使用限制**：不能直接放在名詞前代替 current。

**EXAMPLE · 例句**  
As things stand, the project is still within budget.  
按目前情況，項目仍然沒有超出預算。

## 04 False synonyms / time-status traps · 容易誤選的詞與時間狀態陷阱

### 01 Modern

**現代的 不等於 current**  
modern 通常指較新的時代／風格，並不保證是目前正在使用或存在。

**ENGLISH COMPARISON**  
Modern refers to a recent era or style; current means present now.

### 02 New

**新的 不等於 current**  
new 強調新近產生；current 可以已經存在多年，只是現在仍在使用。

**ENGLISH COMPARISON**  
Something current need not be new.

### 03 Latest

**latest 和 current 常重疊，但不是完全同義**  
latest 是序列中最最近的一個；current 是現在有效／使用的一個。

**ENGLISH COMPARISON**  
The latest version may not yet be the current production version.

### 04 Recent

**最近的 不等於 current**  
recent 指不久前發生；current 指現在仍然存在／有效。

**ENGLISH COMPARISON**  
A recent event may already be over; a current event is happening now.

### 05 Future

**未來的 和 current 相反**  
future 指尚未發生／尚未生效；current 指現在。

**ENGLISH COMPARISON**  
Future is prospective; current is present.

### 06 Previous

**之前的 和 current 不同**  
previous 指當前之前的一個版本、職位或時段。

**ENGLISH COMPARISON**  
Previous comes before the current one.

### 07 Temporary

**臨時的 不等於 current**  
temporary 描述持續時間短；current 描述時間位置，現行安排可以是永久的。

**ENGLISH COMPARISON**  
A current arrangement may be temporary or permanent.

### 08 Current (electricity)

**注意同形異義詞：電流**  
current 作名詞可指電流、水流、氣流；本課處理的是形容詞『目前的／現行的』。

**ENGLISH COMPARISON**  
Electrical current and the adjective current are different senses.

### 練習 01.1

**Tier 1 · Target word / phrase**: Present · 目前的；現時的；當前的

**READ THE CONTEXT · 閱讀語境**

The current system will remain in place until next year.

**中文翻譯**  
現行制度會維持至明年。

- A. present
- B. modern
- C. new
- D. recent
- E. future
- F. previous

**CORRECT ANSWER · 正確答案**

**present** · 目前的；現時的；當前的

**Correct rewrite · 正確改寫**  
The present system will remain in place until next year.

**SIX-OPTION FEEDBACK · 六個選項的詳細解釋**

- **A. present ✓ — system currently in place 可自然改寫成 present system。**
- **B. modern — modern 只表示較現代，不代表現在採用。**
- **C. new — 系統可能已用了很多年，current 不等於新。**
- **D. recent — recent system 不自然，也只表示近期。**
- **E. future — 與 current 相反。**
- **F. previous — 指現行之前的系統。**

## 06 Semantic map · 語義總覽

| Current 的語境 | 最接近的詞／表達 | Diagnostic question |
|---|---|---|
| 一般目前狀態 | **present** | 是否只是表示『現在的』？ |
| 目前已存在 | **existing** | 是否與 new/proposed 對比？ |
| 現今時代 | **present-day** | 是否和過去時代作比較？ |
| 當代文化／社會 | **contemporary** | 是否是 art / culture / social issues？ |
| 仍在進行 | **ongoing** | 是否有 continue / not yet resolved？ |
| 已更新至最新狀態 | **up-to-date** | 是否是 information / records / software？ |
| 序列中最新一個 | **latest** | 是否是 version / report / figures？ |
| 目前普遍／主導 | **prevailing** | 是否是 view / rate / practice / conditions？ |
| 法律／規則現時生效 | **in force** | 是否是 law / regulation / agreement？ |
| 現任職位人士 | **incumbent** | 是否是 president / mayor / chair / government？ |
| 目前啟用 | **active** | 是否是 account / subscription / case？ |
| 目前正在使用 | **now in use** | 是否是 system / method / form？ |
| 按目前情況 | **as things stand** | 是否需要整句改寫 current situation / position？ |

## 07 Direct contrasts · 核心辨析

- **current vs present**: 兩者高度接近；present 更直接指目前狀態。
- **current vs existing**: existing 只表示已存在；current 還可表示正在使用／有效。
- **current vs present-day**: present-day 常用於較長時間尺度的『現今時代』。
- **current vs contemporary**: contemporary 常用於文化、藝術、思想和社會議題。
- **current vs ongoing**: ongoing 強調事情仍在進行。
- **current vs up-to-date**: up-to-date 強調已更新；current 不一定最新。
- **current vs latest**: latest 是序列中最最近的一個；current 是現在有效／使用的一個。
- **current vs prevailing**: prevailing 還有『普遍／占主導』意味。
- **current vs in force**: in force 專門表示法律／規則目前有效。
- **current vs incumbent**: incumbent 專門指現任職位人士／政府。

## 08 Grammar, collocation & time-status traps · 文法、搭配與時間狀態陷阱

- **current + noun**：current situation / version / price / policy / account。
- **present + noun**：present situation / present system；也可用 **at present** 作副詞短語。
- **existing + noun**：existing rules / customers / resources，常和 new / proposed 對比。
- **present-day** 作前置形容詞通常加連字號：present-day society / technology。
- **contemporary** 常見於 art / culture / society / literature / issues。
- **ongoing + activity/problem**：ongoing investigation / discussion / issue。
- **up-to-date** 作形容詞通常加連字號：up-to-date information；但 **keep up to date** 常不加連字號。
- **latest + singular/plural sequence item**：latest version / latest figures / latest news。
- **prevailing + rate/view/practice/conditions**：帶『目前普遍／通行』意思。
- **in force** 通常放在名詞後或述語位置：regulations currently in force / the law remains in force。
- **incumbent + office-holder**：incumbent president / mayor / chair。
- **current ≠ recent**：recent 可以已經完結；current 表示現在仍然存在／有效。
- **current ≠ new/latest**：目前正在使用的東西可能並不新，也可能不是最新研發版本。
- 名詞 **current** 還可指電流、水流、氣流；本課不要和形容詞『目前的』混淆。
