# Solution

**答案、補救辦法、解決方案、前進方向、策略、措施、權宜解法——究竟是哪一種 solution？**

核心近義與近義表達：

**answer; remedy; way forward; fix; resolution; approach; strategy; measure; workaround; corrective action**

> **核心詞數不固定。** 本課保留 **10 個**自然且辨析價值高的核心表達。  
> 你提供的 **answer; remedy; way forward** 全部保留。  
> 本課特別區分「正確答案」「補救辦法」「下一步出路」「直接修正」「處理方法」「長期策略」「政策措施」「權宜解法」。

# 01 同義詞指南


## 01 Answer

**答案；解答**

當 `solution` 指問題、題目、疑問或謎題的正確回答時最直接、最自然。比 `solution` 更偏『回答是甚麼』，而不一定強調處理問題的過程。

### EXAMPLE · 例句

We need an answer to this maths problem.

我們需要這條數學題的答案。

### COMMON COLLOCATIONS · 常見搭配


- answer to a question

- answer to a problem

- correct answer

- find the answer

### EXAMPLE · 例句

# 02 False synonyms


## 01 Answer

**只適合問題／題目 sense**

answer 是 solution 的重要近義詞，但通常要求明確 question / puzzle / calculation。

### ENGLISH COMPARISON

A maths problem has an answer; a housing shortage needs a broader solution.

---

## 02 Remedy

**補救不等於所有 solution**

remedy 適合修正缺陷、改善不良狀況；不常用於純數學或邏輯答案。

### ENGLISH COMPARISON

A legal remedy addresses a wrong; an equation has a solution.

---

## 03 Way forward

**出路不等於完整 solution**

way forward 更強調下一步方向，未必已完全解決問題。

### ENGLISH COMPARISON

The meeting agreed on a way forward, but the final solution still required work.

---

## 04 Method

**方法不保證能解決問題**

method 是做事方式；solution 應對一個具體 problem。

### ENGLISH COMPARISON

A method can be tested without becoming the final solution.

---

## 05 Strategy

**策略比單一 solution 更長期**

strategy 是一套方向／行動安排，通常比單一 fix 更廣。

### ENGLISH COMPARISON

A strategy may contain several measures and solutions.

---

## 06 Treatment

**處理／治療不等於 solution**

treatment 在醫療或處理語境很常見，但不是所有 solution 的近義詞。

### ENGLISH COMPARISON

A treatment may relieve a condition without providing a permanent solution.

---

## 07 Solve / solution

**詞性陷阱**

`solve` 是動詞；`solution` 是名詞。

### ENGLISH COMPARISON

We solved the problem; we found a solution.

---

## 08 Solution / solutional

**詞形陷阱**

標準一般英語用 `solution` 作名詞；`solutional` 很少見且多屬專門語境，不應作一般替換。

### ENGLISH COMPARISON

Use 'a practical solution', not 'a solutional answer' in ordinary English.

# 05 高價值近義詞對比

## Solution vs Answer
`answer` 最適合 question / puzzle / maths problem 等有明確答案的語境。

## Solution vs Remedy
`remedy` 偏補救、修正已有問題或不良狀況。

## Solution vs Way forward
`way forward` 重點是下一步方向，不一定已經完成解決。

## Solution vs Fix
`fix` 較口語，尤其自然於技術問題、故障、bug、小型操作問題。

## Solution vs Resolution
`resolution` 較正式，適合 dispute / complaint / issue。

## Solution vs Approach
`approach` 是處理問題的方法，不一定保證最後成功。

## Solution vs Strategy
`strategy` 比單一 solution 更長期、更有計劃。

## Solution vs Measure
`measure` 是一項具體政策／管理行動，常只是整體 solution 的一部分。

## Solution vs Workaround
`workaround` 只繞過限制，不處理 root cause。

## Solution vs Corrective action
`corrective action` 特別自然於 audit / safety / compliance / incident 後正式整改。

# 07 Grammar and usage notes

## 01 Solution to
最常見：
- solution to the problem
- solution to the puzzle
- solution to the crisis

通常不是：
- solution for the problem
但 `solution for X` 可在某些產品／技術語境表示「為 X 提供的方案」。

## 02 Answer to
- answer to a question
- answer to the problem

## 03 Remedy for
- remedy for the problem
- remedy for the shortage

## 04 Approach to
- approach to the problem
- approach to managing costs

## 05 Strategy for / strategy to
- strategy for reducing costs
- strategy to improve safety

## 06 Workaround for
- workaround for a bug
- workaround for a limitation
