# 01 同義詞指南

## Button 的 14 種更精準說法

### 01 Control
**控制鈕；控制項；操作控制**

表示用來操作裝置、系統或介面的某個控制元件。它比 `button` 更廣，可以是按鈕、旋鈕、滑桿或其他控制方式。

**EXAMPLE · 例句**

> Press the control to start the machine.

按下控制鈕以啟動機器。

**USAGE CLUE**

- control panel
- volume control
- on-screen control
- 是上位概念，不一定是按壓式按鈕

---

### 02 Switch
**開關；切換開關**

表示把裝置在兩種或多種狀態之間切換，例如 on/off。

**EXAMPLE · 例句**

> Flip the switch to turn on the light.

撥動開關把燈打開。

**USAGE CLUE**

- light switch
- power switch
- on/off switch
- 重點是「切換狀態」，不一定是按壓式

---

### 03 Key
**按鍵；鍵**

表示鍵盤、電話、遙控器或其他按鍵式裝置上的單一鍵。

**EXAMPLE · 例句**

> Press the Enter key to continue.

按 Enter 鍵繼續。

**USAGE CLUE**

- keyboard key
- number key
- function key
- 常見於鍵盤和數字鍵盤

---

### 04 Push button
**按鈕；按壓式按鈕**

最直接的實體裝置用語之一，表示以按壓方式啟動功能的按鈕。

**EXAMPLE · 例句**

> Press the red push button in an emergency.

緊急時按下紅色按鈕。

**USAGE CLUE**

- emergency push button
- push-button control
- industrial / physical device
- 明確強調「按下去」

---

### 05 Control button
**控制按鈕**

表示設備或介面上負責某項控制功能的按鈕。

**EXAMPLE · 例句**

> Use the control button to adjust the speed.

使用控制按鈕調整速度。

**USAGE CLUE**

- device control
- remote control
- neutral technical wording
- 比單純 button 更強調功能性

---

### 06 Command button
**命令按鈕；操作按鈕**

主要用於軟件或介面，表示按下後立即執行一項命令。

**EXAMPLE · 例句**

> Click the command button to save the record.

按一下命令按鈕以儲存紀錄。

**USAGE CLUE**

- software / GUI
- executes an action
- save / submit / print 等操作

---

### 07 Action button
**操作按鈕；動作按鈕**

表示在網站、應用程式或介面中觸發具體動作的按鈕。

**EXAMPLE · 例句**

> The main action button submits the form.

主要操作按鈕會提交表格。

**USAGE CLUE**

- UI / UX
- primary action button
- call-to-action contexts
- 重點是「觸發動作」

---

### 08 Toggle
**切換控制；切換鍵**

表示在兩個狀態之間切換的控制元件，例如開／關、啟用／停用。

**EXAMPLE · 例句**

> Use the toggle to turn notifications off.

使用切換控制關閉通知。

**USAGE CLUE**

- toggle on/off
- settings UI
- 可以是滑動式，不一定像傳統 button

---

### 09 Toggle button
**切換按鈕**

表示按下後會在兩個狀態之間反覆切換的按鈕。

**EXAMPLE · 例句**

> The mute toggle button switches the microphone on and off.

靜音切換按鈕可開啟或關閉麥克風。

**USAGE CLUE**

- pressed / unpressed states
- mute / bold / visibility
- 更精確地描述可切換狀態的 button

---

### 10 Selector
**選擇控制；選擇器**

表示從幾個選項或模式中選擇其中一個的控制元件。

**EXAMPLE · 例句**

> Use the mode selector to choose a wash cycle.

使用模式選擇器選擇洗衣程序。

**USAGE CLUE**

- mode selector
- option selector
- 可能是按鈕、旋鈕或介面控制
- 不一定是單一按鈕

---

### 11 Trigger
**觸發鍵；觸發控制**

表示按下或啟動後會立即觸發某個動作的控制元件。

**EXAMPLE · 例句**

> Pull the trigger to take the photograph.

按下觸發鍵拍照。

**USAGE CLUE**

- camera / controller / tools
- trigger an action
- 比 button 更具「立即觸發」意味

---

### 12 Soft key
**軟鍵；功能隨畫面改變的按鍵**

表示功能由螢幕標示決定、可隨不同介面畫面改變的按鍵。

**EXAMPLE · 例句**

> Press the left soft key to open the menu.

按左軟鍵打開選單。

**USAGE CLUE**

- phones / handheld devices
- function changes by screen context
- physical key + dynamic function

---

### 13 On-screen button
**螢幕按鈕；畫面按鈕**

直接表示顯示在螢幕上的可點擊／觸控按鈕。

**EXAMPLE · 例句**

> Tap the on-screen button to confirm your choice.

點按螢幕按鈕確認選擇。

**USAGE CLUE**

- touchscreens
- apps / kiosks
- 與 physical button 對比

---

### 14 Press control
**按壓控制；按壓式控制件**

技術性或說明性表達，表示透過按壓操作的控制元件。

**EXAMPLE · 例句**

> The panel includes a press control for emergency shutdown.

面板上設有一個用於緊急停機的按壓控制件。

**USAGE CLUE**

- technical / descriptive
- not as common as push button
- useful when describing control type rather than label

# 02 False synonyms

## 01 button / switch

### 按鈕不一定是開關

`button` 描述外形或操作方式；`switch` 強調在不同狀態之間切換。

**ENGLISH COMPARISON**

> Press the button to start the timer.  
> Flip the switch to turn the power on.

---

## 02 button / key

### 一般按鈕不一定是鍵盤按鍵

`key` 最常見於 keyboard、keypad、telephone 等有成組按鍵的裝置。

---

## 03 button / icon

### 圖示不一定可以點擊

`icon` 是視覺符號；只有當它具有互動功能時才可能同時是一個按鈕。

---

## 04 button / control

### control 是上位概念

滑桿、旋鈕、按鈕、切換器都可以是 controls。

---

## 05 button / toggle

### toggle 的核心是「狀態切換」

一個普通 Submit button 通常只執行一次動作；toggle 則在 on/off 等狀態之間切換。

---

## 06 button / knob

### 旋鈕不是按鈕

`knob` 通常靠旋轉調節，例如音量或溫度。

---

## 07 button / link

### 網頁連結不等於按鈕

`link` 的核心是導航到另一頁／位置；`button` 更常觸發動作。

---

## 08 button / tab

### 分頁標籤不等於一般按鈕

`tab` 用於切換內容頁或介面分區，功能比一般 button 更特定。

---

## 練習 01.1

**Target word: Control · 控制鈕；控制項**

### READ THE CONTEXT · 閱讀語境

> Press the button on the panel to start the machine.

**中文翻譯**

按下面板上的控制鈕以啟動機器。

A. control  
B. icon  
C. label  
D. indicator  
E. display  
F. cable

### CORRECT ANSWER · 正確答案

**control · 控制鈕**

> Press the control on the panel to start the machine.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. control ✓**  
`control` 是操作裝置的上位詞。句中的按鈕具有啟動機器的控制功能，所以可自然改寫為 control。

**B. icon**  
`icon` = 圖示，主要是視覺符號。實體機器面板上的可按壓控制並不自然稱為 icon。

**C. label**  
`label` = 標籤，只用來說明控制功能，本身通常不能被按下操作。

**D. indicator**  
`indicator` = 指示器，用來顯示狀態，例如燈號；主要功能不是接受輸入。

**E. display**  
`display` = 顯示器／畫面，主要輸出資訊，而不是這個啟動控制。

**F. cable**  
`cable` = 電纜／線材，沒有操作功能。

**Target phrase: On-screen button · 螢幕操作按鈕**

### READ THE CONTEXT

> A large button appears on the tablet when the download is ready.

**中文翻譯**

下載準備好後，平板電腦畫面上會出現一個大型按鈕。

A. on-screen button

keycap 是鍵盤實體鍵帽。

**D. socket**  
接口不是介面控制。

**E. microphone**  
聲音輸入元件。

**F. sensor**  
感測器不是顯示按鈕。

# 05 高混淆組

## button vs control
- **button**：具體按鈕。
- **control**：所有操作元件的上位概念。

## button vs switch
- **button**：強調按壓式介面／元件。
- **switch**：強調狀態切換。

## button vs key
- **button**：一般按鈕。
- **key**：鍵盤、電話、keypad 中的一個鍵。

## command button vs action button
- **command button**：偏傳統 GUI／技術用語，執行命令。
- **action button**：現代 UI/UX 用語，強調觸發主要操作。

## toggle vs toggle button
- **toggle**：任何切換控制。
- **toggle button**：按鈕形態的切換控制。

## button vs selector
- **button**：一次按下的控制。
- **selector**：從多個選項中選擇的控制。

## physical button vs on-screen button
- **physical button**：硬件。
- **on-screen button**：軟件畫面中的虛擬控制。

## push button vs press control
- **push button**：最自然、常見的實體術語。
- **press control**：較技術性、說明性的控制類型描述。

# 08 生成／評估注意事項

1. 新格式固定為 **3 questions per synonym**；14 個 target = **42 題**。
2. 每一題保留：
   - Target word / phrase
   - READ THE CONTEXT
   - 中文翻譯
   - 六個選項
   - 正確答案
   - 正確改寫
   - A–F 每個選項獨立解釋
3. A–F 解釋應包含：
   - 詞義／控制類型
   - 典型搭配或裝置語境
   - 為甚麼此語境適合或不適合
4. `control` 與 `switch` 是最重要的核心近義詞：
   - control = 上位概念
   - switch = 狀態切換
5. `key` 主要限於鍵盤、keypad、電話按鍵等語境。
6. `push button` 是描述實體按壓式按鈕最自然的專門表達之一。
7. `command button` 和 `action button` 都屬軟件介面：
   - command button = 執行命令
   - action button = 觸發某個主要動作
8. `toggle` 不一定是傳統 button；它可以是滑動式 UI switch。
9. `toggle button` 則明確是具有按鈕形態、可保持狀態的控制。
10. `selector` 主要是多選一控制，不應機械替換所有 button。
11. `trigger` 適合相機、控制器、工具等「立即觸發動作」的元件。
12. `soft key` 有特定技術含義：實體鍵本身不變，但功能由螢幕情境決定。
13. `on-screen button` 是高價值、非常清楚的 physical/digital 對比表達。
14. `press control` 屬說明性技術表達，常用度低於 `push button`；只有需要描述控制方式時才值得使用。
15. 真正進階題目應直接比較：
    - button / control / switch
    - button / key
    - command button / action button
    - switch / toggle / toggle button
    - button / selector
    - physical button / on-screen button
16. `button` 本身仍然是最廣泛、最自然的核心詞；其他替代語主要增加「控制方式、狀態行為、裝置類型、介面環境與技術精度」上的區別。
