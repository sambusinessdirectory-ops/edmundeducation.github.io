# Archive · noun

「檔案集合／已儲存檔案／長期保存資料庫」，究竟是哪一種 archive？

如果 `archive` 指一批被保存供日後查閱的紀錄，可用 `record collection`；在數碼環境中指已經儲存下來的舊檔案，可用 `stored files`。強調集中保存資料的地方或系統，可用 `repository / records repository / file repository`；圖書館、博物館或檔案館所藏的一整批資料可用 `holdings`；主要由書面文件構成時可用 `document collection`；若內容主要用來記錄過去事件，則可用 `historical records`——英文會按 archive 是資料集合、保存地點、數碼檔案、機構館藏還是歷史紀錄，選用不同但更精確的說法。

# 01 同義詞指南

## Archive 的 8 種更精準說法

### 01 Record collection

檔案集合；紀錄彙集

最直接、最透明的近義說法之一。當 `archive` 指一批被保存、整理以供日後查閱的文件、紀錄或資料時很自然。

**EXAMPLE · 例句**

The museum maintains a record collection documenting the town's industrial history.

博物館保存了一批記錄這座城鎮工業歷史的檔案集合。

### 02 Stored files

已儲存檔案；保存下來的文件

直接對應使用者提供的意思。當 `archive` 指電腦、系統或機構中已保存、暫時不再使用但仍需保留的檔案時很自然。

**EXAMPLE · 例句**

The server contains stored files from projects completed several years ago.

伺服器中保存着幾年前已完成項目的檔案。

### 03 Repository

資料庫；儲存庫；典藏庫

當 `archive` 指集中保存文件、數據、程式碼、研究材料或其他資源的地方或系統時很常用；比 archive 更強調『儲存位置』。

**EXAMPLE · 例句**

The university created a digital repository for research papers and datasets.

大學建立了一個數碼儲存庫，用來保存研究論文和數據集。

### 04 Records repository

紀錄儲存庫；檔案庫

較正式，當 `archive` 指專門保存行政、法律、機構或歷史紀錄的系統或地方時很精確。

**EXAMPLE · 例句**

The agency transferred older case files to a central records repository.

機構把較舊的個案檔案轉移到中央紀錄儲存庫。

### 05 Holdings

館藏；所藏資料

當 `archive` 指圖書館、博物館、檔案館或研究機構所保存的一整批資料、文件或收藏時可用；通常用複數。

**EXAMPLE · 例句**

The library's holdings include letters, maps, and early photographs.

圖書館館藏包括信件、地圖和早期照片。

### 06 Document collection

文件集；文件收藏

當 `archive` 主要由書面文件、報告、信件、手稿或行政資料組成時很自然；比 general archive 更具體。

**EXAMPLE · 例句**

The researcher consulted a document collection relating to the railway company.

研究人員查閱了一批與鐵路公司有關的文件集。

### 07 Historical records

歷史紀錄；史料

當 `archive` 指保存過去事件、機構或人物資料的紀錄時很合適；比 archive 更直接突出歷史用途。

**EXAMPLE · 例句**

The archive contains historical records from the early twentieth century.

這個檔案庫保存了二十世紀初的歷史紀錄。

### 08 File repository

檔案儲存庫

當 `archive` 指數碼環境中集中保存檔案的系統或位置時很自然，常見於 IT、雲端儲存和團隊協作語境。

**EXAMPLE · 例句**

The team moved old design files to a separate file repository.

團隊把舊設計檔案移到另一個檔案儲存庫。

# 02 False synonyms

看起來相關，意思卻不同。`archive` 的核心是把紀錄、文件或舊資料長期保存，以便日後查閱；`backup` 主要是防止資料遺失，`folder / storage` 只是整理或存放方式，`database` 又特別偏結構化資料。`library / collection / history` 都可能和 archive 有關，但範圍或功能並不相同。

### 01 Library

圖書館不等於 archive

`library` 通常主要收藏書籍和可借閱資料；`archive` 更常保存原始文件、紀錄、舊檔案或需要長期保存的材料。

**ENGLISH COMPARISON**

A library mainly provides published materials; an archive preserves records and original documents.

### 02 Database

資料庫不等於所有 archive

`database` 是有結構地儲存和查詢數據的系統；archive 可以是紙本、照片、聲音或其他非資料庫形式。

**ENGLISH COMPARISON**

A database stores structured data; an archive can contain many kinds of preserved records.

### 03 Backup

備份不等於 archive

`backup` 是為防止資料遺失而建立的副本；archive 是為長期保存和查閱而保留的資料。

**ENGLISH COMPARISON**

A backup protects against data loss; an archive preserves material for long-term access.

### 04 Folder

資料夾不等於 archive

`folder` 只是整理檔案的容器；archive 通常是一整批有保存價值的資料。

**ENGLISH COMPARISON**

A folder organizes files; an archive is a preserved collection.

### 05 Collection

收藏範圍太廣

`collection` 可以是任何被集合起來的東西；archive 通常帶有保存紀錄、歷史資料或舊檔案的目的。

**ENGLISH COMPARISON**

Collection is broad; archive usually implies preservation of records or historical material.

### 06 Storage

儲存空間不等於 archive

`storage` 指保存資料或物品的空間或容量；archive 更強調被長期保存的資料集合。

**ENGLISH COMPARISON**

Storage is the capacity or place for keeping things; an archive is the preserved material itself or its repository.

### 07 History

歷史不等於 archive

`history` 是過去事件或其研究；archive 是保存這些歷史證據和紀錄的資料集合。

**ENGLISH COMPARISON**

History is the past or its study; an archive contains records of that past.

### 08 Archive / archival

名詞與形容詞不同

`archive` 是名詞；`archival` 是形容詞，表示與檔案保存、檔案館或長期保存品質有關。

**ENGLISH COMPARISON**

Archive is a noun. Archival is an adjective.
