# SYNONYMS · 同義詞學習系統

# Screen

**本課集中在 `screen = projection surface / display screen` 的『屏幕、顯示面、投影面』意思，而不是 `screen = 篩查 / 遮擋 / 隔板` 等其他意思。不同替代表達主要按『是否電子顯示』『是否專供投影』『是否獨立裝置』『是否內置面板』來區分。**

核心替代表達：

`projection surface / display screen / monitor / display / projection screen / viewing screen / video display / display panel`

> **核心原則**：先判斷 screen 指的是 **projection surface, electronic display screen, standalone monitor, generic display, dedicated projection screen, viewing screen, video display, or built-in display panel**。

---

# 01 同義詞指南

## 01 Projection surface

**投影表面；投影面**

當 `screen` 指投影機把影像投射到的實體表面時，`projection surface` 很精準。它比 `screen` 更技術化，而且不一定是專門製造的幕，也可以是牆面或其他平面。

**EXAMPLE · 例句**

> The image remained clear across the entire projection surface.

影像在整個投影表面上都保持清晰。

**SEMANTIC CUE · 語義提示**

> **the physical surface onto which an image is projected**

**REGISTER · 語域**

投影、技術、正式

---

## 02 Display screen

**顯示屏；顯示螢幕**

和 `screen` 非常接近，特別適合電腦、電話、儀器、售票機和電子設備。它明確表示這個 screen 的功能是顯示資訊或影像。

**EXAMPLE · 例句**

> The machine shows the instructions on a display screen.

機器在顯示屏上顯示指示。

**SEMANTIC CUE · 語義提示**

> **an electronic screen used to show information or images**

**REGISTER · 語域**

科技、一般、正式

---

## 03 Monitor

**顯示器；監視器**

當 `screen` 指電腦或監控系統使用的獨立電子顯示裝置時，`monitor` 很自然。它通常指整個裝置，而不只是發光表面。

**EXAMPLE · 例句**

> The designer uses a large monitor for editing photographs.

設計師使用大型顯示器編輯相片。

**SEMANTIC CUE · 語義提示**

> **a standalone electronic display device, especially for computers or monitoring**

**REGISTER · 語域**

科技、辦公、一般

---

## 04 Display

**顯示器；顯示畫面；顯示裝置**

當 `screen` 泛指顯示資訊的電子介面或裝置時，`display` 很實用。它比 `screen` 更功能化，也可指實際顯示出來的內容。

**EXAMPLE · 例句**

> The dashboard display shows the remaining battery level.

儀表板顯示器顯示剩餘電量。

**SEMANTIC CUE · 語義提示**

> **an electronic visual output area or device**

**REGISTER · 語域**

科技、一般、技術

---

## 05 Projection screen

**投影幕；投影屏幕**

當 `screen` 是專門供投影機使用的幕時，`projection screen` 是最直接的精確詞。它比 `projection surface` 更暗示專用設備。

**EXAMPLE · 例句**

> The presenter lowered the projection screen before the talk.

講者在演講前把投影幕放下來。

**SEMANTIC CUE · 語義提示**

> **a screen specifically designed for projected images**

**REGISTER · 語域**

教育、會議、影音

---

## 06 Viewing screen

**觀看屏幕；觀景顯示屏**

較描述性，表示供人觀看影像、影片或即時畫面的屏幕。常見於設備、攝影、監察或技術說明。

**EXAMPLE · 例句**

> The camera feed appears on the viewing screen.

攝影機畫面出現在觀看屏幕上。

**SEMANTIC CUE · 語義提示**

> **a screen used for viewing images or video**

**REGISTER · 語域**

技術、攝影、描述性

---

## 07 Video display

**視頻顯示器；影像顯示屏**

當 `screen` 的功能特別是顯示動態影像或視頻訊號時，`video display` 很合適。它較技術化，常見於影音、監控和設備規格。

**EXAMPLE · 例句**

> The control room has a video display for each camera feed.

控制室為每個攝影機訊號設有視頻顯示器。

**SEMANTIC CUE · 語義提示**

> **an electronic display used for video images**

**REGISTER · 語域**

影音、監控、技術

---

## 08 Display panel

**顯示面板；顯示板**

當 `screen` 指設備上的一塊電子顯示面板時，`display panel` 很自然，尤其適合儀器、家電、車輛和工業設備。它比 `display screen` 更偏硬件構件。

**EXAMPLE · 例句**

> The oven's display panel shows the cooking time.

焗爐的顯示面板顯示烹調時間。

**SEMANTIC CUE · 語義提示**

> **a panel built into equipment for displaying information**

**REGISTER · 語域**

家電、工業、技術

# 02 False synonyms

## Screen / Projection surface
`projection surface` 強調影像投射到的實體平面，未必是專門製造的幕。

**ENGLISH COMPARISON**  
A white wall can be used as a projection surface.  
A projection screen is a dedicated piece of equipment.

## Screen / Display screen
`display screen` 明確是電子顯示用途，常見於手機、機器和儀器。

**ENGLISH COMPARISON**  
The projector shines onto a screen.  
The ticket machine shows instructions on a display screen.

## Screen / Monitor
`monitor` 通常指整部獨立顯示裝置，而不只是表面。

**ENGLISH COMPARISON**  
The laptop has a built-in screen.  
The desktop computer uses an external monitor.

## Screen / Display
`display` 更功能化，可指顯示裝置或視覺輸出區域。

**ENGLISH COMPARISON**  
The phone screen is cracked.  
The dashboard display shows the battery level.

## Projection surface / Projection screen
前者可包括牆面；後者通常是專用投影設備。

**ENGLISH COMPARISON**  
The wall served as a projection surface.  
The presenter lowered the projection screen.

## Screen / Viewing screen
`viewing screen` 強調用途是觀看影像，較描述性、技術化。

**ENGLISH COMPARISON**  
The camera sends its feed to a viewing screen.  
The device's display screen also shows menus and settings.

## Screen / Video display
`video display` 特別指視頻／動態影像輸出，範圍比一般 display screen 更窄。

**ENGLISH COMPARISON**  
A display screen may show text or icons.  
A video display is designed to show video imagery.

## Screen / Display panel
`display panel` 常指設備內置的硬件面板，如焗爐、洗衣機、控制器。

**ENGLISH COMPARISON**  
The computer uses a separate monitor.  
The oven has a built-in display panel.

## 練習 01.1

**Target phrase: Projection surface · 投影表面；投影面**

### READ THE CONTEXT · 閱讀語境

> The projector image was too large for the screen.

**中文翻譯**

| | 選項 |
|---|---|
| A | projection surface |
| B | projection screen |
| C | display screen |
| D | monitor |
| E | surface projection |
| F | keyboard |

### CORRECT ANSWER · 正確答案

**A. projection surface · 投影表面；投影面**

> The projector image was too large for the projection surface.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. projection surface ✓**  
線索「projector image + physical area receiving the projection」關注的是影像投射到的實體表面，而不一定是專用設備，所以 `projection surface` 最精準。

**B. projection screen**  
`projection screen`：專用投影幕；通常是獨立或可捲動設備。 本句線索是「projector image + physical area receiving the projection」；它把 screen 解讀成投影幕、獨立顯示器、內置面板、觀看用途或其他不同硬件類型，因此不是最佳替代。

**C. display screen**  
`display screen`：電子顯示屏；用來顯示資訊或影像。 本句線索是「projector image + physical area receiving the projection」；它把 screen 解讀成投影幕、獨立顯示器、內置面板、觀看用途或其他不同硬件類型，因此不是最佳替代。

**D. monitor**  
`monitor`：獨立顯示裝置，常用於電腦或監控。 本句線索是「projector image + physical area receiving the projection」；它把 screen 解讀成投影幕、獨立顯示器、內置面板、觀看用途或其他不同硬件類型，因此不是最佳替代。

**E. surface projection**  
`surface projection`：詞序不自然；標準是 `projection surface`。 本句線索是「projector image + physical area receiving the projection」；除了語義不同外，詞序、單複數、詞性或構詞形式也不符合。

**F. keyboard**  
`keyboard`：鍵盤；不是屏幕。 本句線索是「projector image + physical area receiving the projection」；它把 screen 解讀成投影幕、獨立顯示器、內置面板、觀看用途或其他不同硬件類型，因此不是最佳替代。

# 05 高價值近義詞辨析

- **Projection surface vs Projection screen** — surface 可是牆；screen 是專用幕。
- **Display screen vs Monitor** — screen 偏顯示表面；monitor 常指整部裝置。
- **Display vs Display screen** — display 更廣、更功能化。
- **Viewing screen vs Video display** — viewing screen 強調用途；video display 強調訊號／內容類型。
- **Display panel vs Display screen** — panel 更常是設備內置硬件構件。
- **Monitor vs Display panel** — monitor 通常獨立；panel 通常嵌入設備。
- **Screen ≠ projector** — screen 接收／顯示影像；projector 產生投影影像。
- **Screen ≠ display content** — screen 是裝置／表面；display 也可指實際顯示內容，因此要看語境。

# 08 Grammar & structure traps

## Projection surface
標準詞序：

> projection surface

不是：

> surface projection ✗

## Display screen
> display screen

不要把動詞分詞誤作名詞：

> displaying screen △

## Monitor
> a monitor  
> two monitors

## Display
既可作名詞，也可作動詞：

> the display is bright  
> the device displays an error

## Projection screen
固定搭配：

> projection screen

## Display panel
> display panel  
> control panel

兩者不同：control panel 重點是控制；display panel 重點是顯示。

# 09 核心決策問題

1. 是投影落下的任何表面？ → **projection surface**
2. 是手機／機器的電子顯示屏？ → **display screen**
3. 是獨立電腦／監控顯示器？ → **monitor**
4. 只是泛指電子視覺輸出？ → **display**
5. 是專用投影幕？ → **projection screen**
6. 強調供人觀看影像？ → **viewing screen**
7. 強調視頻訊號／動態影像？ → **video display**
8. 是家電／設備內置硬件面板？ → **display panel**

# 10 Final note for system use

核心替代表達：

`projection surface / display screen / monitor / display / projection screen / viewing screen / video display / display panel`

尤其要記住：

> **projection surface** = 投影面  
> **display screen** = 電子顯示屏  
> **monitor** = 獨立顯示器  
> **projection screen** = 專用投影幕  
> **display panel** = 內置顯示面板

最重要的一點：

> **projection surface ≠ projection screen**

牆可以是 **projection surface**，但通常不是專用 **projection screen**。
