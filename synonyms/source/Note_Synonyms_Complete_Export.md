# NOTE — Complete Synonym Lesson

## 01 同義詞指南

### Note 的 7 種更精準說法

> Note: The number of alternatives is based on what is genuinely natural and useful for this noun sense, not on a fixed quota. “Note” can mean **a written reminder, a study note, an annotation, an internal memo, a short message, a quick jotting, or a comment expressing an opinion**.
> 本課按 **note = 筆記／便條／註釋** 這個名詞語義真正自然的替代表達選詞，不追求固定數量。它可以表示 **書面提醒、學習筆記、註釋、備忘錄、留言、隨手筆記，以及評語**。

### 01 Written Reminder
**書面提醒；提醒便條**

當 note 是為了提醒自己或別人記住某件事而寫下的短句、便條或提示時，可用 written reminder。重點是『提醒功能』。

**EXAMPLE · 例句**  
I left a written reminder beside the door.  
我在門旁留下了一張書面提醒。

---

### 02 Study Note
**學習筆記；溫習筆記**

當 note 指學生為課堂、閱讀、考試或溫習整理的重要內容時，可用 study note。重點是『幫助學習和記憶』。

**EXAMPLE · 例句**  
She reviewed her study notes before the exam.  
她在考試前溫習自己的學習筆記。

---

### 03 Annotation
**註釋；批註**

當 note 是加在書本、文件、圖表、圖片或程式碼旁的補充解釋、標記或評論時，可用 annotation。它強調『附加在原內容上』。

**EXAMPLE · 例句**  
The manuscript contains handwritten annotations in the margins.  
手稿頁邊有手寫註釋。

---

### 04 Memo
**備忘錄；內部短文件**

當 note 是工作場所或組織內部用來傳達安排、決定或提醒的短文件時，可用 memo。比一般 note 更正式。

**EXAMPLE · 例句**  
The manager sent a memo about the new policy.  
經理發了一份有關新政策的備忘錄。

---

### 05 Message
**留言；訊息**

當 note 是留給某人的短訊息，例如桌上便條、門口留言或簡短書面通知時，可用 message。它強調『傳遞給某人』。

**EXAMPLE · 例句**  
She left a message on his desk.  
她在他的桌上留了一則留言。

---

### 06 Jotting
**隨手記下的文字；簡短筆記**

當 note 是快速、隨手寫下的幾個字、想法或資料，而且不講究完整格式時，可用 jotting。語氣較非正式。

**EXAMPLE · 例句**  
I found a few jottings in the margin of the notebook.  
我在筆記簿頁邊發現幾則隨手筆記。

---

### 07 Comment
**評語；評論；附註**

當 note 是對某段文字、工作、文件或想法所作的簡短評價或意見時，可用 comment。它強調『表達看法』而不是單純記錄。

**EXAMPLE · 例句**  
The teacher added a comment beside the paragraph.  
老師在段落旁加了一則評語。

---

## 02 False synonyms

### 看起來相關，意思卻不同

### 01 Notebook
**筆記簿不等於一般的 note**

**notebook = 筆記簿**

notebook 是用來寫 notes 的本子或電子裝置，不是單一 note 本身。

**ENGLISH COMPARISON**  
A notebook contains notes.

---

### 02 Notice
**告示；通知不等於一般的 note**

**notice = 告示；通知**

notice 通常是公開或正式張貼的通知，和短便條、學習筆記或註釋不同。

**ENGLISH COMPARISON**  
A notice informs a group; a note may be private or personal.

---

### 03 Notation
**記號系統；符號表示法不等於一般的 note**

**notation = 記號系統；符號表示法**

notation 指音樂、數學、科學等使用的符號系統，不等於一般 note。

**ENGLISH COMPARISON**  
Musical notation uses symbols; a note is written information.

---

### 04 Record
**紀錄不等於一般的 note**

**record = 紀錄**

record 是較完整、正式或永久保存的資料。note 通常更短、更臨時或更局部。

**ENGLISH COMPARISON**  
A record preserves information formally; a note may be brief.

---

### 05 Letter
**信件不等於一般的 note**

**letter = 信件**

letter 通常是完整書信，有稱呼、正文和較完整內容；note 往往更短。

**ENGLISH COMPARISON**  
A note can be only one line; a letter is usually fuller.

---

### 06 Footnote
**腳註不等於一般的 note**

**footnote = 腳註**

footnote 是特定類型的 note，出現在頁面底部提供來源或補充說明，不能代表所有 note。

**ENGLISH COMPARISON**  
A footnote is one specialized type of note.

---

### 07 Note As A Verb
**注意；記下不等於一般的 note**

**note as a verb = 注意；記下**

note 也可作動詞，表示『注意到』或『記下』。本課處理的是名詞 note。

**ENGLISH COMPARISON**  
Please note the change. I wrote a note.

---

### 08 Banknote
**紙幣不等於一般的 note**

**banknote = 紙幣**

banknote 中的 note 指紙幣，是完全不同的詞義，不能和書面筆記混淆。

**ENGLISH COMPARISON**  
A banknote is money, not a written reminder.

---

# 01 Written Reminder · 書面提醒；提醒便條

## 練習 01.1

**Target word: Written Reminder · 書面提醒；提醒便條**

### READ THE CONTEXT · 閱讀語境

She left herself a note on the fridge so she would remember to call the dentist.

### 中文翻譯

她在雪櫃上留了一張便條，提醒自己記得打電話給牙醫。

A. written reminder
B. study note
C. annotation
D. memo
E. message
F. jotting

### CORRECT ANSWER · 正確答案

**written reminder · 書面提醒；提醒便條**

She left herself a written reminder on the fridge so she would remember to call the dentist.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. written reminder ✓**  
written reminder = 書面提醒。so she would remember 是決定性線索，這張 note 的主要作用就是提醒。

**B. study note**  
study note = 學習筆記。通常用於整理課堂、閱讀或溫習內容，和打電話給牙醫無關。

**C. annotation**  
annotation = 註釋。通常附加在書本、文件或圖像旁，用來解釋或標記內容。

**D. memo**  
memo = 備忘錄。可以提醒工作事項，但一般比雪櫃上的個人便條更正式。

**E. message**  
message = 留言／訊息。通常是傳遞給別人的內容，這裡是提醒自己。

**F. jotting**  
jotting = 隨手記下的文字。可以很短，但沒有 written reminder 那麼突出『提醒』目的。
