# POINT — Complete Synonym Lesson

## 01 同義詞指南

### Point 的 7 種更精準說法

> Note: This lesson focuses only on **point = purpose / reason / use**, as in “What’s the point?” or “The point of this exercise is…”. The number of alternatives is based on what is genuinely natural and useful, not on a fixed quota.
> 本課只處理 **point = 目的／理由／用處** 這個意思。按語境可更精準地分成 **purpose, reason, use, aim, objective, rationale, function**。

### 01 Purpose
**目的；用意**

當 point 指某件事存在或進行的主要目的、用意或要達成的基本作用時，可用 purpose。這是最直接、最中性的替代詞之一。

**EXAMPLE · 例句**  
The purpose of the exercise is to improve accuracy.  
這項練習的目的是提高準確度。

---

### 02 Reason
**原因；理由**

當 point 指做某事的理由、依據，尤其在『有甚麼理由這樣做？』的語境中，可用 reason。它重點是『為甚麼』，而不是『要達成甚麼』。

**EXAMPLE · 例句**  
I see no reason to delay the decision.  
我看不出有甚麼理由延遲決定。

---

### 03 Use
**用處；用途；效用**

當 point 指某件事『有甚麼用』、是否有實際效用時，可用 use。常見結構是 What is the use of...? / There is no use in...。

**EXAMPLE · 例句**  
What is the use of this extra button?  
這個額外按鈕有甚麼用？

---

### 04 Aim
**目標；目的**

當 point 指一項活動、計劃或行動想達到的較清楚目標時，可用 aim。常見搭配是 the aim of... / our aim is to...。

**EXAMPLE · 例句**  
The aim of the campaign is to reduce waste.  
這項活動的目標是減少浪費。

---

### 05 Objective
**具體目標；任務目標**

當 point 指正式計劃、項目、任務或課程中明確、具體、通常可衡量的目標時，可用 objective。它比 aim 更正式。

**EXAMPLE · 例句**  
The main objective is to cut delivery times by ten percent.  
主要目標是把送貨時間縮短百分之十。

---

### 06 Rationale
**理據；根據；理由**

當 point 指某項政策、決定或方法背後的邏輯和合理依據時，可用 rationale。它較正式，常見於商業、政策、研究和學術語境。

**EXAMPLE · 例句**  
The report explains the rationale behind the policy change.  
報告解釋政策改動背後的理據。

---

### 07 Function
**功能；作用**

當 point 指某個部件、設計、制度或功能元素『是用來做甚麼』時，可用 function。它比 purpose 更偏技術或結構上的作用。

**EXAMPLE · 例句**  
The function of this sensor is to detect movement.  
這個感應器的功能是偵測移動。

---

## 02 False synonyms

### 看起來相關，意思卻不同

### 01 Point As A Location
**點；位置不等於本課的 point（目的／理由／用處）**

**point as a location = 點；位置**

point 也可表示地點或位置，例如 meeting point。這不是本課『目的／理由／用處』的意思。

**ENGLISH COMPARISON**  
A meeting point is a place; the point of a meeting is its purpose.

---

### 02 Point As A Score
**分；得分不等於本課的 point（目的／理由／用處）**

**point as a score = 分；得分**

point 可表示比賽或測驗中的分數，和目的、用意無關。

**ENGLISH COMPARISON**  
The team won by one point. That is a score, not a purpose.

---

### 03 Point As An Argument
**要點；論點不等於本課的 point（目的／理由／用處）**

**point as an argument = 要點；論點**

point 也可表示談話或論證中的重點，如 That's a good point. 這個意思和本課不同。

**ENGLISH COMPARISON**  
A good point is a valid argument; the point of an action is its purpose.

---

### 04 Cause
**原因；成因不等於本課的 point（目的／理由／用處）**

**cause = 原因；成因**

cause 指造成某結果的因素，而 reason 指做某事的理由。兩者容易混淆，但不是所有 point 都能換成 cause。

**ENGLISH COMPARISON**  
The cause of the fire is not the same as the reason for a decision.

---

### 05 Meaning
**意思；意義不等於本課的 point（目的／理由／用處）**

**meaning = 意思；意義**

meaning 指字詞、訊息或事件所表達的意思。它有時和 point 接近，但不等於『目的／用途』。

**ENGLISH COMPARISON**  
The meaning of a sentence is not necessarily its purpose.

---

### 06 Benefit
**好處；益處不等於本課的 point（目的／理由／用處）**

**benefit = 好處；益處**

benefit 是某事帶來的正面結果。它可能是做某事的目的之一，但不等於 point 本身。

**ENGLISH COMPARISON**  
A benefit is an advantage; a purpose is what something is intended to achieve.

---

### 07 Importance
**重要性不等於本課的 point（目的／理由／用處）**

**importance = 重要性**

importance 表示某事有多重要，不表示它的目的或用處。

**ENGLISH COMPARISON**  
Something may be important even if its purpose is unclear.

---

### 08 Pointless
**沒有意義的；無用的不等於本課的 point（目的／理由／用處）**

**pointless = 沒有意義的；無用的**

pointless 是形容詞，表示沒有目的、價值或用處；它不是名詞 point 的同義詞。

**ENGLISH COMPARISON**  
The task seems pointless because nobody understands its purpose.

---

## 03 練習

# 01 Purpose · 目的；用意

## 練習 01.1

**Target word: Purpose · 目的；用意**

### READ THE CONTEXT · 閱讀語境

The point of this exercise is to help students notice common pronunciation errors.

### 中文翻譯

這項練習的目的，是幫助學生留意常見發音錯誤。

A. purpose
B. reason
C. use
D. aim
E. rationale
F. function

### CORRECT ANSWER · 正確答案

**purpose · 目的；用意**

The purpose of this exercise is to help students notice common pronunciation errors.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. purpose ✓**  
purpose = 目的。The purpose of this exercise is to... 是最自然的結構，直接說明練習被設計來做甚麼。

**B. reason**  
reason = 原因。reason 通常回答『為甚麼發生／為甚麼做』，不如 purpose 直接表示設計目的。

**C. use**  
use = 用處。若問物件有甚麼實際用途較合適，但 exercise 的教學目標更自然叫 purpose。

**D. aim**  
aim = 目標。也接近，但通常說 the aim of the exercise；本題強調整體設計目的，purpose 更中性。

**E. rationale**  
rationale = 理據。指背後理由或論證，不是練習本身要達成的功能。

**F. function**  
function = 功能。多用於系統、部件、器官等，對教學練習較不自然。

# 02 Reason · 原因；理由

## 練習 02.1

**Target word: Reason · 原因；理由**

### READ THE CONTEXT · 閱讀語境

### 中文翻譯

A. purpose
B. reason
C. use
D. aim
E. objective
F. function

### CORRECT ANSWER · 正確答案

**reason · 原因；理由**

What's the reason for leaving now if the train does not depart for another two hours?

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. purpose**  
purpose = 目的。可以問離開的目的，但本句由 if-clause 質疑的是『為甚麼現在就走』的合理理由。

**B. reason ✓**  
reason = 理由。What's the reason for leaving now...? 直接對應『為甚麼』。

**C. use**  
use = 用處。What is the use of leaving now? 也可能成立，但偏質疑效用；本題更明確是理由。

**D. aim**  
aim = 目標。不是在問要達成哪個具體成果。

**E. objective**  
objective = 目標。過於正式，且不是問原因。

**F. function**  
function = 功能。不能用於一次離開行動。
