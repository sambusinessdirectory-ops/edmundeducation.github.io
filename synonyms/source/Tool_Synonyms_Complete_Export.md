# TOOL — Complete Synonym Lesson

## 01 同義詞指南

### Tool 的 10 種更精準說法

> **tool** 的範圍很廣：可以是手持器具、精密儀器、電子裝置、廚房用具、工作設備，也可以比喻成輔助資源或達成目的的手段。本課保留 **implement, instrument, device, utensil, piece of equipment, apparatus, aid, resource, means,** 和軟件語境中的 **utility**。每個詞都只在合適語境中替換，而不是彼此完全等義。

### 01 Implement
**工具；器具（尤指手持或實用工具）**

**implement** 是 **tool** 最直接的正式近義詞之一，通常指為某種工作而設計的實體工具，尤其是手持、農業、園藝或工藝用具。

**EXAMPLE · 例句**
The shed contains gardening implements such as spades and hoes.
工具棚裡放着鏟子、鋤頭等園藝工具。

---

### 02 Instrument
**儀器；工具；器械（較精密／專門）**

當 **tool** 指精密、專業或測量用途的工具時，可用 **instrument**。常見於 scientific / surgical / measuring instrument。

**EXAMPLE · 例句**
The technician calibrated the measuring instrument before use.
技術員在使用前校準了測量儀器。

---

### 03 Device
**裝置；器件；工具**

當 **tool** 指為特定功能設計的機械、電子或技術裝置時，可用 **device**。它比 implement 更偏現代、機械或電子用途。

**EXAMPLE · 例句**
The device checks the pressure automatically.
這個裝置會自動檢查壓力。

---

### 04 Utensil
**用具；器皿（尤指廚房／家居）**

當 **tool** 指廚房、烹飪或家居中的小型實用器具時，可用 **utensil**。常見於 kitchen utensil / cooking utensil。

**EXAMPLE · 例句**
A wooden spoon is a basic kitchen utensil.
木匙是一種基本廚房用具。

---

### 05 Piece Of Equipment
**一件設備；一件工具**

當 **tool** 是較大型、專業或工作用的實體設備，而且單用 equipment 因為不可數而不方便時，可用 **a piece of equipment**。

**EXAMPLE · 例句**
The scanner is an essential piece of equipment in the workshop.
掃描器是工作室一件重要設備。

---

### 06 Apparatus
**器械；裝置；整套設備（較正式／技術）**

**apparatus** 常指較專業、科學或技術性的器械，或由多個部分組成的一套裝置。它比 tool 更正式，也通常比單一簡單手工具複雜。

**EXAMPLE · 例句**
The laboratory apparatus must be cleaned after each experiment.
實驗器械每次實驗後都必須清潔。

---

### 07 Aid
**輔助工具；幫助物**

當 **tool** 不是主要設備，而是幫助人完成學習、工作、記憶、溝通等任務的東西時，可用 **aid**。常見於 teaching aid / visual aid / memory aid。

**EXAMPLE · 例句**
The chart is a useful visual aid for explaining the process.
這張圖表是解釋流程的實用視覺輔助工具。

---

### 08 Resource
**資源；可利用的工具／資料**

當 **tool** 指可供學習、工作、研究或解難使用的資料、網站、指南或服務時，可用 **resource**。它通常不是手持實體工具，而是『可利用的東西』。

**EXAMPLE · 例句**
The website is a useful resource for language teachers.
這個網站是語言教師很有用的資源。

---

### 09 Means
**手段；方法；工具（抽象）**

當 **tool** 比喻指達到某個目的的手段或途徑時，可用 **means**。常見於 **a means of doing something**。它不是實體工具。

**EXAMPLE · 例句**
Education can be a means of social mobility.
教育可以是促進社會流動的一種手段。

---

### 10 Utility
**實用程式；工具程式（軟件語境）**

在電腦與軟件語境中，**utility** 可指執行特定維護、轉換、清理或管理工作的工具程式。這是非常實用但範圍受限的 tool 近義詞。

**EXAMPLE · 例句**
The utility scans the disk for duplicate files.
這個工具程式會掃描磁碟中的重複檔案。

---

## 02 False synonyms

### 看起來相關，但功能、範圍或詞類不同。Tool 的核心是『被用來完成某項工作／任務的器具、資源或手段』；以下詞語不能一般性互換。

### 01 Machine
**機器不等於一般的 tool**

machine 通常指有機械部件、動力或自動運作的設備；很多 tools 並不是 machines。

**ENGLISH COMPARISON**
A machine can be a tool, but many tools are simple hand implements.

---

### 02 Appliance
**家用電器；器具不等於一般的 tool**

appliance 多指冰箱、焗爐、洗衣機等家用設備，比 tool 更特定。

**ENGLISH COMPARISON**
An appliance is usually a household device, not a general tool.

---

### 03 Accessory
**配件；附件不等於一般的 tool**

accessory 是附加在主要物件上的輔助或裝飾部件；tool 通常本身有主要工作功能。

**ENGLISH COMPARISON**
An accessory supports or decorates something else; a tool performs a task.

---

### 04 Material
**材料不等於一般的 tool**

material 是製作或加工的物質，例如木、金屬、布；tool 是用來加工材料或完成工作的東西。

**ENGLISH COMPARISON**
Materials are worked on; tools are used to do the work.

---

### 05 Technique
**技巧；技法不等於一般的 tool**

technique 是做事的方法或技巧，不是實體工具。雖然 tool 可比喻指方法，但 technique 不能一般替代 tool。

**ENGLISH COMPARISON**
A technique is a way of doing something, not an implement.

---

### 06 Skill
**技能不等於一般的 tool**

skill 是人的能力或熟練程度；tool 是可使用的器具、資源或手段。

**ENGLISH COMPARISON**
Skill belongs to the user; a tool is something the user employs.

---

### 07 Toy
**玩具不等於一般的 tool**

toy 的主要用途是玩樂；tool 的主要用途是完成工作或任務。

**ENGLISH COMPARISON**
A toy is for play; a tool is for performing a task.

---

### 08 Weapon
**武器不等於一般的 tool**

weapon 是用來攻擊或防禦的器具。雖然武器也是一種具用途的 implement，但不能一般當作 tool 的同義詞。

**ENGLISH COMPARISON**
A weapon is a specialized implement for combat or defense.

---

## 練習 01.1

**Target word/expression: Implement · 工具；器具（尤指手持或實用工具）**

### READ THE CONTEXT · 閱讀語境

Each tool in the gardening set has a wooden handle and a metal head.

### 中文翻譯

這套園藝工具中的每件器具都有木柄和金屬頭。

A. machine
B. implement
C. material
D. accessory
E. toy
F. skill

### CORRECT ANSWER · 正確答案

**implement · 工具；器具（尤指手持或實用工具）**

Each implement in the gardening set has a wooden handle and a metal head.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. machine**
machine = 機器。通常有機械部件或動力，不等於一般手持園藝工具。

**B. implement ✓**
implement = 器具。gardening set + wooden handle + metal head 是典型 implement 語境。

**C. material**
material = 材料。是製造工具的東西，不是工具本身。

**D. accessory**
accessory = 配件。只是附加物，不是主要工作器具。

**E. toy**
toy = 玩具。不是用來完成園藝工作的工具。

**F. skill**
skill = 技能。是能力，不是實體物件。
