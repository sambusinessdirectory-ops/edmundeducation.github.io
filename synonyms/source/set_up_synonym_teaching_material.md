# SYNONYMS · 同義詞學習系統

# Set Up

**本課限定語境：set up = to establish, create, organize, arrange, launch, or prepare something so that it can begin operating or be used · 「設立；建立；創辦；安排；架設；安裝」**

> **同義詞數量不固定。**
> `set up` 是一個非常廣的片語動詞，可以用於公司、制度、會議、設備、帳戶、工作空間等，因此不同替代表達只適用於特定語境。
>
> 本課保留 **7 個**真正有教學價值的替代表達：
>
> **establish, create, launch, found, arrange, install, configure**
>
> 主要區別：
>
> - **establish** → 正式建立機構、制度、關係或規則
> - **create** → 創建新的東西，範圍最廣
> - **launch** → 正式推出或啟動新產品、服務、計劃或企業
> - **found** → 創辦公司、機構、學校等
> - **arrange** → 安排會議、活動、預約等
> - **install** → 安裝設備、軟件或系統
> - **configure** → 設定系統、裝置或軟件，使其按需要運作
>
> 特別注意：
>
> - `set up a company` 可以是 **establish / found / launch a company**，但三者重點不同。
> - `set up a meeting` 應偏向 **arrange**，不能自然改成 `found a meeting`。
> - `set up a computer` 常是 **install / configure**，取決於是「安裝」還是「設定」。
> - `launch` 強調開始公開運作；`establish` 強調正式建立。
>
> 每個 target expression 配 **3 道完整練習題**，共 **21 題**。
> 每題會優先使用真正可能令人猶豫的近義競爭者，並完整解釋 **詞義、典型搭配，以及句中哪個線索決定答案**。

# 01 同義詞指南

## 01 Establish

**建立；設立；確立**

表示正式建立一個機構、制度、關係、規則或長期安排。

**EXAMPLE · 例句**

The charity was established in 1998.

這間慈善機構於 1998 年成立。

**USAGE · 用法提示**

常見：
- establish a company
- establish a committee
- establish a system
- establish a relationship
- establish procedures

比 `set up` 更正式。

---

## 02 Create

**創建；建立**

表示使某個新的東西出現，範圍非常廣。

**EXAMPLE · 例句**

The team created a new database for customer records.

團隊建立了一個新的客戶紀錄資料庫。

**USAGE · 用法提示**

常見：
- create an account
- create a database
- create a system
- create a plan
- create a workspace

`create` 強調「使某物存在」，不一定強調正式機構成立。

---

## 03 Launch

**推出；啟動；正式開始**

表示產品、服務、計劃、活動或企業正式開始運作或公開推出。

**EXAMPLE · 例句**

The company launched a new online service.

公司推出了一項新的網上服務。

**USAGE · 用法提示**

常見：
- launch a product
- launch a service
- launch a campaign
- launch a programme
- launch a start-up

核心是：
> begin publicly / officially.

---

## 04 Found

**創辦；創立**

表示創立公司、機構、學校、組織等。

**EXAMPLE · 例句**

She founded the organization with two colleagues.

她與兩位同事共同創辦了該組織。

**USAGE · 用法提示**

常見：
- found a company
- found a school
- found an organization
- founder of a business

`found` 比 `set up` 更明確突出「創辦者」這個角色。

---

## 05 Arrange

**安排；籌備**

表示安排會議、活動、交通、預約或其他計劃性事項。

**EXAMPLE · 例句**

I'll arrange a meeting with the client.

我會安排與客戶開會。

**USAGE · 用法提示**

常見：
- arrange a meeting
- arrange an appointment
- arrange transport
- arrange a visit

如果 `set up` 的意思是「安排某件事發生」，`arrange` 往往最自然。

---

## 06 Install

**安裝；裝設**

表示把設備、軟件或系統放置／安裝好，使其可以使用。

**EXAMPLE · 例句**

A technician installed the new printer.

技術員安裝了新打印機。

**USAGE · 用法提示**

常見：
- install software
- install equipment
- install a camera
- install a system

`install` 更偏實際安裝，而不是一般「設定」。

---

## 07 Configure

**設定；配置**

表示調整裝置、系統或軟件的設定，使其符合特定需要。

**EXAMPLE · 例句**

The engineer configured the router for the office network.

工程師為辦公室網絡設定了路由器。

**USAGE · 用法提示**

常見：
- configure a device
- configure a server
- configure settings
- configure a network

比 `set up` 更技術化、更精確。

---

# 02 False Synonyms / 容易誤選的相關詞

## 01 Start

**開始 ≠ 所有 set up**

`start` 只表示開始，不一定包含建立、安排或準備。

**ENGLISH COMPARISON**

You can start a meeting after someone has already set it up.

---

## 02 Build

**建造 ≠ 所有 set up**

build 適合實體結構、系統或長期發展，但不能自然替代所有 set up。

---

## 03 Open

**開設／開啟 ≠ 所有 set up**

可以說：
> open a shop

但 `open` 強調開始營業，而不是建立整個組織的過程。

---

## 04 Organize

**組織 ≠ 所有 set up**

organize 很適合活動、會議，但不適合：
> organize a router

---

## 05 Install

**安裝 ≠ 一般建立**

install 只適合設備／軟件／系統。

---

## 06 Established / Establish

**形容詞／過去分詞 vs 動詞**

- establish = 建立
- established = 已建立的／成立已久的

> establish a company  
> an established company

---

## 07 Founder / Found

**名詞 vs 動詞**

- found = 創辦
- founder = 創辦人

---

## 08 Setup / Set Up

**名詞 vs 動詞片語**

- setup = 設定／配置／安排（名詞）
- set up = 設立／設定（動詞）

> The setup is simple.  
> Please set up the system.

# 01 Establish

## 練習 01.1

The government plans to set up a new committee to review the policy.

**中文翻譯**

政府計劃成立一個新委員會檢討政策。

A. launch  
B. establish  
C. arrange  
D. configure  
E. install  
F. advertise

### CORRECT ANSWER · 正確答案

The government plans to **establish** a new committee to review the policy.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. launch**  
`launch a committee` 並非最自然搭配；launch 更適合產品、計劃、活動或服務正式推出。

**B. establish ✓**  
`government` + `committee` 是典型正式制度語境，establish 表示正式設立機構。

**C. arrange**  
arrange 通常用於 meeting/appointment/event，不表示創建一個委員會。

**D. configure**  
只適合技術系統或設備設定。

**E. install**  
不能用於建立委員會。

**F. advertise**  
表示宣傳，不是設立。

只表示調整設定，不代表攝影機已實體安裝。

**D. founded**  
不合。

**E. established**  
不適合具體設備。

**F. launched**  
不合。

# 05 高階辨析補充

## Set Up vs Establish

- **set up**：日常、廣泛。
- **establish**：較正式，特別適合機構、制度、關係。

> set up a committee  
> establish a committee

---

## Set Up vs Create

`create` 重點是「使某物存在」。

特別自然：
- create an account
- create a database
- create a folder

但不能自然用 `create` 取代所有 set up。

---

## Set Up vs Launch

- **set up a service**：建立服務所需結構。
- **launch a service**：正式向使用者推出服務。

所以 launch 更偏 **go live / begin publicly**。

---

## Set Up vs Found

`found` 只適合機構、公司、學校、組織等。

> found a company ✓  
> found a meeting ✗

---

## Set Up vs Arrange

如果 `set up` 是「安排時間、地點或參與者」，通常用 arrange：

> arrange a meeting  
> arrange transport  
> arrange an appointment

---

## Set Up vs Install

`install` 重點是：
> put equipment/software in place so it can be used.

所以：
> install a printer  
> install software

---

## Set Up vs Configure

`configure` 重點是：
> adjust settings so the system works as required.

例如：
> configure a router  
> configure user permissions

設備可能已安裝，但仍需要 configuration。

# 08 教學核心

**Set up 的自然替代表達，最重要的是先判斷你是在說「正式建立、創建新東西、正式推出、創辦機構、安排活動、安裝設備，還是技術設定」。**

- 正式建立制度／機構 → **establish**
- 創建新物件／帳戶／資料 → **create**
- 正式推出／啟動 → **launch**
- 創辦公司／組織 → **found**
- 安排會議／預約／交通 → **arrange**
- 安裝設備／軟件 → **install**
- 技術設定／配置 → **configure**

最重要的界線是：

> **`set up` 是非常廣的上位片語；`establish / found` 偏機構建立，`launch` 偏正式開始，`arrange` 偏安排活動，而 `install / configure` 則屬技術設備與系統語境。**
