# SYNONYMS · 同義詞學習系統

# Priority (noun)

**`priority` 可以表示最重要的關注事項、決策時首先考慮的因素、正式優先次序、排名最高的任務、首要目標、急務、目前工作重點，或選項中的偏好。**

核心替代表達：

`main concern / first consideration / precedence / top priority / primary objective / urgent matter / focus / preference`

---

# 01 同義詞指南

## 01 Main concern

**主要關注事項**

the issue that matters most

**EXAMPLE · 例句**

> Safety is our main concern during the renovation.

翻新期間，安全是我們最主要的關注事項。

---

## 02 First consideration

**首要考慮**

the factor considered before others in a decision

**EXAMPLE · 例句**

> Safety should be the first consideration when choosing equipment.

選擇設備時，安全應是首要考慮。

---

## 03 Precedence

**優先次序**

the state of coming before something else in importance

**EXAMPLE · 例句**

> Emergency cases take precedence over routine appointments.

緊急個案優先於一般預約。

---

## 04 Top priority

**最高優先事項**

the most important item

**EXAMPLE · 例句**

> Reducing waiting times is our top priority this year.

縮短輪候時間是我們今年的最高優先事項。

---

## 05 Primary objective

**首要目標**

the main goal to be achieved

**EXAMPLE · 例句**

> The primary objective is to improve access to public services.

首要目標是改善公共服務的可及性。

---

## 06 Urgent matter

**緊急事項**

an issue requiring immediate attention

**EXAMPLE · 例句**

> The data breach is an urgent matter requiring immediate action.

數據外洩是需要立即處理的緊急事項。

---

## 07 Focus

**重點；焦點**

the area receiving most attention or effort

**EXAMPLE · 例句**

> Customer retention will be our main focus this quarter.

今季我們的工作重點將是留住顧客。

---

## 08 Preference

**偏好；優先選擇**

a stronger choice for one option over another

**EXAMPLE · 例句**

> Applicants may indicate a preference for morning interviews.

申請人可表示較偏好上午面試。

# 02 False synonyms

## Priority / Main concern
`main concern` 強調「最值得關注甚麼」，不一定有正式先後次序。

## Priority / First consideration
`first consideration` 特別適合作決定時「首先考慮哪個因素」。

## Priority / Precedence
`precedence` 是正式的優先次序，高頻搭配是 **take precedence over**。

## Priority / Top priority
`top priority` 比一般 `priority` 更強，直接表示排名最高。

## Priority / Primary objective
`primary objective` 強調主要目標，不等於所有類型的 priority。

## Priority / Urgent matter
`urgent matter` 強調需要立即處理；重要但不緊急的 priority 不宜這樣改。

## Priority / Focus
`focus` 強調注意力和資源目前集中在哪裏。

## Priority / Preference
`preference` 只在 priority 表示「較偏好哪個選項」時接近。

# 04 Target-word / phrase contrast map

| `priority` 真正重點 | 較精準替代表達 |
|---|---|
| 最重要、最需要關注的事情 | **main concern** |
| 決策時首先考慮的因素 | **first consideration** |
| 正式先後次序 | **precedence** |
| 所有事項中排名最高 | **top priority** |
| 最主要要達成的目標 | **primary objective** |
| 因時間／風險必須立即處理 | **urgent matter** |
| 注意力／資源集中的重點 | **focus** |
| 選項中的較高偏好 | **preference** |

# 05 高價值近義詞辨析

- **Main concern vs Top priority** — 前者偏「最關注甚麼」；後者偏正式排名第一。
- **First consideration vs Primary objective** — consideration 是決策因素；objective 是要達成的目標。
- **Precedence vs Priority** — precedence 更正式，常比較 A 和 B 的先後。
- **Urgent matter vs Top priority** — urgent 強調時間壓力；top priority 強調重要性排名。
- **Focus vs Priority** — focus 是注意力集中點，不一定排名第一。
- **Preference vs Priority** — preference 是選擇傾向；priority 是重要性或先後。
- **Priority ≠ urgency** — 很重要的事不一定要立即做。
- **Priority ≠ objective** — priority 也可以是風險、關注或處理次序。

# 08 Grammar & structure traps

- **priority for + person/group**
- **priority over + another item**
- **give priority to + noun**
- **take precedence over + noun**
- **a top priority / the top priority**
- **primary objective + be + to-infinitive**
- **focus on + noun**
- **preference for + noun**
- **prioritise/prioritize** = verb；**priority** = noun
- **prefer** = verb；**preference** = noun

# 09 核心決策問題

1. 最需要關注？ → **main concern**
2. 決策時第一個考慮因素？ → **first consideration**
3. 正式地 A 先於 B？ → **precedence**
4. 所有事項中排名第一？ → **top priority**
5. 計劃最主要要達成的目標？ → **primary objective**
6. 因風險／時間必須立即處理？ → **urgent matter**
7. 本期工作資源集中在哪裏？ → **focus**
8. 只是較喜歡某個選項？ → **preference**

# 10 Final note for system use

核心替代表達：

`main concern / first consideration / precedence / top priority / primary objective / urgent matter / focus / preference`

最重要的一點：

> **priority ≠ urgency ≠ preference**

`priority` = 優先重要性；  
`urgency` = 需要多快處理；  
`preference` = 較喜歡哪個選項。
