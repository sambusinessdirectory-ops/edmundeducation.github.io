# Accessory

**額外物品、附加件、裝飾品、附件、組件、零售配件、裝飾性物品、補充用品、周邊設備——究竟是哪一種 accessory？**

核心近義與近義表達：

**extra item; add-on; ornament; attachment; component; accessory item; decorative item; supplementary item; peripheral**

> **核心詞數不固定。** 本課保留 **9 個**自然且辨析價值高的核心表達。  
> 你提供的 **extra item; add-on; ornament** 全部保留。  
> 本課只處理 `accessory = an extra item used with something or worn/used for decoration`，並分開 **功能擴充、裝飾、設備附件、技術組件、零售分類、周邊設備**。

# 01 同義詞指南


## 01 Extra Item

**附加物品；額外配件**

最透明、最廣泛的改寫之一。當 `accessory` 只是指主要物品之外另外加入、方便使用或增加功能的東西時很自然。

### EXAMPLE · 例句

The camera comes with several useful extra items.

這部相機附有幾件實用的額外配件。

# 02 False synonyms


## 01 Extra item

**最廣泛、最透明**

只表示主產品之外的額外物品，不說明功能。

### ENGLISH COMPARISON

The camera comes with several extra items.

---

## 02 Add-on

**擴充功能**

常見於 software, vehicles, electronics, equipment。

### ENGLISH COMPARISON

This add-on adds extra features.

---

## 03 Ornament

**純裝飾**

ornament 的核心是美觀，不一定和某個主產品配套。

### ENGLISH COMPARISON

The shelf held a small ornament.

---

## 04 Attachment

**要有接駁／附着關係**

常見於 vacuum, camera, tool, appliance。

### ENGLISH COMPARISON

The vacuum has a narrow cleaning attachment.

---

## 05 Component

**通常更核心**

component 往往是系統本身的一部分，而 accessory 常是額外／可選。

### ENGLISH COMPARISON

The battery is a component of the device.

---

## 06 Peripheral

**只適合電腦／電子系統**

keyboard, mouse, external drive 等最自然。

### ENGLISH COMPARISON

A keyboard is a computer peripheral.

---

## 07 Accessory / accessories

**單複數**

一件配件 = an accessory；多件 = accessories。

### ENGLISH COMPARISON

The bag includes one accessory; extra accessories are sold separately.

---

## 08 Accessory

**其他 sense**

`accessory` 也可指法律上的共犯／從犯。本課只處理『配件／飾物』sense。

### ENGLISH COMPARISON

An accessory to a crime uses a different sense.

# 03 練習與解釋

> **每個核心近義表達 3 題，共 27 題。**
> 每題均以 **是否附屬、是否可選、是否裝飾、是否接駁主設備、是否屬系統組件、是否是電子周邊** 作辨析。


## 練習 01.1

**Target expression:** extra item · 附加物品；額外配件

### READ THE CONTEXT · 閱讀語境

The camera comes with several useful accessories.

### 中文翻譯

這部相機附有幾件實用的額外配件。

### OPTIONS


- **A. extra item**

- **B. add-on**

- **C. attachment**

- **D. supplementary item**

- **E. core item**

- **F. essential part**


### CORRECT ANSWER · 正確答案

**extra item · 附加物品；額外配件**

The camera comes with several useful **extra items**.

### SIX-OPTION FEEDBACK · 六個選項的解釋


- **A. extra item ✓** — `extra item` = 主要物品以外的額外用品。 **本句為何最合適：** the sentence refers broadly to non-core items included with the main product。

- **B. add-on** — `add-on` = 另外加上的功能／擴充配件。 需要附加／擴充主產品功能的意味；純裝飾品或已內建組件不一定是 add-on。 **本句線索：** the sentence refers broadly to non-core items included with the main product。

- **C. attachment** — `attachment` = 接駁／安裝到主設備上的附件。 通常會實際接駁或安裝到主設備上；完全獨立的小配件不一定是 attachment。 **本句線索：** the sentence refers broadly to non-core items included with the main product。

- **D. supplementary item** — `supplementary item` = 非核心、補充主產品用途的附屬用品。 強調非核心、補充用途；若它其實是必需結構部件，則不合。 **本句線索：** the sentence refers broadly to non-core items included with the main product。

- **E. core item** — `core item` = 核心物品。 是核心物品，和 accessory 的附屬性相反。 **本句線索：** the sentence refers broadly to non-core items included with the main product。

- **F. essential part** — `essential part` = 必需部分。 是必需部分，和 optional accessory 不同。 **本句線索：** the sentence refers broadly to non-core items included with the main product。
