# CREATE · 分層同義詞學習系統

## Create

**「創造／製作／產生／開發」，要先分清是日常製作、系統產出、逐步開發、正式建立，還是精心創作。**

本單元集中處理 **create = to bring something new into existence, whether by making, producing, generating, designing, developing, organising, or composing it**。你提供的 **make; produce; generate; develop** 正好代表四個核心方向：**make = 日常製作**、**produce = 產出／生產**、**generate = 系統性產生**、**develop = 逐步開發**。

這次保留 **13 個**高實用度詞／表達，並把 **建立組織、設計方案、構思方法、創作文字／音樂、結構化建造、正式使某事誕生** 分開。每個目標設 **3 道題**；所有 distractor 均完整說明其本身意思及為何在該句不合適。

## Tier 1 — Core making / production equivalents · 核心製作與產生近義詞

### 01 Make

**Tier**：1  
**中文**：製作；做出；創造  
**語域**：neutral / very common  
**核心語義**：to bring something into existence by forming, assembling, preparing, or doing it  
**用法提示**：和 create 最直接、最日常的替代之一，適合物件、食物、計劃、改動等一般語境。  
**常見搭配**：make a product; make a plan; make a model; make a change; make something from.  
**常見搭配對象**：object, plan, meal, model, product.  
**與 create 的辨析**：Make 比 create 更日常、更廣；create 常帶原創、產生新事物的意味。  
**使用限制**：正式創意、制度或抽象成果語境，create / develop 往往更精準。

**EXAMPLE · 例句**  
The students made a simple model from recycled materials.  
學生用回收材料製作了一個簡單模型。

### 02 Produce

**Tier**：1  
**中文**：生產；製作；產生  
**語域**：neutral / formal  
**核心語義**：to make or bring forth something, especially as a result of a process, system, or organised activity  
**用法提示**：當 create 涉及工業、媒體、文件、成果或某個過程的輸出時非常自然。  
**常見搭配**：produce goods; produce a report; produce a film; produce results; produce evidence.  
**常見搭配對象**：goods, report, film, output, result.  
**與 create 的辨析**：Produce 強調『產出／生產結果』；create 更常突出創造本身。  
**使用限制**：個人即興想出一個點子時通常不用 produce an idea 作首選。

**EXAMPLE · 例句**  
The factory produces thousands of components each week.  
工廠每週生產數千個零件。

### 03 Generate

**Tier**：1  
**中文**：產生；生成；創造  
**語域**：neutral / technical  
**核心語義**：to cause something to come into existence, especially data, energy, ideas, income, output, or automatic results  
**用法提示**：當 create 是由系統、過程、活動或機器『產生』結果時很精準。  
**常見搭配**：generate data; generate electricity; generate ideas; generate revenue; generate a report.  
**常見搭配對象**：data, energy, revenue, idea, output.  
**與 create 的辨析**：Generate 常帶系統化／自動化產生；create 更廣。  
**使用限制**：手工製作物件或藝術品不一定適合 generate。

**EXAMPLE · 例句**  
The software generates a report automatically.  
軟件會自動生成報告。

### 04 Develop

**Tier**：1  
**中文**：開發；發展；研製；形成  
**語域**：neutral / very common  
**核心語義**：to create something gradually through planning, improvement, testing, or growth  
**用法提示**：當 create 不是一次完成，而是逐步建立、改良或成熟時最自然。  
**常見搭配**：develop a product; develop a system; develop a strategy; develop software; develop an idea.  
**常見搭配對象**：product, system, strategy, software, concept.  
**與 create 的辨析**：Develop 強調過程和演進；create 可只指最終產生。  
**使用限制**：極簡單、即時製作的小物件通常用 make 更自然。

**EXAMPLE · 例句**  
The team developed a new booking system over six months.  
團隊用六個月開發了一套新的預約系統。

### 05 Build

**Tier**：1  
**中文**：建立；建造；創建  
**語域**：neutral / very common  
**核心語義**：to create something by assembling parts or progressively establishing structure  
**用法提示**：適合實體結構、團隊、品牌、系統、關係和能力。  
**常見搭配**：build a house; build a team; build a system; build a brand; build trust.  
**常見搭配對象**：structure, team, system, organisation, relationship.  
**與 create 的辨析**：Build 強調結構、組合或逐步建立；create 更抽象、更普遍。  
**使用限制**：對單一文件、圖像或短訊息，build 通常不如 create / produce。

**EXAMPLE · 例句**  
The company is building a new platform for small businesses.  
公司正在建立一個供小型企業使用的新平台。

## Tier 2 — Structured / planned creation equivalents · 結構化與規劃型創造

### 06 Form

**Tier**：2  
**中文**：形成；組成；建立  
**語域**：neutral / formal  
**核心語義**：to bring something into existence by organising parts, people, or elements into a whole  
**用法提示**：當 create 涉及團體、結構、關係、模式或形狀逐漸形成時很適合。  
**常見搭配**：form a committee; form a partnership; form a pattern; form a habit; form an alliance.  
**常見搭配對象**：group, committee, partnership, pattern, relationship.  
**與 create 的辨析**：Form 偏『由部分組成整體』；create 不要求組合過程。  
**使用限制**：一般產品製造不用 form 作首選。

**EXAMPLE · 例句**  
The organisations formed a new partnership.  
這些機構建立了新的合作關係。

### 07 Establish

**Tier**：2  
**中文**：建立；創立；設立  
**語域**：formal / professional  
**核心語義**：to create something intended to be stable, recognised, or lasting  
**用法提示**：當 create 的對象是制度、機構、規則、聯繫、基礎或正式安排時非常自然。  
**常見搭配**：establish a company; establish a system; establish a committee; establish a relationship; establish procedures.  
**常見搭配對象**：organisation, system, procedure, relationship, institution.  
**與 create 的辨析**：Establish 強調正式設立和持續存在；create 更中性。  
**使用限制**：製作圖片、影片、物件時不宜用 establish。

**EXAMPLE · 例句**  
The university established a new research centre.  
大學成立了一個新的研究中心。

### 08 Design

**Tier**：2  
**中文**：設計；構思  
**語域**：neutral / professional  
**核心語義**：to plan and create the form, structure, function, or appearance of something  
**用法提示**：當 create 涉及預先構思用途、結構或外觀時很精準。  
**常見搭配**：design a product; design a website; design a system; design a programme; design an experiment.  
**常見搭配對象**：product, website, system, programme, experiment.  
**與 create 的辨析**：Design 強調規劃與構思；create 可包括沒有正式設計過程的創作。  
**使用限制**：單純產生數據、收入或熱力不說 design。

**EXAMPLE · 例句**  
The team designed a simpler mobile interface.  
團隊設計了一個更簡單的流動介面。

### 09 Devise

**Tier**：2  
**中文**：設計出；想出；策劃  
**語域**：formal / neutral  
**核心語義**：to create a plan, method, system, or solution through careful thought  
**用法提示**：當 create 的成果是經思考後想出的方案、方法或制度時很自然。  
**常見搭配**：devise a plan; devise a strategy; devise a method; devise a solution; devise a system.  
**常見搭配對象**：plan, strategy, method, solution, procedure.  
**與 create 的辨析**：Devise 強調動腦構思；create 更廣。  
**使用限制**：實體大量生產或自動生成結果不適合。

**EXAMPLE · 例句**  
Researchers devised a new method for testing the material.  
研究人員設計出一種測試該材料的新方法。

### 10 Compose

**Tier**：2  
**中文**：創作；撰寫；組成  
**語域**：neutral / formal  
**核心語義**：to create a piece of writing, music, or other arranged work  
**用法提示**：當 create 的對象是音樂、文章、訊息、詩歌等有組織的作品時很精準。  
**常見搭配**：compose music; compose a message; compose a poem; compose a letter; compose a piece.  
**常見搭配對象**：music, poem, message, letter, written work.  
**與 create 的辨析**：Compose 只適合特定創作類型；create 範圍更廣。  
**使用限制**：一般產品、制度、機器輸出不適用。

**EXAMPLE · 例句**  
She composed a short piece for the school concert.  
她為學校音樂會創作了一首短曲。

## Tier 3 — Formal / crafted / constructed variants · 正式、精心與構建型變體

### 11 Construct

**Tier**：3  
**中文**：建造；構成；構建  
**語域**：formal / technical  
**核心語義**：to create something by putting parts together in a planned and structured way  
**用法提示**：當 create 涉及物理結構、模型、論證、框架或技術系統時可用。  
**常見搭配**：construct a building; construct a model; construct an argument; construct a framework; construct a prototype.  
**常見搭配對象**：building, model, argument, framework, prototype.  
**與 create 的辨析**：Construct 強調結構化組裝；create 更一般。  
**使用限制**：日常簡單製作可顯得過正式。

**EXAMPLE · 例句**  
The engineers constructed a prototype for testing.  
工程師建造了一個測試用原型。

### 12 Bring into being

**Tier**：3  
**中文**：使……誕生；創立；使出現  
**語域**：formal / literary  
**核心語義**：to cause something entirely new to begin to exist  
**用法提示**：當 create 強調『從無到有』而且語氣較正式／抽象時可用。  
**常見搭配**：bring an organisation into being; bring a system into being; bring a new institution into being; bring into existence; bring about creation.  
**常見搭配對象**：institution, system, organisation, arrangement, entity.  
**與 create 的辨析**：比 create 更正式、更強調誕生。  
**使用限制**：一般日常製作不自然。

**EXAMPLE · 例句**  
The legislation brought the new agency into being.  
該法例使新機構正式成立。

### 13 Craft

**Tier**：3  
**中文**：精心製作；精心創作  
**語域**：neutral / expressive  
**核心語義**：to create something carefully and skilfully, often with attention to detail  
**用法提示**：當 create 強調技巧、細節、文字表達或手工質感時很有用。  
**常見搭配**：craft a message; craft a speech; craft a strategy; craft a story; carefully crafted.  
**常見搭配對象**：message, speech, story, strategy, handmade object.  
**與 create 的辨析**：Craft 帶精心、技巧性的語氣；create 不一定。  
**使用限制**：自動生成結果或大量工業生產通常不適合。

**EXAMPLE · 例句**  
The team crafted a clear message for the campaign.  
團隊為宣傳活動精心設計了一個清晰訊息。

## 04 False synonyms / creation traps · 容易誤選的詞與創造陷阱

### 01 Copy

**複製不等於 create**  
copy 是重製已有東西；create 通常涉及產生新的東西。

**ENGLISH COMPARISON**  
Copying reproduces something existing; creating brings something new into existence.

### 02 Find

**找到不等於 create**  
find 表示發現已存在的東西；create 表示令某物出現。

**ENGLISH COMPARISON**  
You find what already exists; you create what did not.

### 03 Use

**使用不等於 create**  
use 是利用現有資源；create 是產生新成果。

**ENGLISH COMPARISON**  
Using applies something existing; creating produces something new.

### 04 Change

**改變不等於 create**  
change 是修改已有事物；create 可以完全從無到有。

**ENGLISH COMPARISON**  
Changing modifies something; creating may originate it.

### 05 Discover

**發現不等於 create**  
discover 是找到以前未知但已存在的事物；create 是使新事物產生。

**ENGLISH COMPARISON**  
Discovery reveals; creation originates.

### 06 Assemble

**組裝不等於所有 create**  
assemble 只表示把部分組合起來；create 也可以是寫作、設計、產生抽象成果。

**ENGLISH COMPARISON**  
Assembly is one method of creation, not creation in general.

### 07 Invent

**發明不等於所有 create**  
invent 通常是創造以前沒有的裝置、方法或想法；create 的範圍更廣。

**ENGLISH COMPARISON**  
Invention is a special kind of creation.

### 08 Develop

**develop 和 create 很接近，但強調過程**  
develop 通常是逐步改良／形成；create 只需表示產生。

**ENGLISH COMPARISON**  
Development emphasises progression; creation emphasises bringing something into existence.

## 05 練習與解釋 · Practice

### 練習 01.1

**Tier 1 · Target word / phrase**: Make · 製作；做出；創造

**READ THE CONTEXT · 閱讀語境**

The students created a simple model from recycled materials.

**中文翻譯**  
學生用回收材料製作了一個簡單模型。

- A. made
- B. copied
- C. found
- D. used
- E. discovered
- F. changed

**CORRECT ANSWER · 正確答案**

**made** · 製作；做出；創造

**Correct rewrite · 正確改寫**  
The students made a simple model from recycled materials.

**SIX-OPTION FEEDBACK · 六個選項的詳細解釋**

- **A. made ✓ — model from materials 是日常『製作』語境，make 最自然。**
- **B. copied — copy 會表示照已有模型重製，原句沒有這層意思。**
- **C. found — model 是學生做出來，不是原本已存在而被找到。**
- **D. used — 他們確實使用材料，但 use 不等於產生模型。**
- **E. discovered — discovery 是發現已有事物，不是製作。**
- **F. changed — 修改材料不等於完成一個新模型。**

## 06 Semantic map · 語義總覽

| Create 的語境 | 最接近的詞／表達 | Diagnostic question |
|---|---|---|
| 日常製作 | **make** | 是否是物件／食物／簡單成果？ |
| 生產／產出 | **produce** | 是否有工業、媒體或過程輸出？ |
| 系統／過程生成 | **generate** | 是否是 data / revenue / electricity / automatic output？ |
| 逐步開發 | **develop** | 是否經歷時間、測試和改良？ |
| 逐步建立結構 | **build** | 是否是 platform / team / trust / network？ |
| 由部分形成整體 | **form** | 是否是 committee / partnership / habit？ |
| 正式設立 | **establish** | 是否是 institution / system / procedure / relationship？ |
| 規劃設計 | **design** | 是否重點是 form / function / structure？ |
| 想出方案 | **devise** | 是否是 plan / method / strategy / solution？ |
| 創作文字／音樂 | **compose** | 是否是 music / poem / message / letter？ |
| 結構化構建 | **construct** | 是否由 parts/evidence/elements 組成？ |
| 正式使之誕生 | **bring into being** | 是否強調 entirely new entity 從無到有？ |
| 精心創作 | **craft** | 是否強調 skill / wording / careful shaping？ |

## 07 Direct contrasts · 核心辨析

- **create vs make**: make 更日常、更廣；create 常帶原創／產生新事物意味。
- **create vs produce**: produce 強調過程的產出或生產結果。
- **create vs generate**: generate 常見於系統、數據、收入、能量等『產生』。
- **create vs develop**: develop 強調逐步成熟和改良。
- **create vs build**: build 強調結構和逐步建立。
- **create vs establish**: establish 強調正式設立並持續存在。
- **create vs design**: design 強調規劃形式、功能和結構。
- **create vs devise**: devise 是經思考想出計劃／方法。
- **create vs compose**: compose 專用於音樂、文字等組織性作品。
- **create vs construct**: construct 強調按結構組裝／構建。
- **create vs invent**: invent 是 create 的特殊子類，通常指真正新發明。
- **create vs copy**: copy 重製已有東西，和原創 create 不同。

## 08 Grammar, collocation & creation traps · 文法、搭配與創造陷阱

- **make + object/result**：make a model / cake / plan / change。
- **produce + output/product/result**：produce goods / a report / evidence / a film。
- **generate + abstract/system output**：generate data / revenue / electricity / ideas。
- **develop + system/product/strategy/skill**：develop software / a method / a strategy。
- **build + structure/system/relationship**：build a platform / team / network / trust。
- **form + group/relationship/pattern**：form a committee / partnership / habit。
- **establish + formal entity/system**：establish a company / procedure / relationship。
- **design + product/system/experiment**：design a website / programme / experiment。
- **devise + plan/method/solution**：devise a strategy / method / workaround。
- **compose + music/text**：compose a piece / poem / message / letter。
- **construct + structured whole**：construct a prototype / argument / framework。
- **bring + object + into being**：bring a new institution into being。
- **craft + message/speech/strategy/story** 帶精心製作和細節處理意味。
- **create ≠ discover/find**：前者令新東西出現；後者找到已存在的東西。
- **create ≠ copy**：copy 可以完全沒有原創性。
