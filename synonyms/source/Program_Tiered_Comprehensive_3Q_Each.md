# PROGRAM · 分層同義詞學習系統

## Program

**Program 是高度多義詞，必須先分 sense。** 本課主要處理兩大類：**(A) organised plan / training / course / initiative**，以及 **(B) computer software / application**。在英式／香港英語中，非電腦 sense 通常寫 **programme**；但電腦程式通常仍寫 **program**。

你提供的 **programme; training scheme; structured course; software; application** 正好涵蓋這兩大語義家族。本次保留 **10 個**自然且高實用度的近義／情境表達，不把 project、curriculum、schedule 等相關詞硬當成全面同義詞。

共 **30 道練習**，每個目標 **3 題**。所有 source sentences 都先保持自然的 **program** 用法，再用明確語境判斷究竟是計劃／課程 sense，還是 computing sense。

## Sense split · 義項分流

| Program 的 sense | 核心問題 | 典型替代表達 |
|---|---|---|
| organised plan / course / broadcast | 是否是活動、培訓、學習或公共計劃？ | programme, training scheme, structured course, initiative |
| computer program | 是否是電腦執行的程式／使用者軟件？ | software, application, computer program, app |

## Tier 1 — Core programme / course / software equivalents · 核心計劃、課程與軟件近義詞

### 01 Programme

**Tier**：1  
**中文**：計劃；項目；節目；課程  
**語域**：British English / very common  
**核心語義**：the standard British spelling for program when referring to an organised plan, course, series of activities, broadcast, or event schedule  
**用法提示**：你提供的 seed 是最重要的地區拼寫對應。英式／香港英語一般用 **programme** 表示培訓計劃、活動項目、電視節目等；但電腦程式通常仍寫 **program**。  
**常見搭配**：training programme; education programme; television programme; programme of activities; programme schedule.  
**常見搭配對象**：training, education, television, activity, event.  
**與 program 的辨析**：非電腦 sense 中，programme 與美式 program 高度對應；差別主要是英美拼寫慣例。  
**使用限制**：英式英語的 computer program 通常不用 *computer programme*。

**EXAMPLE · 例句**  
The organisation launched a six-month training programme for new staff.  
機構為新員工推出一個為期六個月的培訓計劃。

### 02 Training scheme

**Tier**：1  
**中文**：培訓計劃；訓練方案  
**語域**：British English / workplace / public sector  
**核心語義**：an organised plan that provides training over a defined period or through a set of stages  
**用法提示**：你提供的 seed 很自然，尤其適合公司、政府、學徒、就業和職業技能培訓。  
**常見搭配**：graduate training scheme; staff training scheme; apprenticeship scheme; join a scheme; structured training.  
**常見搭配對象**：graduate, employee, apprentice, staff, trainee.  
**與 program 的辨析**：Training scheme 比 program 更窄，只適合 training / development；也常有制度化、分階段意味。  
**使用限制**：不能用來表示電腦軟件、電視節目或一般活動 program。

**EXAMPLE · 例句**  
The company runs a graduate training scheme for new engineers.  
公司為新入職工程師設有畢業生培訓計劃。

### 03 Structured course

**Tier**：1  
**中文**：有系統的課程；結構化課程  
**語域**：neutral / education  
**核心語義**：an organised course with a planned sequence of lessons, modules, or learning activities  
**用法提示**：你提供的 seed 適合 program = organised course of instruction，尤其當課程有明確 syllabus / modules / progression。  
**常見搭配**：structured course; structured learning; course modules; course syllabus; complete a course.  
**常見搭配對象**：language, training, professional development, study, module.  
**與 program 的辨析**：Structured course 強調教學結構；program 可以比 course 更廣，包含實習、評估、活動或支援。  
**使用限制**：非教育／培訓語境不適用。

**EXAMPLE · 例句**  
Participants complete a structured course with eight weekly modules.  
參加者完成一個包含八個每週單元的有系統課程。

### 04 Software

**Tier**：1  
**中文**：軟件  
**語域**：neutral / computing  
**核心語義**：computer programs and related data or instructions considered collectively  
**用法提示**：你提供的 seed 是 program 在電腦語境中的重要上位詞，尤其當不是指單一程式，而是一整套軟件。  
**常見搭配**：software package; software system; install software; update software; software developer.  
**常見搭配對象**：computer, device, package, system, tool.  
**與 program 的辨析**：Software 通常是不可數上位詞；a program 是一個具體電腦程式。  
**使用限制**：不能把所有單一 program 都機械改成 *a software*；應說 software / a software package / an application。

**EXAMPLE · 例句**  
The software analyses the data and produces a report.  
這套軟件分析資料並產生報告。

### 05 Application

**Tier**：1  
**中文**：應用程式；應用軟件  
**語域**：neutral / computing  
**核心語義**：a computer program designed to perform a particular task for a user  
**用法提示**：你提供的 seed 很精準，當 program 是 user-facing software used for a specific task 時自然。  
**常見搭配**：software application; mobile application; desktop application; application software; run an application.  
**常見搭配對象**：phone, computer, user, task, platform.  
**與 program 的辨析**：Application 是 program 的 subtype，通常是給使用者完成特定工作的程式。  
**使用限制**：作業系統元件、底層系統程式不一定叫 application。

**EXAMPLE · 例句**  
The application lets users edit photographs on their phones.  
這個應用程式讓使用者在手機上編輯相片。

## Tier 2 — Training / academic / policy / computing-specific variants · 培訓、學術、政策與電腦限定變體

### 06 Training programme

**Tier**：2  
**中文**：培訓計劃；培訓課程  
**語域**：British English / very common  
**核心語義**：an organised set of training activities, sessions, or modules designed to develop skills  
**用法提示**：當 program 的 sense 明確是培訓時，這是英式／香港英語最穩妥的具體改寫之一。  
**常見搭配**：staff training programme; induction programme; professional training programme; programme content; complete a programme.  
**常見搭配對象**：staff, trainee, manager, apprentice, participant.  
**與 program 的辨析**：比 general programme 更窄，專指技能或工作培訓。  
**使用限制**：一般教育學位、軟件、活動計劃不適用。

**EXAMPLE · 例句**  
All new employees complete a three-week training programme.  
所有新員工都要完成一個為期三週的培訓計劃。

### 07 Course of study

**Tier**：2  
**中文**：修讀課程；學習課程  
**語域**：formal / education  
**核心語義**：a planned sequence of study leading through a subject, qualification, or educational objective  
**用法提示**：當 program 指較長期、正式的 academic study 時很自然。  
**常見搭配**：course of study; full-time study; academic programme; pursue a course of study; prescribed course.  
**常見搭配對象**：student, degree, subject, qualification, institution.  
**與 program 的辨析**：Course of study 強調學習路線；program 可能包含更廣的制度、實習和行政元素。  
**使用限制**：短期活動或電腦 program 不適用。

**EXAMPLE · 例句**  
Students follow a two-year course of study before the final examination.  
學生在期末考試前修讀兩年的課程。

### 08 Initiative

**Tier**：2  
**中文**：倡議；計劃；行動方案  
**語域**：formal / policy / organisational  
**核心語義**：an organised effort or new plan intended to achieve a particular social, organisational, or policy goal  
**用法提示**：當 program 是機構／政府為解決問題而推出的一項 organised effort 時可用。  
**常見搭配**：government initiative; community initiative; launch an initiative; policy initiative; new initiative.  
**常見搭配對象**：government, community, health, environment, organisation.  
**與 program 的辨析**：Initiative 強調目的和推動行動；program 更常暗示持續結構、資源和一系列活動。  
**使用限制**：一般課程、電腦程式、廣播節目不適用。

**EXAMPLE · 例句**  
The council introduced an initiative to reduce food waste.  
市議會推出一項減少食物浪費的倡議。

### 09 Computer program

**Tier**：2  
**中文**：電腦程式  
**語域**：neutral / computing  
**核心語義**：a set of coded instructions that a computer executes to perform tasks  
**用法提示**：當 program 的 computer sense 需要消除多義性時，這是最直接、最精確的明確化表達。  
**常見搭配**：computer program; run a program; write a program; program code; program execution.  
**常見搭配對象**：computer, code, instruction, operating system, task.  
**與 program 的辨析**：這是 program 的 computing-specific full form；在英式英語也用 **program** 而不是 **programme**。  
**使用限制**：不能指培訓計劃、課程或活動安排。

**EXAMPLE · 例句**  
The computer program checks each file for errors.  
這個電腦程式檢查每個檔案有沒有錯誤。

## Tier 3 — Informal application variant · 口語應用程式變體

### 10 App

**Tier**：3  
**中文**：應用程式；App  
**語域**：informal / computing  
**核心語義**：an informal shortened form of application, especially for mobile or user-facing software  
**用法提示**：當 program 是手機／平板或一般使用者操作的應用程式，而且語氣較口語時很自然。  
**常見搭配**：mobile app; download an app; open the app; app store; app developer.  
**常見搭配對象**：phone, tablet, user, service, platform.  
**與 program 的辨析**：App 比 application 更口語，也通常更 user-facing。  
**使用限制**：底層電腦程式、系統服務或正式技術文件不一定適合。

**EXAMPLE · 例句**  
The app sends users a reminder before each appointment.  
這個應用程式會在每次預約前向使用者發出提醒。

## 04 False synonyms / program traps · 容易誤選的計劃、課程與軟件陷阱

### 01 Project

**項目 ≠ 所有 program**  
project 通常有明確起止、交付成果或單一目標；program 可長期持續並管理多個活動／項目。

**ENGLISH COMPARISON**  
A project is usually narrower and more time-bounded.

### 02 Curriculum

**課程內容體系 ≠ program**  
curriculum 是教學內容與學習要求，不等於整個 training/education program。

**ENGLISH COMPARISON**  
A curriculum is the content framework, not the whole programme.

### 03 Schedule

**時間表 ≠ program**  
schedule 只是時間安排；program 可包含內容、活動、目標和資源。

**ENGLISH COMPARISON**  
A schedule is only the timing plan.

### 04 Scheme

**scheme 有時接近，但範圍與語感不同**  
英式 scheme 可指有組織計劃，但也可有制度／方案甚至負面『陰謀』義。

**ENGLISH COMPARISON**  
Scheme is context-dependent.

### 05 Course

**課程 ≠ 所有 program**  
course 通常是一門／一段學習；program 可包含多門課、實習、評估和其他活動。

**ENGLISH COMPARISON**  
A course is often one component of a programme.

### 06 Operating system

**作業系統 ≠ 一般 application/program**  
作業系統是特殊系統軟件，不等於一般使用者應用程式。

**ENGLISH COMPARISON**  
An operating system is a specific class of system software.

### 07 Application

**只在 user-facing computer sense 接近**  
application 是電腦 program 的 subtype，不是所有 program 的同義詞。

**ENGLISH COMPARISON**  
Application is computing-specific.

### 08 Program / programme

**拼寫與多義陷阱**  
英式英語非電腦 sense 常用 programme；電腦程式仍通常用 program。

**ENGLISH COMPARISON**  
British English distinguishes programme and computer program.

| 手機／使用者端口語稱呼 | **app** | 是否 mobile/user-facing informal context？ |

## 07 Direct contrasts · 核心辨析

- **program vs programme**: 英式／香港非電腦 sense 通常用 programme；computer program 通常保留 program。
- **program vs training scheme**: training scheme 只限制度化培訓。
- **program vs structured course**: structured course 聚焦教學結構；programme 可更廣。
- **program vs software**: software 是電腦程式的上位／集合詞，通常不可數。
- **program vs application**: application 是 user-facing computer program 的 subtype。
- **program vs course of study**: course of study 聚焦學術修讀路線。
- **program vs initiative**: initiative 強調解決問題／推動目標，而未必有固定課程結構。
- **program vs project**: project 通常更有明確起止和交付成果。
- **program vs curriculum**: curriculum 是課程內容框架，不是整個 programme。
- **program vs schedule**: schedule 只是時間安排。

## 08 Grammar, spelling & polysemy traps · 文法、拼寫與多義陷阱

- 英式／香港英語：**training programme, television programme, education programme**。
- 電腦語境：即使英式英語通常也寫 **computer program / program code**。
- 美式英語通常所有 sense 都寫 **program**。
- **software** 通常不可數：install software；不要說 *a software*，除非改成 **a software package/application**。
- **application / app** 是 program 的 subtype，通常是 user-facing。
- **training scheme** 很適合 graduate / apprenticeship / workplace training。
- **course** 可以是一門課；**programme** 可以包含多門課、實習、評估和其他活動。
- **curriculum** 是教學內容與要求；**schedule** 是時間安排；兩者都不是整個 programme。
- **initiative** 常見於 government/community/health/environment policy contexts。
- 不要把 **project** 和 **programme** 完全等同：programme 可以統籌多個 projects。
- 香港／英式拼寫保持 **programme, organisation**；但 computing sense 保持 **program**。
