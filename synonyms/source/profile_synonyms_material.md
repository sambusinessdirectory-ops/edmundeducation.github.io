# SYNONYMS · 同義詞學習系統

# Profile

**個人資料、帳戶頁、網上形象、用戶記錄、公開檔案——究竟是哪一種 profile？**

本課聚焦數碼平台／帳戶 sense：

**profile = the page, data set, record, or online representation associated with a user/account**

核心近義與近義表達：

**account page; user profile; online profile; online persona; user record; account record; personal page; public profile; member profile; profile page**

> **核心詞數不固定。** 本課保留 **10 個**自然且辨析價值高的核心表達。  
> 本課不處理 `profile = side view / outline / description of a person or company` 等其他 sense。

---

# 01 同義詞指南


## 01 Account page

**帳戶頁面；個人帳戶頁**

當 `profile` 指網站或應用程式中顯示帳戶資料、設定、活動或公開資訊的頁面時很自然。重點是介面中的一個 page。

### EXAMPLE · 例句

You can change your password from your account page.

你可以在帳戶頁面更改密碼。

### COMMON COLLOCATIONS · 常見搭配


- account page

- open your account page

- account settings

- billing details


### DIAGNOSTIC QUESTION · 判斷問題

> 這裡的 `profile` 是帳戶管理頁、用戶資料集合、網上公開資料、網上人設、後端記錄，還是會員／公開頁面？

## 02 User profile

**用戶個人資料；用戶檔案**

最直接、最通用的近義表達之一。可指平台中代表某位用戶的資料集合，也可指顯示這些資料的頁面。

### EXAMPLE · 例句

Each user has a user profile containing their name, photo, and preferences.

每名用戶都有一份包含姓名、相片和偏好的用戶個人資料。

### COMMON COLLOCATIONS · 常見搭配


- user profile

- create a user profile

- edit a user profile

- profile data

## 03 Online profile

**網上個人資料；網上檔案**

強調個人資料存在於網上平台、網站或社交媒體中。比 `user profile` 更強調 online context。

### EXAMPLE · 例句

Employers sometimes review a candidate's online profile before an interview.

僱主有時會在面試前查看求職者的網上個人資料。

### COMMON COLLOCATIONS · 常見搭配

### EXAMPLE · 例句

### EXAMPLE · 例句

## 07 Personal page

### EXAMPLE · 例句

Her personal page includes a biography, portfolio, and contact links.

她的個人頁面包括簡介、作品集和聯絡連結。

# 02 False synonyms


## 01 Account

**帳戶不等於 profile**

account 是用戶在系統中的整體帳戶；profile 只是帳戶中的個人資料／展示部分。

### ENGLISH COMPARISON

You can have one account with a profile, settings, billing information, and security controls.

---

## 02 Username

**用戶名稱只是 profile 的一個欄位**

username 是識別名稱，不等於完整個人資料。

### ENGLISH COMPARISON

A username may appear on a profile, but it is not the whole profile.

---

## 03 Avatar

**頭像不等於 profile**

avatar 只是照片／圖像欄位。

### ENGLISH COMPARISON

An avatar is one visual element of a user profile.

---

## 04 Bio

**簡介不是整份 profile**

bio 是文字介紹，只是 profile 的其中一部分。

### ENGLISH COMPARISON

A profile may contain a bio, photo, links, and activity.

---

## 05 Homepage

**首頁不等於個人資料頁**

homepage 通常是網站／應用程式的主要入口。

### ENGLISH COMPARISON

A homepage can link to a user's profile page.

---

## 06 Dashboard

**控制台不等於 profile**

dashboard 偏管理、摘要和操作介面。

### ENGLISH COMPARISON

A dashboard may provide a link to edit your profile.

---

## 07 Persona

**形象不等於資料記錄**

persona 強調別人看到的身份／形象；user record 則是系統資料。

### ENGLISH COMPARISON

An online persona is how someone presents themselves, not a database record.

---

## 08 Profiled / profiling

**詞形陷阱**

`profile` 可作名詞或動詞；`profiling` 是建立／分析人物特徵的過程，不等於一份 profile。

### ENGLISH COMPARISON

The app stores a user profile; profiling refers to analysing or categorising users.

# 07 Grammar and usage notes

## 01 Profile is polysemous
本課只處理 digital/account sense。

其他常見 sense：
- side profile = 側面輪廓
- company profile = 公司簡介
- personality profile = 性格檔案
- risk profile = 風險概況

## 02 Profile vs account
- account = 整體帳戶
- profile = 帳戶中的個人資料／展示部分

## 03 Profile page vs user profile
- profile page = 頁面本身
- user profile = 資料集合，也可泛指顯示頁

## 04 Public profile
只指可見部分，通常不包括：
- password
- billing data
- private verification data

## 05 Online persona
這是語義最不同的一項：
它不是 database data，而是「一個人在網上呈現成怎樣的人」。

## 06 User record
後端／行政語境常見：
- database
- administrator
- access control
- support system
