# SCREEN TIME · 分層同義詞學習系統

## Screen time

**Screen time 主要是一個 duration concept：花多少時間看或使用有螢幕的裝置。** 但實際語境可再分成 **screen-duration、device-use behaviour、visual exposure、digital-media activity**。這些概念高度相關，但不能全部視為完全同義。

你提供的 **time spent using screens; device-use time** 正好代表兩個核心方向：**透明的螢幕使用時長改寫** 與 **以裝置為中心的使用時間**。

這是一個較窄的現代概念，因此本次保留 **8 個**真正自然且有教學價值的近義／情境表達，而不為數量加入生硬詞。共 **24 道練習**，每個目標 **3 題**。

## Sense split · 義項分流

| Screen time 的語境 | 核心問題 | 典型替代表達 |
|---|---|---|
| 純粹時長 | 是否只計算分鐘／小時？ | time spent using screens, device-use time, screen-use time |
| 數碼裝置行為 | 是否關心裝置種類／使用模式？ | digital-device use, time on devices |
| 視覺暴露 | 是否健康、睡眠、眼睛疲勞語境？ | time in front of screens, screen exposure |
| 數碼媒體內容使用 | 是否比較 games/video/social media/education？ | digital media use |

## Tier 1 — Core duration / device-use equivalents · 核心使用時長與裝置使用近義表達

### 01 Time spent using screens

**Tier**：1  
**中文**：使用螢幕的時間；螢幕使用時間  
**語域**：neutral / explanatory  
**核心語義**：the amount of time a person spends looking at or interacting with screen-based devices  
**用法提示**：你提供的 seed 是 **screen time** 最直接、最透明的改寫，適合教育、健康、研究和家長指引。  
**常見搭配**：time spent using screens; reduce time spent using screens; daily screen use; hours spent on screens.  
**常見搭配對象**：phone, tablet, computer, television, child.  
**與 screen time 的辨析**：語義非常接近 screen time，但較長、較解釋性；可避免把所有裝置活動壓縮成一個術語。  
**使用限制**：若需要簡潔的研究變項或日常名詞，screen time 本身通常更自然。

**EXAMPLE · 例句**  
Parents were asked to record the time their children spent using screens each day.  
家長被要求記錄子女每天使用螢幕的時間。

### 02 Device-use time

**Tier**：1  
**中文**：裝置使用時間  
**語域**：neutral / research / descriptive  
**核心語義**：the amount of time spent using digital devices, especially phones, tablets, or computers  
**用法提示**：你提供的 seed 很實用，當 screen time 想強調 devices rather than the visual screen itself 時可用。  
**常見搭配**：device-use time; daily device use; reduce device use; device-use habits; total device-use time.  
**常見搭配對象**：phone, tablet, computer, digital device, child.  
**與 screen time 的辨析**：Device-use time 可包括一些不需持續看螢幕的裝置操作，因此範圍有時比 screen time 略廣。  
**使用限制**：純電視觀看或只強調視覺暴露時，screen time 更直接。

**EXAMPLE · 例句**  
The study compared device-use time on school days and weekends.  
研究比較上課日與週末的裝置使用時間。

### 03 Screen-use time

**Tier**：1  
**中文**：螢幕使用時間  
**語域**：neutral / research  
**核心語義**：the amount of time spent actively using devices with screens  
**用法提示**：這是 screen time 的近乎直接結構改寫，常見於研究、問卷和健康建議。  
**常見搭配**：screen-use time; daily screen use; screen-use habits; reduce screen use; prolonged screen use.  
**常見搭配對象**：phone, tablet, computer, television, user.  
**與 screen time 的辨析**：比 screen time 稍正式、較 descriptive；語義基本相同。  
**使用限制**：一般口語中 screen time 更簡潔。

**EXAMPLE · 例句**  
Average screen-use time increased during the school holidays.  
學校假期期間，平均螢幕使用時間有所增加。

### 04 Digital-device use

**Tier**：1  
**中文**：數碼裝置使用；數碼設備使用時間  
**語域**：neutral / formal  
**核心語義**：use of digital devices such as smartphones, tablets, laptops, and similar equipment  
**用法提示**：當 screen time 的重點是數碼裝置使用行為，而非單純觀看螢幕時很自然。  
**常見搭配**：digital-device use; patterns of digital-device use; excessive device use; daily digital-device use.  
**常見搭配對象**：smartphone, tablet, laptop, child, adolescent.  
**與 screen time 的辨析**：Digital-device use 更行為導向，也可討論 frequency/type，而不只 duration。  
**使用限制**：如果句子必須明確表示『時間長度』，最好加 time/duration。

**EXAMPLE · 例句**  
Researchers tracked daily digital-device use among adolescents.  
研究人員追蹤青少年的每日數碼裝置使用情況。

## Tier 2 — Informal / visual-exposure variants · 口語與視覺暴露型變體

### 05 Time on devices

**Tier**：2  
**中文**：使用裝置的時間  
**語域**：informal / common  
**核心語義**：time spent using phones, tablets, computers, or other digital devices  
**用法提示**：當需要自然、口語化地改寫 screen time 時很實用。  
**常見搭配**：spend time on devices; limit time on devices; too much time on devices; daily time on devices.  
**常見搭配對象**：phone, tablet, computer, child, family.  
**與 screen time 的辨析**：Time on devices 較口語，亦比 screen time 更 device-centred。  
**使用限制**：正式研究寫作通常用 screen time / device-use time。

**EXAMPLE · 例句**  
The family agreed to limit time on devices before bedtime.  
這個家庭同意限制睡前使用裝置的時間。

### 06 Time in front of screens

**Tier**：2  
**中文**：在螢幕前的時間  
**語域**：neutral / common  
**核心語義**：time spent looking at or using screens, especially for extended periods  
**用法提示**：這個表達很自然，並較突出 visual exposure / sitting in front of a screen。  
**常見搭配**：time in front of screens; spend hours in front of screens; reduce time in front of screens.  
**常見搭配對象**：television, computer, tablet, child, worker.  
**與 screen time 的辨析**：比 screen time 更具體地突出『面對螢幕』，不一定適合背景播放或無視覺互動。  
**使用限制**：音訊型裝置使用或短暫通知操作不一定算典型 time in front of screens。

**EXAMPLE · 例句**  
Office workers may spend many hours in front of screens each day.  
辦公室員工每天可能花很多時間面對螢幕。

### 07 Screen exposure

**Tier**：2  
**中文**：螢幕暴露；接觸螢幕的時間／程度  
**語域**：formal / health / research  
**核心語義**：the extent or duration of exposure to screen-based visual media  
**用法提示**：當 screen time 出現在健康、睡眠、眼睛疲勞或兒童發展研究，而且重點是 exposure 時可用。  
**常見搭配**：screen exposure; prolonged screen exposure; reduce screen exposure; evening screen exposure.  
**常見搭配對象**：child, eye, sleep, evening, visual media.  
**與 screen time 的辨析**：Screen exposure 比 screen time 更 health-oriented，像 risk/exposure variable，而不是一般生活用語。  
**使用限制**：談工作生產力或裝置活動類型時未必合適。

**EXAMPLE · 例句**  
The guidance recommends reducing evening screen exposure before sleep.  
指引建議在睡前減少晚間螢幕暴露。

## Tier 3 — Digital-content contextual variant · 數碼媒體內容型情境變體

### 08 Digital media use

**Tier**：3  
**中文**：數碼媒體使用；使用數碼媒體的時間  
**語域**：formal / research / contextual  
**核心語義**：use of digital media through screen-based devices, including social media, video, games, and online content  
**用法提示**：當 screen time 的研究焦點其實是 content/media consumption 而非裝置本身時可作較廣的情境變體。  
**常見搭配**：digital media use; patterns of media use; excessive digital media use; media-use habits.  
**常見搭配對象**：social media, video, games, online content, adolescent.  
**與 screen time 的辨析**：Digital media use 比 screen time 更著重 content/activity type，而且不一定直接表示時長。  
**使用限制**：不能當作 screen time 的全面同義詞；若只計算分鐘／小時，要明確加 duration/time。

**EXAMPLE · 例句**  
The survey examined digital media use among secondary-school students.  
調查研究中學生使用數碼媒體的情況。

## 04 False synonyms / screen-time traps · 容易誤選的裝置、網上活動與久坐陷阱

### 01 Internet use

**上網時間 ≠ screen time**  
screen time 可包括離線遊戲、電視、電子書等；internet use 只涵蓋網上活動。

**ENGLISH COMPARISON**  
Internet use is narrower and connectivity-focused.

### 02 Phone use

**手機使用 ≠ 所有 screen time**  
screen time 可來自平板、電腦、電視等，不只手機。

**ENGLISH COMPARISON**  
Phone use covers only one device category.

### 03 Television viewing

**看電視 ≠ 所有 screen time**  
電視只是 screen-based activity 的一種。

**ENGLISH COMPARISON**  
Television viewing is one subtype.

### 04 Social media use

**社交媒體使用 ≠ screen time**  
社交媒體只是眾多 screen activities 之一。

**ENGLISH COMPARISON**  
Social media use is content-specific.

### 05 Sedentary time

**久坐時間 ≠ screen time**  
可以坐着不看螢幕，也可以站着使用螢幕。

**ENGLISH COMPARISON**  
Sedentary time and screen time overlap but differ.

### 06 Online time

**網上時間 ≠ screen time**  
離線螢幕活動不屬 online time。

**ENGLISH COMPARISON**  
Online time is connectivity-based.

### 07 Digital media use

**只在媒體內容使用 sense 接近**  
digital media use 更著重活動／內容類型，不一定是 duration measure。

**ENGLISH COMPARISON**  
Digital media use is broader in activity type.

### 08 Screen / screen time

**詞形與概念陷阱**  
screen 是裝置部件／動詞；screen time 是一個 duration concept。

**ENGLISH COMPARISON**  
Do not confuse the object with the time measure.

### 練習 01.1

**Tier 1 · Target word / phrase**: Time spent using screens · 使用螢幕的時間；螢幕使用時間

**READ THE CONTEXT · 閱讀語境**

The study measured children's screen time on weekdays.

**中文翻譯**  
研究量度兒童平日的螢幕使用時間。

- A. Time spent using screens
- B. Device-use time
- C. Screen-use time
- D. Internet use
- E. Phone use
- F. Sedentary time

**CORRECT ANSWER · 正確答案**

**A. Time spent using screens** · 使用螢幕的時間；螢幕使用時間

**Correct rewrite · 正確改寫**  
The study measured the time children spent using screens on weekdays.

**SIX-OPTION FEEDBACK · 六個選項的詳細解釋**

- **A.** **Time spent using screens ✓** — means the duration a person spends looking at or interacting with screen-based devices. Here, the sentence is simply describing duration in transparent language. That makes **Time spent using screens** the most accurate reformulation of this particular meaning of *screen time*.
- **B.** **Device-use time** — means the duration of using digital devices such as phones, tablets or computers. This is device-centred and can be slightly broader than visual screen exposure, so it is not always the best match. The decisive clue is that the sentence is simply describing duration in transparent language.
- **C.** **Screen-use time** — means the amount of time spent actively using devices with screens. This is a close duration term, but it misses the more specific device, health-exposure, or content-use nuance tested here. The decisive clue is that the sentence is simply describing duration in transparent language.
- **D.** **Internet use** — means activity using internet connectivity and excludes offline screen activities. This requires online activity; offline gaming, television or document work can still count as screen time. The decisive clue is that the sentence is simply describing duration in transparent language.
- **E.** **Phone use** — means use of phones specifically and is narrower than all screen time. This is too narrow because screen time can come from tablets, computers, televisions and other devices. The decisive clue is that the sentence is simply describing duration in transparent language.
- **F.** **Sedentary time** — means time spent sitting or otherwise inactive and does not require screen use. This tracks inactivity rather than screens: someone can sit without a screen or use a screen while standing. The decisive clue is that the sentence is simply describing duration in transparent language.

## 07 Direct contrasts · 核心辨析

- **screen time vs time spent using screens**: 幾乎同義；後者較透明、較長。
- **screen time vs device-use time**: device-use time 更以裝置為中心，範圍有時略廣。
- **screen time vs screen-use time**: 語義很接近；screen-use time 稍正式、研究化。
- **screen time vs digital-device use**: digital-device use 可研究活動類型、頻率，不一定只看時長。
- **screen time vs time on devices**: 後者更口語、更適合家庭建議。
- **screen time vs time in front of screens**: 後者更突出視覺上面對螢幕。
- **screen time vs screen exposure**: screen exposure 更 health-oriented。
- **screen time vs digital media use**: digital media use 更關心內容／活動類型。
- **screen time vs internet use**: internet use 只涵蓋網上活動；screen time 可離線。
- **screen time vs sedentary time**: 久坐與螢幕使用有重疊，但不是同一概念。

## 08 Grammar, collocation & measurement traps · 文法、搭配與螢幕時間量度陷阱

- **screen time** 通常不可數：reduce screen time / average screen time。
- **daily screen time**：每日螢幕使用時間。
- **spend + time + on screens/devices**：children spend two hours on devices。
- **time spent + -ing**：time spent using screens。
- **device-use time / screen-use time**：研究與問卷中可作 measurement label。
- **screen exposure** 常與 **prolonged / evening / reduce** 搭配。
- **digital media use** 不一定直接表示時長；如需 duration，可說 **time spent using digital media**。
- **internet use / online time** 只計算連線活動，不能覆蓋離線 screen time。
- **phone use** 只是一個裝置類別，不能代表所有 screen time。
- **television viewing** 是 screen time 的 subtype。
- **sedentary time** 和 screen time 不等同：坐着讀書可無螢幕，站着亦可用手機。
- 英式／香港用語保持 **programme, organisation, digitise** 等拼寫；本詞組 **screen time** 本身沒有英美拼寫差異。
