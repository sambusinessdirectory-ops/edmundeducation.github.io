# SYNONYMS · 同義詞學習系統

# As long as

**本課集中在 `as long as = provided that / on condition that` 的條件連詞意思，而不是表示時間長度的 `as long as = 和……一樣長／長達……`。在條件句中，它通常表示『只要某個條件成立，另一件事便可以／會發生』。**

核心替代表達：

`provided that / on condition that / so long as / if / assuming that / subject to / only if / provided`

> **核心原則**：先判斷 as long as 是表示 **sufficient condition, formal condition, ordinary if-condition, assumption, formal dependency, or necessary condition**。

---

# 01 同義詞指南

## 01 Provided that

**只要；如果……的話；條件是**

和 `as long as` 在條件句中非常接近，尤其用於較正式或清楚列明條件的語境。它表示前件成立，後件才適用。

**EXAMPLE · 例句**

> You may leave early provided that your work is finished.

只要你完成工作，就可以提早離開。

**SEMANTIC CUE · 語義提示**

> **a condition that must be satisfied**

**REGISTER · 語域**

正式、一般、工作

---

## 02 On condition that

**條件是；只要**

和 `as long as` 意思非常接近，但更正式、更明確帶有 contractual / conditional tone。常見於協議、批准、安排和正式要求。

**EXAMPLE · 例句**

> The permit will be granted on condition that safety rules are followed.

只要遵守安全規則，許可便會批出。

**SEMANTIC CUE · 語義提示**

> **a formally stated condition that must be met**

**REGISTER · 語域**

正式、法律、行政

---

## 03 So long as

**只要**

和 `as long as` 幾乎直接同義，在條件句中非常自然。語氣稍偏書面或英式，但一般英語也常見。

**EXAMPLE · 例句**

> You can stay here so long as you keep the room tidy.

只要你保持房間整潔，就可以住在這裏。

**SEMANTIC CUE · 語義提示**

> **provided that a particular condition remains true**

**REGISTER · 語域**

一般、書面

---

## 04 If

**如果**

最基本、最廣泛的條件連詞。很多 `as long as` 句子可以用 `if` 改寫，但 `if` 只表示條件，不一定有 `as long as` 的『只要這一條件滿足就足夠』意味。

**EXAMPLE · 例句**

> You can join us if you arrive before six.

如果你六時前到達，就可以加入我們。

**SEMANTIC CUE · 語義提示**

> **introducing a condition without necessarily implying sufficiency**

**REGISTER · 語域**

所有語域

---

## 05 Assuming that

**假設；如果假定**

當 `as long as` 的條件帶有假設性、推測性或前提性時，`assuming that` 很有用。它更像『在假設……成立的情況下』。

**EXAMPLE · 例句**

> The plan should work, assuming that costs remain stable.

假設成本保持穩定，這個計劃應該可行。

**SEMANTIC CUE · 語義提示**

> **on the assumption that something is true**

**REGISTER · 語域**

分析、正式、一般

---

## 06 Subject to

**在……條件下；須視乎**

當 `as long as` 表示某項安排、批准或權利取決於一個正式條件時，`subject to` 很自然。它後面通常接名詞／名詞片語，而不是完整 that-clause。

**EXAMPLE · 例句**

> The offer is valid subject to final approval.

這項要約在取得最終批准的條件下有效。

**SEMANTIC CUE · 語義提示**

> **depending on a formal requirement or approval**

**REGISTER · 語域**

正式、法律、商業

---

## 07 Only if

**只有在……情況下才**

當 `as long as` 的條件需要更強調『這是必要條件』時，`only if` 很精準。它比 `as long as` 更限制性。

**EXAMPLE · 例句**

> You can enter only if you have a valid pass.

只有持有效通行證才可以進入。

**SEMANTIC CUE · 語義提示**

> **introducing a necessary condition**

**REGISTER · 語域**

所有語域

---

## 08 Provided

**只要；條件是**

是 `provided that` 的較簡潔版本，尤其在英式英語中自然。可直接引導條件子句，但語氣仍比普通 `if` 正式。

**EXAMPLE · 例句**

> You can borrow the car provided you return it by midnight.

只要你在午夜前把車還回來，就可以借車。

**SEMANTIC CUE · 語義提示**

> **a concise form of provided that**

**REGISTER · 語域**

英式、一般、正式

# 02 False synonyms

## As long as / Provided that
兩者在條件句中非常接近；`provided that` 稍正式，更像明確列明條件。

**ENGLISH COMPARISON**  
You can stay as long as you are quiet.  
You can stay provided that you are quiet.

## As long as / On condition that
`on condition that` 更正式、更像協議／批准條款。

**ENGLISH COMPARISON**  
You may use the room as long as you book it first.  
You may use the room on condition that it is booked in advance.

## As long as / So long as
兩者在條件意思上幾乎直接同義。

**ENGLISH COMPARISON**  
You can come as long as you call first.  
You can come so long as you call first.

## As long as / If
`if` 只表示一般條件；`as long as` 常帶「只要這條件滿足便足夠」的意味。

**ENGLISH COMPARISON**  
You can join if you arrive early.  
You can join as long as you arrive before six.

## As long as / Assuming that
`assuming that` 更像在分析／預測中設定一個前提。

**ENGLISH COMPARISON**  
The plan will work as long as costs remain stable.  
The plan should work, assuming that costs remain stable.

## As long as / Subject to
`subject to` 通常較正式，而且後面多接名詞／名詞片語，而不是完整 that-clause。

**ENGLISH COMPARISON**  
The booking is confirmed as long as final approval is received.  
The booking is confirmed subject to final approval.

## As long as / Only if
`only if` 強調必要條件，限制性比 as long as 更強。

**ENGLISH COMPARISON**  
You may enter as long as you have a pass.  
You may enter only if you have a valid pass.

## As long as / Provided
`provided` 是 `provided that` 的簡潔形式，在英式英語尤其自然。

**ENGLISH COMPARISON**  
You can leave early as long as the work is finished.  
You can leave early provided the work is finished.

### CORRECT ANSWER · 正確答案

**A. provided that · 只要；如果……的話；條件是**

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. provided that ✓**  
線索「permission depends on one clearly stated condition」明確是『只要條件成立便可』，且語氣較正式，因此 `provided that` 最自然。

**B. so long as**

**C. if**  
`if`：最基本條件連詞，語氣較中性。 本句線索是「permission depends on one clearly stated condition」；它把條件解讀成普通 if、必要條件、正式批准條件或假設前提等不同類型，因此不是本句最佳替代。

**D. on condition that**  
`on condition that`：正式表示『條件是』。 本句線索是「permission depends on one clearly stated condition」；它把條件解讀成普通 if、必要條件、正式批准條件或假設前提等不同類型，因此不是本句最佳替代。

**E. providedly that**  
`providedly that`：不是標準英文。 本句線索是「permission depends on one clearly stated condition」；除了語義差異外，連詞、介詞、詞序或固定片語也不符合。

**F. regardless of cleanliness**  
`regardless of cleanliness`：不論是否保持整潔；和條件句相反。 本句線索是「permission depends on one clearly stated condition」；它把條件解讀成普通 if、必要條件、正式批准條件或假設前提等不同類型，因此不是本句最佳替代。

# 05 高價值近義詞辨析

- **As long as vs Provided that** — 意思很近；provided that 更正式。
- **As long as vs On condition that** — 後者更像條款／協議語氣。
- **As long as vs If** — if 最中性；as long as 常暗示這條件足夠。
- **As long as vs Only if** — only if 更強調必要性。
- **Assuming that vs Provided that** — assuming that 偏假設；provided that 偏條件。
- **Subject to vs Provided that** — subject to 多接名詞片語；provided that 接完整子句。
- **Provided vs Provided that** — 意思相同，前者較簡潔。
- **As long as ≠ as long as（時間長度）** — 本課只處理條件用法。

# 08 Grammar & structure traps

## As long as
條件用法：

> You can stay **as long as** you are quiet.

時間長度用法：

> Stay **as long as** you like.

兩者語義不同。

## Provided that / Provided
> provided that + clause  
> provided + clause

## On condition that
固定：

> on condition **that** + clause

## Subject to
通常：

> subject **to** + noun / noun phrase

例如：

> subject to approval  
> subject to verification

## Only if
> only if + clause

注意：若 only if 子句置前，主句有時會出現倒裝：

> Only if you have a pass **may you enter**.

# 09 核心決策問題

1. 想較正式地說「只要」？ → **provided that**
2. 是正式協議／批准條件？ → **on condition that**
3. 想用幾乎直接同義詞？ → **so long as**
4. 只是一般「如果」？ → **if**
5. 是分析／預測中的假設前提？ → **assuming that**
6. 後面是 approval / verification 等名詞片語？ → **subject to**
7. 要強調必要條件？ → **only if**
8. 想用簡潔英式版本？ → **provided**

# 10 Final note for system use

核心替代表達：

`provided that / on condition that / so long as / if / assuming that / subject to / only if / provided`

尤其要記住：

> **provided that** = 較正式「只要」  
> **on condition that** = 條款式「條件是」  
> **if** = 一般「如果」  
> **assuming that** = 假設前提  
> **subject to** = 須視乎／受制於條件  
> **only if** = 只有……才

最重要的一點：

> **as long as ≠ only if ≠ assuming that**

三者分別偏向 **條件足夠、必要條件、假設前提**。
