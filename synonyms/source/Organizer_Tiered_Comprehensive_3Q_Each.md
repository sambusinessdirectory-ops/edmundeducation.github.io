# ORGANIZER · 分層同義詞學習系統

## Organizer

**「組織者／主辦人／統籌人」，要先分清是負責前期規劃的 planner、跨人員與任務統籌的 coordinator、專業活動營運的 event manager，還是只負責召集會議的 convenor。**

本單元集中處理 **organizer = a person responsible for planning, arranging, coordinating, or running an event, project, programme, or organised activity**。你提供的 **planner; coordinator; event manager** 分別代表 **策劃、協調、專業活動管理** 三個核心方向。

這個詞的自然替代表達主要取決於責任範圍，因此本次保留 **11 個**高實用度詞／表達，而不是追求固定數量。共 **33 道練習**，每個目標 **3 題**；正確答案位置在 A–F 間盡量平均分布。

## Tier 1 — Core planner / coordinator / event-management equivalents · 核心策劃、協調與活動管理近義詞

### 01 Planner

**Tier**：1  
**中文**：策劃者；規劃人員  
**語域**：neutral / common  
**核心語義**：a person who plans the details, timing, resources, or structure of an activity or event  
**用法提示**：你提供的 seed 是 organizer 的核心近義詞之一，尤其適合活動、行程、項目和流程的前期規劃。  
**常見搭配**：event planner; wedding planner; project planner; strategic planner; planning team.  
**常見搭配對象**：event, schedule, trip, project, wedding.  
**與 organizer 的辨析**：Planner 強調事前規劃；organizer 還可包括聯絡、執行和現場安排。  
**使用限制**：若重點是跨部門協調，coordinator 更精準。

**EXAMPLE · 例句**  
The planner prepared a detailed schedule for the conference.  
策劃者為會議準備了詳細時間表。

### 02 Coordinator

**Tier**：1  
**中文**：協調員；統籌人  
**語域**：neutral / very common  
**核心語義**：a person who brings people, tasks, schedules, or resources together so that an activity runs smoothly  
**用法提示**：你提供的 seed 很核心，當 organizer 的主要工作是聯絡各方、統籌時間和資源時最自然。  
**常見搭配**：project coordinator; event coordinator; programme coordinator; volunteer coordinator; logistics coordinator.  
**常見搭配對象**：team, schedule, supplier, volunteer, programme.  
**與 organizer 的辨析**：Coordinator 比 organizer 更強調 coordination across people and tasks。  
**使用限制**：若某人負責整體商業活動營運，event manager 可能更合適。

**EXAMPLE · 例句**  
The coordinator confirmed the timetable with all the speakers.  
統籌人向所有講者確認時間表。

### 03 Event manager

**Tier**：1  
**中文**：活動經理；活動統籌經理  
**語域**：neutral / professional  
**核心語義**：a professional who oversees the planning, logistics, staffing, budget, and delivery of an event  
**用法提示**：你提供的 seed 很重要，適合較大型、商業或專業活動。  
**常見搭配**：event manager; venue manager; event-management team; manage an event; event operations.  
**常見搭配對象**：conference, festival, venue, budget, supplier.  
**與 organizer 的辨析**：Event manager 比 organizer 更專業化，通常負責整體營運和執行。  
**使用限制**：小型社區活動未必需要 manager 這個職銜。

**EXAMPLE · 例句**  
The event manager supervised the venue setup and supplier schedule.  
活動經理監督場地佈置和供應商時間表。

### 04 Event organiser

**Tier**：1  
**中文**：活動主辦人；活動組織者  
**語域**：British English / very common  
**核心語義**：a person or organisation responsible for arranging and running an event  
**用法提示**：這是英式英語中對 organizer 最直接的寫法和表達之一；香港／英式文本特別實用。  
**常見搭配**：event organiser; conference organiser; festival organiser; lead organiser; organising team.  
**常見搭配對象**：event, conference, festival, meeting, workshop.  
**與 organizer 的辨析**：語義幾乎等同 event organizer；差別主要是英式拼法 organiser。  
**使用限制**：只適用於活動／事件語境；一般項目 organizer 未必叫 event organiser。

**EXAMPLE · 例句**  
The event organiser sent final instructions to participants.  
活動主辦人向參加者發出最後指示。

### 05 Event coordinator

**Tier**：1  
**中文**：活動協調員；活動統籌  
**語域**：neutral / professional  
**核心語義**：a person who coordinates the practical details and people involved in an event  
**用法提示**：當 organizer 的核心工作是場地、講者、供應商、參加者和時間表統籌時很自然。  
**常見搭配**：event coordinator; conference coordinator; venue coordinator; coordinate logistics; event schedule.  
**常見搭配對象**：speaker, venue, supplier, guest, timetable.  
**與 organizer 的辨析**：比 event manager 稍偏執行細節與協調。  
**使用限制**：若負責預算、策略和整體決策，event manager 更高層。

**EXAMPLE · 例句**  
The event coordinator arranged transport for the guest speakers.  
活動協調員為嘉賓講者安排交通。

## Tier 2 — Programme / project / meeting-specific variants · 計劃、項目與會議特定角色變體

### 06 Event planner

**Tier**：2  
**中文**：活動策劃人；活動策劃師  
**語域**：neutral / professional  
**核心語義**：a person who designs and plans an event, including its programme, schedule, venue, and practical arrangements  
**用法提示**：當 organizer 特別強調構思與前期設計時最自然。  
**常見搭配**：event planner; wedding planner; party planner; plan an event; event-planning service.  
**常見搭配對象**：wedding, party, conference, programme, venue.  
**與 organizer 的辨析**：Event planner 比 organizer 更偏 planning stage。  
**使用限制**：若活動已進入現場執行，coordinator / manager 可能更精準。

**EXAMPLE · 例句**  
The event planner helped the couple choose the venue and schedule.  
活動策劃師協助新人選擇場地和時間表。

### 07 Programme coordinator

**Tier**：2  
**中文**：計劃統籌員；課程／項目統籌  
**語域**：neutral / education / NGO / public sector  
**核心語義**：a person who coordinates an ongoing programme, including schedules, participants, communication, and administration  
**用法提示**：當 organizer 其實負責一個持續性 programme 而不是單次活動時很實用。  
**常見搭配**：programme coordinator; training coordinator; community programme; coordinate sessions; programme delivery.  
**常見搭配對象**：course, training, community, schedule, participant.  
**與 organizer 的辨析**：Programme coordinator 強調持續性 programme，而不是單次 event。  
**使用限制**：單一晚宴或會議通常不用 programme coordinator。

**EXAMPLE · 例句**  
The programme coordinator arranged weekly sessions with local schools.  
計劃統籌員安排每週與本地學校舉行的活動。

### 08 Project coordinator

**Tier**：2  
**中文**：項目協調員；項目統籌  
**語域**：neutral / professional  
**核心語義**：a person who coordinates tasks, deadlines, information, and team members within a project  
**用法提示**：當 organizer 的工作圍繞一個有目標、期限和多項工作任務的 project 時很自然。  
**常見搭配**：project coordinator; project schedule; project team; coordinate tasks; project administration.  
**常見搭配對象**：deadline, team, task, document, stakeholder.  
**與 organizer 的辨析**：比 organizer 更 project-management oriented。  
**使用限制**：純社交活動或一次性聚會通常不用。

**EXAMPLE · 例句**  
The project coordinator tracked deadlines and updated the team.  
項目協調員追蹤期限並向團隊更新進度。

### 09 Convenor

**Tier**：2  
**中文**：召集人；會議召集者  
**語域**：British English / formal  
**核心語義**：a person responsible for calling, arranging, or leading meetings of a group, committee, or panel  
**用法提示**：當 organizer 具體是召集會議、委員會或工作小組時很精準。  
**常見搭配**：meeting convenor; panel convenor; committee convenor; convene a meeting; group convenor.  
**常見搭配對象**：committee, panel, meeting, working group, discussion.  
**與 organizer 的辨析**：Convenor 比 organizer 更窄，專注於召集／安排 group meetings。  
**使用限制**：一般大型活動主辦不宜叫 convenor。

**EXAMPLE · 例句**  
The convenor circulated the agenda before the committee meeting.  
召集人在委員會會議前傳閱議程。

## Tier 3 — Leadership / production-specific variants · 主責領導與活動製作變體

### 10 Lead organiser

**Tier**：3  
**中文**：首席主辦人；主要統籌人  
**語域**：neutral / descriptive  
**核心語義**：the person with primary responsibility for organising an event, campaign, or activity  
**用法提示**：當需要指出 organizer 中的主要負責人／帶頭者時非常自然。  
**常見搭配**：lead organiser; chief organiser; organising team; lead the organisation; principal organiser.  
**常見搭配對象**：event, campaign, protest, festival, conference.  
**與 organizer 的辨析**：比 organizer 多了一層『主要負責』的角色階級。  
**使用限制**：如果團隊沒有明確主責人，就不宜加 lead。

**EXAMPLE · 例句**  
The lead organiser coordinated the final preparations with the venue team.  
首席主辦人與場地團隊協調最後準備工作。

### 11 Event producer

**Tier**：3  
**中文**：活動製作人；活動製作統籌  
**語域**：professional / events / media  
**核心語義**：a professional responsible for shaping and delivering the creative and operational production of an event  
**用法提示**：當 organizer 涉及舞台、節目內容、技術製作和整體活動呈現時很有用。  
**常見搭配**：event producer; live-event producer; production schedule; event production; producer team.  
**常見搭配對象**：stage, show, festival, production, technical crew.  
**與 organizer 的辨析**：Event producer 比 organizer 更偏創意製作與技術執行。  
**使用限制**：一般行政型主辦人不一定是 producer。

**EXAMPLE · 例句**  
The event producer worked closely with the lighting and sound teams.  
活動製作人與燈光和音響團隊緊密合作。

## 04 False synonyms / organizer traps · 容易誤選的詞與『主辦／統籌』角色陷阱

### 01 Host

**主持人／主人不等於 organizer**  
host 負責接待或主持；不一定負責整個活動的規劃與統籌。

**ENGLISH COMPARISON**  
A host may present or welcome guests without organising the event.

### 02 Chairperson

**主席不等於 organizer**  
chairperson 主持會議或委員會；其工作重點不是整體組織安排。

**ENGLISH COMPARISON**  
A chairperson leads proceedings, not necessarily logistics.

### 03 Facilitator

**引導員不等於 organizer**  
facilitator 幫助討論或活動順利進行，但未必負責策劃。

**ENGLISH COMPARISON**  
A facilitator supports a process rather than owning the organisation.

### 04 Administrator

**行政人員不等於 organizer**  
administrator 處理行政工作，範圍可很廣。

**ENGLISH COMPARISON**  
Administration is broader and may not involve organising an event.

### 05 Promoter

**推廣人／主辦商不等於所有 organizer**  
promoter 常有宣傳、售票或商業推廣角色。

**ENGLISH COMPARISON**  
Promoter is commercial/publicity-focused.

### 06 Manager

**經理不等於 organizer**  
manager 是職級／管理角色，未必負責具體活動組織。

**ENGLISH COMPARISON**  
Manager is broader than organiser.

### 07 Coordinator

**只在協調 sense 接近**  
coordinator 著重聯絡人和任務，不必負責整體主辦。

**ENGLISH COMPARISON**  
Coordination is one part of organising.

### 08 Organizer / organiser

**拼寫陷阱**  
organizer 是美式常見拼法；organiser 是英式常見拼法。

**ENGLISH COMPARISON**  
Organizer is common in AmE; organiser is common in BrE.

## 07 Direct contrasts · 核心辨析

- **organizer vs planner**: planner 更偏前期規劃；organizer 可涵蓋整體執行。
- **organizer vs coordinator**: coordinator 更偏聯絡與統籌多方。
- **organizer vs event manager**: event manager 通常承擔更完整的專業活動營運責任。
- **organizer vs event planner**: event planner 更偏活動概念與前期設計。
- **organizer vs convenor**: convenor 只專注召集會議／委員會。
- **organizer vs host**: host 接待／主持，不一定負責活動組織。
- **organizer vs facilitator**: facilitator 引導討論／流程，不一定負責 logistics。
- **organizer vs promoter**: promoter 偏宣傳、售票或商業推廣。
- **organizer vs event producer**: producer 偏創意內容和技術製作。
- **organizer vs lead organiser**: lead organiser 是多位主辦人中的主要負責人。

## 08 Grammar, spelling & role traps · 文法、拼寫與角色陷阱

- **organizer** 是常見美式拼法；**organiser** 是常見英式拼法。
- 香港／英式英文正式寫作可優先使用 **organiser**。
- **event organiser / event organizer** 都自然，依拼寫系統而定。
- **planner** 常與 event / wedding / project 搭配。
- **coordinator** 常與 event / programme / project / volunteer / logistics 搭配。
- **event manager** 通常比 event coordinator 責任更全面。
- **programme coordinator** 適合持續性 programme；英式拼法 **programme**。
- **project coordinator** 聚焦項目期限、任務和團隊。
- **convenor** 在英式正式語境常見；亦可見 **convener**。
- **host / chairperson / facilitator ≠ organizer**：它們可能參與活動，但角色核心不同。
- **organise** 是英式動詞拼法；美式常用 **organize**。
