# FRAME · 分層同義詞學習系統

## Frame · verb

**本課集中處理 frame = compose / position a subject within a visual view 的攝影、電影與視覺構圖義項。** 不處理 **frame a question / frame an argument / frame someone for a crime** 等其他動詞義項。

你提供的 **compose; position within a view** 正好代表兩個核心方向：**安排整體構圖** 與 **把主體放在畫面中的特定位置**。

這個義項本身相對窄，因此本次只保留 **7 個**自然且具教學價值的近義／情境表達，共 **21 道練習**，每個目標 **3 題**。不把 **crop, zoom, focus, capture** 等攝影相關但不同動作硬當同義詞。

## Sense split · 義項分流

| Frame 的語境 | 最接近的詞／表達 |
|---|---|
| 安排整體畫面構圖 | **compose** |
| 把主體放在特定位置 | **position** |
| 明確說明放入取景框內 | **place within the frame** |
| 把主體放在中央 | **centre** |
| 在鏡頭中安排多人／多物件 | **arrange in the shot** |
| 把主體／地平線與線條對齊 | **line up** |
| 確保某人／物出現在鏡頭內 | **include in the shot** |

## Tier 1 — Core composition / positioning equivalents · 核心構圖與定位近義詞

### 01 Compose

**Tier**：1  
**中文**：構圖；安排畫面  
**語域**：neutral / photography / art  
**核心語義**：arrange the visual elements of an image so that they form an effective composition  
**用法提示**：你提供的 seed 是 **frame** 在攝影、電影與視覺設計語境中最核心的近義詞之一。  
**常見搭配**：compose a shot; compose an image; carefully compose; compose the scene.  
**常見搭配對象**：shot, image, photograph, scene, portrait.  
**與 frame 的辨析**：Compose 強調整體構圖與各元素關係；frame 更常強調鏡頭邊界內『放甚麼、怎樣放』。  
**使用限制**：若只是把某個人物移到畫面中央，position / centre 更精準。

**EXAMPLE · 例句**  
The photographer composed the shot so that the bridge led the eye towards the skyline.  
攝影師安排構圖，讓橋樑把視線引向天際線。

### 02 Position

**Tier**：1  
**中文**：定位；把……置於畫面某位置  
**語域**：neutral / very common  
**核心語義**：place a subject or object in a particular location within the visual field  
**用法提示**：你提供的 seed **position within a view** 正是 frame 的核心動作之一，尤其適合人物、物件與視覺焦點的位置安排。  
**常見搭配**：position the subject; position in the foreground; position off-centre; carefully position.  
**常見搭配對象**：subject, person, object, camera, foreground element.  
**與 frame 的辨析**：Position 聚焦位置；frame 可以同時包含邊界、構圖與背景選擇。  
**使用限制**：若要談整體美學構圖，compose 更完整。

**EXAMPLE · 例句**  
She positioned the subject slightly to the left of the centre.  
她把主體稍微放在畫面中央偏左的位置。

### 03 Place within the frame

**Tier**：1  
**中文**：放入畫面；置於取景框內  
**語域**：neutral / explanatory  
**核心語義**：put a person or object at a chosen location inside the boundaries of the image  
**用法提示**：這是 **frame** 在教學或技術解說中非常透明的改寫，直接說明『把主體放在畫面邊界內』。  
**常見搭配**：place within the frame; place near the edge; place in the foreground; place centrally.  
**常見搭配對象**：subject, object, face, horizon, foreground element.  
**與 frame 的辨析**：比 frame 更解釋性，適合教學；語氣不如 compose 精煉。  
**使用限制**：正式成品描述通常直接用 frame / position / compose。

**EXAMPLE · 例句**  
Place the subject within the frame so that there is space above the head.  
把主體放入畫面時，要在頭頂上方留出空間。

### 04 Centre

**Tier**：1  
**中文**：置中；把……放在畫面中央  
**語域**：neutral / photography / design  
**核心語義**：place the main subject at or near the centre of the image  
**用法提示**：當 frame 的具體做法是『把主體放在正中央』時，centre 是最自然的精確替代。  
**常見搭配**：centre the subject; centre the face; centre the horizon; centrally framed.  
**常見搭配對象**：subject, face, object, text, horizon.  
**與 frame 的辨析**：Centre 只是 frame 的一種具體構圖選擇；frame 不一定要置中。  
**使用限制**：若主體本來要放在三分線或畫面邊緣，不應用 centre。

**EXAMPLE · 例句**  
The director centred the actor in the shot to create a formal, symmetrical image.  
導演把演員置於畫面中央，營造正式而對稱的影像。

### 05 Arrange in the shot

**Tier**：1  
**中文**：在鏡頭中安排；安排畫面位置  
**語域**：neutral / film / photography  
**核心語義**：organise people or objects inside a shot so that their positions create the intended visual effect  
**用法提示**：當 frame 涉及多人、多件物件或 foreground/background 關係時很自然。  
**常見搭配**：arrange in the shot; arrange the figures; arrange foreground elements; arrange the scene.  
**常見搭配對象**：people, props, furniture, foreground, background.  
**與 frame 的辨析**：Arrange in the shot 強調多個元素如何擺放；frame 可只處理單一主體。  
**使用限制**：如果只是把相機對準一個人，不必用 arrange。

**EXAMPLE · 例句**  
The crew arranged the actors in the shot so that no one blocked the doorway.  
工作人員在鏡頭中安排演員位置，避免有人擋住門口。

## Tier 2 — Alignment-focused variant · 對齊型變體

### 06 Line up

**Tier**：2  
**中文**：對齊；把……排入畫面  
**語域**：informal / practical  
**核心語義**：align a subject, object, or visual feature with another element before taking the image  
**用法提示**：當 frame 的重點是 horizon, subject, edge, architectural line 等『對準／排好』時可用。  
**常見搭配**：line up the horizon; line up the subject; line up the shot; line up with.  
**常見搭配對象**：horizon, subject, edge, building, camera.  
**與 frame 的辨析**：Line up 強調 alignment；frame 更廣，還包括整體構圖與畫面邊界。  
**使用限制**：不是所有 framing 都涉及對齊。

**EXAMPLE · 例句**  
He lined up the horizon with the lower third of the viewfinder.  
他把地平線對齊取景器下方三分之一的位置。

## Tier 3 — Inclusion-focused contextual variant · 納入畫面情境變體

### 07 Include in the shot

**Tier**：3  
**中文**：納入鏡頭；讓……出現在畫面中  
**語域**：neutral / contextual  
**核心語義**：make sure a person, object, or feature appears within the visible shot  
**用法提示**：當 frame 的核心不是精細構圖，而是『確保某物出現在畫面內』時，這是自然的情境改寫。  
**常見搭配**：include in the shot; include the background; include both subjects; include enough context.  
**常見搭配對象**：person, building, background, sign, landscape.  
**與 frame 的辨析**：只表示納入可見範圍，不一定說明位置好不好看。  
**使用限制**：如果重點是構圖品質、中心位置或對齊，compose / position / centre 更準。

**EXAMPLE · 例句**  
The photographer included the old station sign in the shot to give the location context.  
攝影師把舊車站招牌納入鏡頭，讓畫面更有地點背景。

## 04 False synonyms / framing traps · 容易誤選的裁剪、變焦、對焦與拍攝陷阱

### 01 Crop

**裁剪 ≠ frame**  
crop 是拍攝後或取景時刪走畫面邊緣內容；frame 是決定畫面內如何呈現。

**ENGLISH COMPARISON**  
Cropping removes; framing arranges.

### 02 Zoom

**變焦 ≠ frame**  
zoom 改變焦距／視角大小，不等於構圖安排。

**ENGLISH COMPARISON**  
Zoom changes magnification/field of view.

### 03 Focus

**對焦 ≠ frame**  
focus 決定哪裏清晰；frame 決定畫面包含甚麼、如何安排。

**ENGLISH COMPARISON**  
Focus concerns sharpness.

### 04 Capture

**拍下 ≠ frame**  
capture 是取得影像；frame 是拍攝前／拍攝時的畫面安排。

**ENGLISH COMPARISON**  
Capture is the act of recording.

### 05 Shoot

**拍攝 ≠ frame**  
shoot 是拍照／拍片的整體行為，不等於構圖。

**ENGLISH COMPARISON**  
Shooting is broader than framing.

### 06 Edit

**剪輯／編輯 ≠ frame**  
edit 通常是拍攝後處理影像或影片。

**ENGLISH COMPARISON**  
Editing is post-production.

### 07 Rotate

**旋轉 ≠ frame**  
rotate 只改變方向，不等於構圖安排。

**ENGLISH COMPARISON**  
Rotation is orientation-focused.

### 08 Frame / framing

**詞形陷阱**  
frame 可作動詞／名詞；framing 可作名詞／分詞。

**ENGLISH COMPARISON**  
Check word class and role.

## 05 練習與解釋 · Practice

### 練習 01.1

**Tier 1 · Target word / phrase**: Compose · 構圖；安排畫面

**READ THE CONTEXT · 閱讀語境**

The photographer framed the image so that the road led towards the mountains.

**中文翻譯**  
攝影師安排構圖，讓道路把視線帶向山脈。

- A. Compose
- B. Position
- C. Centre
- D. Crop
- E. Zoom
- F. Focus

**CORRECT ANSWER · 正確答案**

**A. Compose** · 構圖；安排畫面

**Correct rewrite · 正確改寫**  
The photographer composed the image so that the road led towards the mountains.

**SIX-OPTION FEEDBACK · 六個選項的詳細解釋**

- **A.** **Compose ✓** — arrange the visual elements of an image into an effective composition。這句的決定性線索是 **the whole visual composition is being designed**。因此 **Compose** 最準確表達這種 *frame*。
- **B.** **Position** — place a subject or object in a particular location within the visual field。**position** 只聚焦主體位置；若句子是在設計整體構圖、排列多個元素或單純確保某物入鏡，可能不夠完整。
- **C.** **Centre** — place the main subject at or near the centre of the image。**centre** 只表示置中；如果主體是 off-centre、沿三分線或只需出現在鏡頭內，就不適合。
- **D.** **Crop** — remove unwanted outer parts of an image。**crop** 是刪走影像邊緣內容，通常屬拍攝後或取景裁切；它不是安排主體位置。
- **E.** **Zoom** — change magnification or field of view。**zoom** 改變焦距／視角大小，不決定主體在畫面中的具體構圖。
- **F.** **Focus** — adjust sharpness or choose what appears sharp。**focus** 關乎清晰度，不是畫面位置與構圖。

**SIX-OPTION FEEDBACK · 六個選項的詳細解釋**

- **A.** **Include in the shot ✓** — make sure a person, object, or feature appears within the visible shot。這句的決定性線索是 **the main requirement is simply that the sign appears in the image**。因此 **Include in the shot** 最準確表達這種 *frame*。

- **C.** **Compose** — arrange the visual elements of an image into an effective composition。**compose** 適合整體美學構圖；如果題目只要求把主體置中、對齊或確保入鏡，會太廣。
- **D.** **Crop** — remove unwanted outer parts of an image。**crop** 是刪走影像邊緣內容，通常屬拍攝後或取景裁切；它不是安排主體位置。
- **E.** **Zoom** — change magnification or field of view。**zoom** 改變焦距／視角大小，不決定主體在畫面中的具體構圖。
- **F.** **Focus** — adjust sharpness or choose what appears sharp。**focus** 關乎清晰度，不是畫面位置與構圖。

## 06 Semantic map · 語義總覽

| Frame 的語境 | 最接近的詞／表達 | Diagnostic question |
|---|---|---|
| 道路／人物／負空間的整體構圖 | **compose** | 是否 the whole image composition is being designed？ |
| 主體放在畫面某位置 | **position** | 是否 location within the frame is central？ |
| 教學：確保主體完整入鏡 | **place within the frame** | 是否 image boundaries are the main concern？ |
| 正正放在畫面中央 | **centre** | 是否 exact central placement is intended？ |
| 多名演員／道具的畫面安排 | **arrange in the shot** | 是否 multiple elements are being organised？ |
| 地平線／門口／塔樓對齊 | **line up** | 是否 alignment with another visual feature is central？ |
| 讓招牌／背景／兩人都入鏡 | **include in the shot** | 是否 visibility/inclusion is enough？ |

## 07 Direct contrasts · 核心辨析

- **frame vs compose**：compose 強調整體畫面構圖。
- **frame vs position**：position 強調主體在畫面中的具體位置。
- **frame vs centre**：centre 只是 frame 的一種特定選擇。
- **frame vs arrange in the shot**：後者特別適合多個元素。
- **frame vs line up**：line up 聚焦對齊。
- **frame vs include in the shot**：後者只要求某物出現在鏡頭內。
- **frame vs crop**：crop 是裁剪，不是構圖安排。
- **frame vs focus**：focus 是清晰度／焦點，不是位置。
- **frame vs zoom**：zoom 是變焦，不是構圖本身。

## 08 Grammar, collocation & photography traps

- **frame + subject/person/object**：frame the subject carefully。
- **frame + shot/image/scene**：可指安排畫面內容與邊界。
- **compose a shot / compose an image**：攝影與電影常見。
- **position + subject + adverbial**：position the subject off-centre。
- **centre + object**：centre the face / centre the subject。
- **line up A with B**：line up the horizon with the lower third。
- **include + object + in the shot**：include the sign in the shot。
- **framing** 可作名詞：tight framing / careful framing。
- 不要把 **crop, zoom, focus, shoot, edit** 當作 frame 的全面同義詞。
