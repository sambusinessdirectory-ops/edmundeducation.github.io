# GOOD MEMORY — Complete Synonym Lesson

## 01 同義詞指南

### Good memory 的 8 種更精準說法

> Note: “good memory” can refer to **strong recall, long-lasting retention, generally sharp memory, highly accurate recall, strong retention of learned material, a retentive memory, strong powers of recall, or a special ability to remember small details**.
> 「good memory」可以表示 **回想能力很強、資訊保留得很久、整體記性敏銳、回憶特別準確、學習內容保持得好、記憶保持力強、正式語境中的強大回想能力，或特別擅長記住細節**。以下按這些重點區分。

### 01 Strong Recall
**很強的回憶能力；記得很牢**

表示能夠迅速、準確地把先前學過或見過的資訊從記憶中提取出來。常見於學習、測驗、名字、事實和細節。

**EXAMPLE · 例句**  
She has strong recall for names and dates.  
她對名字和日期有很強的回憶能力。

---

### 02 Excellent Retention
**極佳的記憶保持力；能長時間記住**

強調學過或接收過的資訊能長時間保留在記憶中。常見於教育、培訓、學習成效和知識保存。

**EXAMPLE · 例句**  
The students showed excellent retention of the material several weeks later.  
幾星期後，學生仍很好地記得教材內容。

---

### 03 Sharp Memory
**敏銳的記憶力；記性很好**

常見、自然的日常表達，表示一個人記性敏銳，能準確記住事情。比 strong recall 更一般，也常用於描述整體記憶表現。

**EXAMPLE · 例句**  
Even in her eighties, she still has a sharp memory.  
即使八十多歲，她的記憶力仍然很敏銳。

---

### 04 Excellent Recall
**極佳的回憶能力；能準確想起**

和 strong recall 很接近，語氣更強。適合正式或半正式語境，強調能準確把已知資訊、事件或細節重新想起。

**EXAMPLE · 例句**  
The witness demonstrated excellent recall of the conversation.  
證人對那次談話展現出極佳的回憶能力。

---

### 05 Strong Retention
**良好的記憶保持力；保存資訊能力強**

表示資訊在記憶中保留得很好。語氣比 excellent retention 稍弱，常用於學習成效、訓練和教育評估。

**EXAMPLE · 例句**  
Regular review can lead to strong retention of new vocabulary.  
定期複習有助新詞彙長時間保留在記憶中。

---

### 06 Retentive Memory
**記憶保持力強的記性；很能記住**

較正式、較少見，但自然。用來形容一個人能把學過或接觸過的資訊保留很久。常見搭配是 a highly retentive memory。

**EXAMPLE · 例句**  
She has a highly retentive memory for languages.  
她對語言有很強的記憶保持力。

---

### 07 Strong Powers Of Recall
**很強的回想能力；出色的記憶提取能力**

較正式、帶書面語色彩，表示一個人有很強的能力把名字、事件、資料或細節從記憶中重新想起。

**EXAMPLE · 例句**  
The historian had strong powers of recall even late in life.  
這位歷史學家晚年仍有很強的回想能力。

---

### 08 Memory For Detail
**對細節的記憶力；很會記細節**

當 good memory 特別表現在能記住小細節，例如顏色、數字、衣着、位置或措辭時，可用 memory for detail。

**EXAMPLE · 例句**  
She has an excellent memory for detail.  
她對細節的記憶力非常好。

---

## 02 False synonyms

### 看起來相關，意思卻不同

### 01 Photographic Memory
**過目不忘般的記憶不等於一般的 good memory**

**photographic memory = 過目不忘般的記憶**

photographic memory 是很強、很特殊的說法，通常指能像影像一樣極精確地記住所見內容。它不能用來泛指所有 good memory。

**ENGLISH COMPARISON**  
Someone can have a very good memory without having a photographic memory.

---

### 02 Memorization
**記憶；背誦過程不等於一般的 good memory**

**memorization = 記憶；背誦過程**

memorization 是把資訊記進腦中的過程或技巧；good memory 是記憶能力或表現。

**ENGLISH COMPARISON**  
Memorization is a process; a good memory is an ability.

---

### 03 Recollection
**回憶；記起的內容不等於一般的 good memory**

**recollection = 回憶；記起的內容**

recollection 通常指一次回憶或某人對往事的記憶內容，不直接等於整體記憶力好。

**ENGLISH COMPARISON**  
A recollection is something remembered; good memory describes ability.

---

### 04 Recognition
**辨認；認出不等於一般的 good memory**

**recognition = 辨認；認出**

recognition 是看到人、物或答案後認出來；recall 則是沒有直接提示也能把資訊想起來。

**ENGLISH COMPARISON**  
Recognition and recall are different memory processes.

---

### 05 Nostalgia
**懷舊；念舊不等於一般的 good memory**

**nostalgia = 懷舊；念舊**

nostalgia 是對過去的情感和懷念。很懷舊的人未必記憶特別準確。

**ENGLISH COMPARISON**  
Nostalgia is an emotion, not memory accuracy.

---

### 06 Intelligence
**智力不等於一般的 good memory**

**intelligence = 智力**

intelligence 和 memory 有關但不是同一能力。聰明的人未必特別會記，而記性好也不等於整體智力較高。

**ENGLISH COMPARISON**  
Intelligence and memory overlap in some tasks but are not synonyms.

---

### 07 Concentration
**專注力不等於一般的 good memory**

**concentration = 專注力**

concentration 是把注意力集中在某件事上的能力。它可以幫助記憶形成，但不是記憶本身。

**ENGLISH COMPARISON**  
Concentration can support memory, but it is not memory.

---

### 08 Attention Span
**注意力持續時間不等於一般的 good memory**

**attention span = 注意力持續時間**

attention span 指能維持注意多久，和資訊能否被長期保留或準確回想是不同概念。

**ENGLISH COMPARISON**  
A long attention span does not automatically mean strong memory.

---

# 01 Strong Recall · 很強的回憶能力；記得很牢

## 練習 01.1

**Target word: Strong Recall · 很強的回憶能力；記得很牢**

### READ THE CONTEXT · 閱讀語境

He has a good memory for names and can usually remember people after meeting them only once.

### 中文翻譯

他很會記名字，通常只見過一次便能記得對方。

A. strong recall
B. excellent retention
C. memory for detail
D. photographic memory
E. concentration
F. recognition

### CORRECT ANSWER · 正確答案

**strong recall · 很強的回憶能力；記得很牢**

He has strong recall for names and can usually remember people after meeting them only once.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. strong recall ✓**  
strong recall = 很強的回憶能力。remember people after meeting them only once 明確強調把已見過的名字和人物迅速從記憶中提取出來。

**B. excellent retention**  
excellent retention = 保留資訊能力很強。也和記憶相關，但更偏資訊能保存多久，而這句突出需要時能想起名字。

**C. memory for detail**  
memory for detail = 對細節記憶好。若題目強調衣着、數字或具體細節更合適；這裡核心是名字的 recall。

**D. photographic memory**  
photographic memory = 過目不忘般的記憶。語氣非常強，也不是『見一次便通常記得』就足以支持。

**E. concentration**  
concentration = 專注力。專心可能幫助記憶，但不是記憶能力本身。

**F. recognition**  
recognition = 辨認。認得一張臉不等於能主動回想出名字。
