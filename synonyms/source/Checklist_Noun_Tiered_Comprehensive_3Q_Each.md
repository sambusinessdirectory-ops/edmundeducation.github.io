# CHECKLIST · 分層同義詞學習系統

## Checklist · noun

**Checklist = a list of items, tasks, or checks that are completed or verified one by one.** 它可以偏向 **to-do tasks, inspection items, verification checks, tick-off completion, compliance verification,** 或 **ordered process steps**。因此替換前要先判斷清單的主要功能。

你提供的 **list of tasks; inspection list** 正好代表兩個核心方向：**待辦任務** 與 **檢查項目**。

本次保留 **7 個**自然且具教學價值的近義／情境表達，共 **21 道練習**，每個目標 **3 題**。不把 **schedule, agenda, inventory, form** 等其他類型清單硬當同義詞。

## Sense split · 義項分流

| Checklist 的語境 | 最接近的詞／表達 |
|---|---|
| 一般待辦任務 | **list of tasks** |
| 設備／安全／車輛檢查 | **inspection list** |
| 日常／項目待辦事項 | **task list** |
| 逐項核對正確／安全／完成 | **list of checks** |
| 完成一項便打勾 | **tick list** |
| 審核／合規／驗收核證 | **verification list** |
| 有固定先後次序的清單 | **step-by-step list** |

## Tier 1 — Core task / inspection / check-list equivalents · 核心任務、檢查與核對近義詞

### 01 List of tasks

**Tier**：1  
**中文**：工作清單；任務清單  
**語域**：neutral / very common  
**核心語義**：a list of tasks or actions that need to be completed, often checked off one by one  
**用法提示**：你提供的 seed 是 **checklist** 最直接、最自然的解釋性改寫之一，尤其適合 daily work, project preparation, travel, study 等語境。  
**常見搭配**：list of tasks; complete the list of tasks; work through a list of tasks; daily task list.  
**常見搭配對象**：project, day, trip, assignment, preparation.  
**與 checklist 的辨析**：List of tasks 強調『要做甚麼』；checklist 還可包括檢查項目、標準、條件，而不一定全是 action。  
**使用限制**：若重點是檢查某物是否符合標準，inspection list / list of checks 更精準。

**EXAMPLE · 例句**  
I made a list of tasks to finish before the meeting.  
我列了一張工作清單，要在會議前完成。

### 02 Inspection list

**Tier**：1  
**中文**：檢查清單；檢驗項目表  
**語域**：formal / operational  
**核心語義**：a list of items or conditions to inspect, verify, or confirm  
**用法提示**：你提供的 seed 很核心，特別適合 maintenance, safety, quality control, site inspection 等語境。  
**常見搭配**：inspection list; safety inspection list; equipment inspection list; inspection checklist.  
**常見搭配對象**：equipment, site, vehicle, safety, quality.  
**與 checklist 的辨析**：Inspection list 專注『檢查甚麼』；checklist 可以是任何待辦／核對項目。  
**使用限制**：日常購物、旅行打包、學習任務等不適合。

**EXAMPLE · 例句**  
The engineer used an inspection list before restarting the machine.  
工程師在重新啟動機器前使用了一張檢查清單。

### 03 Task list

**Tier**：1  
**中文**：任務清單；待辦事項表  
**語域**：neutral / common  
**核心語義**：a practical list of tasks to be completed  
**用法提示**：當 **checklist** 主要是待辦事項、工作步驟或項目任務時非常自然。  
**常見搭配**：task list; daily task list; project task list; work through the task list.  
**常見搭配對象**：work, project, study, household, team.  
**與 checklist 的辨析**：Task list 比 checklist 更純粹是『事情要完成』，不強調核對／確認。  
**使用限制**：若每一項是檢查標準或 yes/no verification，不如 checklist / list of checks。

**EXAMPLE · 例句**  
The team reviewed the task list before starting work.  
團隊開工前檢視了任務清單。

### 04 List of checks

**Tier**：1  
**中文**：核對清單；檢查項目列表  
**語域**：neutral / explanatory  
**核心語義**：a list of checks to carry out in order to verify condition, accuracy, safety, or completion  
**用法提示**：當 **checklist** 真正意思是逐項確認、核對而不是做任務時很精準。  
**常見搭配**：list of checks; carry out a list of checks; pre-flight checks; safety checks.  
**常見搭配對象**：system, equipment, document, vehicle, procedure.  
**與 checklist 的辨析**：List of checks 把 verification function 說得很清楚。  
**使用限制**：如果是純待辦事項而沒有核對性，task list 更自然。

**EXAMPLE · 例句**  
The technician followed a list of checks before signing off the repair.  
技術員完成維修簽核前，逐項完成核對清單。

## Tier 2 — Tick-off / verification variants · 勾選與核證變體

### 05 Tick list

**Tier**：2  
**中文**：勾選清單；逐項打勾清單  
**語域**：British English / informal  
**核心語義**：a list of items that are marked or ticked as each one is completed or confirmed  
**用法提示**：在 British/HK English 中，當 **checklist** 的重點是完成一項便打勾，可用。  
**常見搭配**：tick list; tick items off; work through a tick list; simple tick list.  
**常見搭配對象**：task, item, packing, preparation, event.  
**與 checklist 的辨析**：Tick list 很強調『逐項勾選』這個使用方式；checklist 更正式、更通用。  
**使用限制**：正式報告／技術文件通常仍用 checklist。

**EXAMPLE · 例句**  
She used a tick list while packing for the trip.  
她收拾行李時用了一張逐項勾選清單。

### 06 Verification list

**Tier**：2  
**中文**：核證清單；驗證項目表  
**語域**：formal / technical  
**核心語義**：a list used to verify that requirements, conditions, or steps have been satisfied  
**用法提示**：當 **checklist** 出現在 compliance, audit, testing, validation, quality assurance 等正式語境時很自然。  
**常見搭配**：verification list; compliance verification list; verification step; verification criteria.  
**常見搭配對象**：requirement, audit, test, process, compliance.  
**與 checklist 的辨析**：Verification list 比 checklist 更 technical，強調證明／確認已符合要求。  
**使用限制**：日常 personal checklist 會顯得太正式。

**EXAMPLE · 例句**  
Auditors used a verification list to confirm that each requirement had been met.  
核數人員使用核證清單確認每項要求均已符合。

## Tier 3 — Ordered-process contextual variant · 有序流程情境變體

### 07 Step-by-step list

**Tier**：3  
**中文**：逐步清單；步驟清單  
**語域**：neutral / descriptive  
**核心語義**：an ordered list that shows each step to follow or complete in sequence  
**用法提示**：當 **checklist** 同時也是一套 sequential procedure，尤其 onboarding, setup, process, preparation，可作情境改寫。  
**常見搭配**：step-by-step list; follow a step-by-step list; step-by-step procedure.  
**常見搭配對象**：setup, onboarding, installation, preparation, process.  
**與 checklist 的辨析**：Step-by-step list 強調順序；普通 checklist 的項目未必有固定次序。  
**使用限制**：若 checklist 只是獨立核對項目，這個表達會增加『順序』意味。

**EXAMPLE · 例句**  
New staff receive a step-by-step list for setting up their accounts.  
新員工會收到一張逐步清單，用來設定帳戶。

## 04 False synonyms / checklist traps · 容易誤選的時間表、議程、存貨表與程序

### 01 Schedule

**時間表 ≠ checklist**  
schedule 強調時間安排；checklist 強調要做／要核對的項目。

**ENGLISH COMPARISON**  
Schedule is time-focused.

### 02 Agenda

**議程 ≠ checklist**  
agenda 是會議／討論項目，不等於任務或檢查清單。

**ENGLISH COMPARISON**  
Agenda is meeting-focused.

### 03 Inventory

**存貨清單 ≠ checklist**  
inventory 記錄物品／存貨，不一定是待辦或檢查項目。

**ENGLISH COMPARISON**  
Inventory is stock/item-focused.

### 04 Task list

**只在待辦任務 sense 接近**  
task list 不一定有 verification/ticking function。

**ENGLISH COMPARISON**  
Task list is action-focused.

### 05 Inspection list

**只在檢查 sense 接近**  
inspection list 專用於 inspection，範圍較窄。

**ENGLISH COMPARISON**  
Inspection is narrower.

### 06 Procedure

**程序 ≠ checklist**  
procedure 是完整做法／流程；checklist 可以只是提示／核對工具。

**ENGLISH COMPARISON**  
Procedure is process-focused.

### 07 Form

**表格 ≠ checklist**  
form 可以收集資料，不一定包含逐項核對。

**ENGLISH COMPARISON**  
Form is data-entry-focused.

### 08 Checklist / check list

**拼寫陷阱**  
現代一般名詞拼寫 **checklist** 一字；check list 較少見。

**ENGLISH COMPARISON**  
Check spelling.

## 05 練習與解釋 · Practice

### 練習 01.1

**Tier 1 · Target word / phrase**: List of tasks · 工作清單；任務清單

**READ THE CONTEXT · 閱讀語境**

I made a checklist of everything I needed to finish before Friday.

**中文翻譯**  
我列了一張清單，寫下星期五前要完成的所有事情。

- A. List of tasks
- B. Task list
- C. List of checks
- D. Schedule
- E. Agenda
- F. Inventory

**CORRECT ANSWER · 正確答案**

**A. List of tasks** · 工作清單；任務清單

**Correct rewrite · 正確改寫**  
I made a list of tasks I needed to finish before Friday.

**SIX-OPTION FEEDBACK · 六個選項的詳細解釋**

- **A.** **List of tasks ✓** — a list of tasks or actions that need to be completed。本句關鍵是 **the checklist consists of actions to complete**；因此 **List of tasks** 最精準。
- **B.** **Task list** — a practical list of tasks to be completed。**task list** 只強調待辦事項；若句子是 inspection、verification 或固定順序程序，另有更精準詞。
- **C.** **List of checks** — a list of checks used to verify condition, accuracy, safety, or completion。**list of checks** 強調核對／確認；如果只是要完成的工作項目，會改變功能。
- **D.** **Schedule** — a plan showing times for events or tasks。**schedule** 是時間安排，不是逐項完成／核對的清單。
- **E.** **Agenda** — a list of topics for a meeting。**agenda** 主要是會議／討論項目，不等於待辦或檢查清單。
- **F.** **Inventory** — a list of goods, materials, or items in stock。**inventory** 記錄物品／存貨，不是要做的任務或核對步驟。

**Tier 3 · Target word / phrase**: Step-by-step list · 逐步清單；步驟清單

**READ THE CONTEXT · 閱讀語境**

The guide includes a checklist that takes users through the process one stage at a time.

**中文翻譯**  
指南包括一張逐步清單，帶用戶一個階段一個階段完成程序。

- A. Task list
- B. Procedure
- C. Step-by-step list
- D. Schedule
- E. Agenda
- F. Inventory

**CORRECT ANSWER · 正確答案**

**C. Step-by-step list** · 逐步清單；步驟清單

**Correct rewrite · 正確改寫**  
The guide includes a step-by-step list that takes users through the process one stage at a time.

**SIX-OPTION FEEDBACK · 六個選項的詳細解釋**

- **A.** **Task list** — a practical list of tasks to be completed。**task list** 只強調待辦事項；若句子是 inspection、verification 或固定順序程序，另有更精準詞。
- **B.** **Procedure** — an established series of actions or steps。**procedure** 是完整流程；checklist 只是輔助核對工具，不一定等同整個程序。
- **C.** **Step-by-step list ✓** — an ordered list showing each step to follow in sequence。本句關鍵是 **sequential process guidance is central**；因此 **Step-by-step list** 最精準。
- **D.** **Schedule** — a plan showing times for events or tasks。**schedule** 是時間安排，不是逐項完成／核對的清單。
- **E.** **Agenda** — a list of topics for a meeting。**agenda** 主要是會議／討論項目，不等於待辦或檢查清單。
- **F.** **Inventory** — a list of goods, materials, or items in stock。**inventory** 記錄物品／存貨，不是要做的任務或核對步驟。

## 06 Semantic map · 語義總覽

| Checklist 的語境 | 最接近的詞／表達 | Diagnostic question |
|---|---|---|
| 星期五前要完成的工作 | **list of tasks** | 是否 the items are simply actions to complete？ |
| 車輛／設備／安全檢查 | **inspection list** | 是否 formal inspection is central？ |
| 每日／項目待辦事項 | **task list** | 是否 a practical to-do list is intended？ |
| 起飛／系統／文件逐項核對 | **list of checks** | 是否 verification rather than action is central？ |
| 打包／關店時完成一項便打勾 | **tick list** | 是否 ticking items off is explicit？ |
| 審核／驗收／合規確認 | **verification list** | 是否 formal verification against requirements？ |
| 入職／設定程序必須按次序 | **step-by-step list** | 是否 fixed sequence is central？ |

## 07 Direct contrasts · 核心辨析

- **checklist vs list of tasks**：後者只強調要做甚麼。
- **checklist vs inspection list**：後者只適合 inspection。
- **checklist vs task list**：task list 是待辦；不一定需要逐項核對。
- **checklist vs list of checks**：後者專門強調 verification。
- **checklist vs tick list**：tick list 強調逐項打勾。
- **checklist vs verification list**：後者更 formal/technical，適合 audit/compliance。
- **checklist vs step-by-step list**：後者加入固定次序。
- **checklist vs schedule**：schedule 是時間安排。
- **checklist vs agenda**：agenda 是會議／討論項目。

## 08 Grammar, collocation & checklist traps

- **a checklist of + items/tasks**。
- **checklist for + purpose**：checklist for packing / inspection / onboarding。
- **work through / follow / complete a checklist**。
- **tick/check items off a checklist**。
- **task list**：待辦用途。
- **inspection checklist/list**：安全、設備、車輛檢查。
- **verification list**：audit / compliance / acceptance。
- **step-by-step list**：有固定順序。
- 現代一般拼寫是 **checklist** 一字。
