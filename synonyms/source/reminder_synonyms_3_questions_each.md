# SYNONYMS · 同義詞學習系統

# Reminder (noun)

**`reminder` 可以指直接提示、助記工具、數碼通知、較強警示、觸發記憶的線索、書面便條、工作備忘，或溫和促使行動的 nudge。**

核心替代表達：

`prompt / memory aid / notification / alert / cue / note / memo / nudge`

---

# 01 同義詞指南

## 01 Prompt

**提示；提醒**

當 `reminder` 指一句話、提示訊息或小提示，目的是令某人記得做某事時，`prompt` 很自然。它強調 trigger / cue，而不是儲存資訊的工具。

**EXAMPLE · 例句**

> The app sends a prompt to complete the daily check-in.

這個應用程式會發出提示，提醒完成每日登記。

**SEMANTIC CUE · 語義提示**

> **a cue that triggers an action or memory**

**REGISTER · 語域**

一般、科技、工作

---

## 02 Memory aid

**記憶輔助工具；助記工具**

當 `reminder` 指用來幫助記憶的筆記、清單、圖像或其他工具時，`memory aid` 很精準。它強調 supporting memory rather than notifying at a particular time。

**EXAMPLE · 例句**

> I keep a checklist as a memory aid.

我保留一張清單作為記憶輔助工具。

**SEMANTIC CUE · 語義提示**

> **something used to help a person remember information**

**REGISTER · 語域**

教育、一般、正式

---

## 03 Notification

**通知；提示通知**

當 `reminder` 指手機、電腦、應用程式或系統自動顯示／發出的訊息時，`notification` 很自然。它偏 digital/system-generated message。

**EXAMPLE · 例句**

> A notification appeared ten minutes before the meeting.

會議前十分鐘出現了一則通知。

**SEMANTIC CUE · 語義提示**

> **a system-generated message alerting someone to something**

**REGISTER · 語域**

科技、工作、一般

---

## 04 Alert

**警示；提示**

當 `reminder` 較強烈，目的是立即引起注意，尤其涉及時間、風險、截止日期或需要行動的事項時，`alert` 很合適。它通常比 notification 更 urgent。

**EXAMPLE · 例句**

> The calendar alert warned me that the deadline was approaching.

日曆警示提醒我截止日期快到了。

**SEMANTIC CUE · 語義提示**

> **a signal designed to attract immediate attention**

**REGISTER · 語域**

科技、工作、一般

---

## 05 Cue

**提示；暗示**

當 `reminder` 指一個能觸發記憶或行動的視覺、聲音、動作或情境線索時，`cue` 很精準。它不一定是明文訊息。

**EXAMPLE · 例句**

> The photo served as a cue to call his grandmother.

那張照片成為提示，令他記得致電祖母。

**SEMANTIC CUE · 語義提示**

> **a signal or clue that prompts memory or action**

**REGISTER · 語域**

所有語域

---

## 06 Note

**便條；備忘**

當 `reminder` 指自己寫下的一段簡短文字，用來日後提醒自己時，`note` 很自然。它強調 written record。

**EXAMPLE · 例句**

> She left herself a note to buy milk.

她給自己留了張便條，提醒買牛奶。

**SEMANTIC CUE · 語義提示**

> **a short written message used to remember something**

**REGISTER · 語域**

所有語域

---

## 07 Memo

**備忘錄；備忘**

當 `reminder` 是較正式、工作場合中的書面提醒或簡短通告時，`memo` 很合適。它比 note 更正式、更 organisational。

**EXAMPLE · 例句**

> The office circulated a memo about the new procedure.

辦公室傳閱了一份有關新程序的備忘錄。

**SEMANTIC CUE · 語義提示**

> **a short formal written message, often in a workplace**

**REGISTER · 語域**

工作、正式

---

## 08 Nudge

**輕推式提醒；溫和提示**

當 `reminder` 指輕微、非強制地促使某人記得或採取行動時，`nudge` 很自然，尤其常見於產品設計、行為科學和數碼服務。

**EXAMPLE · 例句**

> The email was a gentle nudge to finish the form.

這封電郵是一個溫和提示，提醒完成表格。

**SEMANTIC CUE · 語義提示**

> **a gentle prompt encouraging someone to act**

**REGISTER · 語域**

一般、科技、行為設計

# 02 False synonyms

## Reminder / Prompt
`prompt` 直接觸發某個動作或回憶；通常比 reminder 更聚焦「現在做甚麼」。

**ENGLISH COMPARISON**  
The app sends a reminder to submit the form.  
The app sends a prompt to submit the form.

## Reminder / Memory aid
`memory aid` 是幫助記住資訊的工具，不一定在某個特定時間發出訊息。

**ENGLISH COMPARISON**  
I use the checklist as a reminder.  
I use the checklist as a memory aid.

## Reminder / Notification
`notification` 強調手機、電腦、應用程式或系統自動顯示的訊息。

**ENGLISH COMPARISON**  
My phone displayed a reminder.  
My phone displayed a notification.

## Reminder / Alert
`alert` 通常比 reminder 更強、更即時，常涉及 deadline、風險或系統狀態。

**ENGLISH COMPARISON**  
The calendar sent a reminder before the deadline.  
The calendar sent an alert before the deadline.

## Reminder / Cue
`cue` 可以是物件、聲音、氣味、顏色或情境，不一定是文字訊息。

**ENGLISH COMPARISON**  
The umbrella was a reminder to check the weather.  
The umbrella was a cue to check the weather.

## Reminder / Note
`note` 是寫下來的簡短提醒，重點是 written message。

**ENGLISH COMPARISON**  
She left a reminder on the fridge.  
She left a note on the fridge.

## Reminder / Memo
`memo` 較正式，尤其是工作場所內的書面提醒／通告。

**ENGLISH COMPARISON**  
The manager sent a reminder about the rule.  
The manager sent a memo about the rule.

## Reminder / Nudge
`nudge` 是溫和、非強制地促使人採取行動。

**ENGLISH COMPARISON**  
The email was a friendly reminder to finish the form.  
The email was a gentle nudge to finish the form.

# 05 高價值近義詞辨析

- **Prompt vs Cue** — prompt 通常更直接叫人做事；cue 可以只是觸發記憶的線索。
- **Notification vs Alert** — notification 中性；alert 通常更急、更需要立即注意。
- **Note vs Memo** — note 較個人、非正式；memo 較正式、常見於工作場所。
- **Memory aid vs Reminder** — memory aid 是助記工具；reminder 可以是一次性的訊息。
- **Nudge vs Alert** — nudge 溫和、不強制；alert 直接吸引注意，甚至帶警示意味。
- **Reminder ≠ warning** — warning 強調危險／不良後果；reminder 可以完全中性。
- **Reminder ≠ memory** — reminder 是幫你想起某事的東西；memory 是記憶本身。
- **Reminder ≠ appointment** — appointment 是預約本身；reminder 只是提醒預約。

# 08 Grammar & structure traps

- **prompt to + verb / prompt for + action**
- **memory aid for + noun**
- **notification about/of + event**
- **alert about/to + issue**
- **cue to + verb / cue for + noun**
- **note to + verb / note about + noun**
- **memo about/on + topic**
- **nudge to + verb / nudge toward + action**
- **remind** = verb；**reminder** = noun
- **notify** = verb；**notification** = noun

# 09 核心決策問題

1. 是直接叫人記得做某事？ → **prompt**
2. 是幫助學習／記憶的工具？ → **memory aid**
3. 是手機／電腦系統訊息？ → **notification**
4. 是較急、要立即注意的提示？ → **alert**
5. 是視覺／聲音／情境線索？ → **cue**
6. 是自己寫下的短便條？ → **note**
7. 是工作場所較正式的書面提醒？ → **memo**
8. 是溫和、不強制地推動行動？ → **nudge**

# 10 Final note for system use

核心替代表達：

`prompt / memory aid / notification / alert / cue / note / memo / nudge`

最重要的一點：

> **notification ≠ alert ≠ nudge**

`notification` = 中性系統通知；  
`alert` = 較急、需要立即注意；  
`nudge` = 溫和、非強制地促使行動。
