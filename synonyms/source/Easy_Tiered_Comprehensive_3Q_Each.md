# EASY · 分層同義詞學習系統

## Easy

**「容易的／簡單的／輕鬆的」，要分清到底是『不複雜』、『不費力』、『可應付』、『容易使用』，還是『整個過程很順利』。**

本單元集中處理 **easy = not difficult to understand, do, use, manage, or complete**。你提供的 **simple; effortless; straightforward** 正好代表三個核心方向：**simple = 不複雜**、**effortless = 幾乎不費力**、**straightforward = 清楚直接、沒有複雜環節**。

這次保留 **13 個**自然且高實用度的詞／表達，並按最新 inspection 標準區分 **manageable / undemanding / painless / user-friendly / accessible / trouble-free / a breeze / plain sailing**。每個目標設 **3 道題**；所有 distractor 都完整解釋其語義和不適用原因。

## Tier 1 — Core simplicity / effort equivalents · 核心簡單、輕鬆與易處理近義詞

### 01 Simple

**Tier**：1  
**中文**：簡單的；容易理解／完成的  
**語域**：neutral / very common  
**核心語義**：not complicated, difficult, or elaborate  
**用法提示**：和 easy 最核心的近義詞之一，尤其適合任務、方法、解釋、設計和程序。  
**常見搭配**：simple task; simple method; simple explanation; simple process; simple solution.  
**常見搭配對象**：task, method, explanation, process, solution.  
**與 easy 的辨析**：Simple 偏『不複雜』；easy 偏『不難做／理解』。  
**使用限制**：有些事情結構很簡單但做起來仍然不容易，因此兩者不能永遠互換。

**EXAMPLE · 例句**  
The instructions are simple enough for beginners to follow.  
這些指示很簡單，初學者也能跟從。

### 02 Effortless

**Tier**：1  
**中文**：毫不費力的；輕鬆的  
**語域**：neutral / expressive  
**核心語義**：requiring little or no effort, or appearing to require no effort  
**用法提示**：當 easy 強調幾乎不用費力、做起來非常輕鬆時最自然。  
**常見搭配**：effortless movement; effortless performance; effortless transition; make it effortless; seem effortless.  
**常見搭配對象**：movement, performance, transition, use, experience.  
**與 easy 的辨析**：Effortless 比 easy 更強，突出幾乎沒有努力成本。  
**使用限制**：只是『不複雜』但仍要花力氣時，不宜用 effortless。

**EXAMPLE · 例句**  
The new interface makes switching between accounts almost effortless.  
新介面令切換帳戶幾乎毫不費力。

### 03 Straightforward

**Tier**：1  
**中文**：直接簡單的；易明的；不複雜的  
**語域**：neutral / very common  
**核心語義**：easy to understand or deal with because there are no unnecessary complications  
**用法提示**：當 easy 的原因是程序清晰、步驟直接、沒有複雜之處時非常實用。  
**常見搭配**：straightforward process; straightforward task; straightforward explanation; straightforward solution; straightforward procedure.  
**常見搭配對象**：process, task, explanation, solution, procedure.  
**與 easy 的辨析**：Straightforward 強調沒有複雜環節；easy 更廣。  
**使用限制**：純粹體力上容易，但流程不一定清楚時，不宜硬換成 straightforward。

**EXAMPLE · 例句**  
The application process is straightforward and takes only a few minutes.  
申請程序簡單直接，只需幾分鐘。

### 04 Uncomplicated

**Tier**：1  
**中文**：不複雜的；簡明的  
**語域**：neutral  
**核心語義**：not involving many difficult parts, conditions, or complications  
**用法提示**：當 easy 的核心是事情結構簡單、沒有額外麻煩或複雜條件時很自然。  
**常見搭配**：uncomplicated process; uncomplicated design; uncomplicated task; uncomplicated system; relatively uncomplicated.  
**常見搭配對象**：process, design, task, system, arrangement.  
**與 easy 的辨析**：Uncomplicated 強調『沒有複雜性』；easy 可指能力要求低或省力。  
**使用限制**：形容人的性格時有另外語感，本課集中在 task/process sense。

**EXAMPLE · 例句**  
The booking system is uncomplicated and easy to learn.  
預約系統並不複雜，而且很容易學會。

### 05 Manageable

**Tier**：1  
**中文**：可應付的；不太難的  
**語域**：neutral / very common  
**核心語義**：not so difficult, large, or demanding that it cannot be handled  
**用法提示**：當 easy 並非毫無難度，而是『仍然做得到、應付得來』時最準確。  
**常見搭配**：manageable workload; manageable task; manageable size; manageable amount; manageable problem.  
**常見搭配對象**：workload, task, size, amount, problem.  
**與 easy 的辨析**：Manageable 比 easy 弱，通常承認仍有一定難度。  
**使用限制**：若真的是毫不費力，effortless 更貼切。

**EXAMPLE · 例句**  
The project is challenging, but the workload is manageable.  
這個項目有挑戰性，但工作量仍可應付。

## Tier 2 — Low-demand / usability / accessibility variants · 低要求、易用與易理解變體

### 06 Undemanding

**Tier**：2  
**中文**：要求不高的；輕鬆的  
**語域**：neutral  
**核心語義**：requiring relatively little skill, effort, concentration, or energy  
**用法提示**：當 easy 指工作、活動、閱讀或任務要求不高時很自然。  
**常見搭配**：undemanding task; undemanding job; undemanding read; undemanding activity; relatively undemanding.  
**常見搭配對象**：task, job, activity, exercise, reading.  
**與 easy 的辨析**：Undemanding 強調要求低；easy 可以因熟悉、清楚或工具好用而容易。  
**使用限制**：對正式程序或介面可用 simple/user-friendly 更自然。

**EXAMPLE · 例句**  
The warm-up exercise is deliberately undemanding.  
這項熱身練習刻意設計得要求不高。

### 07 Painless

**Tier**：2  
**中文**：輕鬆無痛苦的；不麻煩的  
**語域**：neutral / figurative  
**核心語義**：causing little difficulty, inconvenience, stress, or discomfort  
**用法提示**：當 easy 指一個轉換、申請、設定或改變過程幾乎沒有麻煩時很地道。  
**常見搭配**：painless process; painless transition; painless setup; relatively painless; make something painless.  
**常見搭配對象**：process, transition, setup, change, procedure.  
**與 easy 的辨析**：Painless 強調沒有麻煩／壓力／不適；easy 是更一般難度描述。  
**使用限制**：不應把所有普通容易任務都稱為 painless。

**EXAMPLE · 例句**  
The software update was quick and painless.  
軟件更新既快又不麻煩。

### 08 User-friendly

**Tier**：2  
**中文**：容易使用的；對使用者友善的  
**語域**：neutral / technology / product  
**核心語義**：designed so that people can use or understand it easily  
**用法提示**：當 easy 修飾網站、軟件、裝置、介面、表格或系統時非常精準。  
**常見搭配**：user-friendly interface; user-friendly website; user-friendly design; user-friendly system; user-friendly app.  
**常見搭配對象**：interface, website, system, app, device.  
**與 easy 的辨析**：User-friendly 專門說『容易使用』；easy 還可形容問題、考試、工作等。  
**使用限制**：人、論證、路線等通常不能用 user-friendly。

**EXAMPLE · 例句**  
The redesigned website is much more user-friendly.  
重新設計的網站容易使用得多。

### 09 Accessible

**Tier**：2  
**中文**：易懂的；易於使用／接觸的  
**語域**：neutral / formal  
**核心語義**：easy to understand, use, reach, or engage with  
**用法提示**：當 easy 指內容容易理解，或服務／工具容易被使用者接觸時很有用。  
**常見搭配**：accessible language; accessible explanation; accessible website; accessible service; make information accessible.  
**常見搭配對象**：language, explanation, website, information, service.  
**與 easy 的辨析**：Accessible 的『容易』通常是理解／接觸門檻低；easy 更廣。  
**使用限制**：accessible 亦可指無障礙可及性，實際語境要分清。

**EXAMPLE · 例句**  
The guide explains the topic in clear, accessible language.  
指南用清晰易懂的語言解釋這個題目。

### 10 Easy to use

**Tier**：2  
**中文**：容易使用的  
**語域**：neutral / very common  
**核心語義**：requiring little difficulty to operate, learn, or handle  
**用法提示**：當 easy 明確修飾工具、系統、產品或功能的使用難度時，是最透明自然的改寫。  
**常見搭配**：easy to use; easy-to-use tool; easy-to-use interface; simple to operate; easy to learn.  
**常見搭配對象**：tool, system, product, interface, device.  
**與 easy 的辨析**：這是直接的功能型改寫，不代表事情本身『簡單』。  
**使用限制**：作前置形容詞時通常寫 **easy-to-use**。

**EXAMPLE · 例句**  
The device is compact and easy to use.  
這部裝置體積小，而且容易使用。

## Tier 3 — Smooth-process / idiomatic variants · 順利過程與慣用表達

### 11 Trouble-free

**Tier**：3  
**中文**：沒有麻煩的；順利的  
**語域**：neutral  
**核心語義**：happening or operating without problems, faults, or complications  
**用法提示**：當 easy 指一段操作、旅程、安裝或使用過程很順利、沒有出問題時可用。  
**常見搭配**：trouble-free operation; trouble-free installation; trouble-free journey; trouble-free experience; trouble-free service.  
**常見搭配對象**：operation, installation, journey, experience, service.  
**與 easy 的辨析**：Trouble-free 強調沒有問題；easy 強調難度低。  
**使用限制**：一個考試很容易不代表它是 trouble-free。

**EXAMPLE · 例句**  
The installation was completely trouble-free.  
安裝過程完全沒有麻煩。

### 12 A breeze

**Tier**：3  
**中文**：非常容易的事；輕而易舉  
**語域**：informal / idiomatic  
**核心語義**：something that is extremely easy to do  
**用法提示**：當 easy 的程度很高，而且語氣口語、輕鬆時很地道。  
**常見搭配**：be a breeze; make something a breeze; absolute breeze; setup is a breeze; exam was a breeze.  
**常見搭配對象**：task, setup, exam, process, job.  
**與 easy 的辨析**：A breeze 比 easy 更口語、更強。  
**使用限制**：正式學術或政策文本通常不用。

**EXAMPLE · 例句**  
Once you know the shortcuts, editing the document is a breeze.  
一旦懂得快捷鍵，編輯文件就變得輕而易舉。

### 13 Plain sailing

**Tier**：3  
**中文**：一帆風順；非常順利容易  
**語域**：British / idiomatic  
**核心語義**：a situation that proceeds easily and without serious difficulty once the main obstacles are removed  
**用法提示**：英式英語中，當 easy 指整個過程進展順利時很自然。  
**常見搭配**：be plain sailing; not all plain sailing; from then on it was plain sailing; relatively plain sailing; make progress plain sailing.  
**常見搭配對象**：project, process, journey, implementation, progress.  
**與 easy 的辨析**：Plain sailing 強調整段過程順利；easy 可形容單一問題或任務。  
**使用限制**：正式文件通常改用 straightforward / trouble-free。

**EXAMPLE · 例句**  
After the initial setup, the rest of the process was plain sailing.  
完成最初設定後，其餘程序便一帆風順。

## 04 False synonyms / easy traps · 容易誤選的詞與「容易」陷阱

### 01 Basic

**基本不等於 easy**  
basic 表示基礎、初階或不複雜；初階內容也可能對初學者很難。

**ENGLISH COMPARISON**  
Basic describes level or complexity, not necessarily difficulty.

### 02 Quick

**快不等於 easy**  
quick 表示所需時間短；一件事可以很快但很難。

**ENGLISH COMPARISON**  
Quick concerns time; easy concerns difficulty.

### 03 Small

**小不等於 easy**  
small 描述尺寸或規模；小任務也可以技術上很難。

**ENGLISH COMPARISON**  
Size and difficulty are different.

### 04 Obvious

**明顯不等於 easy**  
obvious 表示答案／事實容易看出；完成一件事是否容易是另一問題。

**ENGLISH COMPARISON**  
Something obvious is easy to notice, not necessarily easy to do.

### 05 Convenient

**方便不等於 easy**  
convenient 表示省時、省事或適合需要；方便的選項仍可能需要技巧。

**ENGLISH COMPARISON**  
Convenience and difficulty are related but not identical.

### 06 Comfortable

**舒服不等於 easy**  
comfortable 是身體／心理舒適；easy 是難度低。

**ENGLISH COMPARISON**  
Comfort does not necessarily mean low difficulty.

### 07 Effortless

**effortless 比普通 easy 更強**  
effortless 暗示幾乎不需努力；普通 easy 仍可能需要一些能力和注意力。

**ENGLISH COMPARISON**  
Effortless is stronger than merely easy.

### 08 Easy / easily

**詞性陷阱**  
easy 是形容詞；easily 是副詞。

**ENGLISH COMPARISON**  
Easy modifies nouns or follows linking verbs; easily modifies verbs.

## 05 練習與解釋 · Practice

### 練習 01.1

**Tier 1 · Target word / phrase**: Simple · 簡單的；容易理解／完成的

**READ THE CONTEXT · 閱讀語境**

The instructions are easy for beginners to follow.

**中文翻譯**  
這些指示對初學者來說很容易理解。

- A. simple
- B. basic
- C. quick
- D. small
- E. obvious
- F. comfortable

**CORRECT ANSWER · 正確答案**

**simple** · 簡單的；容易理解／完成的

**Correct rewrite · 正確改寫**  
The instructions are simple enough for beginners to follow.

**SIX-OPTION FEEDBACK · 六個選項的詳細解釋**

- **A. simple ✓ — instructions + beginners 表示內容不複雜、容易理解，simple 最自然。**
- **B. basic — basic 只表示基礎程度，基礎指示仍可能寫得難懂。**
- **C. quick — quick 表示所需時間短，不表示理解難度低。**
- **D. small — small 只描述尺寸／範圍。**
- **E. obvious — obvious 表示一眼可見，不等於步驟本身簡單。**
- **F. comfortable — comfortable 是舒適感，不描述指示結構。**

## 06 Semantic map · 語義總覽

| Easy 的語境 | 最接近的詞／表達 | Diagnostic question |
|---|---|---|
| 不複雜 | **simple** | 是否是 task / method / explanation 結構簡單？ |
| 幾乎不用力 | **effortless** | 是否是 almost no effort？ |
| 程序清楚直接 | **straightforward** | 是否是 process / procedure 沒有複雜環節？ |
| 沒有複雜條件 | **uncomplicated** | 是否只是缺乏 complications？ |
| 仍可應付 | **manageable** | 是否 not easy but still possible to handle？ |
| 要求不高 | **undemanding** | 是否只需少量 skill / concentration / energy？ |
| 沒有麻煩／壓力 | **painless** | 是否是 transition / update / setup 很順利？ |
| 產品容易使用 | **user-friendly** | 是否是 website / app / interface usability？ |
| 內容容易理解／接觸 | **accessible** | 是否是 language / explanation / service？ |
| 功能上容易操作 | **easy to use** | 是否明確是 tool / device / controls？ |
| 運作過程沒有問題 | **trouble-free** | 是否 no faults / delays / complications？ |
| 口語：輕而易舉 | **a breeze** | 是否語氣 informal 且非常容易？ |
| 英式：一帆風順 | **plain sailing** | 是否障礙解除後整個過程順利？ |

## 07 Direct contrasts · 核心辨析

- **easy vs simple**: simple 是不複雜；easy 是不難。
- **easy vs effortless**: effortless 程度更強，幾乎不用努力。
- **easy vs straightforward**: straightforward 是沒有複雜步驟或間接性。
- **easy vs manageable**: manageable 承認仍有難度，只是應付得來。
- **easy vs undemanding**: undemanding 強調技能／精力要求低。
- **easy vs painless**: painless 強調沒有麻煩、壓力或不適。
- **easy vs user-friendly**: user-friendly 專門指設計得容易使用。
- **easy vs accessible**: accessible 常指容易理解或容易被接觸／使用。
- **easy vs trouble-free**: trouble-free 是沒有問題，不等於任務本身難度低。
- **easy vs basic**: basic 是層級／基礎，不保證容易。

## 08 Grammar, collocation & easy traps · 文法、搭配與容易程度陷阱

- **easy + noun**：easy task / easy question；也可 **be easy to + verb**。
- 副詞是 **easily**：The problem can be solved easily。
- **simple** 通常描述結構／複雜度：a simple process / explanation。
- **effortless** 通常表示幾乎不需努力：an effortless performance。
- **straightforward** 很適合 process / method / task / explanation。
- **manageable** 常和 workload / amount / task / problem 搭配。
- **undemanding** 常和 job / task / activity 搭配。
- **painless** 可比喻表示流程沒有麻煩：a painless transition。
- **user-friendly** 作前置形容詞通常加連字號。
- **easy-to-use** 作前置形容詞要加連字號：an easy-to-use device；作表語則寫 easy to use。
- **trouble-free** 作前置形容詞通常加連字號：trouble-free operation。
- **a breeze** 是名詞慣用語：The exam was a breeze。
- **plain sailing** 常作表語：After that, it was plain sailing。
- **easy ≠ quick / basic / obvious / convenient**：這些詞只在特定語境相關，不能機械替代。
