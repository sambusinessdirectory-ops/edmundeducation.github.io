# SYNONYMS · 同義詞學習系統

# Goal

**`goal` 很廣：可以是一般方向、量化指標、正式項目目標、做事目的、長遠抱負、階段里程碑或比較基準。**

核心替代表達：

`aim / target / objective / purpose / intention / ambition / aspiration / end / milestone / benchmark`

> **核心原則**：`aim` 最接近一般目標；`target` 偏量化；`objective` 偏正式；`purpose` 回答為甚麼；`ambition / aspiration` 偏長遠；`milestone` 是階段性成就；`benchmark` 是比較基準。

---

# 01 同義詞指南

## 01 Aim

**目標；目的**

一般想達到的結果或方向。

---

## 02 Target

**目標；指標**

較具體、可量度、需要達成的結果。

---

## 03 Objective

**目標；具體目的**

較正式，常見於項目、研究、課程和政策。

---

## 04 Purpose

**目的；宗旨**

強調為甚麼做某事，而不是要達到哪個數字。

---

## 05 Intention

**意圖；打算**

強調某人打算做甚麼，未必已形成具體可量度目標。

---

## 06 Ambition

**抱負；志向**

長遠、具挑戰性，常和職業或人生發展有關。

---

## 07 Aspiration

**抱負；願望；追求**

較正式、理想導向的長遠追求。

---

## 08 End

**目的；最終目標**

較正式、書面，表示最後想達到的目的。

---

## 09 Milestone

**里程碑；階段性目標**

通往更大目標途中一個重要階段。

---

## 10 Benchmark

**基準；參照目標**

用作比較表現、衡量進度或設定標準。

---

# 02 False synonyms

- **Goal / Aim** — 高度接近；aim 稍偏整體方向。
- **Goal / Target** — target 更具體、可量度。
- **Goal / Objective** — objective 更正式、計劃化。
- **Goal / Purpose** — goal = 想達到甚麼；purpose = 為甚麼做。
- **Goal / Intention** — intention 是打算，未必是正式目標。
- **Goal / Ambition** — ambition 更長遠、更有挑戰性。
- **Goal / Milestone** — milestone 只是通往更大目標的一個重要階段。
- **Goal / Benchmark** — benchmark 是比較標準，不一定是想達到的結果。

# 05 高價值近義詞辨析

- **Goal vs Aim** — aim 很接近，通常較一般。
- **Goal vs Target** — target 更具體、可量度。
- **Goal vs Objective** — objective 更正式、計劃化。
- **Goal vs Purpose** — goal = 想達到甚麼；purpose = 為甚麼做。
- **Goal vs Intention** — intention = 打算；未必是正式目標。
- **Ambition vs Aspiration** — ambition 往往更強、更有成就驅動；aspiration 稍柔和、理想導向。
- **Goal vs End** — end 更正式，偏最終目的。
- **Goal vs Milestone** — milestone 是中途的重要節點。
- **Goal vs Benchmark** — benchmark 是比較標準，不一定是結果本身。

# 09 核心決策問題

1. 一般想達到的結果？ → **aim**
2. 有數字／期限／可量度？ → **target**
3. 正式項目／研究／課程目標？ → **objective**
4. 問的是「為甚麼要做」？ → **purpose**
5. 是某人的打算？ → **intention**
6. 是長遠、有挑戰性的抱負？ → **ambition**
7. 是理想化、長遠追求？ → **aspiration**
8. 是正式說「最終目的」？ → **end**
9. 是通往更大目標的重要階段？ → **milestone**
10. 是用來比較表現的標準？ → **benchmark**

# 10 Final note

核心替代表達：

`aim / target / objective / purpose / intention / ambition / aspiration / end / milestone / benchmark`

最重要的 near-miss：

`task / plan / method / result / deadline`

尤其要記住：

> **goal** = 想達到的結果  
> **plan / method** = 如何達到  
> **task** = 要做的工作  
> **result** = 最後發生的結果，未必預先設定
