# SYNONYMS · 同義詞學習系統

# Vending machine

**自動售貨機、自動分配器、自助機、投幣機、零食機、飲品機、售票機——究竟是哪一種 vending machine？**

核心近義與近義表達：

**automated dispenser; self-service machine; dispensing machine; automatic vending machine; coin-operated machine; snack machine; drink machine; ticket machine**

> **核心詞數不固定。** 本課保留 **8 個**自然且辨析價值高的核心表達。  
> 你提供的 **automated dispenser; self-service machine** 全部保留。  
> 本課特別區分「自動分配」「自助操作」「自動售賣」「投幣付款」以及按商品類型細分的 snack / drink / ticket machine。

---

# 01 同義詞指南


## 01 Automated dispenser

**自動售貨機；自動分配器**

非常接近、較正式的近義表達，強調機器會自動分配或售出商品、票券、飲品或其他物品。

### EXAMPLE · 例句

The station has an automated dispenser that sells bottled water.

車站有一部售賣樽裝水的自動售貨機。

### COMMON COLLOCATIONS · 常見搭配


- automated dispenser

- product dispenser

- automated retail dispenser

- dispense products automatically


### DIAGNOSTIC QUESTION · 判斷問題

> 這裡重點是自動售賣、單純分配物品、自助操作、投幣付款，還是機器只售零食、飲品或票券？

---

## 02 Self-service machine

**自助機；自助式機器**

較廣泛，表示使用者可自行操作、無需店員協助的機器。它包括 vending machine，但也可涵蓋自助付款機、票務機等其他設備。

### EXAMPLE · 例句

Customers can buy drinks from the self-service machine without staff assistance.

顧客毋須店員協助，便可透過自助機購買飲品。

### COMMON COLLOCATIONS · 常見搭配


- self-service machine

- self-service kiosk

- self-service equipment

- use the machine independently

### EXAMPLE · 例句

# 02 False synonyms


## 01 Self-service machine

**高度相關但範圍更廣**

self-service machine 包括售貨機，也可包括自助付款機、登記機、售票機等。

### ENGLISH COMPARISON

Every vending machine is self-service, but not every self-service machine is a vending machine.

---

## 02 Automated dispenser

**功能接近但不一定售賣**

dispenser 只要求自動分配某物，可能免費、不涉及付款。

### ENGLISH COMPARISON

A soap dispenser is automated but is not a vending machine.

---

## 03 Dispenser

**過於廣泛**

dispenser 可指紙巾機、肥皂機、飲水器等，並不保證有商品交易。

### ENGLISH COMPARISON

A vending machine dispenses goods, but many dispensers do not sell anything.

---

## 04 Kiosk

**自助亭不等於 vending machine**

kiosk 可以提供資訊、登記、付款或票務，不一定放出商品。

### ENGLISH COMPARISON

An airport kiosk may print boarding passes without vending products.

---

## 05 ATM

**功能完全不同**

ATM 是自動櫃員機，主要處理銀行交易與現金提取。

### ENGLISH COMPARISON

An ATM dispenses cash, but it is not called a vending machine.

---

## 06 Self-checkout

**結帳系統不等於售貨機**

self-checkout 讓顧客自行掃描和付款，但商品通常不是由機器自動放出。

### ENGLISH COMPARISON

A supermarket self-checkout is not a vending machine.

---

## 07 Vending machine / vending-machine

**連字符用法**

作名詞通常寫 `vending machine`；作複合定語有時可見 `vending-machine`。

### ENGLISH COMPARISON

vending machine sales / a vending-machine operator

---

## 08 Vend / vending

**詞形辨析**

`vend` 是售賣的動詞；`vending` 常作定語或活動名詞。

### ENGLISH COMPARISON

The machine vends drinks; vending machines are common.

### SIX-OPTION FEEDBACK · 六個選項的解釋


- **A. automated dispenser ✓** — `automated dispenser` = 自動分配／售出商品或物品的機器。 **本句為何最合適：** machine automatically dispenses a product。

- **E. staffed counter** — `staffed counter` = 有職員服務的櫃檯。 需要職員，與自助自動機器相反。 **本句判斷：** machine automatically dispenses a product。

- **F. storage cabinet** — `storage cabinet` = 儲物櫃。 只用來儲物，不自動售賣。 **本句判斷：** machine automatically dispenses a product。

# 04 核心對比表

| 表達 | 核心差異 |
|---|---|
| **automated dispenser** | 正式：自動分配／售出物品 |
| **self-service machine** | 強調毋須職員協助、自行操作 |
| **dispensing machine** | 強調 dispense 機制，不一定涉及售賣 |
| **automatic vending machine** | 完整保留自動售貨功能 |
| **coin-operated machine** | 強調投幣付款／啟動方式 |
| **snack machine** | 專售零食／輕食 |
| **drink machine** | 專售飲品 |
| **ticket machine** | 自助售票／發票機 |

# 05 高價值近義詞對比

## Vending machine vs Automated dispenser
非常接近，但 `automated dispenser` 不一定涉及付款。

## Vending machine vs Self-service machine
後者範圍更廣，還包括自助登記、付款、售票等設備。

## Vending machine vs Dispensing machine
`dispensing machine` 重點是放出／分配產品，不一定是零售交易。

## Vending machine vs Coin-operated machine
不是所有 vending machines 都投幣；現代機器常接受卡、手機付款。

## Vending machine vs Snack machine / Drink machine
這兩個詞只適用於特定商品類型。

## Vending machine vs Ticket machine
售票機屬相似的自助售賣設備，但標準名稱通常是 `ticket machine`，不是一般 `vending machine`。

# 07 Grammar and usage notes

## 01 Vending machine
一般作名詞：
- a vending machine
- vending machines

## 02 Vending as modifier
- vending machine operator
- vending machine sales
- vending machine industry

## 03 Vend
`vend` = 售賣：
- The machine vends drinks.

但日常英語通常直接說：
- The machine sells drinks.

## 04 Dispenser vs vending machine
- dispenser = 分配／放出
- vending machine = 通常還涉及選擇商品與付款

## 05 Coin-operated is not universal
現代售貨機可接受：
- coins
- bank cards
- contactless payment
- mobile payment

所以 `coin-operated machine` 只適合部分 vending machines。
