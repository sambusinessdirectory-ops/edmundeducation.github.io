# SYNONYMS · 同義詞學習系統

# Race

**比賽、競賽、速度賽事、計時項目、分組賽、短跑、跑步賽——究竟是哪一種 race？**

本課聚焦競賽 sense：

**race = a competition in which participants try to finish first or complete a course in the shortest time**

核心近義與近義表達：

**competition; contest; speed event; racing event; timed event; event; heat; sprint; run**

> **核心詞數不固定。** 本課保留 **9 個**自然且辨析價值高的核心表達。  
> 你提供的 `event` 保留，但視為**較廣的 contextual substitute**；它本身不等於 race。  
> 本課不處理 `race = ethnic/racial group` 的另一個完全不同 sense。

# 01 同義詞指南


## 01 Competition

**比賽；競爭**

最廣泛的近義詞之一，表示參賽者為勝出、取得排名或達成最好表現而互相比較。比 `race` 更廣，不一定涉及速度。

### EXAMPLE · 例句

The competition attracted athletes from six countries.

這項比賽吸引了來自六個國家的運動員。

### COMMON COLLOCATIONS · 常見搭配


- enter a competition

- international competition

- competitive event

- win a competition


### DIAGNOSTIC QUESTION · 判斷問題

> 這裡只是一般競賽，還是明確以速度／時間為核心？它是整個 event、分組預賽、短跑，還是跑步活動？

## 02 Contest

**競賽；比賽**

表示為勝出而進行的比賽，適合體育、技能、知識或表演活動。比 `race` 更廣，未必以最快完成為核心。

### EXAMPLE · 例句

The school organised a contest between the four houses.

學校為四個社別舉辦了一場競賽。

- final contest

# 02 False synonyms


## 01 Event

**活動／項目不等於所有 race**

event 是上位詞，可以是比賽、表演、典禮或其他活動；只有上下文已清楚是體育賽事時才可自然代替。

### ENGLISH COMPARISON

A race is an event, but not every event is a race.

---

## 02 Competition

**競爭比 race 更廣**

competition 可以是足球、辯論、作文或其他競賽，不一定比速度。

### ENGLISH COMPARISON

A race is a competition, but many competitions are not races.

---

## 03 Contest

**比賽不一定是競速**

contest 著重勝負，不要求參賽者以最快完成為目標。

### ENGLISH COMPARISON

A singing contest has a winner but is not a race.

---

## 04 Match

**對賽通常不是 race**

match 常見於兩方／兩隊對賽，例如 football match、tennis match。

### ENGLISH COMPARISON

A match is head-to-head competition; a race usually compares speed or finishing order.

---

## 05 Tournament

**錦標賽不等於單場 race**

tournament 是由多場比賽組成的賽事結構。

### ENGLISH COMPARISON

A tournament contains multiple matches or events; a race may be one event within a championship.

---

## 06 Heat

**預賽只是 race 的 subtype**

heat 是多輪賽制中的一場分組賽。

### ENGLISH COMPARISON

A heat is a race used to qualify competitors for a later round.

---

## 07 Sprint

**短跑只是 race 的 subtype**

sprint 只適用於短距離、爆發速度競賽。

### ENGLISH COMPARISON

A 100-metre sprint is a race, but a marathon is not a sprint.

---

## 08 Racing

**詞性／概念陷阱**

`race` 可指一場比賽；`racing` 常指競速活動／運動類別。

### ENGLISH COMPARISON

Motor racing is the sport; a motor race is one event.

The 400 metres is one of the most popular races at the meeting.

### OPTIONS


- **A. event**

- **B. competition**

- **C. contest**

- **D. heat**

- **E. venue**

- **F. schedule**


### CORRECT ANSWER · 正確答案

**event · 賽事；項目**

The 400 metres is one of the most popular **events** at the meeting.

### SIX-OPTION FEEDBACK · 六個選項的解釋


- **A. event ✓** — `event` = 活動／賽事項目，最廣。 **句中線索：** 在 athletics meeting 中，400 metres 是一個 event；上下文已供應競賽類型。

- **C. contest** — `contest` = 為勝出而進行的比賽，範圍比 race 廣。 它強調競爭和勝負，但不一定涉及速度；正式速度賽事可能有更精確用語。 **本句判斷：** 在 athletics meeting 中，400 metres 是一個 event；上下文已供應競賽類型。

- **D. heat** — `heat` = 多輪賽制中的分組賽／預賽。 它只適用於多輪賽制中的分組賽／預賽；決賽或單次比賽不能用。 **本句判斷：** 在 athletics meeting 中，400 metres 是一個 event；上下文已供應競賽類型。

**Target expression:** Run · 跑步賽；跑步活動

### READ THE CONTEXT · 閱讀語境

Thousands joined the ten-kilometre race through the city.

### 中文翻譯

數以千計的人參加穿越市區的十公里跑。

### OPTIONS


- **A. run**

- **B. race**

- **C. sprint**

- **D. event**

- **E. drive**

- **F. swim**


### CORRECT ANSWER · 正確答案

**run · 跑步賽；跑步活動**

Thousands joined the ten-kilometre **run** through the city.

### SIX-OPTION FEEDBACK · 六個選項的解釋


- **A. run ✓** — `run` = 以跑步形式進行的賽事／活動。 **句中線索：** ten-kilometre + joined thousands 是路跑活動語境。

- **B. race** — `race` = 以速度、先後次序或最快完成為核心的比賽。 它是原詞，涵蓋速度／先後競賽；本題要求按語境選更精確表達。 **本句判斷：** ten-kilometre + joined thousands 是路跑活動語境。

- **C. sprint** — `sprint` = 短距離、爆發速度型競賽。 它只適用於短距離爆發型競速；中長距離或非跑步／非短距離賽事不合。 **本句判斷：** ten-kilometre + joined thousands 是路跑活動語境。

- **D. event** — `event` = 活動／賽事項目，最廣。 它是上位詞，只表示一個賽事項目；不能保證一定是 race。 **本句判斷：** ten-kilometre + joined thousands 是路跑活動語境。

- **E. drive** — `drive` = 駕駛活動，不是跑步賽。 它是駕駛，不是 run。 **本句判斷：** ten-kilometre + joined thousands 是路跑活動語境。

- **F. swim** — `swim` = 游泳活動，不是跑步活動。 它是游泳，不是跑步活動。 **本句判斷：** ten-kilometre + joined thousands 是路跑活動語境。

# 04 核心對比表

| 表達 | 核心差異 |
|---|---|

| **competition** | 最廣：互相比拼、排名、勝負 |

| **contest** | 重勝負，不必以速度為核心 |

| **speed event** | 明確以速度為核心 |

| **racing event** | 正式競速賽事／賽車等語境 |

| **timed event** | 完成時間是主要判定依據 |

| **event** | 一般賽事項目名稱；範圍更廣 |

| **heat** | 多輪賽制中的分組預賽 |

| **sprint** | 短距離、爆發型競速 |

| **run** | 以跑步形式進行的賽事／活動 |

# 07 Grammar and usage notes

## 01 Race is countable
- a race
- two races
- several races

## 02 Race vs event
在體育賽程中：
- 100 metres = an event
- the 100-metre race = the actual race

`event` 是上位項目名；`race` 更具體。

## 03 Race vs heat
- heat = 預賽／分組賽
- semi-final = 準決賽
- final = 決賽

## 04 Race vs sprint
`sprint` 只適合短距離、爆發速度：
- 100 m
- 200 m
- short cycling sprint

## 05 Race vs run
`run` 常見：
- charity run
- fun run
- road run
- 10K run

它通常比 `race` 更強調活動／跑步形式，未必每次都高度競爭。

## 06 Other sense excluded
`race` 還可指：
- racial / ethnic group

這和競賽 sense 完全不同，不應混在同一 synonym pool。
