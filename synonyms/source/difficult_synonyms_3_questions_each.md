# SYNONYMS · 同義詞學習系統

# Difficult

**「困難」，究竟是在說一般難、有挑戰性、要求很高、艱苦費力、結構複雜，還是令人疲累？**

核心替代表達：

`hard / challenging / demanding / tough / arduous / strenuous / complicated / tricky / problematic / formidable / laborious / taxing`

---

# 01 同義詞指南

## 01 Hard

**困難的；艱難的**

最直接、最常用的近義詞之一，語氣較日常。

---

## 02 Challenging

**具挑戰性的**

表示不容易，但常帶測試能力、值得克服的正面意味。

---

## 03 Demanding

**要求高的；費心力的**

表示需要大量時間、精力、注意力、技能或體力。

---

## 04 Tough

**艱難的；棘手的**

較口語，常形容難做的決定、艱苦時期、難回答的問題。

---

## 05 Arduous

**艱苦的；費力的**

較正式，強調長時間持續努力、過程辛苦。

---

## 06 Strenuous

**費力的；劇烈的**

強調高強度體力消耗，常見於 exercise / activity / climb。

---

## 07 Complicated

**複雜的；難處理的**

因為涉及很多部分、規則、步驟或相互關係而難。

---

## 08 Tricky

**棘手的；難處理的**

需要技巧、小心或判斷，而且容易出錯。

---

## 09 Problematic

**有問題的；棘手的**

表示某事本身造成問題、風險、爭議或方法缺陷。

---

## 10 Formidable

**艱巨的；令人畏懼的**

挑戰或對手規模很大、令人忌憚、難以克服。

---

## 11 Laborious

**費工夫的；繁重費時的**

需要大量重複、細緻、耗時的人工作業。

---

## 12 Taxing

**費神的；吃力的**

對人的精神、體力或耐力造成明顯負擔。

---

# 02 False synonyms

## Difficult / Hard
兩者高度接近；`hard` 較日常、較廣。

## Difficult / Challenging
`challenging` 常帶較正面的「測試能力／值得克服」意味。

## Difficult / Demanding
`demanding` 重點是需要大量 effort / attention / energy / skill。

## Difficult / Complicated
`complicated` = 因為有很多 parts / rules / relationships 而難。

## Difficult / Tricky
`tricky` = 容易出錯，需要技巧、小心或判斷。

## Difficult / Arduous
`arduous` 常帶 prolonged sustained effort。

## Difficult / Strenuous
`strenuous` 幾乎一定和高強度 physical exertion 有關。

## Difficult / Problematic
`problematic` = 造成問題／有方法缺陷，不只是難。

## 練習 01.1

**Target: Hard · 困難的；艱難的**

### READ THE CONTEXT · 閱讀語境

> The instructions were difficult to understand at first.

**中文翻譯**

起初那些指示很難理解。

| | 選項 |
|---|---|
| A | Challenging |
| B | Complicated |
| C | Hard |
| D | Demanding |
| E | Easy |
| F | Technical |

### CORRECT ANSWER · 正確答案

**C. Hard · 困難的；艱難的**

> The instructions were hard to understand at first.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. Challenging**  
challenging = 具挑戰性的；常帶測試能力或值得克服的正面意味。 本句的關鍵是「一般理解難度」。`challenging` 常帶測試能力、值得克服的意味；如果只是負擔大、程序複雜或令人疲累，語氣會偏正面。

**B. Complicated**  
complicated = 複雜的；因部分、步驟或規則很多而難。 本句的關鍵是「一般理解難度」。`complicated` 要有很多部分、步驟或規則；若只是很累、很難捱或需要韌性，就錯判難度來源。

**C. Hard ✓**  
`Hard` = 困難的；艱難的。題目的關鍵線索是 **一般理解難度**；這正好對應 `Hard` 的核心語義和典型搭配，因此是最精準的選擇。

**D. Demanding**  
demanding = 要求高的；需要大量精力、專注、時間或技能。 本句的關鍵是「一般理解難度」。`demanding` 要求大量精力／時間／專注；若難點是結構複雜或技巧細節，就不夠準。

**E. Easy**  
easy = 容易的；和 difficult 方向相反。 本句明確以「一般理解難度」表達難度或負擔；`Easy` 的語義方向相反或明顯弱化，因此不合。

**F. Technical**  
technical = 技術性的；技術性不等於難度高。 `technical` 只表示技術性；「一般理解難度」要求的是難度特徵，技術性高低不能直接替代 difficult。

**E. Risky**  
risky = 有風險的；風險高不一定操作上困難。 `risky` 強調風險，而「一般決策難度」是在描述難度本身；有風險不等於一定難做。

`Taxing` = 費神的；吃力的。題目的關鍵線索是 **持續精神負擔**；這正好對應 `Taxing` 的核心語義和典型搭配，因此是最精準的選擇。

**F. Routine**  
routine = 例行的；熟悉而常規，不表示高難度。 `routine` 表示例行／常規；「持續精神負擔」突出的是難度或負擔，routine 沒有這個意思。

# 05 高價值近義詞辨析

## Difficult vs Hard
`hard` 更日常；`difficult` 稍中性、正式。

## Difficult vs Challenging
`challenging` 常帶較正面的成長／能力測試意味。

## Difficult vs Demanding
`demanding` 問的是：這件事要求你付出多少 effort / attention / energy。

## Tough vs Hard
`tough` 更常見於 tough decision / tough year / tough question / tough opponent。

## Arduous vs Strenuous
`arduous` = prolonged sustained effort。  
`strenuous` = high physical exertion。

## Complicated vs Tricky
`complicated` = many parts / rules。  
`tricky` = easy to get wrong / needs skill。

## Difficult vs Problematic
`difficult` = hard to do/deal with。  
`problematic` = causes a problem / is questionable。

## Formidable vs Challenging
`formidable` 更有 daunting / intimidating scale。

## Laborious vs Tedious
`laborious` = requires lots of effort/time。  
`tedious` = boring because repetitive/long。

## Demanding vs Taxing
`demanding` 描述任務要求高；`taxing` 描述它對人造成疲累。

# 09 核心決策問題

1. 一般地說很難？ → **hard**
2. 難但能測試能力？ → **challenging**
3. 要求大量精力／專注？ → **demanding**
4. 艱難決定／艱苦時期？ → **tough**
5. 長時間艱苦任務／旅程？ → **arduous**
6. 主要是體力劇烈？ → **strenuous**
7. 因規則／部分太多而難？ → **complicated**
8. 容易出錯、要技巧／小心？ → **tricky**
9. 本身有問題／風險？ → **problematic**
10. 規模大到令人畏懼？ → **formidable**
11. 手動、重複、費時工作？ → **laborious**
12. 令人精神／體力疲累？ → **taxing**

# 10 Final note for system use

核心替代表達：

`hard / challenging / demanding / tough / arduous / strenuous / complicated / tricky / problematic / formidable / laborious / taxing`

最重要的 near-miss：

`complex / exhausting / tedious / risky / technical / important / lengthy`

真正的選詞依據是：

> **Why is it difficult—because it is complex, demanding, physically strenuous, mentally taxing, easy to get wrong, problematic, or simply hard?**
