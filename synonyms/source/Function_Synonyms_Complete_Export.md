# FUNCTION — Complete Synonym Lesson

## 01 同義詞指南

### Function 的 8 種更精準說法

> Note: This lesson focuses mainly on **function as a noun meaning what a product, system, component, or tool does**. Depending on context, it may mean a specific feature, overall functionality, a capability, a usable tool, an intended purpose, a role within a larger system, an operation, or a selectable option.
> 本課主要處理 **function 作名詞，表示產品、系統、組件或工具能做甚麼**。按語境可表示具體功能、整體功能性、能力、實用工具、用途、在整體中的作用、運作，或可由使用者選擇的選項。

### 01 Feature
**功能；特色功能**

當 function 指產品、軟件、裝置或服務提供的一項具體功能時，feature 很自然。它通常是使用者能看到、使用或啟用的功能。

**EXAMPLE · 例句**  
The app includes a feature that automatically saves unfinished drafts.  
這個應用程式有一項可自動儲存未完成草稿的功能。

---

### 02 Functionality
**功能性；整體功能**

較技術化，常指一個系統或產品整體能提供的功能，或某部分的功能表現。比單一 feature 更常表示整體功能範圍。

**EXAMPLE · 例句**  
The update adds new functionality for team collaboration.  
這次更新加入了新的團隊協作功能。

---

### 03 Capability
**能力；可執行的功能**

當 function 強調系統、裝置或人有能力做到某事時，可用 capability。常見於技術規格、設備和系統能力。

**EXAMPLE · 例句**  
The device has the capability to operate offline.  
這部裝置具備離線運作的能力。

---

### 04 Tool
**工具；實用功能**

當 function 是使用者用來完成某項具體工作的實用功能時，可用 tool，尤其常見於軟件、編輯器和工作平台。

**EXAMPLE · 例句**  
The editor includes a tool for removing image backgrounds.  
這個編輯器有一個移除圖片背景的工具。

---

### 05 Purpose
**用途；目的**

當 function 指某物存在是為了做甚麼、或某部分的主要用途時，可用 purpose。這是 function 的『用途／目的』義。

**EXAMPLE · 例句**  
The main purpose of the filter is to remove dust from the air.  
這個濾網的主要用途是去除空氣中的灰塵。

---

### 06 Role
**作用；角色；功能**

當 function 指某個部分、人員或機制在更大系統中扮演甚麼作用時，可用 role。

**EXAMPLE · 例句**  
The sensor plays an important role in maintaining system safety.  
感應器在維持系統安全方面發揮重要作用。

---

### 07 Operation
**運作；操作；功能運行**

當 function 指機器、程序或系統如何運作，或某個運作過程時，可用 operation。重點是執行和運行，而不是用途。

**EXAMPLE · 例句**  
The manual explains the operation of the braking system.  
手冊解釋煞車系統的運作方式。

---

### 08 Option
**選項；可選功能**

當 function 是使用者可選擇開啟、關閉或設定的一項功能時，可用 option。它只適合具選擇性的功能。

**EXAMPLE · 例句**  
The app includes an option to hide notifications.  
這個應用程式有一個隱藏通知的選項。

---

## 02 False synonyms

### 看起來相關，意思卻不同

### 01 Button
**按鈕不等於一般的 function**

**button = 按鈕**

button 是使用者介面中的控制元件；它可以啟動一項 function，但不是 function 本身。

**ENGLISH COMPARISON**  
A button can activate a function.

---

### 02 Setting
**設定；設定值不等於一般的 function**

**setting = 設定；設定值**

setting 是使用者可調整的參數或配置。某個 function 可以有多個 settings，但兩者不等同。

**ENGLISH COMPARISON**  
A setting changes how a function behaves.

---

### 03 Command
**指令不等於一般的 function**

**command = 指令**

command 是要求系統執行某動作的輸入或命令；function 是系統能做的事情。

**ENGLISH COMPARISON**  
A command may call or trigger a function.

---

### 04 Interface
**介面不等於一般的 function**

**interface = 介面**

interface 是使用者或系統之間互動的方式或畫面，不等於其中某一項功能。

**ENGLISH COMPARISON**  
The interface gives access to functions.

---

### 05 Performance
**效能；表現不等於一般的 function**

**performance = 效能；表現**

performance 描述系統做得多快、多穩定或多有效，不是它有哪些 function。

**ENGLISH COMPARISON**  
Function describes what a system does; performance describes how well it does it.

---

### 06 Design
**設計不等於一般的 function**

**design = 設計**

design 是外觀、結構或規劃方式。良好 design 可以支援 function，但不是 function 本身。

**ENGLISH COMPARISON**  
Design shapes how a function is presented or built.

---

### 07 Service
**服務不等於一般的 function**

**service = 服務**

service 是提供給使用者的一整項服務或後台能力；一個 service 可以包含很多 functions。

**ENGLISH COMPARISON**  
A service may provide many different functions.

---

### 08 Functional
**可運作的；功能性的不等於一般的 function**

**functional = 可運作的；功能性的**

functional 是形容詞，而 function 通常是名詞。詞義相關，但不能直接在同一語法位置互換。

**ENGLISH COMPARISON**  
The device has a function. The device is functional.

---

# 01 Feature · 功能；特色功能

## 練習 01.1

**Target word: Feature · 功能；特色功能**

### READ THE CONTEXT · 閱讀語境

The new phone has a function that lets users unlock it with facial recognition.

### 中文翻譯

這部新手機有一項功能，讓使用者可以用面部識別解鎖。

A. feature
B. purpose
C. role
D. operation
E. tool
F. capacity

### CORRECT ANSWER · 正確答案

**feature · 功能；特色功能**

The new phone has a feature that lets users unlock it with facial recognition.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. feature ✓**  
feature = 功能。a function that lets users... 明確是在描述產品提供的一項具體使用者功能。

**B. purpose**  
purpose = 用途；目的。purpose 說明產品為甚麼存在，不是其中一項可用功能。

**C. role**  
role = 作用；角色。通常說某部分在系統中扮演甚麼作用，不是功能清單中的項目。

**D. operation**  
operation = 運作；操作。更常描述系統如何運作，而不是一項獨立功能。

**E. tool**  
tool = 工具。功能有時可視為工具，但這題是手機的一項內建 feature。

**F. capacity**  
capacity = 容量；能力。通常表示能承受或容納多少，不是面部解鎖功能。
