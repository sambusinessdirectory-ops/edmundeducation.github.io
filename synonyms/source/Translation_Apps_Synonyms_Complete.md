# Translation Apps

「翻譯應用程式／數碼翻譯工具」，究竟是哪一種 translation apps？

最直接的 `language translation applications / translation applications`、較廣義的 `digital translation tools / translation software`、技術導向的 `machine-translation tools / automatic translation tools`、手機或網頁限定的 `mobile translation apps / online translation tools`，以及多功能企業系統 `translation platforms`——英文會按 translation apps 是手機 app、網頁工具、軟件、平台還是自動翻譯技術產品，選用不同但更精確的說法。

# 01 同義詞指南

## Translation Apps 的 11 種更精準說法

### 01 Language translation applications

語言翻譯應用程式

最直接、最正式的描述性替換，表示專門用來翻譯語言的手機或電腦應用程式。

**EXAMPLE · 例句**

Language translation applications can help travellers understand signs and menus.

語言翻譯應用程式可以幫助旅客理解標誌和餐牌。

### 02 Digital translation tools

數碼翻譯工具

較廣義，除了 app，也可包括網站、瀏覽器功能、桌面軟件和其他數碼翻譯服務；比 `translation apps` 範圍更廣。

**EXAMPLE · 例句**

Students often use digital translation tools when reading foreign-language texts.

學生閱讀外語文本時常使用數碼翻譯工具。

### 03 Translation software

翻譯軟件

常見而自然，表示用來翻譯文字或語音的軟件；可包括手機 app、桌面程式和企業工具。

**EXAMPLE · 例句**

The company installed translation software for multilingual customer support.

公司安裝了翻譯軟件，以支援多語言客戶服務。

### 04 Translation applications

翻譯應用程式

和 `translation apps` 幾乎同義，但語氣較正式，適合書面、教育和技術語境。

**EXAMPLE · 例句**

Several translation applications offer offline language packs.

數款翻譯應用程式提供離線語言包。

### 05 Machine-translation tools

機器翻譯工具

當重點是由電腦自動進行語言翻譯時最精確；比一般 translation apps 更偏技術和翻譯方法。

**EXAMPLE · 例句**

Machine-translation tools can process large amounts of text quickly.

機器翻譯工具可以快速處理大量文字。

### 06 Automatic translation tools

自動翻譯工具

表示可自動把文字、語音或內容轉換成另一種語言的數碼工具；比 `machine-translation tools` 稍容易理解。

**EXAMPLE · 例句**

Automatic translation tools are useful for getting the general meaning of a message.

自動翻譯工具有助快速理解訊息的大意。

### 07 Mobile translation apps

手機翻譯應用程式

當 `translation apps` 明確指在智能手機或平板上使用的應用程式時最精確。

**EXAMPLE · 例句**

Mobile translation apps are especially useful when travelling abroad.

手機翻譯應用程式在海外旅行時尤其有用。

### 08 Online translation tools

網上翻譯工具

當服務需要透過網站、雲端或網絡平台使用時可用；不一定是安裝在裝置上的 app。

**EXAMPLE · 例句**

Online translation tools can translate short passages within seconds.

網上翻譯工具可以在數秒內翻譯短篇文字。

### 09 Language translator apps

語言翻譯器應用程式

較口語、商業產品導向，強調 app 的主要功能是把一種語言翻成另一種語言。

**EXAMPLE · 例句**

Many language translator apps now support voice input.

很多語言翻譯器應用程式現在支援語音輸入。

### 10 Translation platforms

翻譯平台

當工具提供多種翻譯功能，例如文字、文件、語音、網頁或團隊協作時可用；比單一 app 更平台化。

**EXAMPLE · 例句**

The organisation uses a translation platform for multilingual documents.

該機構使用翻譯平台處理多語言文件。

### 11 Electronic translation aids

電子翻譯輔助工具

較正式、較廣義，表示用來輔助理解或轉換語言的電子工具；可包括 app、手提翻譯器和其他電子裝置。

**EXAMPLE · 例句**

Electronic translation aids can support communication in unfamiliar languages.

電子翻譯輔助工具可以支援陌生語言環境中的溝通。

# 02 False synonyms

看起來相關，意思卻不同。`translation apps` 是把一種語言轉換成另一種語言的數碼工具；dictionary apps、language-learning apps、spell-checkers 等分別是查詞、學習和拼字檢查工具。也要分清 `machine translation` 這個翻譯技術／過程，以及 `translation software` 這個比 apps 更廣的軟件類別。

### 01 Dictionary apps

字典應用程式不等於翻譯應用程式

`dictionary apps` 主要查單字意思、拼寫和用法；`translation apps` 通常可翻譯完整短語、句子或語音。

**ENGLISH COMPARISON**

A dictionary explains words; a translation app converts language.

### 02 Language-learning apps

語言學習 app 不等於翻譯工具

`language-learning apps` 主要教學、練習和記憶語言；translation apps 的核心是即時翻譯。

**ENGLISH COMPARISON**

Language-learning apps teach languages; translation apps translate them.

### 03 Spell-checkers

拼字檢查工具不等於翻譯工具

`spell-checkers` 檢查拼字和部分文法錯誤，不會把內容轉成另一種語言。

**ENGLISH COMPARISON**

A spell-checker corrects spelling; a translation tool changes language.

### 04 Machine translation

機器翻譯是技術／過程，不是 app 本身

`machine translation` 指自動翻譯這個方法；`translation apps` 是使用這種技術的應用程式。

**ENGLISH COMPARISON**

Machine translation is a process; a translation app is a product or tool.

### 05 Interpreter

口譯員不等於翻譯 app

`interpreter` 通常指真人口譯員，或在某些情況指口譯服務；不是數碼應用程式。

**ENGLISH COMPARISON**

An interpreter is a person or service; a translation app is software.

### 06 Translation software

翻譯軟件範圍比 apps 更廣

`translation software` 可以是桌面、企業或網頁工具，不一定是 mobile app。

**ENGLISH COMPARISON**

All translation apps are software, but not all translation software is an app.

### 07 Online translator

網上翻譯器不一定是 app

`online translator` 可以只是網站服務；app 通常指安裝或專門應用程式形式。

**ENGLISH COMPARISON**

An online translator may run in a browser rather than as an app.

### 08 Translator / translation

翻譯者、翻譯和翻譯工具不同

`translator` 可指人或工具；`translation` 是翻譯這個結果或過程。

**ENGLISH COMPARISON**

A translator produces a translation; a translation app is a digital tool.
