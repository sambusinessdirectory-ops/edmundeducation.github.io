# Application

**申請、申請表、書面提交、應用程式——哪些詞真的接近 application？**

`application` 是一個多義詞。這份材料只聚焦使用者提供的兩個主要語義：

1. **application = a formal request or the document/form used to make that request**
   - job application
   - university application
   - visa application
   - application form

2. **application = a software program/app used to perform a task**
   - mobile application
   - software application
   - desktop application

這次沿用較嚴格的原則：**只保留與 application 在特定語義中高度接近、可在部分情境中近乎互換的詞、短語或常用表達；不刻意湊固定數量。**

核心近義表達：

### 申請／申請文件義
**application form; form; request form; written submission; submission**

### 軟件義
**app; software application; program; software tool**

---

# 01 同義詞指南

## Sense A — Application = 申請／申請文件

---

## 01 Application form

**申請表**

和 `application` 在「需要填寫並提交的申請文件」語境中非常接近。比 `application` 更明確指出是**表格本身**。

### EXAMPLE · 例句

Please complete the application form before Friday.

請在星期五前填妥申請表。

### COMMON COLLOCATIONS · 常見搭配

- complete an application form
- submit an application form
- online application form
- paper application form

### DIAGNOSTIC QUESTION · 判斷問題

> 這裡的 application 是否明確指需要填寫的表格？

---

## 02 Form

**表格；申請表**

當上下文已清楚知道是在申請甚麼時，`form` 可以自然地代替 `application form`。

### EXAMPLE · 例句

You can download the form from the university website.

你可以從大學網站下載申請表。

### COMMON COLLOCATIONS · 常見搭配

- fill in a form
- complete the form
- submit the form
- online form

### DIAGNOSTIC QUESTION · 判斷問題

> 上下文是否已經清楚，讓單獨的 `form` 不會產生歧義？

---

## 03 Request form

**申請表；請求表格**

表示用來正式提出某項要求的表格。比一般 `application form` 更適合設備、假期、退款、服務、許可等**請求型申請**。

### EXAMPLE · 例句

Employees must complete a request form to apply for additional leave.

員工如要申請額外假期，必須填寫申請表。

### COMMON COLLOCATIONS · 常見搭配

- leave request form
- refund request form
- service request form
- complete a request form

### DIAGNOSTIC QUESTION · 判斷問題

> 這是否是一份用來正式提出某項要求的表格？

---

## 04 Written submission

**書面提交；書面申請**

表示以書面形式正式提交的申請、陳述或材料。比 `application` 更強調**書面內容與正式提交**，而不一定是一張固定格式表格。

### EXAMPLE · 例句

Candidates must provide a written submission explaining their experience.

申請人必須提交書面材料，說明自己的經驗。

### COMMON COLLOCATIONS · 常見搭配

- written submission
- formal submission
- submit in writing
- written application materials

### DIAGNOSTIC QUESTION · 判斷問題

> 這裡是否不是單純填表，而是提交一份較完整的書面材料？

---

## 05 Submission

**提交材料；申請文件**

表示已提交的文件、資料或申請。和 `application` 很接近，但 `submission` 更突出**交出去的那份材料**或「提交」這個結果。

### EXAMPLE · 例句

Late submissions will not be considered.

逾期提交的申請材料將不獲考慮。

### COMMON COLLOCATIONS · 常見搭配

- online submission
- late submission
- final submission
- review a submission

### DIAGNOSTIC QUESTION · 判斷問題

> 這裡是否重點在已提交的申請材料，而不是申請行為本身？

---

# Sense B — Application = 軟件／應用程式

---

## 06 App

**應用程式；App**

最常見、最口語的替代。尤其常用於手機、平板、網頁服務和消費者軟件。

### EXAMPLE · 例句

The app lets users scan documents with their phone.

這個應用程式讓使用者用手機掃描文件。

### COMMON COLLOCATIONS · 常見搭配

- mobile app
- download an app
- open the app
- app store

### DIAGNOSTIC QUESTION · 判斷問題

> 這是否是一般使用者會稱為 app 的軟件？

---

## 07 Software application

**軟件應用程式**

和 tech sense 的 `application` 幾乎完全相同，但表達更完整、正式，也可避免和「申請」義混淆。

### EXAMPLE · 例句

The company developed a software application for inventory management.

公司開發了一個用於庫存管理的軟件應用程式。

### COMMON COLLOCATIONS · 常見搭配

- software application
- business application
- enterprise application
- application software

### DIAGNOSTIC QUESTION · 判斷問題

> 是否需要正式、清楚地表明這個 application 是軟件？

---

## 08 Program

**程式；軟件程式**

在很多一般電腦語境中，`program` 可以和 `application` 接近，尤其指可以執行特定工作的軟件。

### EXAMPLE · 例句

This program allows users to edit audio files.

這個程式讓使用者編輯音訊檔案。

### COMMON COLLOCATIONS · 常見搭配

- computer program
- run a program
- install a program
- software program

### DIAGNOSTIC QUESTION · 判斷問題

> 這裡是否只是一般地指能執行某功能的電腦程式？

---

## 09 Software tool

**軟件工具；數碼工具**

表示用來完成特定工作或任務的軟件。和 `application` 接近，但比 `app/program` 更突出**工具用途**。

### EXAMPLE · 例句

The team uses a software tool to track project deadlines.

團隊使用一個軟件工具追蹤項目期限。

### COMMON COLLOCATIONS · 常見搭配

- software tool
- digital tool
- productivity tool
- analysis tool

### DIAGNOSTIC QUESTION · 判斷問題

> 這個 application 是否主要被視為完成某項工作的工具？

# 02 False synonyms

以下詞語和 `application` 有關，但不能在所有語境中直接互換。

---

## 01 Request

**請求不等於申請文件**

`request` 是提出要求本身；`application` 通常更正式，而且往往有固定程序或文件。

### ENGLISH COMPARISON

She made a **request** for more information.  
She submitted an **application** for the scholarship.

---

## 02 Petition

**請願不等於一般申請**

`petition` 通常是正式請願，常涉及公共、法律或集體訴求。

---

## 03 Proposal

**提案不等於申請**

`proposal` 是提出計劃、想法或方案；不是一般 job/visa/university application 的同義詞。

---

## 04 Registration

**登記不等於申請**

`registration` 通常是正式登記加入、記錄或註冊；某些流程可能先申請再登記。

---

## 05 Software

**軟件不等於單一應用程式**

`software` 是更廣泛的總稱，可包括 operating systems、drivers、applications 等。

---

## 06 Platform

**平台不等於 app**

`platform` 通常是提供服務、生態系統或運行環境的系統，範圍比單一 application 大。

---

## 07 System

**系統不等於應用程式**

`system` 可以包含多個 applications、database、hardware 和流程。

---

## 08 Website

**網站不一定是應用程式**

有些 web apps 也是網站，但一般資訊網站不等於 application。

---

# 05 高價值近義詞對比

## Application vs Application form

**Application**
- 可以指整個申請
- 也可以指申請文件

**Application form**
- 明確只指表格本身

---

## Form vs Submission

**Form**
- 要填寫的文件格式

**Submission**
- 已提交出去的材料
- 可以包括表格、CV、證明文件、作品等

---

## Application form vs Request form

**Application form**
- 廣泛用於工作、學校、簽證、計劃等

**Request form**
- 更像正式提出某項要求
- leave / refund / equipment / service

---

## Written submission vs Form

**Written submission**
- 可能是長篇文字、陳述或完整材料

**Form**
- 通常有預先設計好的欄位

---

## App vs Software application

**App**
- 口語、日常
- 手機和消費者軟件特別常見

**Software application**
- 正式
- 適合技術、企業、文件語境

---

## Program vs App

**Program**
- 傳統電腦用語
- 桌面軟件很常見

**App**
- 現代、日常
- 手機、平板、web service 語境特別常見

---

## Software application vs Software tool

**Software application**
- 描述軟件種類本身

**Software tool**
- 強調它被用來完成某項工作

---

# 06 Common expressions / close paraphrases

**填寫申請**

Please **fill out an application** online.

---

## Submit an application

**提交申請**

All candidates must **submit an application** by Friday.

---

## Put in an application

**遞交申請；提出申請**

較口語的常見表達。

She **put in an application** for the position.

---

## Apply through the app

**透過應用程式申請**

這個表達有意展示 `application` 的兩個不同 sense：

You can **apply through the app**.
