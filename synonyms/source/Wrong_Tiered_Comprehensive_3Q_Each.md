# WRONG · 分層同義詞學習系統

## Wrong

**本課集中處理 wrong = factually / logically / technically not correct 的義項。** 不把『道德上錯誤』作為本課主線。Wrong 可以表示答案不正確、信念弄錯、數據不準確、說法不實、推理有缺陷、判斷失當或在規則／邏輯上無效。

你提供的 **incorrect; mistaken; inaccurate** 正好代表三個核心方向：**客觀不正確、認知／判斷弄錯、準確度不足**。

本次保留 **9 個**自然且具教學價值的近義／情境表達。會特別區分 **false / faulty / invalid / misguided**，避免把不同類型的『錯』混在一起。共 **27 道練習**，每個目標 **3 題**。

## Sense split · 義項分流

| Wrong 的語境 | 典型替代表達 |
|---|---|
| 答案／資料／計算客觀錯 | **incorrect** |
| 人或信念弄錯 | **mistaken** |
| 估計／數據不準確 | **inaccurate** |
| 說法／傳聞不真實 | **false** |
| 正式：假設／結論／記錄有誤 | **erroneous** |
| 推理／設備／過程有缺陷 | **faulty** |
| 政策／判斷方向失當 | **misguided** |
| 邏輯／規則／法律上不成立 | **invalid** |
| 口語：不太對 | **not right** |

## Tier 1 — Core correctness / belief / accuracy equivalents · 核心正確性、認知與準確度近義詞

### 01 Incorrect

**Tier**：1  
**中文**：不正確的；錯誤的  
**語域**：neutral / very common  
**核心語義**：not correct according to facts, rules, calculations, or an expected answer  
**用法提示**：你提供的 seed 是 **wrong** 最直接、最中性的近義詞之一，尤其適合答案、資料、計算、程序和陳述。  
**常見搭配**：incorrect answer; incorrect information; incorrect calculation; factually incorrect; technically incorrect.  
**常見搭配對象**：answer, information, calculation, statement, procedure.  
**與 wrong 的辨析**：Incorrect 比 wrong 稍正式、更中性；wrong 可更口語，也可表示道德上不對。  
**使用限制**：如果 wrong = morally wrong，不應用 incorrect。

**EXAMPLE · 例句**  
The figure in the report is incorrect.  
報告中的數字是不正確的。

### 02 Mistaken

**Tier**：1  
**中文**：弄錯的；誤解的；錯誤的  
**語域**：neutral / common  
**核心語義**：based on a wrong belief, judgement, identification, or understanding  
**用法提示**：你提供的 seed 很核心，當 wrong 的原因是 **person has misunderstood / believed something incorrectly** 時最自然。  
**常見搭配**：mistaken belief; mistaken assumption; mistaken identity; be mistaken about; if I am not mistaken.  
**常見搭配對象**：belief, assumption, identity, impression, judgement.  
**與 wrong 的辨析**：Mistaken 常形容人、信念或判斷；incorrect 更常形容答案、資料和客觀內容。  
**使用限制**：純計算錯誤通常用 incorrect 更自然。

**EXAMPLE · 例句**  
I was mistaken about the meeting time.  
我弄錯了會議時間。

### 03 Inaccurate

**Tier**：1  
**中文**：不準確的；有誤的  
**語域**：neutral / formal  
**核心語義**：not accurate, precise, or faithful to the facts  
**用法提示**：你提供的 seed 適合數據、描述、報道、估計、測量等『不夠準確』的語境。  
**常見搭配**：inaccurate data; inaccurate estimate; inaccurate description; factually inaccurate; inaccurate measurement.  
**常見搭配對象**：data, estimate, report, description, measurement.  
**與 wrong 的辨析**：Inaccurate 重點是 accuracy/precision；incorrect 更像明確對錯。  
**使用限制**：選擇題答案或道德判斷通常不說 inaccurate。

**EXAMPLE · 例句**  
The article contained several inaccurate claims.  
這篇文章包含數項不準確的說法。

### 04 False

**Tier**：1  
**中文**：錯誤的；不實的；虛假的  
**語域**：neutral / formal  
**核心語義**：not true or not corresponding to reality  
**用法提示**：當 wrong 的核心是 **truth value = false**，尤其 statements, claims, allegations, information 時很自然。  
**常見搭配**：false claim; false statement; false information; prove false; false impression.  
**常見搭配對象**：claim, statement, allegation, information, impression.  
**與 wrong 的辨析**：False 強調『不真實』；incorrect 可只是答案或程序不對，不一定涉及真假陳述。  
**使用限制**：一般『做法錯了』或『算錯了』未必用 false。

**EXAMPLE · 例句**  
The rumour turned out to be false.  
這個傳聞後來證實是不實的。

### 05 Erroneous

**Tier**：1  
**中文**：錯誤的；有誤的  
**語域**：formal / academic / technical  
**核心語義**：containing or based on an error  
**用法提示**：適合正式報告、研究、法律、技術文本，尤其 assumption, conclusion, data entry, interpretation。  
**常見搭配**：erroneous assumption; erroneous conclusion; erroneous data; erroneous belief; erroneous entry.  
**常見搭配對象**：assumption, conclusion, data, interpretation, entry.  
**與 wrong 的辨析**：Erroneous 比 incorrect 更正式，通常強調『由錯誤造成／含有錯誤』。  
**使用限制**：日常對話會顯得過度正式。

**EXAMPLE · 例句**  
The decision was based on an erroneous assumption.  
這項決定建基於一個錯誤假設。

## Tier 2 — Defect / judgement / validity variants · 缺陷、判斷與有效性變體

### 06 Faulty

**Tier**：2  
**中文**：有缺陷的；錯誤的；不可靠的  
**語域**：neutral / technical  
**核心語義**：containing a defect, flaw, or error that makes something unreliable or incorrect  
**用法提示**：當 wrong 指 reasoning, equipment, process, logic, assumption 等『有毛病／有缺陷』時很自然。  
**常見搭配**：faulty reasoning; faulty equipment; faulty logic; faulty assumption; faulty process.  
**常見搭配對象**：logic, reasoning, equipment, process, assumption.  
**與 wrong 的辨析**：Faulty 強調 underlying defect or flaw，不只是結果不對。  
**使用限制**：單純答案錯通常用 incorrect，不必用 faulty。

**EXAMPLE · 例句**  
The conclusion came from faulty reasoning.  
這個結論源於有缺陷的推理。

### 07 Misguided

**Tier**：2  
**中文**：誤導的；判斷失當的；出於錯誤想法的  
**語域**：neutral / evaluative  
**核心語義**：based on poor judgement, misunderstanding, or a mistaken idea about what is appropriate or effective  
**用法提示**：當 wrong 是 judgement/policy/action 的『出發點或判斷失誤』時很精準。  
**常見搭配**：misguided policy; misguided attempt; misguided belief; misguided decision; well-meaning but misguided.  
**常見搭配對象**：policy, attempt, decision, belief, action.  
**與 wrong 的辨析**：Misguided 常帶評價色彩，表示想法／方向不對，而不只是 factual error。  
**使用限制**：數字、答案、拼字等客觀錯誤不用 misguided。

**EXAMPLE · 例句**  
The policy was well-intentioned but misguided.  
這項政策出發點良好，但方向判斷失當。

### 08 Invalid

**Tier**：2  
**中文**：無效的；不成立的；無效力的  
**語域**：formal / logical / technical / legal  
**核心語義**：not acceptable or sound because it fails a rule, condition, logical requirement, or legal standard  
**用法提示**：當 wrong 指 argument, conclusion, ticket, code, result, procedure 等『不成立／無效』時可用。  
**常見搭配**：invalid argument; invalid conclusion; invalid code; invalid result; legally invalid.  
**常見搭配對象**：argument, code, ticket, result, contract.  
**與 wrong 的辨析**：Invalid 不是一般的 wrong；它表示『不符合規則／條件，所以不能成立或使用』。  
**使用限制**：純事實錯誤通常說 incorrect/false/inaccurate。

**EXAMPLE · 例句**  
The argument is invalid because the conclusion does not follow from the evidence.  
這個論證無效，因為結論並非由證據合理推出。

## Tier 3 — Conversational paraphrase · 口語改寫

### 09 Not right

**Tier**：3  
**中文**：不對；不正確  
**語域**：informal / conversational  
**核心語義**：a plain conversational way to say that something is wrong, incorrect, or inappropriate  
**用法提示**：這是 **wrong** 很自然的口語改寫，尤其在日常回應、簡單判斷、輕度糾正中。  
**常見搭配**：that's not right; something is not right; not quite right; doesn't look right.  
**常見搭配對象**：answer, situation, result, behaviour, detail.  
**與 wrong 的辨析**：比 wrong 稍柔和、更口語；語義也可從 factual error 延伸到『情況不妥』。  
**使用限制**：正式學術、法律或技術文本通常不夠精確。

**EXAMPLE · 例句**  
That total does not look right to me.  
那個總數我看起來不太對。

## 04 False synonyms / wrong traps · 容易誤選的『不同、不尋常、不好』陷阱

### 01 Different

**不同 ≠ wrong**  
different 只表示不一樣，不代表有錯。

**ENGLISH COMPARISON**  
Different does not imply error.

### 02 Unusual

**不尋常 ≠ wrong**  
unusual 只表示少見或不典型。

**ENGLISH COMPARISON**  
Unusual is about normality, not correctness.

### 03 Bad

**不好 ≠ wrong**  
bad 表示質素差／負面，不一定是不正確。

**ENGLISH COMPARISON**  
Bad is evaluative, not necessarily factual.

### 04 False

**只在『不真實』sense 接近**  
false 適合 claims/statements，不等於所有 wrong。

**ENGLISH COMPARISON**  
False is truth-value-focused.

### 05 Inaccurate

**只在『不準確』sense 接近**  
inaccurate 偏 precision/accuracy，不適合所有對錯判斷。

**ENGLISH COMPARISON**  
Inaccurate is precision-focused.

### 06 Mistaken

**只在信念／判斷出錯 sense 接近**  
mistaken 常形容人、信念、身份、假設。

**ENGLISH COMPARISON**  
Mistaken is belief/judgement-focused.

### 07 Invalid

**只在規則／邏輯／法律上不成立 sense 接近**  
invalid 是『無效／不成立』，不是一般錯誤。

**ENGLISH COMPARISON**  
Invalid is rule-validity-focused.

### 08 Wrong / wrongly

**詞性陷阱**  
wrong 可作形容詞／副詞；wrongly 是較正式副詞。

**ENGLISH COMPARISON**  
Check grammar and register.

## 07 Direct contrasts · 核心辨析

- **wrong vs incorrect**：incorrect 更正式、更中性。
- **wrong vs mistaken**：mistaken 偏人、信念、假設、身份判斷。
- **wrong vs inaccurate**：inaccurate 偏數值、估計、描述的準確度。
- **wrong vs false**：false 強調說法不真。
- **wrong vs erroneous**：erroneous 更正式、學術／技術化。
- **wrong vs faulty**：faulty 強調內在缺陷。
- **wrong vs misguided**：misguided 強調判斷或方向失當。
- **wrong vs invalid**：invalid 強調規則／邏輯／法律上不能成立。
- **wrong vs different**：different 不代表有錯。
- **wrong vs bad**：bad 只是負面評價，不一定不正確。

## 08 Grammar, collocation & error-type traps

- **incorrect answer / information / calculation**。
- **be mistaken about + noun**：I was mistaken about the date。
- **mistaken belief / assumption / identity**。
- **inaccurate data / estimate / description / measurement**。
- **false claim / statement / allegation / information**。
- **erroneous assumption / conclusion / entry**：偏正式。
- **faulty logic / reasoning / equipment / process**。
- **misguided policy / attempt / decision**。
- **invalid argument / code / ticket / result**。
- **wrong** 可作形容詞，也可非正式地作副詞；**wrongly** 是較正式副詞。
- 本課聚焦 factual/logical wrong；**morally wrong** 應另作 ethical / immoral / improper 等義項處理。
