# SYNONYMS · 同義詞學習系統

# Coding

**編程、寫程式碼、編寫軟件、軟件開發——究竟是哪一種 coding？**

本課聚焦：

**coding = the activity of writing instructions in a programming language so that a computer can perform tasks**

核心近義與近義表達：

**programming; computer programming; writing code; creating computer code; writing software; software development; program development; implementing software; scripting; software engineering**

> **Internal precision:** `programming / writing code` 是直接近義；`software development / software engineering` 是更廣概念；`scripting` 是較窄 subtype。

---

# 01 同義詞指南
## 01 Programming

**編程；程式設計**

最直接、最標準的近義詞；通常稍廣於純粹寫 code。

### EXAMPLE · 例句

She learned programming by building small web applications.

她透過製作小型網頁應用程式學習編程。

### COMMON COLLOCATIONS · 常見搭配
- programming skills
- programming language
- learn programming
- programming task

### DIAGNOSTIC QUESTION · 判斷問題

> 是否一般地指寫程式和實作功能，而不只是一小段 code？

---
## 02 Computer programming

**電腦編程；電腦程式設計**

更明確指出是電腦程式編寫，適合教育與正式技術語境。

### EXAMPLE · 例句

Computer programming requires logical thinking and attention to detail.

電腦編程需要邏輯思考和仔細留意細節。

### COMMON COLLOCATIONS · 常見搭配
- computer programming course
- computer programming skills
- study computer programming
- computer programming language

### DIAGNOSTIC QUESTION · 判斷問題

> 是否需要明確指出是電腦程式編寫？

---
## 03 Writing code

**寫程式碼；編寫代碼**

聚焦實際撰寫 source code，是 coding 最透明的動作性改寫。

### EXAMPLE · 例句

She spent the afternoon writing code for the new feature.

她下午一直為新功能編寫程式碼。

### COMMON COLLOCATIONS · 常見搭配
- write code
- write clean code
- write code in Python
- write code for a feature

### DIAGNOSTIC QUESTION · 判斷問題

> 是否重點在實際撰寫 source code？

---
## 04 Creating computer code

**建立電腦程式碼；編寫電腦代碼**

定義式 paraphrase，特別適合教學與 machine-readable 語境。

### EXAMPLE · 例句

Creating computer code is one part of building reliable software.

編寫電腦程式碼只是建立可靠軟件的一部分。

### COMMON COLLOCATIONS · 常見搭配
- create computer code
- create source code
- computer-code creation
- creating code

### DIAGNOSTIC QUESTION · 判斷問題

> 是否需要定義式地說明 coding 是建立電腦程式碼？

---
## 05 Writing software

**編寫軟件；開發程式**

結果導向，強調建立軟件產品或功能；比 writing code 稍廣。

### EXAMPLE · 例句

The team spends most of its time writing software for medical devices.

團隊大部分時間都在為醫療裝置編寫軟件。

### COMMON COLLOCATIONS · 常見搭配
- write software
- writing software for
- software-writing work
- write application software

### DIAGNOSTIC QUESTION · 判斷問題

> 是否重點在建立一個軟件產品／應用程式？

---
## 06 Software development

**軟件開發**

廣泛 near-synonym；包含 requirements、design、coding、testing、deployment、maintenance。

### EXAMPLE · 例句

Software development involves much more than writing code.

軟件開發遠不只是寫程式碼。

### COMMON COLLOCATIONS · 常見搭配
- software development team
- software-development process
- software development skills
- software development lifecycle

### DIAGNOSTIC QUESTION · 判斷問題

> 上下文是否包含 coding 以外的設計、測試、部署等開發工作？

## 07 Program development

**程式開發**

較正式，常指建立具體程式的過程，由設計到測試。

### EXAMPLE · 例句

Program development begins with a clear definition of the problem.

程式開發由清楚界定問題開始。

### COMMON COLLOCATIONS · 常見搭配

- computer program development
- program-development process
- program development work

### DIAGNOSTIC QUESTION · 判斷問題

> 是否是在建立一個具體 computer program？

## 08 Implementing software

**實作軟件；把功能寫成程式**

情境式 near-synonym；強調把規格或設計轉成可運行程式。

### EXAMPLE · 例句

The team spent two weeks implementing the new search feature.

團隊花了兩星期實作新的搜尋功能。

### COMMON COLLOCATIONS · 常見搭配
- implement a feature
- implement a design
- implement a specification
- software implementation

### DIAGNOSTIC QUESTION · 判斷問題

> 是否把已有設計／規格真正轉成可運行程式？

## 09 Scripting

**編寫腳本；腳本編程**

較窄 subtype，常見於 automation、shell、系統與資料處理。

### EXAMPLE · 例句

Scripting can automate repetitive administrative tasks.

### COMMON COLLOCATIONS · 常見搭配

### DIAGNOSTIC QUESTION · 判斷問題

## 10 Software engineering

更廣的工程專業 umbrella；包含架構、測試、維護與工程流程。

### EXAMPLE · 例句

軟件工程把編程與設計、測試和維護結合起來。

### COMMON COLLOCATIONS · 常見搭配

- software engineering degree

### DIAGNOSTIC QUESTION · 判斷問題

> 是否是較完整、專業的工程職能，而不是單純寫 code？

# 02 False synonyms

以下詞語和 **coding** 密切相關，但不是一般同義詞。
## 01 Debugging

**除錯只是 coding / development 的一部分**

找出和修正程式錯誤；可修改 code，但不等於整個 coding。

### ENGLISH COMPARISON

She coded the feature, then spent an hour debugging it.

---
## 02 Testing

**測試不等於寫程式**

驗證軟件是否正確運作；測試人員可以不寫新 code。

### ENGLISH COMPARISON

The developer writes code; the tester checks whether it works.

---
## 03 Software development

**高度相關但範圍更廣**

包括 requirements、design、coding、testing、deployment、maintenance。

### ENGLISH COMPARISON

Coding is one part of software development.

---
## 04 Software engineering

**更廣、更工程化**

強調架構、品質、可靠性和維護，不只是寫 code。

### ENGLISH COMPARISON

Software engineering includes programming but goes beyond it.

---
## 05 IT support

**資訊科技支援不等於 coding**

主要解決使用者、裝置、帳戶和系統問題。

### ENGLISH COMPARISON

IT support may use scripts, but its core role is support.

---
## 06 Configuration

**設定系統不等於 coding**

修改設定值、權限或環境，不一定寫 source code。

### ENGLISH COMPARISON

Changing a configuration file is not necessarily programming.

---
## 07 Data entry

**資料輸入不等於 coding**

把資料錄入系統，不涉及程式邏輯。

### ENGLISH COMPARISON

Typing customer records is data entry, not coding.

---
## 08 Markup / HTML authoring

**標記語言與 programming 要區分**

HTML 常被非正式稱 coding，但技術上是 markup language。

### ENGLISH COMPARISON

HTML authoring can be called coding informally, but it is not general-purpose programming.

---

# 03 練習與解釋

> **每個核心近義表達 3 題，共 30 題。**
> 每題盡量保留原句句法，只在目標表達要求不同結構時作必要改寫。
> Distractors 優先使用 debugging / testing / configuration / support / development 等 plausible near-misses。

# Programming
## 練習 01.1

**Target expression:** Programming · 編程；程式設計

### READ THE CONTEXT · 閱讀語境

Coding is an important skill for many software jobs.

### 中文翻譯

編程是很多軟件工作的重要技能。

### OPTIONS

- **A. programming**
- **B. debugging**
- **C. testing**
- **D. configuration**
- **E. IT support**
- **F. data entry**

### CORRECT ANSWER · 正確答案

**Programming · 編程；程式設計**

Programming is an important skill for many software jobs.

### SIX-OPTION FEEDBACK · 六個選項的解釋

- **A. programming ✓** — `Programming` 是本題最合適的改寫；它保留原句中 coding 的核心意思，同時符合本題的語域與範圍。
- **B. debugging** — `debugging` = 除錯；它只處理既有程式中的錯誤，並不等於一般 coding。
- **C. testing** — `testing` = 測試；重點是驗證程式行為，不是建立程式碼。
- **D. configuration** — `configuration` = 系統設定；很多設定工作不需要編寫 source code。
- **E. IT support** — `IT support` = 資訊科技支援；核心是協助使用者和維持系統運作。
- **F. data entry** — `data entry` = 資料輸入；雖然也使用鍵盤，但不涉及程式邏輯或程式語言。

# 04 核心對比表

| 表達 | 與 coding 的接近程度 | 核心差異 |
|---|---:|---|
| **programming** | 非常高 | 最直接標準近義詞；常稍廣 |
| **computer programming** | 非常高 | 明確限定電腦程式 |
| **writing code** | 非常高 | 聚焦實際撰寫 source code |
| **creating computer code** | 非常高 | 透明、定義式 paraphrase |
| **writing software** | 很高 | 聚焦建立軟件產品／功能 |
| **software development** | 高 | 更廣；包含 coding、testing、deployment 等 |
| **program development** | 很高 | 較正式；建立具體程式 |
| **implementing software** | 很高（情境限定） | 把設計／規格轉成可執行程式 |
| **scripting** | 高（較窄） | automation / shell / script 類 coding |
| **software engineering** | 高（更廣） | 專業工程 umbrella，包含 architecture / maintenance |

# 05 高價值近義詞對比

## Coding vs Programming
兩者日常高度可互換；**programming** 常稍廣，可能包含設計邏輯、測試和除錯。

## Coding vs Writing code
**writing code** 最聚焦實際撰寫 source code。

## Coding vs Software development
**software development** 明顯更廣；coding 是其中核心階段之一。

## Coding vs Implementing software
**implementing** 特別強調把設計／規格變成可運行程式。

## Coding vs Scripting
**scripting** 是較窄 subtype，常用於自動化、shell、資料處理。

## Coding vs Software engineering
**software engineering** 是更完整的工程專業，包括架構、測試、維護與流程。

# 07 Grammar and usage notes

## 01 Coding vs programming
日常高度可互換，但精確技術語境中 `coding` 常更聚焦寫 code，`programming` 可稍廣。

## 02 Code as noun and verb
- write code
- clean code
- source code
- code a feature
- code in Python

## 03 Programming-language pattern
最穩妥：`code in Python`, `program in Java`, `write code in JavaScript`.

## 04 Software development is broader
通常包含 requirements, design, coding, testing, debugging, deployment, maintenance。

## 05 Software engineering is broader still
強調 architecture, scalability, reliability, maintainability, testing strategy, engineering process。

## 06 Implement / implementation
`implement a feature/design/specification` 通常表示把設計真正寫成工作中的軟件。

## 07 Scripting is narrower
偏 automation, glue code, system tasks, data processing。

## 08 HTML and coding
日常可把寫 HTML 稱作 coding，但技術上 HTML 是 markup language，不是 general-purpose programming language。
