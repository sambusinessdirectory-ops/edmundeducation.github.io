# SYNONYMS · 同義詞學習系統

# Effort (noun)

**`effort` 可以表示工夫、用力、一次嘗試、持續努力、奮鬥、辛勞、用功或主動行動。**

核心替代表達：

`work / exertion / attempt / endeavour / striving / labour / application / initiative`

---

# 01 同義詞指南

## 01 Work

**工作；付出的工夫**

實際投入的工作量或工夫。

**EXAMPLE · 例句**

> A lot of work went into preparing the exhibition.

籌備這個展覽投入了大量工夫。

---

## 02 Exertion

**用力；努力；體力消耗**

身體或精神上的用力與能量消耗。

**EXAMPLE · 例句**

> Climbing the hill required considerable physical exertion.

爬上山坡需要相當大的體力。

---

## 03 Attempt

**嘗試；試圖**

一次具體的嘗試，不一定投入大量工夫。

**EXAMPLE · 例句**

> Her first attempt at the exam was unsuccessful.

她第一次應考沒有成功。

---

## 04 Endeavour

**努力；盡力；努力事項**

較正式，指持續、認真的努力或重要 undertaking。

**EXAMPLE · 例句**

> The project is a major scientific endeavour.

這個項目是一項重大的科學努力。

---

## 05 Striving

**努力；奮鬥**

持續為改善或達成目標而努力。

**EXAMPLE · 例句**

> Her striving for improvement impressed the coach.

她不斷努力求進，令教練印象深刻。

---

## 06 Labour

**勞動；辛勞；工夫**

大量、辛苦或長時間的工作，常帶艱苦意味。

**EXAMPLE · 例句**

> Years of labour went into restoring the old building.

修復這幢舊建築投入了多年的辛勞。

---

## 07 Application

**用功；專心努力**

學習或工作中的專注、勤奮與用功。

**EXAMPLE · 例句**

> Her application to her studies has improved greatly.

她在學業上的用功程度大大提高。

---

## 08 Initiative

**主動努力；倡議；行動**

主動採取行動或發起計劃，而不是被動等待。

**EXAMPLE · 例句**

> The recycling programme began as a student initiative.

這個回收計劃最初是由學生主動發起的。

---

# 02 False synonyms

## Effort / Work
`work` 強調實際工作量；`effort` 更可表示主觀用力程度。

**ENGLISH COMPARISON**  
The task required a lot of effort.  
A lot of work went into preparing the report.

## Effort / Exertion
`exertion` 強調身體或精神能量消耗。

**ENGLISH COMPARISON**  
The task required effort.  
Climbing the hill required considerable physical exertion.

## Effort / Attempt
`attempt` 只表示一次 try，不保證投入很多努力。

**ENGLISH COMPARISON**  
She made a great effort to improve.  
Her first attempt at the test was unsuccessful.

## Effort / Endeavour
`endeavour` 較正式，常指持續、認真的努力或重要 undertaking。

## Effort / Striving
`striving` 強調持續為改善或達成目標而奮鬥。

## Effort / Labour
`labour` 常帶辛苦、長時間或體力工作的意味。

## Effort / Application
`application` 在教育／工作語境可表示用功、專心和勤奮。

## Effort / Initiative
`initiative` 不表示努力程度，而表示主動採取行動或發起計劃。

# 04 Target-word / phrase contrast map

| `effort` 真正重點 | 較精準替代表達 |
|---|---|
| 實際投入的工作量 | **work** |
| 身體／精神用力 | **exertion** |
| 一次具體嘗試 | **attempt** |
| 正式、持續的重要努力 | **endeavour** |
| 持續奮鬥求進 | **striving** |
| 艱苦／長時間辛勞 | **labour** |
| 專心、勤奮用功 | **application** |
| 主動發起的行動 | **initiative** |

# 05 高價值近義詞辨析

- **Work vs Effort** — work 偏實際工作量；effort 偏投入多少力氣／心力。
- **Exertion vs Labour** — exertion 偏能量消耗；labour 偏持續艱苦工作。
- **Attempt vs Effort** — attempt = 一次 try；effort 可持續很久。
- **Endeavour vs Attempt** — endeavour 更正式、可長期；attempt 可只是一次短暫嘗試。
- **Striving vs Endeavour** — striving 強調持續力求進步；endeavour 可指整個正式努力／項目。
- **Application vs Work** — application 偏專心用功；work 是實際工作。
- **Initiative vs Effort** — initiative 強調主動開始，不是付出多少。
- **Effort ≠ result** — 努力不等於成果。

# 08 Grammar & structure traps

- **work** 在「工作量」意思通常不可數：`a lot of work`
- **exertion** = noun；**exert** = verb
- **attempt** = noun/verb：`make an attempt / attempt to do`
- **endeavour** 是英式拼法；US 常見 **endeavor**
- **striving** = noun/gerund；動詞是 **strive**
- **labour** 是英式／港式拼法；US **labor**
- **application** 在此是「用功」，不是「申請」
- **initiative** 常見：`take the initiative / launch an initiative`

# 09 核心決策問題

1. 重點是投入多少實際工作？ → **work**
2. 是身體／精神用力程度？ → **exertion**
3. 是一次具體 try？ → **attempt**
4. 是正式、長期、重要的努力？ → **endeavour**
5. 是不斷努力求進？ → **striving**
6. 是艱苦、長時間辛勞？ → **labour**
7. 是學習／工作上的專心用功？ → **application**
8. 是主動發起行動？ → **initiative**

# 10 Final note for system use

核心替代表達：

`work / exertion / attempt / endeavour / striving / labour / application / initiative`

最重要的一點：

> **effort ≠ attempt ≠ exertion**

`effort` = 廣義努力；  
`attempt` = 一次嘗試；  
`exertion` = 身體／精神用力。
