# SYNONYMS · 同義詞學習系統

# Jogging

**詞性：noun · 名詞**

**本課限定語境：jogging = running at a slow or comfortable pace, usually for exercise rather than competition · 「慢跑；輕鬆跑；以舒適速度跑步」**

> **同義詞數量不固定。**
> `jogging` 本身已經是一個很精確的運動詞。真正自然的替代表達不算很多，因此本課不勉強增加數量。
>
> 本課保留 **5 個**有教學價值的替代表達：
>
> **light running, easy running, running at an easy pace, gentle running, recreational running**
>
> 主要區別：
>
> - **light running** → 輕鬆、強度低的跑步
> - **easy running** → 以舒適、不吃力的速度跑；跑步訓練語境很常見
> - **running at an easy pace** → 最透明、最直接的描述性改寫
> - **gentle running** → 溫和、低強度的跑步；較描述性
> - **recreational running** → 以休閒、健康為目的的跑步，而非競賽
>
> 特別注意：
>
> - `running` 比 `jogging` 廣，可以包括 sprinting、racing 和長距離高強度跑。
> - `light running` / `gentle running` 強調強度低，但不一定精確指定速度。
> - `easy running` 是跑步訓練中很自然的說法，通常表示 conversational pace。
> - `recreational running` 強調目的而不是速度：有些 recreational runners 其實跑得很快。
> - `walking` 不是同義詞；jogging 仍然屬於 running。
>
> 每個 target expression 配 **3 道完整練習題**，共 **15 題**。
> 每題使用真正可能令人猶豫的近義競爭者，並加入強度、速度、目的或搭配上的語義陷阱；每個錯誤選項都會說明 **為何看似合理，以及句中哪個線索最終排除它**。

# 01 同義詞指南

## 01 Light Running

**輕鬆跑；低強度跑步**

表示強度較低、身體負擔較小的跑步。

**EXAMPLE · 例句**

The physiotherapist recommended light running after the pain had improved.

疼痛改善後，物理治療師建議進行輕度跑步。

**USAGE · 用法提示**

常見：
- light running
- light exercise
- light aerobic activity

`light running` 比 `jogging` 更直接標示運動強度低。

---

## 02 Easy Running

**輕鬆跑；舒適配速跑**

表示以不吃力、可以維持的速度跑步。

**EXAMPLE · 例句**

Today’s session is just easy running for thirty minutes.

今天的訓練只需要輕鬆跑三十分鐘。

**USAGE · 用法提示**

常見於跑步訓練：
- easy running
- easy run
- easy pace
- recovery run

通常表示：
> controlled effort, not race pace.

---

## 03 Running at an Easy Pace

**以輕鬆速度跑步**

最透明的描述性改寫，直接說明速度／努力程度。

**EXAMPLE · 例句**

Running at an easy pace is a good way to build basic endurance.

以輕鬆速度跑步是建立基本耐力的好方法。

**USAGE · 用法提示**

很適合：
- health explanations
- beginner guidance
- exercise instructions

這個表達比單字 `jogging` 更長，但意思非常清楚。

---

## 04 Gentle Running

**溫和跑步；低強度慢跑**

表示動作和強度較溫和，不追求速度。

**EXAMPLE · 例句**

She returned to gentle running a few weeks after recovering from the injury.

受傷康復幾星期後，她重新開始做溫和跑步。

**USAGE · 用法提示**

特別適合：
- recovery
- beginners
- warm-ups
- low-impact exercise discussions

它比 `jogging` 更強調「不要太激烈」。

---

## 05 Recreational Running

**休閒跑步；非競賽跑步**

表示以健康、興趣、放鬆為目的的跑步，而非正式競賽。

**EXAMPLE · 例句**

Recreational running has become popular among office workers.

休閒跑步在上班族之間變得很流行。

**USAGE · 用法提示**

常見：
- recreational running
- recreational runner
- recreational sport

注意：
> recreational ≠ necessarily slow

因此它和 jogging 只是部分重疊。

---

# 02 False Synonyms / 容易誤選的相關詞

## 01 Running

**跑步 ≠ 一定慢跑**

`running` 是上位詞，可以包括 jogging、sprinting、racing。

**ENGLISH COMPARISON**

Jogging is a type of running, but not all running is jogging.

---

## 02 Sprinting

**短跑衝刺 ≠ 慢跑**

sprinting 是短距離、高速度、高強度，和 jogging 幾乎相反。

---

## 03 Walking

**步行 ≠ 慢跑**

walking 至少有一隻腳持續接觸地面；jogging 屬於跑步動作。

---

## 04 Brisk Walking

**快走 ≠ 慢跑**

brisk walking 強度可能接近輕鬆慢跑，但動作模式仍不同。

---

## 05 Easy Running

**很接近，但偏訓練語境**

easy running 常用於跑者訓練計劃；jogging 更日常、更大眾化。

---

## 06 Recreational Running

**休閒跑 ≠ 一定慢速**

休閒跑者也可能用較快配速跑步，因此不完全等於 jogging。

---

## 07 Jog / Jogging

- jog = 慢跑（動詞／名詞）
- jogging = 慢跑這項活動（名詞／動名詞）

> I jog every morning.  
> Jogging is good aerobic exercise.

---

## 08 Jogger / Jogging

- jogger = 慢跑者
- jogging = 慢跑活動

# 01 Light Running

## 練習 01.1

The doctor said I could return to jogging, but only at low intensity for the first week.

**中文翻譯**

醫生說我可以重新慢跑，但第一星期只能做低強度運動。

A. sprinting  
B. light running  
C. race training  
D. brisk walking  
E. interval running  
F. hill running

### CORRECT ANSWER · 正確答案

The doctor said I could return to **light running**, but only at low intensity for the first week.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. sprinting**  
跑得快也屬 running，所以表面相關；但 sprinting 是高強度，和 `only at low intensity` 直接衝突。

**B. light running ✓**  
`low intensity` 是決定性線索，light running 正好表示低強度跑步。

**C. race training**  
競賽訓練可以包含不同強度，但通常不會被概括成恢復期的低強度 jogging。

**D. brisk walking**  
強度可能相近，但它仍然是 walking，不是 jogging。

**E. interval running**  
interval training 常包含快慢交替和較高強度，不符合醫生限制。

**F. hill running**  
上坡跑通常增加強度，也不適合此處。

# 05 高階辨析補充

## Jogging vs Running

`running` 是上位詞。

> jogging ⊂ running

所以：
- jogging is running
- not all running is jogging

---

## Jogging vs Light Running

`light running` 更強調 **exercise intensity**。

特別適合：
- recovery
- rehabilitation
- low-intensity exercise

---

## Jogging vs Easy Running

`easy running` 很常見於跑步訓練計劃。

通常指：
> comfortable, controlled effort

比 everyday `jogging` 更有 training vocabulary 的感覺。

---

## Jogging vs Running at an Easy Pace

這是最透明的定義式改寫：

> jogging = running at an easy pace

特別適合教學與解釋。

---

## Jogging vs Gentle Running

`gentle running` 更強調：
> low strain / low intensity

所以很適合傷後恢復、初學者或暖身。

---

## Jogging vs Recreational Running

差別在焦點：

- **jogging** → pace / intensity
- **recreational running** → purpose

一位 recreational runner 也可能跑得很快。

# 08 教學核心

**Jogging 的自然替代表達，最重要的是先判斷你是在說「低強度、舒適配速、描述性慢跑、溫和恢復跑，還是休閒目的」。**

- 低強度跑 → **light running**
- 訓練語境中的輕鬆跑 → **easy running**
- 直接描述速度 → **running at an easy pace**
- 溫和／恢復型跑步 → **gentle running**
- 以健康與興趣為目的 → **recreational running**

最重要的界線是：

> **`jogging` 的核心是「以舒適、較慢配速跑步」；`easy/light/gentle running` 主要描述強度，而 `recreational running` 則主要描述跑步目的，不一定代表慢速。**
