# APP — Complete Synonym Lesson

## 01 同義詞指南

### App 的 10 種更精準說法

> Note: “app” can refer broadly to an application, but the best alternative depends on device and delivery method: mobile, smartphone, desktop, web, or general software.
> 「app」可以泛指應用程式，但更精準的替代詞要看使用裝置和形式，例如手機、智能手機、桌面電腦、網頁或一般軟件。

### 01 Application
**應用程式；應用軟件**

app 的完整寫法，最直接、最正式的改寫；可指手機、電腦或其他裝置上的應用程式。

**EXAMPLE · 例句**  
Please download the application before the meeting.  
請在會議前下載這個應用程式。

---

### 02 Mobile App
**手機應用程式；流動應用程式**

最常見的手機語境說法，表示主要在智能手機或平板上使用的 app。

**EXAMPLE · 例句**  
The bank launched a new mobile app for customers.  
銀行為客戶推出了新的手機應用程式。

---

### 03 Mobile Application
**手機應用程式；流動應用程式**

mobile app 的較正式完整寫法，常見於報告、產品文件和商業語境。

**EXAMPLE · 例句**  
The company developed a mobile application for ticket booking.  
公司開發了一個用來訂票的手機應用程式。

---

### 04 Mobile Software
**手機軟件；流動裝置軟件**

較廣泛、較技術性的說法，表示為手機或其他流動裝置設計的軟件；範圍可比 mobile app 稍廣。

**EXAMPLE · 例句**  
The company specializes in mobile software development.  
公司專門從事手機軟件開發。

---

### 05 Software Application
**軟件應用程式；應用軟件**

較正式和技術性的說法，強調它是一個供用戶執行特定工作的軟件程式。

**EXAMPLE · 例句**  
The software application helps users manage their finances.  
這個軟件應用程式幫助用戶管理財務。

---

### 06 Program
**程式；電腦程式**

較廣泛的電腦用語，表示執行特定功能的一組軟件指令；在桌面電腦語境中常可代替 app。

**EXAMPLE · 例句**  
Open the program and select the file you want to edit.  
開啟程式，然後選擇你想編輯的檔案。

---

### 07 Desktop Application
**桌面應用程式；電腦桌面軟件**

表示安裝並主要在桌面電腦或手提電腦上使用的應用程式，和 mobile app、web app 作區分。

**EXAMPLE · 例句**  
The desktop application works on both Windows and macOS.  
這個桌面應用程式可在 Windows 和 macOS 上運行。

---

### 08 Web App
**網頁應用程式；網絡應用程式**

表示主要透過網頁瀏覽器使用的應用程式，通常不需要傳統方式安裝。

**EXAMPLE · 例句**  
The service is available as a web app in any modern browser.  
這項服務可透過任何現代瀏覽器中的網頁應用程式使用。

---

### 09 Smartphone App
**智能手機應用程式**

非常具體地表示為智能手機設計和使用的 app，通常用於需要強調裝置類型時。

**EXAMPLE · 例句**  
The smartphone app tracks your daily steps.  
這個智能手機應用程式記錄你每天的步數。

---

### 10 Digital Tool
**數碼工具；數碼應用工具**

較廣泛的說法，強調 app 是用來完成某項工作或解決問題的數碼工具，而不是其技術形式。

**EXAMPLE · 例句**  
The app is a useful digital tool for language learners.  
這個應用程式是語言學習者很有用的數碼工具。

---

## 02 False synonyms

### 看起來相關，意思卻不同

### 01 Website
**網站不等於 app**

**website = 網站**

website 是一組網頁；有些網站包含 web app 功能，但普通網站不等於 app。

**ENGLISH COMPARISON**  
A website may mainly provide information; an app usually lets users perform tasks.

---

### 02 Software
**軟件不等於 app**

**software = 軟件**

software 是非常廣泛的總稱，可以包括作業系統、驅動程式和應用程式；app 只是 software 的一類。

**ENGLISH COMPARISON**  
Every app is software, but not all software is an app.

---

### 03 Platform
**平台不等於 app**

**platform = 平台**

platform 通常指提供其他服務、內容或應用運行的環境；不等於單一 app。

**ENGLISH COMPARISON**  
A platform may contain many apps or services.

---

### 04 Operating System
**作業系統不等於 app**

**operating system = 作業系統**

作業系統如 Windows、Android、iOS 是管理裝置和運行 app 的核心系統，不是一般 app。

**ENGLISH COMPARISON**  
Apps run on an operating system.

---

### 05 Browser
**瀏覽器不等於 app**

**browser = 瀏覽器**

browser 是用來瀏覽網站和使用 web app 的軟件；它本身不是所有 app 的同義詞。

**ENGLISH COMPARISON**  
A web app runs in a browser.

---

### 06 File
**檔案不等於 app**

**file = 檔案**

file 是儲存資料的單位，例如文件、圖片或影片；不是可執行功能的 app。

**ENGLISH COMPARISON**  
You open a file with an app.

---

### 07 Account
**帳戶不等於 app**

**account = 帳戶**

account 是用戶身份或登入資料，不是應用程式。

**ENGLISH COMPARISON**  
You sign into an app with an account.

---

### 08 Apk
**Android 安裝檔不等於 app**

**APK = Android 安裝檔**

APK 是 Android app 的安裝檔格式，不等於 app 本身。

**ENGLISH COMPARISON**  
You may install an Android app from an APK file.

---
