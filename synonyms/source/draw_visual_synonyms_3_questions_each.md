# SYNONYMS · 同義詞學習系統

# Draw

**本課集中在 `draw = 畫／描繪` 的視覺創作義。**

核心替代表達：

`sketch / illustrate / depict / portray / render / outline / trace / doodle / diagram / draft`

> **核心原則**
>
> Are you making a quick sketch, illustrating an idea, depicting a scene, portraying a person, rendering a finished image, outlining a shape, tracing existing lines, doodling casually, diagramming a system, or drafting an early version?

---

# 01 同義詞指南

## 01 Sketch

**素描；草畫**

快速、概略地畫出主要形狀或構想。

---

## 02 Illustrate

**圖解；以圖畫說明**

用圖畫或示意圖來說明文字、概念、故事或步驟。

---

## 03 Depict

**描繪；表現**

較正式地以圖像呈現人物、物件或場景。

---

## 04 Portray

**描繪；刻畫**

特別強調人物形象、性格、情緒或特質如何被呈現。

---

## 05 Render

**描繪；呈現；渲染**

以精細、專業或數碼方式把物件／場景呈現出來。

---

## 06 Outline

**勾勒；畫輪廓**

只畫出外形、邊界或基本輪廓。

---

## 07 Trace

**描摹；沿線描畫**

沿已有圖形、模板或物件邊緣複製線條。

---

## 08 Doodle

**隨手塗鴉**

沒有正式目的地隨手畫小圖案、線條或形狀。

---

## 09 Diagram

**以圖表／示意圖表示**

把結構、流程或關係用圖形方式表示。

---

## 10 Draft

**起草圖；畫初稿**

先畫出未完成、可修改的初步版本。

---

# 02 False synonyms

## Draw / Sketch

`sketch` 通常更快、更概略、更像初步版本。

## Draw / Illustrate

`illustrate` 通常有「用圖說明」的功能。

## Draw / Depict

`depict` 強調呈現甚麼內容，而不是畫畫動作本身。

## Draw / Portray

`portray` 特別常見於人物、性格、情緒和形象。

## Draw / Outline

`outline` 只畫外形／邊界，不等於完整繪畫。

## Draw / Trace

`trace` 需要已有線條、模板或物件邊緣可跟着畫。

## Draw / Doodle

`doodle` 是隨手亂畫，通常沒有正式目的。

## Draw / Diagram

`diagram` 的目標是清楚表示結構、流程或關係。

# 03 練習與解釋

> 每個目標詞三題，共 **30 題**。每題六個選項；答案位置平均分散在 **A–F**。每個錯誤選項按自己的詞義和本句語境個別解釋。

## 練習 01.1

**Target word: Sketch · 素描；草畫**

### READ THE CONTEXT · 閱讀語境

> She drew the building quickly before the bus arrived.

**中文翻譯**

巴士到達前，她快速畫下那座建築。

| | 選項 |
|---|---|
| A | Outline |
| B | Draft |
| C | Sketch |
| D | Illustrate |
| E | Paint |
| F | Write |

### CORRECT ANSWER · 正確答案

**C. Sketch · 素描；草畫**

> She sketched the building quickly before the bus arrived.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. Outline**  
`Outline`：只畫外形／邊界，不能表達完整場景或說明功能。 本句關鍵是 **快速概略地畫**，所以不是最精準答案。

**B. Draft**  
`Draft`：可修改的初稿，若已是完成成品就不合。 本句關鍵是 **快速概略地畫**，所以不是最精準答案。

**C. Sketch ✓**  
`Sketch` = 素描；草畫。本句關鍵是 **快速概略地畫**；這正好對應它的繪圖目的、完成程度或技術方式，因此最精準。

**D. Illustrate**  
`Illustrate`：用圖說明，若沒有 explanatory purpose 就不夠精準。 本句關鍵是 **快速概略地畫**，所以不是最精準答案。

**E. Paint**  
`Paint`：用顏料作畫，媒介比 draw 更窄。 本句關鍵是 **快速概略地畫**，所以不是最精準答案。

**F. Write**  
`Write`：書寫文字，不是製作圖像。 本句關鍵是 **快速概略地畫**，所以不是最精準答案。

# 05 高價值近義詞辨析

- **Draw vs Sketch** — draw 可完整或不完整；sketch 通常快速、概略。
- **Draw vs Illustrate** — draw 是製作圖像；illustrate 是用圖幫助說明。
- **Depict vs Portray** — depict 較廣；portray 特別常用於人物形象／性格。
- **Depict vs Render** — depict 強調呈現甚麼；render 更強調精細／技術呈現。
- **Sketch vs Draft** — sketch 是視覺草圖；draft 更明確是會再修改的初稿。
- **Outline vs Trace** — outline 畫外輪廓；trace 沿已有輪廓複製。
- **Draw vs Doodle** — doodle 通常只是隨手畫。
- **Illustrate vs Diagram** — illustrate 可較藝術；diagram 重點是資訊結構清晰。

# 06 Idioms / common expressions

- **draw from life** — 對着真人／實物寫生
- **draw freehand** — 徒手畫
- **draw to scale** — 按比例繪畫
- **sketch out an idea** — 草畫／概略呈現想法
- **rough sketch** — 草圖
- **line drawing** — 線條畫
- **draw an outline** — 畫輪廓
- **trace over the lines** — 沿線描畫
- **doodle in the margin** — 在頁邊塗鴉
- **render in 3D** — 以三維方式渲染

| **trace** | 藝術、教育、技術 |
| **doodle** | 口語、日常 |
| **diagram** | 科學、工程、教育 |
| **draft** | 設計、建築、正式工作 |

# 08 Grammar & structure traps

- `draw a picture / line`
- `sketch a face`
- `sketch out an idea`
- `illustrate how something works`
- `depict someone as...`
- `portray someone as...`
- `trace around an object`
- `diagram a process`

> `paint` = 用顏料作畫  
> `draw` = 更廣，可用鉛筆、筆、數碼工具等

# 09 核心決策問題

1. 快速草畫？ → **sketch**
2. 用圖幫助解釋？ → **illustrate**
3. 正式呈現場景／物件？ → **depict**
4. 重點是人物形象／性格？ → **portray**
5. 精細、專業或數碼呈現？ → **render**
6. 只畫外形／邊界？ → **outline**
7. 沿已有線條複製？ → **trace**
8. 隨手亂畫？ → **doodle**
9. 畫結構／流程示意圖？ → **diagram**
10. 畫將來會修改的初稿？ → **draft**

# 10 Final note for system use

核心替代表達：

`sketch / illustrate / depict / portray / render / outline / trace / doodle / diagram / draft`

最重要的 near-miss：

`paint / colour / copy / photograph / write / label`

真正的選詞依據是：

> **Are you sketching roughly, illustrating an idea, depicting a scene, portraying a person, rendering a finished image, outlining, tracing, doodling, diagramming, or drafting?**
