# INTERNET · 分層同義詞學習系統

## Internet

**「互聯網／網絡」，要先分清是在談全球基礎網絡本身、World Wide Web、抽象的網絡空間，還是人們在線上活動形成的『網上世界』。**

本單元集中處理 **internet = the global system of interconnected computer networks that enables communication and services such as the web, email, streaming, and online applications**。你提供的 **the web; online network; cyberspace** 分別代表 **網頁系統、描述性網絡、虛擬網絡空間** 三個核心方向。

這次保留 **13 個**自然且具教學價值的詞／表達，共 **39 道練習**，每個目標 **3 題**。尤其把 **internet vs web vs Wi-Fi vs website vs browser vs cloud** 清楚拆開，避免技術概念混用。

## Tier 1 — Core web / network / cyberspace equivalents · 核心網絡、萬維網與網絡空間近義詞

### 01 The web

**Tier**：1  
**中文**：網絡；萬維網；網頁世界  
**語域**：neutral / very common  
**核心語義**：the World Wide Web: interconnected websites and webpages accessed through the internet  
**用法提示**：你提供的 seed 很核心，但要分清 web 是 internet 上的一項服務，不等於整個 internet。  
**常見搭配**：browse the web; on the web; web page; web browser; web content.  
**常見搭配對象**：website, page, browser, content, search.  
**與 internet 的辨析**：The web 指網站／網頁系統；internet 是支撐 web、電郵、串流等服務的全球網絡。  
**使用限制**：技術上不要把 World Wide Web 和 Internet 完全等同。

**EXAMPLE · 例句**  
Most people use the web every day for information and services.  
大多數人每天都使用網絡查找資料和使用服務。

### 02 Online network

**Tier**：1  
**中文**：網上網絡；線上網絡  
**語域**：neutral / descriptive  
**核心語義**：a network of connected computers, users, or services operating online  
**用法提示**：你提供的 seed 適合解釋性文本，尤其當重點是『透過線上連接而成的網絡』。  
**常見搭配**：online network; global online network; connected network; online services; network access.  
**常見搭配對象**：computer, user, service, platform, communication.  
**與 internet 的辨析**：Online network 是描述性 near-synonym；internet 是全球特定網絡。  
**使用限制**：單一公司的內部 online network 不等於整個 internet。

**EXAMPLE · 例句**  
The service operates through a large online network.  
這項服務透過大型網上網絡運作。

### 03 Cyberspace

**Tier**：1  
**中文**：網絡空間；虛擬空間  
**語域**：neutral / somewhat formal  
**核心語義**：the virtual environment created by interconnected digital networks and online communication  
**用法提示**：你提供的 seed 很有價值，特別適合談網絡空間、網絡文化、網絡犯罪或虛擬互動。  
**常見搭配**：in cyberspace; cyberspace security; cyberspace regulation; cyberspace activity; cyberspace governance.  
**常見搭配對象**：security, crime, communication, culture, regulation.  
**與 internet 的辨析**：Cyberspace 比 internet 更抽象，指線上活動所形成的虛擬空間。  
**使用限制**：日常說上網通常直接用 internet / online。

**EXAMPLE · 例句**  
Governments are paying more attention to security in cyberspace.  
各國政府愈來愈重視網絡空間安全。

### 04 The net

**Tier**：1  
**中文**：互聯網；網絡  
**語域**：informal / common  
**核心語義**：an informal shortened form of the internet  
**用法提示**：口語、新聞標題和較輕鬆文字中很自然。  
**常見搭配**：on the net; browse the net; net access; net user; net connection.  
**常見搭配對象**：user, access, browsing, information, connection.  
**與 internet 的辨析**：The net 幾乎就是 internet 的口語縮寫。  
**使用限制**：正式技術文件通常直接用 internet。

**EXAMPLE · 例句**  
You can find the manual on the net.  
你可以在網上找到這份手冊。

### 05 World Wide Web

**Tier**：1  
**中文**：萬維網  
**語域**：technical / formal  
**核心語義**：the system of interlinked webpages and resources accessed through browsers over the internet  
**用法提示**：當需要技術上精確地區分 web 和 internet 時很重要。  
**常見搭配**：World Wide Web; web browser; web server; web resource; web standards.  
**常見搭配對象**：page, browser, website, server, hyperlink.  
**與 internet 的辨析**：World Wide Web 是 internet 上的服務，不是整個 internet。  
**使用限制**：電郵、即時通訊、FTP 等可使用 internet 而不屬 web 本身。

**EXAMPLE · 例句**  
The World Wide Web made linked information easy to access through browsers.  
萬維網令使用者可透過瀏覽器方便存取互相連結的資料。

## Tier 2 — Digital / online-world variants · 數碼網絡與網上世界變體

### 06 Global network

**Tier**：2  
**中文**：全球網絡  
**語域**：neutral / formal  
**核心語義**：a worldwide system of interconnected computers and networks  
**用法提示**：當 internet 被描述為全球互聯的基礎設施時很自然。  
**常見搭配**：global network; worldwide network; interconnected network; global connectivity; network infrastructure.  
**常見搭配對象**：computer, server, communication, infrastructure, connection.  
**與 internet 的辨析**：Global network 是描述 internet 的上位表達，不一定專指 internet。  
**使用限制**：其他全球電訊或企業網絡也可叫 global network。

**EXAMPLE · 例句**  
The internet is a global network linking billions of devices.  
互聯網是一個連接數十億裝置的全球網絡。

### 07 Digital network

**Tier**：2  
**中文**：數碼網絡；數字網絡  
**語域**：technical / neutral  
**核心語義**：a network that carries digital data between devices or systems  
**用法提示**：當 internet 被放在數碼通訊、設備連接和資料傳輸語境中可用。  
**常見搭配**：digital network; digital infrastructure; digital connectivity; data network; digital communications network.  
**常見搭配對象**：device, data, infrastructure, communication, system.  
**與 internet 的辨析**：Digital network 比 internet 更廣，包括局域網、流動網絡等。  
**使用限制**：不要把所有 digital networks 都叫 internet。

**EXAMPLE · 例句**  
Modern services depend on reliable digital networks.  
現代服務依賴可靠的數碼網絡。

### 08 Online world

**Tier**：2  
**中文**：網上世界；線上世界  
**語域**：neutral / common  
**核心語義**：the sphere of activities, communities, services, and experiences that exist online  
**用法提示**：當 internet 指人們在線上的生活、文化和互動環境時很自然。  
**常見搭配**：online world; navigate the online world; online world of commerce; online communities; online life.  
**常見搭配對象**：community, commerce, culture, interaction, activity.  
**與 internet 的辨析**：Online world 是社會／文化型比喻，不是技術網絡名稱。  
**使用限制**：談網絡協定或基礎設施時不宜使用。

**EXAMPLE · 例句**  
Children need guidance when navigating the online world.  
兒童在探索網上世界時需要指導。

### 09 Digital space

**Tier**：2  
**中文**：數碼空間；線上空間  
**語域**：neutral / formal  
**核心語義**：the virtual environment in which digital communication, content, and online activity occur  
**用法提示**：適合教育、媒體、文化、政策和線上社群語境。  
**常見搭配**：digital space; online space; shared digital space; digital environment; digital public space.  
**常見搭配對象**：community, platform, content, communication, policy.  
**與 internet 的辨析**：Digital space 比 cyberspace 更現代、更廣泛，也可包括封閉平台環境。  
**使用限制**：不是 internet 的技術同義詞。

**EXAMPLE · 例句**  
The discussion focuses on safety in digital spaces.  
討論集中於數碼空間中的安全問題。

### 10 Networked world

**Tier**：2  
**中文**：互聯世界；網絡化世界  
**語域**：formal / descriptive  
**核心語義**：a world in which people, organisations, and devices are extensively connected through digital networks  
**用法提示**：當 internet 的重點是現代社會高度互聯時很自然。  
**常見搭配**：networked world; networked society; networked communication; interconnected world; networked economy.  
**常見搭配對象**：society, economy, communication, organisation, device.  
**與 internet 的辨析**：Networked world 描述社會狀態，而非 internet 本身。  
**使用限制**：不能用來替代具體連線名稱。

**EXAMPLE · 例句**  
Privacy has become a major issue in a highly networked world.  
在高度互聯的世界中，私隱已成為重大議題。

## Tier 3 — Infrastructure / ecosystem / virtual-realm variants · 基礎設施、生態與虛擬領域變體

### 11 Internet infrastructure

**Tier**：3  
**中文**：互聯網基礎設施  
**語域**：technical / formal  
**核心語義**：the physical and technical systems that enable internet connectivity, including cables, routers, servers, exchanges, and data centres  
**用法提示**：當 internet 指支撐連線的實際基礎設施時最精準。  
**常見搭配**：internet infrastructure; network infrastructure; broadband infrastructure; critical infrastructure; infrastructure investment.  
**常見搭配對象**：cable, router, exchange, data centre, broadband.  
**與 internet 的辨析**：Internet infrastructure 是支撐 internet 的硬件／系統，不是網上活動本身。  
**使用限制**：日常『在網上找資料』不能改寫成 infrastructure。

**EXAMPLE · 例句**  
The country is investing heavily in internet infrastructure.  
該國正大力投資互聯網基礎設施。

### 12 Online ecosystem

**Tier**：3  
**中文**：網上生態系統；數碼生態  
**語域**：business / media / policy  
**核心語義**：the interconnected set of platforms, users, services, businesses, and technologies operating online  
**用法提示**：當 internet 的重點是平台、服務、廣告、創作者和使用者之間的互聯關係時很實用。  
**常見搭配**：online ecosystem; digital ecosystem; platform ecosystem; internet ecosystem; broader ecosystem.  
**常見搭配對象**：platform, service, user, creator, business.  
**與 internet 的辨析**：Ecosystem 強調參與者與服務互相依賴；internet 是底層網絡。  
**使用限制**：若只談網絡連線本身，network / infrastructure 更精準。

**EXAMPLE · 例句**  
Small businesses now depend on a complex online ecosystem.  
小型企業現時依賴複雜的網上生態系統。

### 13 Virtual realm

**Tier**：3  
**中文**：虛擬領域；網絡世界  
**語域**：literary / descriptive  
**核心語義**：the non-physical sphere of digital interaction, communication, and online activity  
**用法提示**：當 internet 需要較修辭化地寫成一個『虛擬領域』時可用。  
**常見搭配**：virtual realm; digital realm; online realm; enter the virtual realm; virtual environment.  
**常見搭配對象**：interaction, communication, culture, identity, activity.  
**與 internet 的辨析**：Virtual realm 是比喻性描述，不是技術術語。  
**使用限制**：技術、工程或精確定義語境中不宜優先使用。

**EXAMPLE · 例句**  
Many social interactions now take place in the virtual realm.  
很多社交互動現時都在虛擬領域進行。

## 04 False synonyms / internet traps · 容易誤選的詞與互聯網概念陷阱

### 01 Website

**網站不等於 internet**  
website 只是 internet / web 上的一個網站。

**ENGLISH COMPARISON**  
A website is one resource on the internet.

### 02 Browser

**瀏覽器不等於 internet**  
browser 是用來瀏覽 web 的軟件。

**ENGLISH COMPARISON**  
A browser accesses web content; it is not the internet.

### 03 Wi-Fi

**Wi-Fi 不等於 internet**  
Wi-Fi 是本地無線連線技術；有 Wi-Fi 不代表一定能連上 internet。

**ENGLISH COMPARISON**  
Wi-Fi is a local wireless networking technology.

### 04 Web

**web 與 internet 接近但技術上不同**  
World Wide Web 是 internet 上的一項服務。

**ENGLISH COMPARISON**  
The web runs over the internet.

### 05 Cloud

**雲端不等於 internet**  
cloud 指透過網絡提供的遠端運算／儲存服務。

**ENGLISH COMPARISON**  
Cloud services use the internet but are not the internet itself.

### 06 Social media

**社交媒體不等於 internet**  
social media 只是 internet 上的一類平台和服務。

**ENGLISH COMPARISON**  
Social media is one category of online service.

### 07 Cyberspace

**cyberspace 只在虛擬空間 sense 接近 internet**  
它描述網絡活動形成的抽象空間，不是基礎網絡本身。

**ENGLISH COMPARISON**  
Cyberspace is conceptual rather than infrastructural.

### 08 Internet / online

**詞性陷阱**  
internet 是名詞；online 通常作形容詞或副詞。

**ENGLISH COMPARISON**  
Internet names the network; online describes being connected or internet-based.

## 05 練習與解釋 · Practice

### 練習 01.1

**Tier 1 · Target word / phrase**: The web · 網絡；萬維網；網頁世界

**READ THE CONTEXT · 閱讀語境**

Most people use the internet every day to read websites and find information.

**中文翻譯**  
大多數人每天使用網絡瀏覽網站和找資料。

- A. the web
- B. Wi-Fi
- C. browser
- D. website
- E. cloud
- F. social media

**CORRECT ANSWER · 正確答案**

**the web** · 網絡；萬維網；網頁世界

**Correct rewrite · 正確改寫**  
Most people use the web every day to read websites and find information.

**SIX-OPTION FEEDBACK · 六個選項的詳細解釋**

- **A. the web ✓ — websites and browsing directly point to the World Wide Web。**
- **B. Wi-Fi — Wi-Fi is only a local wireless connection method。**
- **C. browser — browser is the software used to access the web。**
- **D. website — website is one individual resource。**
- **E. cloud — cloud is a category of remote services。**
- **F. social media — social media is only one type of online platform.**

## 07 Direct contrasts · 核心辨析

- **internet vs the web**: web 是 internet 上的網頁服務；internet 是更底層、更廣的全球網絡。
- **internet vs Wi-Fi**: Wi-Fi 是本地無線連線技術，不等於 internet。
- **internet vs website**: website 只是 web 上的一個資源。
- **internet vs browser**: browser 是存取 web 的軟件。
- **internet vs cloud**: cloud 是經 internet 提供的遠端運算／儲存服務。
- **internet vs social media**: social media 只是 internet 上的一類平台。
- **internet vs cyberspace**: cyberspace 是網絡活動形成的抽象虛擬空間。
- **internet vs global network**: global network 是描述性上位詞，未必專指 internet。
- **internet vs online world**: online world 是社會文化比喻，而不是技術名稱。
- **internet vs infrastructure**: infrastructure 是支撐 internet 的實體與技術系統。

## 08 Grammar, terminology & internet traps · 文法、術語與互聯網概念陷阱

- 現代一般英語常寫 **the internet**；亦可見不加 the 的 Internet/internet，風格依出版規範而定。
- **online** 通常作形容詞／副詞：online service / shop online；它本身不是 internet 的名詞同義詞。
- **the web / World Wide Web** 指網站與網頁系統，不等於整個 internet。
- **website** = 一個網站；**webpage** = 一個網頁。
- **browser** = 瀏覽器，例如用來存取 web content 的軟件。
- **Wi-Fi** = 本地無線網絡技術；有 Wi-Fi 連線不一定代表可上 internet。
- **cloud** = 遠端運算／儲存服務模式；通常透過 internet 使用。
- **cyberspace** 偏抽象、政策、安全和文化語境。
- **digital space / online world / virtual realm** 都是語境型近義表達，不是技術等價詞。
- **internet infrastructure** 包括光纖、海底電纜、路由器、交換中心、數據中心等。
- **online ecosystem** 強調平台、服務、使用者、企業之間互相依賴。
- **social media ≠ internet**：社交媒體只是其中一類服務。
