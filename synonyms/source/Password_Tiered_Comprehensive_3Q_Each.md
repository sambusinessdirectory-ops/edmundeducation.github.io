# PASSWORD · 分層同義詞學習系統

## Password

**「密碼」，這是一個資訊安全概念。最重要的是分清一般 password、較長的 passphrase、較廣的 login/sign-in credential，以及 login/access/security code。**

本單元集中處理 **password = a secret word, phrase, or string of characters used to authenticate a user or control access to an account, device, system, or protected resource**。你提供的 **secret code; passphrase; login credential; login codes; secret passphrases** 分別代表 **一般秘密代碼、長密碼短語、登入憑證、登入碼、保密短語**。

這個概念很窄，而且很多相關資安詞其實只是上位詞或不同認證機制。因此本次保留 **10 個**自然且具教學價值的近義／情境表達，而不是追求固定數量。共 **30 道練習**，每個目標 **3 題**；正確答案位置在 A–F 間完全平均分布。

## Tier 1 — Core password / passphrase / login equivalents · 核心密碼、密碼短語與登入表達

### 01 Secret code

**Tier**：1  
**中文**：密碼；秘密代碼  
**語域**：neutral / common  
**核心語義**：a confidential sequence of characters or symbols used to prove identity or gain access  
**用法提示**：你提供的 seed 很直接，適合向一般讀者解釋 password 的功能。  
**常見搭配**：secret code; enter a secret code; keep the code secret; access code; security code.  
**常見搭配對象**：account, device, service, door, system.  
**與 password 的辨析**：Secret code 比 password 更廣，可指數字碼、門禁碼或其他保密代碼。  
**使用限制**：若明確是文字／字元密碼，password 更精準。

**EXAMPLE · 例句**  
Never share your secret code with anyone.  
切勿把你的密碼告訴任何人。

### 02 Passphrase

**Tier**：1  
**中文**：密碼短語；通行短語  
**語域**：neutral / cybersecurity  
**核心語義**：a longer password-like sequence, often made from multiple words  
**用法提示**：你提供的 seed 很核心，特別適合資訊安全語境中較長、較易記的密碼。  
**常見搭配**：strong passphrase; create a passphrase; long passphrase; memorable passphrase; passphrase security.  
**常見搭配對象**：account, encryption, device, security, authentication.  
**與 password 的辨析**：Passphrase 通常比一般 password 長，也常由多個詞組成。  
**使用限制**：短單詞密碼不一定叫 passphrase。

**EXAMPLE · 例句**  
Use a long passphrase that you can remember.  
使用一個你能記住的長密碼短語。

### 03 Login credential

**Tier**：1  
**中文**：登入憑證；登入認證資料  
**語域**：formal / technology  
**核心語義**：information used to authenticate a user when signing in to an account or system  
**用法提示**：你提供的 seed 很重要，當 password 被放在更正式的登入／身份驗證語境中很自然。  
**常見搭配**：login credential; login credentials; credential theft; credential security; enter credentials.  
**常見搭配對象**：account, platform, system, service, user.  
**與 password 的辨析**：Login credential 比 password 更廣，可能同時包括 username、password、token 等。  
**使用限制**：若只指 password 本身，credential 是上位詞。

**EXAMPLE · 例句**  
Users should never send login credentials by email.  
使用者不應透過電郵傳送登入憑證。

### 04 Login code

**Tier**：1  
**中文**：登入碼；登入代碼  
**語域**：neutral / technology  
**核心語義**：a code used to sign in to an account or service  
**用法提示**：你提供的 seed 可作一般登入代碼表達，但它不一定是固定 password，也可能是一次性代碼。  
**常見搭配**：login code; enter a login code; receive a login code; code for access; sign-in code.  
**常見搭配對象**：account, app, website, service, device.  
**與 password 的辨析**：Login code 強調用途是登入；password 通常是固定秘密字串。  
**使用限制**：若是一次性驗證碼，應明確標示 one-time code / OTP。

**EXAMPLE · 例句**  
Enter your login code to access the account.  
輸入登入碼以存取帳戶。

### 05 Secret passphrase

**Tier**：1  
**中文**：秘密通行短語；保密密碼短語  
**語域**：neutral / cybersecurity  
**核心語義**：a confidential multi-word phrase used in place of a shorter password  
**用法提示**：你提供的 seed 是 passphrase 的更明確描述性版本。  
**常見搭配**：secret passphrase; secure passphrase; memorised passphrase; passphrase protection; long secret phrase.  
**常見搭配對象**：account, encryption, device, vault, security.  
**與 password 的辨析**：和 passphrase 很接近，但更明確強調 confidentiality。  
**使用限制**：日常使用通常直接說 passphrase 即可。

**EXAMPLE · 例句**  
The encrypted file is protected by a secret passphrase.  
加密檔案受一組秘密密碼短語保護。

## Tier 2 — Credential / access / authentication variants · 登入憑證、通行與認證變體

### 06 Sign-in credential

**Tier**：2  
**中文**：登入憑證；登入認證資料  
**語域**：formal / technology  
**核心語義**：authentication information used to sign in to an account or system  
**用法提示**：和 login credential 幾乎同類，特別適合產品介面、身份驗證和企業 IT。  
**常見搭配**：sign-in credential; sign-in credentials; secure credentials; credential manager; credential storage.  
**常見搭配對象**：user, account, system, app, authentication.  
**與 password 的辨析**：是 password 的上位／正式近義表達，範圍可能包括多種認證資料。  
**使用限制**：不要把 credential 理解為只等於 password。

**EXAMPLE · 例句**  
The browser can store sign-in credentials securely.  
瀏覽器可以安全儲存登入憑證。

### 07 Access code

**Tier**：2  
**中文**：存取碼；通行碼  
**語域**：neutral / common  
**核心語義**：a code that allows access to a device, account, building, or protected resource  
**用法提示**：當 password 的功能重點是『准許進入／存取』時很自然。  
**常見搭配**：access code; enter an access code; temporary access code; secure access; access-control code.  
**常見搭配對象**：device, account, building, file, service.  
**與 password 的辨析**：Access code 比 password 更廣，也可用於門禁或短期存取。  
**使用限制**：並非所有 access code 都是帳戶密碼。

**EXAMPLE · 例句**  
The guest received an access code for the secure area.  
訪客獲得一組進入保安區的通行碼。

### 08 Authentication secret

**Tier**：2  
**中文**：認證秘密；身份驗證秘密資料  
**語域**：formal / security  
**核心語義**：secret information used by an authentication system to verify identity  
**用法提示**：適合較技術、資安、系統設計語境。  
**常見搭配**：authentication secret; shared secret; secret authentication data; authentication factor; credential secret.  
**常見搭配對象**：system, user, server, protocol, account.  
**與 password 的辨析**：比 password 更技術性，可能泛指任何秘密認證資料。  
**使用限制**：一般使用者介面不會這樣稱呼 password。

**EXAMPLE · 例句**  
The system must never store the authentication secret in plain text.  
系統絕不能以純文字儲存認證秘密。

### 09 Account password

**Tier**：2  
**中文**：帳戶密碼  
**語域**：neutral / very common  
**核心語義**：a password specifically used to protect and access an online or digital account  
**用法提示**：當需要明確指出 password 所屬的是某個帳戶時很自然。  
**常見搭配**：account password; change your password; reset password; password manager; strong password.  
**常見搭配對象**：email, bank, platform, social media, service.  
**與 password 的辨析**：是 password 的情境限定版本，最適合帳戶安全語境。  
**使用限制**：若是裝置、Wi-Fi 或加密檔案，account password 不合適。

**EXAMPLE · 例句**  
You should use a different account password for each service.  
每項服務都應使用不同的帳戶密碼。

## Tier 3 — Broad security-code variant · 廣義安全碼變體

### 10 Security code

**Tier**：3  
**中文**：安全碼；保安代碼  
**語域**：neutral / broad  
**核心語義**：a confidential code used as part of a security or verification process  
**用法提示**：在某些介面或服務中可和 password 功能重疊，但 security code 範圍更廣。  
**常見搭配**：security code; enter the security code; verification code; code security; security check.  
**常見搭配對象**：account, payment, device, verification, access.  
**與 password 的辨析**：Security code 可能是固定碼，也可能是短期驗證碼。  
**使用限制**：信用卡 CVV、一次性驗證碼等也叫 security code，因此不是精確同義詞。

**EXAMPLE · 例句**  
The system asked for a security code before allowing access.  
系統在允許存取前要求輸入安全碼。

## 04 False synonyms / password traps · 容易誤選的詞與密碼概念陷阱

### 01 PIN

**PIN 不等於一般 password**  
PIN 通常是純數字、長度較短，而且多用於裝置、銀行卡或身份驗證。

**ENGLISH COMPARISON**  
A PIN is a specific numeric credential.

### 02 Username

**使用者名稱不等於 password**  
username 用來識別帳戶；password 用來驗證身份。

**ENGLISH COMPARISON**  
A username identifies; a password authenticates.

### 03 One-time password (OTP)

**一次性密碼不等於固定 password**  
OTP 只在短時間內或單次有效。

**ENGLISH COMPARISON**  
An OTP is temporary and single-use.

### 04 Verification code

**驗證碼不等於 password**  
verification code 常透過短訊／電郵發送，用於額外驗證。

**ENGLISH COMPARISON**  
A verification code is usually temporary.

### 05 Passcode

**通行碼與 password 有重疊但不完全相同**  
passcode 常指數字碼或裝置解鎖碼。

**ENGLISH COMPARISON**  
Passcode is often device- or code-focused.

### 06 Security question

**保安問題不等於 password**  
security question 是另一種身份驗證方式。

**ENGLISH COMPARISON**  
A security question is a separate authentication method.

### 07 Credential

**憑證比 password 更廣**  
credential 可包括 username、password、token、certificate 等。

**ENGLISH COMPARISON**  
Credential is a broader category.

### 08 Password / passphrase

**詞義陷阱**  
password 通常較短；passphrase 通常較長，常由多個詞組成。

**ENGLISH COMPARISON**  
A passphrase is usually longer than a password.

## 07 Direct contrasts · 核心辨析

- **password vs passphrase**: passphrase 通常更長，常由多個詞組成。
- **password vs PIN**: PIN 通常是短數字碼。
- **password vs username**: username 識別帳戶；password 驗證身份。
- **password vs login credential**: credential 是上位詞，可包括多種登入資料。
- **password vs login code**: login code 強調用途，且可能是一次性。
- **password vs OTP**: OTP 只在短時間／單次有效。
- **password vs verification code**: verification code 通常是額外驗證步驟。
- **password vs access code**: access code 可用於門禁、裝置、臨時存取等。
- **password vs security code**: security code 更廣，也可能不是固定密碼。
- **password vs authentication secret**: 後者是資安技術術語，範圍更廣。

## 08 Grammar, security terminology & password traps · 文法、資安術語與密碼陷阱

- **password** 可數：a password / several passwords。
- **strong password** / **unique password** / **reset your password** 都是高頻搭配。
- **passphrase** 通常較長，常由多個詞組成。
- **credentials** 常用複數：login credentials / sign-in credentials。
- **username + password** 常共同構成一組 login credentials。
- **login code / verification code / OTP** 可能是短期碼，不一定等於固定 password。
- **access code** 可用於帳戶、門禁、裝置或其他受限制資源。
- **PIN** 通常是 numeric code；不要把所有 password 都叫 PIN。
- **password manager** 儲存 passwords / credentials。
- **authentication secret** 是技術術語，常見於 security engineering。
- **account password** 適合明確帳戶安全語境。
- 不要透過電郵或訊息分享 **passwords / credentials**；這是語義示例，不是特定平台安全指示。
- **password-protected** 是常見複合形容詞：a password-protected file。
