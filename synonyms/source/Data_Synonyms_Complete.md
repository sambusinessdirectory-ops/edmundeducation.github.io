# 01 同義詞指南

## Data 的 14 種更精準說法

### 01 Information

資訊；資料

最常見的近義詞之一，表示經過收集、整理或傳達而可供理解和使用的資料內容。

**EXAMPLE · 例句**

The survey provides useful information about customer habits.

這項調查提供有關顧客習慣的有用資訊。

### 02 Figures

數字；數據

常指以數值形式呈現的資料，例如銷售額、人口、成本或比例。

**EXAMPLE · 例句**

The latest figures show a fall in unemployment.

最新數字顯示失業率下降。

### 03 Records

紀錄；記錄資料

表示被保存下來以供查閱的資料，常見於醫療、行政、交易和歷史語境。

**EXAMPLE · 例句**

The hospital keeps detailed records of every patient's treatment.

醫院保存每名病人的詳細治療紀錄。

### 04 Statistics

統計數據

表示經收集、整理和分析的數值資料，常用於研究、政府和商業報告。

**EXAMPLE · 例句**

The statistics indicate that road accidents have declined.

統計數據顯示交通意外有所下降。

### 05 Facts

事實；資料

當 `data` 指可核實、客觀的資訊內容時，可用 `facts`，但語氣更偏向已知事實。

**EXAMPLE · 例句**

We need the facts before making a decision.

作決定前，我們需要掌握事實。

### 06 Details

詳細資料；細節

強調資料中的具體項目或細節，而不是整體數據集合。

**EXAMPLE · 例句**

Please send us the details of the incident.

請把事故的詳細資料傳給我們。

### 07 Readings

讀數；測量數據

常指由儀器、感測器或測試得到的數值資料。

**EXAMPLE · 例句**

The sensor sends temperature readings every minute.

感測器每分鐘傳送一次溫度讀數。

### 08 Measurements

測量數據；測量結果

表示透過量度得到的長度、溫度、速度、重量或其他數值。

**EXAMPLE · 例句**

The researchers compared measurements taken at five different sites.

研究人員比較了五個不同地點取得的測量數據。

### 09 Observations

觀察資料；觀察結果

常見於研究和科學語境，指透過觀察記錄所得的資料。

**EXAMPLE · 例句**

The study is based on observations collected over six months.

這項研究建基於六個月內收集的觀察資料。

### 10 Results

結果；結果數據

當 `data` 指測試、分析、調查或實驗所得的結果時，可用 `results`。

**EXAMPLE · 例句**

The test results were entered into the database.

測試結果被輸入資料庫。

### 11 Findings

研究發現；調查結果

較正式，表示分析資料後得出的主要發現或結論。

**EXAMPLE · 例句**

The findings suggest that the new method is more effective.

研究結果顯示新方法更有效。

### 12 Metrics

指標數據；量化指標

常用於商業、產品、技術和績效分析，指用來衡量表現的量化數據。

**EXAMPLE · 例句**

The dashboard tracks key performance metrics in real time.

儀表板即時追蹤主要績效指標。

### 13 Values

數值；數據值

常見於數學、科學和資料分析，指某個變數或欄位所記錄的具體數值。

**EXAMPLE · 例句**

Missing values were removed before the analysis.

分析前已刪除缺失數值。

### 14 Entries

資料項目；記錄項

表示資料庫、表格、清單或系統中的個別資料記錄。

**EXAMPLE · 例句**

The database contains more than two million entries.

這個資料庫包含超過二百萬筆資料。

# 02 False synonyms

看起來相關，意思卻不同。`data` 是被收集、記錄、量度或分析的資料內容；knowledge、opinion、database、report 等可能和資料相關，但分別指理解、看法、儲存系統或呈現文件，不能一般地互換。

### 01 Knowledge

知識不等於資料

`knowledge` 是理解和掌握後形成的知識；`data` 可以只是尚未解讀的原始資料。

**ENGLISH COMPARISON**

Data can be collected first and turned into knowledge through analysis.

### 02 Opinion

意見不等於資料

`opinion` 是個人看法；`data` 通常應是可記錄、量度或驗證的資訊。

**ENGLISH COMPARISON**

An opinion is subjective; data can provide evidence for evaluating it.

### 03 Evidence

證據不完全等於 data

資料可以成為 evidence，但只有當它被用來支持某個主張時才帶有『證據』功能。

**ENGLISH COMPARISON**

The data became evidence when it was used to support the claim.

### 04 Database

資料庫不等於資料

`database` 是儲存和組織 data 的系統；不是資料本身。

**ENGLISH COMPARISON**

The database stores the data.

### 05 Report

報告不等於資料

`report` 是呈現和解釋資料的文件；資料只是報告中的內容之一。

**ENGLISH COMPARISON**

The report summarizes data collected during the study.

### 06 Data / datum

複數／單數形式不同

傳統上 `datum` 是單數、`data` 是複數；現代英語中 `data` 亦常作集合名詞使用。

**ENGLISH COMPARISON**

One datum was missing. The data were analysed carefully.

### 07 Data / database

字形相關但功能不同

`data` 是內容；`database` 是保存、整理和檢索資料的系統。

**ENGLISH COMPARISON**

The database contains customer data.

### 08 Statistic / statistics

單項數字與統計資料不同

`a statistic` 通常是一項統計數字；`statistics` 可指統計數據或統計學。

**ENGLISH COMPARISON**

One statistic stood out, but the full statistics told a broader story.

## 練習 01.1

**Target word: Information · 資訊；資料**

**READ THE CONTEXT · 閱讀語境**

The survey collected data about customer habits and preferences.

**中文翻譯**

這項調查收集有關顧客習慣和偏好的資料。

A. opinion
B. database
C. information
D. report
E. knowledge
F. statistics

**CORRECT ANSWER · 正確答案**

**information · 資訊；資料**

The survey collected information about customer habits and preferences.

**SIX-OPTION FEEDBACK · 六個選項的解釋**

**A. opinion**
opinion = 調查可收集意見，但本句泛指 habits and preferences 的資料內容。

**B. database**
database = 資料庫是儲存工具，不是被收集的內容。

**C. information ✓**
information = 顧客習慣和偏好可以包含文字、選項和描述，不一定只有數字，因此 `information` 最自然。

**D. report**
report = 報告是之後整理資料的文件。

**E. knowledge**
knowledge = 收集到的資料尚未必形成知識。

**F. statistics**
statistics = 本句沒有說資料一定是數值型。
