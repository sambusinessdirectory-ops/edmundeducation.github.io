# SYNONYMS · 同義詞學習系統

# Box

核心近義與近義表達：

**container; carton; case; package; crate; chest; storage container; receptacle**

> **核心詞數不固定。** 本課保留 **8 個**自然且辨析價值高的核心表達。  
> 你提供的 **container; carton; case** 全部保留。  
> 本課只處理 `box = a container used for holding, storing, protecting, packaging, or transporting things`。

---

# 01 同義詞指南


## 01 Container

**容器；盛載物**

當 `box` 的核心只是『用來盛載、存放或運送物品的東西』，而材質、形狀並不重要時，`container` 最自然。

### EXAMPLE · 例句

Put the cables back in the container after use.

使用後請把電線放回容器內。

### COMMON COLLOCATIONS · 常見搭配


- plastic container

- sealed container

- labelled container

- general-purpose container


### DIAGNOSTIC QUESTION · 判斷問題

# 02 False synonyms


## 01 Container

**最廣泛**

任何用來盛載東西的容器都可能是 container，但 container 不一定是 box。

### ENGLISH COMPARISON

Put the parts in a container.

---

## 02 Carton

**材質／包裝義更強**

常見於 food packaging, milk cartons, shipping cartons；通常和紙板相關。

### ENGLISH COMPARISON

The bottles were packed in a carton.

---

## 03 Case

**保護用途**

常見於 glasses case, violin case, tool case。

### ENGLISH COMPARISON

He put the violin back in its case.

---

## 04 Package

**交付／寄送單位**

一個 package 可以是 box、袋或其他包裝形式。

### ENGLISH COMPARISON

Your package is out for delivery.

---

## 05 Crate

**大型運輸箱**

常見於 fruit, bottles, equipment, shipping。

### ENGLISH COMPARISON

The apples arrived in wooden crates.

---

## 06 Chest

**大型長期存放**

常見於 toy chest, storage chest, treasure chest。

### ENGLISH COMPARISON

The blankets were kept in a wooden chest.

---

## 07 Box / boxing

**詞形與其他義**

`box` 作名詞是盒／箱；`box` 亦可作動詞指拳擊或裝箱。本課只處理容器義。

### ENGLISH COMPARISON

Put it in a box; they box professionally.

---

## 08 Box

**形狀不等於功能**

近義詞要按材質、用途、保護需求和規模選。

### ENGLISH COMPARISON

a carton for packaging; a case for protection; a crate for transport

- **A. container ✓** — `container` = 泛指用來盛載、存放或運送物品的容器。 **本句為何最合適：** only the general holding function matters。

- **D. carton** — `carton` = 紙板／硬紙製成的盒或包裝箱。 需要紙板包裝語境；木箱、硬殼保護盒或家具式大箱不適合。 **本句線索：** only the general holding function matters。

- **E. decoration** — `decoration` = 裝飾物。 不是盛載物。 **本句線索：** only the general holding function matters。

- **F. surface** — `surface` = 表面。 只是表面。 **本句線索：** only the general holding function matters。

# 05 高價值近義詞對比

- **container**：最廣，不說明材質或用途。
- **carton**：常見於紙板食品／飲品／貨運包裝。
- **case**：重點是保護，例如 glasses case / violin case。
- **package**：重點是 shipping / delivery / tracking。
- **crate**：通常更大、更堅固、更偏運輸。
- **chest**：大型、有蓋、家具式長期存放。
- **storage container**：專門強調整理和收納。
- **receptacle**：正式、技術或行政語域的接收／盛載容器。
