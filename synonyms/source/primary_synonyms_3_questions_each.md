# SYNONYMS · 同義詞學習系統

# Primary

**本課集中在 `primary = elementary / first-stage / basic` 的「初級、基礎、最初階段」意思，而不是 `primary = main / most important`。不同替代表達會按教育程度、基本程度、程序次序、入門功能、奠基作用和成熟程度來區分。**

核心替代表達：

`elementary / basic / first-stage / introductory / foundational / initial / preliminary / rudimentary`

> **核心原則**：先判斷 primary 指的是 **beginner level, basic essentials, first stage, introduction to a subject, foundation for later learning, first point in time, preparatory stage, or very undeveloped/basic ability**。

# 01 同義詞指南

## 01 Elementary

**初級的；基礎的**

當 `primary` 指學習、教育或知識層面的最初級階段時，`elementary` 很自然。它常形容 education, level, mathematics, language skills。

**EXAMPLE · 例句**

> The course begins with elementary grammar before moving to advanced structures.

課程先由初級文法開始，之後才進入進階句式。

**SEMANTIC CUE · 語義提示**

> **at a very basic or beginner level**

**REGISTER · 語域**

教育、一般、正式

---

## 02 Basic

**基本的；基礎的**

最廣泛的近義詞之一，表示最根本、最簡單或最低限度需要掌握的內容。比 `elementary` 更廣，不限教育語境。

**EXAMPLE · 例句**

> All staff receive basic safety training.

所有員工都接受基本安全訓練。

**SEMANTIC CUE · 語義提示**

> **forming the simplest or most essential level**

**REGISTER · 語域**

所有語域

---

## 03 First-stage

**第一階段的；初階的**

描述性很強，表示某程序、計劃、治療或學習路徑中的第一個階段。它比 `primary` 更直接說明先後次序。

**EXAMPLE · 例句**

> First-stage screening identifies applicants who need further assessment.

第一階段篩查會識別需要進一步評估的申請人。

**SEMANTIC CUE · 語義提示**

> **belonging to the first stage of a process**

**REGISTER · 語域**

程序、政策、教育

---

## 04 Introductory

**入門的；初步介紹的**

當 `primary` 指為初學者提供入門概念時，`introductory` 很精準。它強調介紹和建立初步理解，而不是完整掌握基礎技能。

**EXAMPLE · 例句**

> Students take an introductory course in economics.

學生修讀經濟學入門課程。

**SEMANTIC CUE · 語義提示**

> **designed to introduce a subject to beginners**

**REGISTER · 語域**

教育、正式、一般

---

## 05 Foundational

**基礎性的；奠基的**

強調某知識、技能或原則是之後學習／發展的基礎。比 `basic` 更有『為後續建立根基』的意味。

**EXAMPLE · 例句**

> Reading is a foundational skill for later learning.

閱讀是日後學習的基礎技能。

**SEMANTIC CUE · 語義提示**

> **providing the foundation for later development**

**REGISTER · 語域**

教育、專業、正式

---

## 06 Initial

**最初的；初步的**

當 `primary` 指時間或程序上的最初階段時，`initial` 很自然。它只表示『最先』，不一定表示內容很簡單。

**EXAMPLE · 例句**

> The initial assessment takes about twenty minutes.

初步評估大約需時二十分鐘。

**SEMANTIC CUE · 語義提示**

> **occurring at the beginning of a process**

**REGISTER · 語域**

正式、程序、一般

---

## 07 Preliminary

**初步的；預備性的**

表示正式主體工作之前的初步步驟、測試或討論。比 `initial` 更有『為之後正式階段作準備』的意味。

**EXAMPLE · 例句**

> The team carried out a preliminary inspection before the full survey.

團隊在全面勘察前進行初步檢查。

**SEMANTIC CUE · 語義提示**

> **done in preparation for a later, fuller stage**

**REGISTER · 語域**

正式、研究、程序

---

## 08 Rudimentary

**初步的；粗淺的；尚未完善的**

比 `basic` 更強，通常表示只有最簡單、最不完整的技能或系統。常帶『仍然很初級』的語氣，未必完全中性。

**EXAMPLE · 例句**

> He has only a rudimentary knowledge of coding.

他對編程只有很粗淺的認識。

**SEMANTIC CUE · 語義提示**

> **very basic and not yet fully developed**

**REGISTER · 語域**

正式、描述性

---

# 02 False synonyms

## Primary / Elementary
`elementary` 最適合教育、知識和技能的初級層面。

**ENGLISH COMPARISON**  
Elementary grammar is suitable for beginners.  
Basic safety information may be needed by everyone, not only beginners.

## Primary / Basic
`basic` 最廣，表示最根本或最低限度需要的內容。

**ENGLISH COMPARISON**  
Basic computer skills are enough for simple tasks.  
Elementary mathematics refers more specifically to an early learning level.

## Primary / First-stage
`first-stage` 只表示在多階段流程中排第一。

**ENGLISH COMPARISON**  
First-stage screening comes before later assessment.  
Basic screening describes simplicity, not necessarily sequence.

## Primary / Introductory
`introductory` 強調「讓初學者認識主題」。

**ENGLISH COMPARISON**  
An introductory lecture presents the main ideas of a subject.  
A basic skill may be essential even after the introduction is over.

## Primary / Foundational
`foundational` 強調「為後續建立根基」。

**ENGLISH COMPARISON**  
Reading is a foundational skill for later learning.  
An introductory lesson simply introduces a topic.

## Primary / Initial
`initial` 表示最初發生的，不一定簡單。

**ENGLISH COMPARISON**  
The initial interview is the first interview.  
An elementary interview exercise would be designed for beginners.

## Initial / Preliminary
`preliminary` 更強調為後續正式／完整階段作準備。

**ENGLISH COMPARISON**  
The initial response was positive.  
A preliminary inspection was carried out before the full survey.

## Basic / Rudimentary
`rudimentary` 比 basic 更強，常表示非常粗淺、尚未成熟。

**ENGLISH COMPARISON**  
She has basic computer skills for everyday work.  
He has only rudimentary coding knowledge and needs substantial training.

# 03 練習與解釋

> 每個目標詞／表達三題，共 **24 題**。  
> 每題六個選項；正確答案位置在 **A–F 各出現四次**。  
> 每個選項都按本句的教育層級、程序先後、功能、搭配和詞性作具體解釋。

## 練習 01.1

**Target phrase: Elementary · 初級的；基礎的**

### READ THE CONTEXT · 閱讀語境

> The course starts with primary grammar for complete beginners.

**中文翻譯**

課程由完全初學者適合的初級文法開始。

| | 選項 |
|---|---|
| A | elementary |
| B | basic |
| C | introductory |
| D | foundational |
| E | element |
| F | advanced |

### CORRECT ANSWER · 正確答案

**A. elementary · 初級的；基礎的**

> The course starts with elementary grammar for complete beginners.

### SIX-OPTION FEEDBACK · 六個選項的解釋

**A. elementary ✓**  
線索「complete beginners + grammar」明確是初學／初級知識層面，`elementary` 比一般 `basic` 更有教育階段意味。

**B. basic**  
`basic`：基本的；最簡單或最必要的層級。 本句線索是「complete beginners + grammar」；它強調的是另一種層級、時間次序、功能或成熟程度，因此不是這句最佳替代。

**C. introductory**  
`introductory`：入門的；為初學者介紹一個主題。 本句線索是「complete beginners + grammar」；它強調的是另一種層級、時間次序、功能或成熟程度，因此不是這句最佳替代。

**D. foundational**  
`foundational`：基礎性的；為之後發展奠基。 本句線索是「complete beginners + grammar」；它強調的是另一種層級、時間次序、功能或成熟程度，因此不是這句最佳替代。

**E. element**  
`element`：元素；名詞，不是形容詞。 本句線索是「complete beginners + grammar」；除語義不合外，詞性、構詞或拼寫形式也不能直接放進這個位置。

**F. advanced**  
`advanced`：進階的；和 elementary 相反。 本句線索是「complete beginners + grammar」；它強調的是另一種層級、時間次序、功能或成熟程度，因此不是這句最佳替代。

# 05 高價值近義詞辨析

- **Elementary vs Basic** — elementary 更偏初學層級；basic 最廣。
- **Basic vs Foundational** — basic = 簡單／必要；foundational = 為後續奠基。
- **First-stage vs Initial** — first-stage 明確屬多階段流程；initial 只表示最先。
- **Initial vs Preliminary** — preliminary 更有「為之後正式階段作準備」意味。
- **Introductory vs Elementary** — introductory 偏介紹主題；elementary 偏初級能力層面。
- **Foundational vs Introductory** — foundational 是根基；introductory 是入口。
- **Basic vs Rudimentary** — rudimentary 更粗淺、更未成熟。
- **Primary vs Main** — 本課不處理 `primary = main / principal` 的另一個常見意思。

# 08 Grammar & structure traps

## First-stage
作前置複合形容詞通常用連字號：

> first-stage screening

但名詞片語：

> the first stage of the process

## Introductory / introduction
> an introductory course = 形容詞  
> an introduction to economics = 名詞

## Foundational / foundation
> foundational knowledge = 形容詞  
> a foundation for learning = 名詞

## Initial / initially
> initial response = 形容詞  
> initially, customers were cautious = 副詞

## Preliminary / preliminarily
> preliminary results = 形容詞  
> preliminarily approved = 副詞用法，較正式

## Rudimentary / rudiments
> rudimentary knowledge = 形容詞  
> the rudiments of coding = 基本原理

# 09 核心決策問題

1. 初學者／初級教育程度？ → **elementary**
2. 最基本、最低限度？ → **basic**
3. 多階段流程的第一階段？ → **first-stage**
4. 只是讓新手入門？ → **introductory**
5. 為之後學習奠基？ → **foundational**
6. 單純表示最先發生？ → **initial**
7. 正式／完整階段前的預備工作？ → **preliminary**
8. 非常粗淺、尚未成熟？ → **rudimentary**

# 10 Final note for system use

核心替代表達：

`elementary / basic / first-stage / introductory / foundational / initial / preliminary / rudimentary`

尤其要記住：

> **elementary** = 初級  
> **basic** = 基本  
> **first-stage** = 第一階段  
> **introductory** = 入門  
> **foundational** = 奠基  
> **initial** = 最初  
> **preliminary** = 預備性初步  
> **rudimentary** = 粗淺、未成熟

本課不處理 `primary = main / chief / principal` 的「主要、首要」意思。
