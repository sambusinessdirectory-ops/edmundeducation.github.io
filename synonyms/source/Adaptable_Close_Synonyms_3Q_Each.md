# ADAPTABLE · 同義詞學習系統

## Adaptable

**「能適應／可調整」，有哪些真正接近、幾乎可互換的說法？**

本單元只保留和 **adaptable** 語義高度接近、在常見語境中可直接替換或只需小幅改寫的詞。不同替代詞仍受主語類型和搭配限制：人／團隊較常用 **flexible, versatile, responsive**；物件和設定較常用 **adjustable, modifiable, customisable**。

> **New practice format**: 從本單元開始，每個同義詞提供 **3 道練習題**。

## 01 Close synonyms · 接近同義詞

### 01 Flexible

**中文**：靈活的；能適應變化的  
**語域**：neutral / very common  
**核心語義**：able and willing to change according to circumstances  
**用法提示**：與 adaptable 最接近的常用詞之一。形容人、計劃、制度或方法能因應不同需要而改變，不僵化。

**EXAMPLE · 例句**  
A flexible team can adjust quickly when priorities change.  
靈活的團隊能在工作優先次序改變時迅速調整。

### 02 Adjustable

**中文**：可調校的；可調整的  
**語域**：neutral / common  
**核心語義**：capable of being changed in setting, size, position, or configuration  
**用法提示**：非常接近 adaptable 的『可以調整』一面，但主要形容物件、設定、設備或系統，而不是人的性格。

**EXAMPLE · 例句**  
The chair has an adjustable backrest to suit different users.  
這張椅子的椅背可調校，以配合不同使用者。

### 03 Versatile

**中文**：多用途的；多才多能的；適應性強的  
**語域**：neutral / common  
**核心語義**：able to function effectively in many different roles or situations  
**用法提示**：當 adaptable 表示能在多種用途、角色或情境中有效運作時很接近。比 flexible 更突出『用途／能力多樣』。

**EXAMPLE · 例句**  
She is a versatile employee who can work effectively across several departments.  
她是一名多才多能的員工，能在多個部門有效工作。

### 04 Modifiable

**中文**：可修改的；可改動的  
**語域**：formal / technical  
**核心語義**：capable of being changed to suit different requirements  
**用法提示**：較正式，主要形容設計、系統、文件、計劃或結構可以被修改以配合不同需要。偏被動『可以改』，不像 adaptable 那麼強調自行適應。

**EXAMPLE · 例句**  
The template is easily modifiable for different types of reports.  
這個範本很容易修改，以配合不同類型的報告。

### 05 Customisable

**中文**：可自訂的；可按需要調整的  
**語域**：neutral / technical  
**核心語義**：capable of being tailored to different users or needs  
**用法提示**：適合軟件、產品、介面或系統。強調可以按使用者或情境需要調整。

**EXAMPLE · 例句**  
The dashboard is highly customisable and can display different data for each team.  
這個儀表板高度可自訂，可為不同團隊顯示不同資料。

### 06 Responsive

**中文**：反應靈活的；能迅速因應的  
**語域**：neutral to formal  
**核心語義**：quick to react appropriately to changing needs or conditions  
**用法提示**：當 adaptable 強調對新情況、需求或變化作出反應時很接近。常見於組織、制度、設計或管理。

**EXAMPLE · 例句**  
A responsive organisation changes its services when community needs shift.  
反應靈活的機構會在社區需要改變時調整服務。

### 07 Able to adjust

**中文**：能夠調整；能適應  
**語域**：neutral / explanatory  
**核心語義**：capable of changing behaviour or method when needed  
**用法提示**：最直接的解釋性改寫。當不需要更精煉的單字時，可非常準確地表達 adaptable 的核心意思。

**EXAMPLE · 例句**  
Good managers are able to adjust their approach when circumstances change.  
好的管理者能在情況改變時調整自己的做法。

### 08 Able to respond to change

**中文**：能因應變化；能對變化作出反應  
**語域**：neutral / explanatory  
**核心語義**：capable of reacting effectively when conditions change  
**用法提示**：非常貼近 adaptable 的核心釋義，尤其適合解釋人、組織或系統面對新情況時的適應能力。

**EXAMPLE · 例句**  
Small businesses must be able to respond to change in customer demand.  
小型企業必須能因應顧客需求的變化。

## 02 False / weaker synonyms · 容易誤當同義詞的詞

### 01 Resilient

**恢復力強不等於可適應**  
resilient 強調受壓或受挫後恢復；adaptable 強調改變做法以配合新情況。

**ENGLISH COMPARISON**  
A resilient person recovers from setbacks; an adaptable person changes approach when circumstances change.

### 02 Stable

**穩定不等於靈活**  
stable 強調不容易改變；adaptable 恰恰強調能因應需要而改變。

**ENGLISH COMPARISON**  
A stable system stays consistent; an adaptable system can change when needed.

### 03 Changeable

**容易改變不等於善於適應**  
changeable 可表示經常改變甚至反覆無常；adaptable 帶有有效調整的正面意味。

**ENGLISH COMPARISON**  
Weather can be changeable; a good plan is adaptable.

### 04 Variable

**有變化不等於能適應**  
variable 表示會變動；adaptable 表示能對變動作出有效調整。

**ENGLISH COMPARISON**  
Demand may be variable, while staffing needs to be adaptable.

### 05 Compliant

**順從不等於適應**  
compliant 表示服從規則或要求；adaptable 表示靈活因應新情況。

**ENGLISH COMPARISON**  
A compliant employee follows rules; an adaptable employee can change methods when needed.

### 06 Portable

**可攜帶不等於可調整**  
portable 表示容易攜帶或移動；不表示能改變功能、設定或行為。

**ENGLISH COMPARISON**  
A laptop is portable, but software is adaptable only if it can change to suit different needs.

## 03 練習與解釋

### 練習 01.1

**Target word / phrase**: Flexible · 靈活的；能適應變化的

**READ THE CONTEXT · 閱讀語境**

An adaptable schedule allows staff to change working hours when necessary.

**中文翻譯**  
靈活的時間表讓員工在有需要時調整工作時間。

- A. flexible
- B. stable
- C. resilient
- D. portable
- E. compliant
- F. variable

**CORRECT ANSWER · 正確答案**

**flexible** · 靈活的；能適應變化的

A flexible schedule allows staff to change working hours when necessary.

**SIX-OPTION FEEDBACK · 六個選項的解釋**

- **A. flexible ✓ = 與本題中的 adaptable 語義和搭配最接近。**
- **B. stable = 穩定、不易改變；與 adaptable 強調能因應變化不同。**
- **C. resilient = 能從壓力或挫折中恢復；不等於主動調整以適應新情況。**
- **D. portable = 易於攜帶或移動；不表示能改變設定、功能或行為。**
- **E. compliant = 順從、符合規定；不等於靈活適應。**
- **F. variable = 會變動、不固定；只表示有變化，不表示能有效適應。**

## 04 Semantic map · 語義總覽

| Adaptable 的語境 | 最接近的替換 | 核心差別 |
|---|---|---|
| 人／團隊／政策能因應不同需要 | **flexible** | 最廣泛、最接近 |
| 物件／設定可以調校 | **adjustable** | 偏物理或設定上的調整 |
| 能勝任多種角色／用途 | **versatile** | 突出多用途、多能力 |
| 設計／文件／系統可以修改 | **modifiable** | 偏被動『可被修改』 |
| 軟件／產品可按使用者需要自訂 | **customisable** | 偏個人化設定 |
| 組織／系統能迅速回應新需要 | **responsive** | 突出對變化作出反應 |
| 直接解釋『能調整』 | **able to adjust** | 最透明的意譯 |
| 直接解釋『能因應變化』 | **able to respond to change** | 最貼近核心定義 |

## 05 Core contrast notes

- **adaptable vs flexible**: 最接近的一組；flexible 更突出不僵化、願意改變，adaptable 更突出適應新情況。
- **adaptable vs adjustable**: adjustable 主要用於可以調校的物件或設定；形容人通常用 adaptable/flexible。
- **adaptable vs versatile**: versatile 強調多用途或能勝任多種角色；adaptable 強調因環境改變而調整。
- **adaptable vs modifiable**: modifiable 表示可被修改；adaptable 可表示系統本身能適應新要求。
- **adaptable vs customisable**: customisable 強調由使用者按需要設定；adaptable 的範圍更廣。
- **adaptable vs responsive**: responsive 更突出快速對外界變化作反應；adaptable 也可包括較長期的調整。
- **resilient** 不等於 adaptable：前者是恢復力，後者是調整能力。
