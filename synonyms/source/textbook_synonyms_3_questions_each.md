# SYNONYMS · 同義詞學習系統

# Textbook

**`textbook` 可以表示課程主教材、學校課本、學習文本、入門讀本、學生用書、教學文本、技術手冊或參考書。不同替代表達的核心差別，是「是否配合課程」「是否面向學生」「是否入門」「是否實務操作」「是否主要供查閱」。**

核心替代表達：

`coursebook / schoolbook / learning text / primer / student book / instructional text / manual / reference book`

> **核心原則**：先判斷 textbook 指的是 **main coursebook, general schoolbook, learning text, introductory primer, student-facing book, instructional text, practical manual, or reference book**。

---

# 01 同義詞指南

## 01 Coursebook

**課程教材；課本**

某一課程的主要用書，尤其常見於語言課程；強調按單元和課程進度使用。

**EXAMPLE · 例句**

> Students use the coursebook for reading, grammar, and vocabulary practice.

學生使用課程教材進行閱讀、文法和詞彙練習。

**SEMANTIC CUE · 語義提示**

> **直接配合課程單元與進度**

---

## 02 Schoolbook

**學校課本；教科書**

在學校使用的課本或教材，範圍比正式 textbook 稍廣。

**EXAMPLE · 例句**

> The old schoolbook contains maps that are now out of date.

這本舊學校課本載有現已過時的地圖。

**SEMANTIC CUE · 語義提示**

> **泛指在學校使用的課本**

---

## 03 Learning text

**學習文本；教材文本**

作為學習材料的主要文字內容；較描述性，常見於教育設計和教材分析。

**EXAMPLE · 例句**

> The learning text introduces the key concepts before the exercises.

學習文本在練習前介紹核心概念。

**SEMANTIC CUE · 語義提示**

> **聚焦作為學習材料的文字本身**

---

## 04 Primer

**入門讀本；初級教材**

為初學者介紹一個主題的基本概念；比一般 textbook 更窄。

**EXAMPLE · 例句**

> The book is a useful primer on basic economics.

這本書是基礎經濟學的實用入門讀本。

**SEMANTIC CUE · 語義提示**

> **明確是初學者入門**

---

## 05 Student book

**學生用書；學生課本**

教材套裝中學生主要使用的書，常與 teacher's book、workbook 配套。

**EXAMPLE · 例句**

> Open your student book to Unit 6.

請把學生用書翻到第六單元。

**SEMANTIC CUE · 語義提示**

> **是教材套裝中的學生版本**

---

## 06 Instructional text

**教學文本；教學用書**

以教授知識、程序或概念為目的的文字材料；範圍比 textbook 更廣。

**EXAMPLE · 例句**

> The instructional text explains each process step by step.

這份教學文本逐步解釋每個程序。

**SEMANTIC CUE · 語義提示**

> **以教授知識或程序為主要功能**

---

## 07 Manual

**手冊；操作教材**

偏向操作、程序、技術訓練和實務指引。

**EXAMPLE · 例句**

> The training manual explains how to operate the equipment safely.

培訓手冊解釋如何安全操作設備。

**SEMANTIC CUE · 語義提示**

> **以操作步驟和程序指引為核心**

---

## 08 Reference book

**參考書**

主要用來查閱資料，而不是從頭到尾按課程順序學習。

**EXAMPLE · 例句**

> The dictionary is kept as a reference book rather than a course textbook.

這本字典作為參考書使用，而不是課程課本。

**SEMANTIC CUE · 語義提示**

> **主要功能是查閱而非順序學習**

# 02 False synonyms

## Textbook / Coursebook
`coursebook` 特別強調跟隨某一課程的單元、進度和主要內容，尤其常見於語言學習。

**ENGLISH COMPARISON**  
The textbook explains grammar.  
The coursebook follows the twelve-week language course.

## Textbook / Schoolbook
`schoolbook` 更廣泛，只表示學校使用的課本或教材。

**ENGLISH COMPARISON**  
This is the main science textbook.  
The museum displays several old schoolbooks.

## Textbook / Learning text
`learning text` 更像描述教材中的文字內容本身，不是最固定的日常書名類別。

**ENGLISH COMPARISON**  
The textbook contains exercises.  
Researchers analysed the learning text for vocabulary difficulty.

## Textbook / Primer
`primer` 只適合入門／初級教材。

**ENGLISH COMPARISON**  
A textbook may be advanced.  
A primer introduces the basics to beginners.

## Textbook / Student book
`student book` 常見於教材套裝，和 teacher's book、workbook 等互相區分。

**ENGLISH COMPARISON**  
The teacher uses the teacher's book.  
Learners follow the student book.

## Textbook / Instructional text
`instructional text` 範圍更廣，任何主要用來教概念或程序的文字材料都可以包括。

**ENGLISH COMPARISON**  
A textbook is usually book-length.  
An instructional text may be a shorter teaching document.

## Textbook / Manual
`manual` 偏操作、程序和實務指引，不是一般學術 textbook 的直接同義詞。

**ENGLISH COMPARISON**  
A physics textbook explains theory.  
A machine manual explains how to operate equipment.

## Textbook / Reference book
`reference book` 主要供查閱，而 textbook 通常按課程順序學習。

**ENGLISH COMPARISON**  
Students work through the textbook chapter by chapter.  
They consult the reference book when they need a fact.

# 05 高價值近義詞辨析

- **Textbook vs Coursebook** — coursebook 更強調跟隨課程進度。
- **Textbook vs Schoolbook** — schoolbook 更廣泛，只表示學校用書。
- **Coursebook vs Student book** — coursebook 是課程主教材；student book 是教材套裝中的學生版本。
- **Primer vs Textbook** — primer 必須偏入門、初階。
- **Manual vs Textbook** — manual 偏操作程序；textbook 偏系統學習知識。
- **Reference book vs Textbook** — reference book 供查閱；textbook 通常順序學習。
- **Learning text vs Instructional text** — learning text 偏學習內容本身；instructional text 偏教學目的。
- **Textbook ≠ workbook** — workbook 主要供學生做練習。

# 09 核心決策問題

1. 跟隨完整課程單元與進度？ → **coursebook**
2. 泛指學校使用的課本？ → **schoolbook**
3. 重點是教材文字本身？ → **learning text**
4. 專為初學者介紹基本概念？ → **primer**
5. 教材套裝中學生使用的主書？ → **student book**
6. 以教學為目的的文字材料？ → **instructional text**
7. 重點是操作程序／步驟？ → **manual**
8. 主要用來查資料而不是順序學習？ → **reference book**

# 10 Final note for system use

核心替代表達：

`coursebook / schoolbook / learning text / primer / student book / instructional text / manual / reference book`

最重要的一點：

> **textbook ≠ manual ≠ reference book**

三者分別偏向 **系統學習教材、操作指引、資料查閱**。
