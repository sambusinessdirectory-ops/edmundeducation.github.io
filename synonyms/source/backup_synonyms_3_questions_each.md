# SYNONYMS · 同義詞學習系統

# Backup (noun)

**`backup` 可以表示後備資源、主方案失敗時的第二方案、應變計劃、一般替代選項、實體備用品、待命人員／設備、安全網，或資料／文件的備份副本。不同替代表達的核心差別，是『what is being backed up』以及『when it is used』。**

核心替代表達：

`reserve / fallback / contingency plan / alternative / spare / standby / safety net / backup copy`

---

# 01 同義詞指南

## 01 Reserve

**儲備；後備資源**

當 `backup` 指預留的人手、物資、資金或資源，以便主要資源不足或失效時使用，`reserve` 很自然。它強調 kept in reserve。

**EXAMPLE · 例句**

> The hospital keeps extra oxygen supplies in reserve.

醫院保留額外氧氣供應作後備。

**SEMANTIC CUE · 語義提示**

> **a supply or resource kept for use if needed**

**REGISTER · 語域**

所有語域

---

## 02 Fallback

**後備方案；退而求其次的選擇**

當 `backup` 指主要方案失敗時可以轉用的第二選擇，`fallback` 很精準。它比 alternative 更明確表示 secondary option。

**EXAMPLE · 例句**

> We need a fallback in case the venue becomes unavailable.

我們需要一個後備方案，以防場地不能使用。

**SEMANTIC CUE · 語義提示**

> **a secondary option used if the preferred option fails**

**REGISTER · 語域**

所有語域

---

## 03 Contingency plan

**應變計劃；後備計劃**

當 `backup` 指為可能發生的問題、故障、延誤或緊急情況預先準備的一套計劃時，`contingency plan` 很合適。它比 fallback 更完整、更正式。

**EXAMPLE · 例句**

> The team prepared a contingency plan for a network outage.

團隊為網絡中斷準備了應變計劃。

**SEMANTIC CUE · 語義提示**

> **a prearranged plan for dealing with a possible problem or emergency**

**REGISTER · 語域**

正式、工作、風險管理

---

## 04 Alternative

**替代方案；另一選擇**

當 `backup` 只表示可用的另一個方案、方法或選擇，而不一定只在主方案失敗後才用時，`alternative` 很自然。

**EXAMPLE · 例句**

> Train travel is a practical alternative to flying.

乘火車是飛行以外的一個實用替代方案。

**SEMANTIC CUE · 語義提示**

> **another available option or method**

**REGISTER · 語域**

所有語域

---

## 05 Spare

**備用品；後備物件**

當 `backup` 指額外預留的一件實體物品，例如鎖匙、輪胎、電池、充電器時，`spare` 很自然。它通常比 reserve 更具體、可數。

**EXAMPLE · 例句**

> Keep a spare key with someone you trust.

把一條後備鎖匙交給你信任的人保管。

**SEMANTIC CUE · 語義提示**

> **an extra item kept in case the main one is lost or fails**

**REGISTER · 語域**

所有語域

---

## 06 Standby

**待命後備；候補人員／資源**

當 `backup` 指人員、設備或服務已準備好，隨時可在需要時接替或投入使用，`standby` 很精準。它強調 readiness。

**EXAMPLE · 例句**

> A standby engineer was available throughout the event.

活動期間一直有後備工程師候命。

**SEMANTIC CUE · 語義提示**

> **a person or resource ready to be used if needed**

**REGISTER · 語域**

工作、技術、一般

---

## 07 Safety net

**安全網；保障後備**

當 `backup` 比喻性地指一項安排、資源或制度，在主要計劃失敗時提供保護或避免嚴重後果，`safety net` 很自然。

**EXAMPLE · 例句**

> Emergency savings provide a financial safety net.

緊急儲蓄提供財務安全網。

**SEMANTIC CUE · 語義提示**

> **a protective backup that reduces the consequences of failure**

**REGISTER · 語域**

一般、金融、社會政策

---

## 08 Backup copy

**備份副本**

當 `backup` 指資料、文件、照片或系統的額外副本，以防原本遺失、損壞或遭刪除時，`backup copy` 是最直接的完整表達。

**EXAMPLE · 例句**

> Keep a backup copy of the contract in cloud storage.

把合約備份副本存放在雲端儲存。

**SEMANTIC CUE · 語義提示**

> **an extra copy kept in case the original is lost or damaged**

**REGISTER · 語域**

科技、工作、一般

# 02 False synonyms

## Backup / Reserve
`reserve` 強調資源被保留不用，需要時才動用。

**ENGLISH COMPARISON**  
We keep extra staff as backup.  
We keep extra staff in reserve.

## Backup / Fallback
`fallback` 是主方案失敗時才啟用的第二方案。

**ENGLISH COMPARISON**  
Our backup is to move the meeting online.  
Our fallback is to move the meeting online if the office closes.

## Backup / Contingency plan
`contingency plan` 是為可能問題預先準備的一整套應變方案，比單一 fallback 更完整。

**ENGLISH COMPARISON**  
We have a backup for a power outage.  
We have a contingency plan for a power outage.

## Backup / Alternative
`alternative` 只是另一可行選擇，不一定要等第一方案失敗才使用。

**ENGLISH COMPARISON**  
Video conferencing is a backup to travel.  
Video conferencing is an alternative to travel.

## Backup / Spare
`spare` 特別適合具體實體物件，例如 key / tyre / battery / charger。

**ENGLISH COMPARISON**  
Keep a backup key.  
Keep a spare key.

## Backup / Standby
`standby` 強調人員／設備已經 ready，隨時可以接替或投入使用。

**ENGLISH COMPARISON**  
A backup technician was available.  
A standby technician was available throughout the event.

## Backup / Safety net
`safety net` 是比喻性保障，在主收入、主計劃或主要資源出問題時減輕後果。

**ENGLISH COMPARISON**  
Emergency savings are a financial backup.  
Emergency savings provide a financial safety net.

## Backup / Backup copy
`backup copy` 特別指資料、文件、圖片等額外副本，以防原件遺失或損壞。

**ENGLISH COMPARISON**  
Save a backup of the file.  
Save a backup copy of the file.

**Target phrase: Reserve · 儲備；後備資源**

### READ THE CONTEXT · 閱讀語境

> We keep extra staff as backup during the holiday rush.

**中文翻譯**

| B | standby |

| D | alternative |
| E | reserves |
| F | use every employee immediately |

### CORRECT ANSWER · 正確答案

**A. reserve · 儲備；後備資源**

**D. alternative**  
`alternative`：另一選擇；未必提供風險保護。 本句關鍵是「extra staff are being kept available rather than used at once」。因此它在資源儲備、替代方案、待命狀態、保障功能、實體備件或資料副本方面不如正確答案貼切。

**E. reserves**

# 04 Target-word / phrase contrast map

| `backup` 真正重點 | 較精準替代表達 |
|---|---|
| 保留不用、需要時才動用的資源 | **reserve** |
| 主方案失敗時的第二方案 | **fallback** |
| 預先設計好的應變方案 | **contingency plan** |
| 一般另一可行選擇 | **alternative** |
| 額外實體備用品 | **spare** |
| 隨時可接替的人／設備 | **standby** |
| 減輕失敗後果的保障 | **safety net** |
| 資料／文件的額外副本 | **backup copy** |

# 05 高價值近義詞辨析

- **Reserve vs Standby** — reserve = 被保留；standby = 已準備好、隨時可用。
- **Fallback vs Alternative** — fallback 通常第二順位；alternative 可以正常並列選擇。
- **Fallback vs Contingency plan** — fallback 可以只是一個 Plan B；contingency plan 通常是一整套預先安排。
- **Spare vs Reserve** — spare 常是一件具體物品；reserve 可是人手、資金、物資等較廣資源。
- **Safety net vs Fallback** — fallback 告訴你「改做甚麼」；safety net 告訴你「失敗後如何減少損失」。
- **Backup copy vs Spare** — backup copy 只適合資訊／文件副本；spare 是實體備件。
- **Backup ≠ replacement in every context** — replacement 通常已取代原本；backup 只是候補。
- **Backup ≠ duplicate in every context** — duplicate 是複製品；人手或計劃 backup 不一定是 duplicate。

# 08 Grammar & structure traps

- **in reserve** = 作後備保留
- **fallback** = noun/adjective：`a fallback option`
- **contingency plan for + risk/problem**
- **alternative to + noun/-ing**
- **spare + noun**：`spare key / spare battery`
- **standby + noun**：`standby generator / standby staff`
- **safety net for + person/system**
- **backup copy of + file/document**
- **back up** = verb；**backup** = noun/adjective
- **backup** 與 **back-up** 都可見，但現代科技用法通常常寫作 **backup**

# 09 核心決策問題

1. 是保留不用的後備資源？ → **reserve**
2. 是 Plan B？ → **fallback**
3. 是為風險預先設計的一整套方案？ → **contingency plan**
4. 只是另一個可行選擇？ → **alternative**
5. 是額外鎖匙／電池／輪胎？ → **spare**
6. 是已候命、隨時可以接替？ → **standby**
7. 是用來減少失敗後果的保障？ → **safety net**
8. 是檔案／文件的備份？ → **backup copy**

# 10 Final note for system use

核心替代表達：

`reserve / fallback / contingency plan / alternative / spare / standby / safety net / backup copy`

最重要的一點：

> **fallback ≠ alternative ≠ contingency plan**

`fallback` = 第一方案失敗後用的第二方案；  
`alternative` = 另一個正常可行選擇；  
`contingency plan` = 為可能風險預先準備的一整套應變方案。
